`MapFogSettings` 接受一个 Lua 表：`fog` 为字符串，`fogPower`、`fogOx`、`fogOy` 和 `fogDistort` 为数值。这四个数值必须有限，且落在 float 范围内。`fog` 缺失或为 nil 时默认为 `""`，数值缺失或为 nil 时默认为 `0`。地图中的其他字段一律忽略。类型无效或数值越界会报错。`fog` 为空字符串，或 `fogPower` 为 `0` 或更小时，雾效关闭。`fogPower` 和 `fogDistort` 先向下取整，再限制在 `0..100`。`fogOx` 和 `fogOy` 决定滚动速度。`applyFromMapData` 与 `applyWorldFromMapData` 共用这份配置。

### 区域可见性

对于普通有限地图，`setHideDisconnectedRegions(enabled)` 开关区域隐藏。`setVisibilityObserver(position)` 接受 `sf.Vector2i` 格子坐标，供预览指定观察位置；传入 `nil` 恢复跟随玩家。`isCellVisible(position)` 查询 tile 显示掩码，其中不可通行格保持可见。`isActorVisibleOnMap(actor)` 检查 Actor 及每个祖先的可见性标记和区域规则：可通行锚点按所属区域判断，不可通行锚点要求变换后的图像矩形覆盖可见的可通行格。`getHideDisconnectedRegions()` 是运行时查询当前开关的接口。`getVisibilityRevision()` 返回供显示与预览缓存使用的当前版本，关闭隐藏时也会跟踪地形变化。可见性查询在返回前处理待更新的变化。

地形变化后重新计算连通区域和替换源。同一区域内移动复用掩码，跨区域移动更新绘制与灯光。渲染器使用独立显示图层，保留真实 tilemap。选取规则和玩法效果见 [Global.GameMap](<../../Global APIs/GameMap.md#非连通区域隐藏>)。

## 静态预览绘制

`GlobalCore.PreviewSprite` 与 `GlobalCore.GameMapRenderer` 是仅供运行时 Lua 使用的 API（`metadata = false`），不是蓝图节点。`PreviewSprite.new(table)` 接受以下显示字段：

| 字段 | 含义与默认值 |
|---|---|
| `layer`、`texture`、`rect` | 图层名、持有的 `sf.Texture` 或 `nil`、`sf.IntRect` 源矩形。 |
| `position`、`mapPosition`、`translation` | 像素锚点、区域可见性格子坐标、像素显示偏移。 |
| `rotation`、`scale`、`origin` | 角度制旋转（默认 `0`）、缩放（默认 `{1, 1}`）、像素原点。 |
| `visible`、`parentIndex` | 自身可见性（默认 `true`）；父记录使用从零开始的先前记录下标，根使用 `-1`。 |
| `hue`、`shaderPath` | 角度制色相（默认 `0`）与片段 shader 路径（默认空）。 |

`renderer:setPreviewSprites(records)` 只允许构造时设置了 `previewOnly = true` 的渲染器调用。它持有所需显示资源，在每个配置图层内保留记录顺序。父记录必须先于子记录，非法父下标会报错且不替换已安装记录。显式安装空数组表示不绘制静态精灵；安装记录之前，渲染器保持普通 Actor 绘制契约。

`renderer:setPreviewVisibility(flags)` 要求已经安装记录，且按相同顺序为每条记录提供一个布尔值。它只更新自身可见性，有效可见性还受祖先和地图区域规则控制。`texture = nil` 不绘制图像，但保留几何信息与父节点作用。几何数据已解析为地图坐标；`parentIndex` 只控制显隐，不组合父子变换。

静态 shader 绘制支持色相叠加，提供 `texture`、`textureSize`、`textureRect` 与固定的 `time = 0`，并将精灵变换与调用者的 render states（包括世界偏移）组合。shader 加载失败时报告错误，并以洋红色绘制图像。仅供 C++ 使用的 `GameMapBase::isSpriteVisibleOnMap(position, bounds, transform)` 与实时 Actor 共用几何可见性判断，不提供 Lua 绑定。

## WorldStreamingState

`WorldRegionState` 暴露 `Unloaded`、`Reading`、`Prepared`、`Active` 和 `Dormant`。`WorldRegionDemand` 暴露 `None`、`Prepared` 和 `Active`。`WorldStreamingState` 使用从 1 开始的下标，持有 demand 队列，并负责 Camera 排序、last-used 与缓存核算、淘汰和统计。Camera 排序把 Active 区域排在前面，其次按区域中心的平方距离排序，距离相同时按 region index 决定先后。它的方法均为 `metadata = false`。Blueprint 使用带上下文的世界地图节点。

Lua 调用 `updateCameraCenter` 和 `updateDemand`，消费 `takeReadBatch` 和 `takePublishItem`，上报读取与发布的完成或取消，标记激活、停用和淘汰，并读取 `getEvictionList` 和 `getStats`。文件、builder 和 payload 仍由 Lua 持有。
