# Engine：地图与材质

材质引用使用完整的 `Data/Materials/...json` 路径。`AutoTile.fileName` 与 `Tileset.fileName` 仍使用各自 `/Game/Assets/Autotiles/...` 与 `/Game/Assets/Tilesets/...` 纹理路径。

## MapFogSettings

`Engine.MapFogSettings.new(table)` 创建地图与原生渲染器使用的强类型雾配置。构造时省略的字段保留以下默认值：

| 字段 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `enabled` | `bool` | `false` | 启用雾层。 |
| `colour` | `sf.Color` | 白色 `(255, 255, 255, 255)` | 雾颜色与 alpha。 |
| `density` | `float` | `0.5` | `[0, 1]` 内的密度；零没有可见效果。 |
| `scale` | `float` | `256` | 大地图像素单位的正数噪声尺度。 |
| `velocity` | `sf.Vector2f` | `(15, 15)` | 每秒移动的大地图像素数。 |
| `turbulence` | `float` | `0.5` | `[0, 1]` 内的噪声扭曲强度。 |
| `seed` | `int` | `0` | 有符号 32 位确定性种子。 |

数值字段必须有限。原生 Lua 构造使用 `sf.Color` 与 `sf.Vector2f` 值。序列化地图与大地图数据保存包含全部七个字段的 `fog` 对象，其中 `colour` 为四个 `[0, 255]` 整数通道，`velocity` 为两个数值的数组。地图解析器不接受未知字段或旧贴图雾格式。

```lua
local settings = Engine.MapFogSettings.new({
    enabled = true,
    colour = sf.Color.new(210, 225, 240, 255),
    density = 0.4,
    scale = 256,
    velocity = sf.Vector2f.new(15, 15),
    turbulence = 0.5,
    seed = 42
})
gameMap:setFogSettings(settings)
```

## TileLayer

直接 metadata 基类：`{ "Engine", "TileLayerGraphics" }`

Tile 图形按 32×32 格的 chunk 组织，只绘制与视图相交的 chunk。`deferred = true` 启用运行时的增量构建。

稀疏大地图流送通过 `isCellBuilt(position)`（`metadata = false`）复用 Tile 图形层的 chunk 就绪规则。

## 材质资源

公共标准材质为 `Data/Materials/Global/Standard.json`。效果示例和 `Surfaces` 预设仍分别位于 `Data/Materials` 及其 `Surfaces` 子目录。

编写用的材质是 `Data/Materials/<名称>.json` 节点图，包含 `type: "material"` 和 `version: 1`。Actor、自动图块和图层仍通过这个字符串引用它。空引用使用内置中性材质，与 `Global/Standard.json` 相互独立；非空引用无效时报告错误。导出将这些引用映射到 `Assets/Shaders/MaterialGenerated/Materials/<名称>/` 下的着色器和运行元数据，空引用则对应 `Assets/Shaders/MaterialGenerated/Builtin/Default/`。运行时加载生成文件，支持数据／着色器加密和 `Assets.ldpak`，不再读取源节点图；产物缺失、损坏或格式不受支持时会报错。辅助贴图仍使用规范的 `/Game/Assets/...` 路径，主纹理、当前帧、变换与时间由绘制对象提供。

原生 C++ 调用中，`MaterialResource::load` 加载导出的运行资源；`MaterialResource::fromData` 创建持有编辑用节点图定义的资源，供导出和预览编译使用。生成流程、组合与文件布局见[材质导出](<../../../../编辑器用户指南/材质.md#导出运行文件>)。

原生预览集成可保留 `MaterialResource::Overrides` 快照，复用已解析资源，并通过 `ScopedOverrides` 在每次请求期间激活。快照须覆盖整个作用域的生命周期，并在同一预览线程使用；文档或源资源变化时替换快照。作用域不会在请求之间持续生效。

全部材质都会导出单独使用的版本，基础材质／图层材质组合则来自已保存地图的用法及编辑器中的[额外组合](<../../../../编辑器用户指南/材质.md#材质组合>)。仅由动态构造地图或运行时更换图层材质产生的组合，需要预先在此添加；Actor／UI 切换材质和参数变化无需添加条目。运行时缺少组合会报错，游戏不会从节点图补生成程序。

| 文件部分 | 内容 |
|---|---|
| `parameters` | 参数数组，包含稳定 `id`、`type`、`default`，以及可选的 `displayName`、`group`、`min`、`max`。 |
| `graph.nodes` | 节点包含 `id`、官方 `type`、`inputs` 与 `properties`。输入是字面量，或 `{ "node": "id", "port": "输出端口" }`。 |
| `graph.output` | Surface 输出节点的 ID。 |
| `rendering.maxVertexOffset` | 局部像素坐标下的最大绝对位移 `[x, y]`，默认为 `[0, 0]`。 |
| `editor.positions` | 节点 ID 对应的画布位置，仅用于编辑。 |

参数类型包括 `bool`、`float`、`vec2`、`vec3`、`vec4`、`color` 和 `texture`。向量使用数值数组，颜色使用 `[0, 1]` 范围内的四通道数值。可选的 `displayName` 用于调整编辑器中的显示名称，不会改变参数节点和实例覆盖引用的稳定 `id`。类型不匹配、未知参数 ID 或超出声明范围的值都会报错。材质图是有类型、无环的数据流图，不含玩法执行引脚，也不接受自定义 GLSL 节点。

### Surface 输出

| 输出 | 含义与默认值 |
|---|---|
| `BaseColor` | 当前精灵采样得到的 RGB。 |
| `Alpha` | 精灵透明度，决定最终可见轮廓。 |
| `Emission` | 局部 RGB 自发光，默认为零，不照亮其他对象。 |
| `LightingWeight` | `1` 接受场景光照，`0` 不受光，中间值在两者之间混合。 |
| `LightBlock` | 每像素的阻光量，默认为 `0`；与最终 Alpha 共同决定光线穿过可见轮廓时的透光量。 |
| `ReflectionStrength` | 现有格子镜面反射的强度，默认为 `0`。 |
| `VertexOffset` | 局部二维顶点位移，默认为零。 |

未连接的输出保留对应的 Surface 输入。普通根输入来自原始精灵，不发光、不遮光、不反射，并完整接受光照。宿主颜色与展示透明度由渲染器统一应用一次。表面的光照、自发光和反射先完成计算，再参与正常透明混合，因此前景同样能够遮挡自发光表面。自发光使用 LDR，本格式不包含 HDR、Bloom、法线贴图或 PBR。

官方节点包括 Constant、Parameter、Time、LocalUV、LocalPosition、WorldPosition、FrameSize、SurfaceInput、SampleSprite、SampleTexture、标量与向量算术、Dot、Abs、Floor、Fract、Sin、Clamp、Smoothstep、Lerp、Compose、Swizzle 和 HueShift。`Parameter.properties.id` 指向暴露参数，`HueShift` 使用角度制。`SampleSprite` 输入当前帧内的 UV，输出 Color、Alpha 与 RGBA；越过帧边界的采样返回透明，不会读取其他帧。像素偏移应先除以 FrameSize，再加到 LocalUV 上。自动图块采样的是拼合后的完整格子，可以跨越内部半格接缝。

VertexOffset 的依赖分支可以使用坐标、时间、参数与数学运算，但不能采样纹理。结果受 `maxVertexOffset` 限制，可见范围剔除也包含这段声明位移。图块材质先执行，图层材质再接收其 Surface 结果；两者的顶点位移按原始坐标计算后相加。图层材质只修改明确连接的输出，不影响同层 Actor。因此 `WaterWind` 可以只改变位置，保留各图块的表面属性。

### Actor 实例参数

`Actor.material` 保存共享资源引用，`Actor.materialParameters` 保存兼容 JSON 的实例覆盖字典。更换材质会清空旧覆盖，因此应先设置路径，再设置参数。`getMaterialParameter(id)` 返回实际生效值，`setMaterialParameter(id, value)` 只改变当前 Actor，`resetMaterialParameter(id)` 恢复资源默认值。对整个属性赋值会替换覆盖集合；只修改读取出来的字典不会更新 Actor。

```lua
actor:setMaterial("Data/Materials/Frozen.json")
actor:setMaterialParameter("opacity", 0.65)
actor:setMaterialParameter("hue", 20)
actor:resetMaterialParameter("hue")
```

蓝图默认值和地图实例覆盖可以保存材质引用及参数字典。临时运行时修改不会自动进入存档，应继续使用现有显式状态记录流程。移动速度属于 Actor 玩法状态，不属于材质参数契约。

项目提供 Standard、Rainbow、Frozen、Burning、Petrify、Ghost、Poison、Crystallize、Hologram 和 WaterWind 材质。它们都是普通节点图，不是特殊 Shader 模式。标准材质与角色示例暴露 `opacity`、`hue`、`lightBlock`、`reflectionStrength` 和 `lightingWeight`。Shader 程序的生成与绑定由引擎负责，Actor 不暴露 Shader 路径或可变的 Shader 句柄。

## Tileset

`materials` 是按现有从 0 开始的图块编号索引的稀疏映射；JSON 的键使用十进制字符串。只保存非空的显式引用，缺少条目表示标准默认材质。清除材质应删除键，不补齐默认条目。编辑器按图块编号排序保存。图块数量来自图集尺寸，与映射条目数量无关；`layer:getTilesetTileCount()` 返回有效图块数量。
