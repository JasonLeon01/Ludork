# Engine：动画数据与图形

## 模块图形函数

| 名称 | 参数 | 返回 | 用途 |
|---|---|---|---|
| `BuildPixelGridVertices` | origin: sf.Vector2f; size: sf.Vector2u | sf.VertexArray | 仅供 Lua 使用的 helper，每个像素构建六个三角形顶点，不生成 Blueprint 节点。同一像素的六个顶点都使用该像素中心的纹理坐标。输入尺寸为零时返回空三角形数组，顶点数溢出时报错。 |
| `compressAnimation` | source: Engine.AnimationSourceData 或 nil; imageFormat: string = "png" | Engine.AnimationData | 压缩 `source.assets` 指定的帧图片。该函数不接受资产根参数。 |
