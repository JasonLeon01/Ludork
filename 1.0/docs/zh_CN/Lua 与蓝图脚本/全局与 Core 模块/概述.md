# 全局与 Core 模块总览

本章介绍三个原生 Lua 模块，以及默认玩法中的共享 Lua 模块。

| 模块 | 用途 |
|---|---|
| `Engine` | Actor、组件、输入、图形、数据和 UI 控件。 |
| `GlobalCore` | 场景、地图、摄像机、资源管理器和能力系统。 |
| `GlobalFunctions` | 按 `Components`、`Manager`、`NodeGraph` 和 `UI` 分组的 Lua 辅助函数。 |
| `Global.*` | Game 项目的共享 Lua 模块，如 `Global.GameMap`。 |

原生模块通过 `require("Engine")` 等名称加载；项目模块使用完整路径，如 `require("Global.GameMap")`。`GlobalFunctions.Math` 等 [Lua 节点函数库](<../节点函数/概述.md>)单独加载，不是原生 `GlobalFunctions` 根表的成员。加载顺序见 [Lua 运行时与模块](<../Lua 运行时与模块.md>)。
