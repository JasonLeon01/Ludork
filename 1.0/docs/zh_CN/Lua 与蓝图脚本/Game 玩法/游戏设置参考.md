# 游戏设置参考

**游戏配置** 修改[游戏配置文件](<../../编辑器用户指南/项目设置与资产布局.md#游戏配置>)的 `Main` 配置节中受支持的值。

## 支持的键

| 键 | 类型 | 含义 |
|---|---|---|
| `language` | 字符串 | 游戏语言表 key，见游戏本地化工作流 |
| `scale` | 浮点 | 显示缩放偏好，默认为全屏（`0`） |
| `maxrenderscale` | 浮点 | 内部渲染缩放上限，默认 `2.0`；不限（`0`）表示取消上限 |
| `lightingrenderscale` | 离散浮点 | 直接光照渲染倍率：`0.5`、`0.75` 或 `1.0`；默认 `1.0`，无效值也按 `1.0` 处理 |
| `framerate` | 整数 | 目标帧率，默认 `60`；不限（`0`）表示取消上限 |
| `antialiasinglevel` | 非负整数 | 请求的 SFML 抗锯齿等级，默认 `8` |
| `verticalsync` | 布尔 | 垂直同步 |
| `musicon`、`soundon`、`voiceon` | 布尔 | 各音频通道的启用开关 |
| `musicvolume`、`soundvolume`、`voicevolume` | 浮点 | 通道音量，限制在 0–100 |

编辑器保留未知的配置节与键。受支持字段的值无效时，相应的读取器会退回安全默认值。应当修正源值，而不要依赖回退。

`Main.proj` 保存项目与工具标志，而不是可变的游戏偏好。`Cpp` 选择原生项目行为，`ffmpeg` 选择支持视频的打包方式，`IndividualWindow` 保存编辑器首选的运行模式。`packaging.version` 和 `packaging.dev` 保存发行设置，见[发行包与开发包](<../../编辑器用户指南/运行、调试与打包.md#发行包与开发包>)。

普通保存会写入改动过的设置。新用户配置与缺失设置使用高画质（`2`、`60`、`8`、`1`）和全屏（`scale = 0`），已有值不会被覆盖。

**缩放** 在支持调整窗口大小的平台立即生效。桌面端及 HarmonyOS 自由多窗平板用正数值设置固定窗口大小，用 `0` 选择全屏；其他移动设备不显示此选项。新配置写入 `scale = 0`，缺少该键时只在内存中采用 `0`；负数和非有限值按 `1` 处理。平台差异及运行时接口见 [Display](<../全局与 Core 模块/Core Modules/GlobalCore/场景与系统.md#display>)。

`maxrenderscale` 在界面中显示为 **渲染上限**，用于限制内部画布的渲染分辨率，而不改变窗口、逻辑游戏尺寸或已配置的缩放。它在所有平台上立即生效。上限按可绘制区域的物理像素相对于逻辑游戏尺寸的倍率计算，包含 Retina 像素密度。macOS 上配置的缩放仍以 Cocoa 逻辑点控制窗口尺寸；选择不限时可按完整可绘制分辨率渲染。Config 提供 `0.5`、`0.75`、`1`、`1.5`、`2`、`3`、`4` 与不限（`0`），保留其他有限非负值，并把负数或非有限值按 `2` 处理。

**光照渲染倍率** 只调整直接光照的分辨率，从下一帧地图画面开始生效，不改变窗口或画布尺寸。低于 `1.0` 时平滑放大到显示尺寸。缺失、非有限或不支持的值按 `1.0` 处理；运行时接口见 [Graphics](<../全局与 Core 模块/Core Modules/GlobalCore/场景与系统.md#graphics>)。

**帧率** 提供 `30`、`60`、`90`、`120` 与不限（`0`）。不限会关闭主动帧率限制，同时保留 **垂直同步** 设置。不限时固定更新步长为 `1/60` 秒；帧率为正数时步长为 `1/framerate` 秒。

Config 依次列出低、中、高、超高与原画，并根据（`maxrenderscale`、`framerate`、`antialiasinglevel`、`lightingrenderscale`）确定当前的 **画质预设**：

| 档位 | 数值 |
|---|---|
| 低 | （`0.75`、`30`、`0`、`0.5`） |
| 中 | （`1`、`60`、`2`、`0.75`） |
| 高 | （`2`、`60`、`8`、`1`） |
| 超高 | （`3`、`90`、`8`、`1`） |
| 原画 | （不限（`0`）、`120`、`8`、`1`） |

只有当前组合不匹配任何档位时，列表末尾才追加并选中 **自定义**；选择自定义不会应用任何数值。数值重新匹配某个档位后，Config 会选中该档位并把自定义从列表中移除。配置中不保存档位字段，`scale` 与 `verticalsync` 不参与判定。

抗锯齿等级是请求的多重采样等级，SFML 可能创建平台所支持的最接近的上下文。`0` 是 SFML 的默认值，表示关闭抗锯齿。该值属于上下文创建参数，因此修改只会保存偏好，只有再次初始化显示之后（通常是下次启动游戏）才影响渲染。负数或超出范围的值按 SFML 默认值处理。

桌面端 Standalone 启动（包括 HarmonyOS 2in1）会按主显示器工作区过滤正数缩放预设 `1`、`1.25`、`1.5`、`1.75`、`2`、`3`、`4`；Config 每次打开时都会重新检查窗口当前所在的显示器。HarmonyOS Mobile 自由多窗模式使用显示器可用区域与 Stage 最大值中较小的一方。全屏（`0`）以及能放下的非预设值始终可选。超出上限的值改为能放下的最大预设；若没有任何预设能放下，则改为全屏。移到更大的显示器不会自动提升该值。尺寸查询失败时，选项与数值都保持不变。

## 限制

受支持的键由当前 Game 项目的读取器解释。新增项目专用键必须配套实现相应的运行时处理；只在配置文件中添加它不会产生任何行为。

可配置的 HarmonyOS Mobile 宿主会在原生宿主初始化、启用自由多窗模式，以及应用回到前台且仍处于该模式时采样最大窗口尺寸。应用持续处于前台时，把窗口移到其他显示器或改变显示器可用区域不会自动重新采样上限；下次回到前台、重新启用自由多窗模式或重新初始化宿主时会更新缩放选项所用的容量。HarmonyOS 2in1 则走普通的桌面窗口与显示器查询。
