# 敌人

创建一个物理蓝图与通用数据战斗定义可分别复用的敌人。

## 前置条件

- 有效的 Enemy 通用数据文件，以及兼容 Actor 的敌人父类。
- 新记录所引用的 Item 蓝图路径、特殊效果标识符与动画标识符都已存在。

## 步骤

1. 添加 Enemy 成员，设置战斗数值、奖励、掉落、特殊效果与动画键。
2. 创建或派生 Enemy 蓝图，并让它指向该数据成员。
3. 配置移动、碰撞与表现默认值。
4. 自定义的击败演出放在 Enemy Actor 的 `onDefeat` hook 中，或放在子类授予的 Gameplay Ability 中。Enemy 通用数据没有事件，固定结算仍会等待 `onDefeat`。

共用的战斗算法放在 Gameplay Ability、Gameplay Effect 或 Lua 模块中。

## Game 演练

`BP_Enemy_Slime.json` 继承 `Source.MapActors.Enemy`，并设置 `ID = "Slime"`。该 ID 解析 `Data/General/Enemy.json` 中的 `Slime` 成员。纹理、源矩形、material speed 等物理与表现默认值由蓝图持有，`MAXHP`、`ATK`、`DEF`、`EXP`、`GOLD`、`drops`、`special` 与 `ANIMATION_KEY` 则由通用数据成员持有。

通过[系统配置 → Gameplay](<../../../编辑器用户指南/项目设置与资产布局.md#系统配置>)设置可选的[敌人击败粉碎特效](<../资源、音频、视频与特效.md#shader雾与转场>)。

`drops` 的键填写 Item 蓝图路径，值为 `sf.Vector2i` 格偏移。掉落激活、持久化与击败结算见[敌人](<../Actor、敌人、物品与装备.md#敌人>)。

`GhostSoldier` 演示了 `special.Reborn = "Data.Blueprints.Enemies.BP_Enemy_Skeleton_01"`，在同格、同层替换被击败的敌人。结算会分配新的地图放置标签，让替代者在地图重建后仍可恢复。

## 限制

未知 ID 与缺失的引用记录都是错误。运行时不会合成替代的战斗定义。
