# 资源、音频、视频与特效

## 资源路径

持久化资源使用大小写精确的 `/Game/Assets/...` 路径，以 `/` 分隔并带扩展名。通用 Manager 要求这种完整形式；`loadCharacter("actors/Hero.png")`、`playSE("cursor.ogg")` 之类的类别辅助函数只接受类别内相对参数，并自行补上前缀。

运行时通过相同的逻辑路径读取未打包文件和 `.ldpak` 条目，音乐与视频支持流式播放和跳转。Standard 文件系统 API 和 LuaSF 文件构造函数不解析归档中的逻辑路径。

## 动画缓存

动画源数据位于 `Data/Animations`。无论 Data 是松散目录还是归档，`Engine.getAnimationCacheRoot()` 都会在 `Engine.getUserDataPath()` 下创建 `Cache/Animations`。在 Windows 上，用户数据根目录就是运行时的工作目录；其他平台使用应用的用户数据位置。

初始化会生成缺失的 `.anim.json`/`.anim.ldc` 缓存，并在源数据或引用的帧资产变化时重建，同时保留相对 `Data/Animations` 的路径。缓存可以随时丢弃，不进入模板与玩家包。源数据通过 `Engine.decodeData` 解码，缓存通过 `Engine.saveData` 写入；`.anim.ldc` 保存二进制数据，不经过中间 JSON 转换。载荷为压缩 JSON 的旧缓存须删除，由初始化重新生成。

## 音频

音乐、音效与语音在 `Main.ini` 中各有独立的开关和音量。GlobalFunctions 的 Manager 分组提供面向玩法的辅助函数。缺失的可选音效路径要显式处理。用不同拼写反复加载同一资源会让缓存失效。

玩法 Manager 与蓝图节点使用的音频效果，是由 `Source.Utils.AudioEffects` 定义的 Lua DSP 处理器。Game 提供区分大小写的 `Echo`、`Distortion`、`Underwater` 和 `BehindWall` 预设，默认值分别是 0.3 秒/0.5 衰减的 echo、2.0 drive/0.7 threshold 的 distortion、0.7 depth/0.3 bubble 的 underwater，以及 900 Hz/0.35 transmission 的 behind-wall filter。

`GlobalFunctions.Audio.SetEffect(audioType, effect)` 用 `AudioEffects.Get` 解析名称，并把得到的 attacher 分别按 `Sound`、`Voice` 或 `Music` 类别保存。metadata 把两个参数都呈现为下拉框。选择不会创建 processor，也不会修改已在播放的声源。之后创建的每个声源都会调用 attacher，由它为这个声源创建隔离的音频 Lua state 和全新的 processor。选择字面量字符串 `nil` 会清除后续播放使用的预设；其他未知名称立即报错。`Source.Utils.AudioEffects` 是唯一的预设注册表，因此改动预设注册表时也必须同步更新 `SetEffect` 的 metadata 下拉选项。效果选择不属于 `SoundFilter` 或 `MusicFilter`。

预设非空时，创建声源会在播放前记录当前播放设备的采样率。设备改道后，活动声源仍保留这些系数；要使用新的采样率，需要通过 Manager 重新发起一次播放。attacher 必须恰好安装一个非空 processor，因此选中的预设不会以 dry 方式播放。SFML 为每个声源只保存一个 processor，预设之间不会串联或混合。

热重载后需要重新发起播放，才会使用更新后的音频代码，参见 [Lua 运行时与模块](<../Lua 运行时与模块.md#lua-热更新>)。正在播放的声源与已缓冲的尾音不受影响。

`Echo` 会在流自然结束后排空已缓冲的尾音。通过 Manager 显式停止、跳过对话或关闭会丢弃剩余尾音。直接调用 `sf.SoundSource:setEffectProcessor` 属于另一套底层 API，不具备 Manager 的隔离、EOS 与取消协议。

`GlobalFunctions.Scene.ShowVoiceMessageByTag` 与 `ShowVoiceMessage` 会在对话存续期间捕获并持有本次调用实际启动的 Voice handle。对话结束时，它们的 latent 条件先停止该 handle，再由 `FinishedDialogue` 继续执行下游蓝图。因此紧随其后的 `SetEffect` 配置的是下一段 Voice。离开或销毁地图场景同样会停止当前全局 Voice。普通消息节点不会改变 Voice 播放。

## Shader、雾与转场

Actor 与图层通过官方 2D 材质系统绘制，项目通过通用节点图组合效果。导出将材质着色器和元数据写入 `Data/MaterialGenerated`。游戏加载这些文件，并根据当前实例参数执行导出的数值分析指令，不再解析节点图或拼接 GLSL；着色器仍由显卡驱动编译。生成文件缺失或无效会导致材质加载失败，因此运行或打包前需先导出。

内置天气与雾继续使用各自的跨平台 Shader 管线；加载与编译错误向外传播。进入大地图时使用当前视口预热共用渲染器，并在区域几何变化后重新预热。HarmonyOS 在首次正常绘制、渲染状态与 uniform 完整绑定后编译程序。

材质资源和生成程序可以共享，实例参数独立保存，每次绘制都会绑定当前对象的生效值。原有角色效果以 `Data/Materials` 下的普通节点图提供，色相通过 HueShift 节点与参数表达。Alpha、遮光与顶点位移使用同一张图的对应依赖分支，避免画面已经溶解而原始轮廓仍遮光。自发光在表面内合成，不自动照亮周围，也不会穿过前景。

雾由 GPU 根据大地图坐标、绝对时间和确定性种子生成。四层噪声产生疏密区域；密度控制覆盖程度，颜色 alpha 缩放透明度，不叠加均匀的底色遮罩。减小尺度会产生更小的雾团，黑雾同样保留浓淡层次。地图数据保存含 `enabled`、`colour`、`density`、`scale`、`velocity`、`turbulence`、`seed` 的对象，不再使用雾贴图。共用渲染器在材质和光照之后、前景天气和粒子之前合成雾。雾响应场景光照。每个地图会话独立持有雾状态。

雾效字段、默认值与取值范围见 [FogController](<../全局与 Core 模块/Core Modules/GlobalCore/地图与雾效.md#fogcontroller>)。

地图远景数据使用可选字符串协议。`panorama` 是规范的 `/Game/Assets/...` 路径；缺失、为 `nil` 或为空白时禁用远景。图片在保持宽高比的前提下按 Cover 缩放铺满 `GameMap.MapViewRect`，超出部分按摄像机原点在 `(mapPixels - viewPixels)` 各轴上的比例裁剪。某轴没有摄像机移动时取 `0.5`。透明图块与画布边距露出的远景只乘以环境光；点光源仍然作用于不透明图块。贴图缺失属于必需资源失败。

### 组合式大地图环境

大地图清单可以定义全局雾与全局远景，但不能定义 BGM、BGS、音频 filter 或环境光。全局雾覆盖大地图边界范围，包括空洞。子地图雾裁剪到它的摆放范围内，使用相同的大地图坐标与时间，在全局雾之后按稳定的摆放顺序合成；同样的配置在相邻区域之间保持连续。淘汰子地图会移除其区域雾，重新加载后才恢复。全局远景覆盖大地图 Camera，并按大地图尺寸计算滚动。子地图的 `panorama` 只在该子地图作为独立地图加载时生效。

BGM、BGS 与环境光跟随玩家所在的子地图。音频切换淡变 0.5 秒；淡出期间返回会恢复原声源。之后的环境光变化同样混合 0.5 秒，空洞中使用白色。大地图雾与远景在该处仍然生效。

Game 项目的高级敌人击败特效由全局类设置 `Enemy.DefeatShatterEffectEnabled` 控制，默认 `true`，且不是蓝图字段。它的 shader 把快照渲染成世界空间的逻辑像素碎片，在约 0.65 秒内从中心径向向外散开。被击败的敌人此时已经被记录并销毁，因此快照不影响通行性、碰撞或遮光。该设置为 `false`，或 `sf.Shader.isAvailable()` 返回 false 时，敌人改为立即消失。

## 视频

视频播放需要启用 FFmpeg 的项目或模板。文件放在 `Assets/Videos` 下，并以 `/Game/Assets/Videos/...` 引用。松散文件与根级 `Assets.ldpak` 中的条目遵循同一套播放与跳转规则。Android 支持 MOV、H.264/AAC、swscale 与 swresample，但不支持 network、JNI、MediaCodec 和硬件加速。构建与分发要求见 [项目模板](<../../快速入门/项目模板.md#ffmpeg-选项>)。

通过 `require("GlobalFunctions.Video")` 调用 `Video.PlayVideo(videoFileName, mute, skipable, subtitleFileName)`。可选第四个参数使用项目相对 `Data/Subtitles/...json` 路径；省略或传入空字符串时保持纯视频播放。

```lua
local Video = require("GlobalFunctions.Video")
Video.PlayVideo("/Game/Assets/Videos/intro.mp4", false, true, "Data/Subtitles/intro.json")
```

[字幕数据](<../../编辑器用户指南/视频字幕.md>) 包含 `type: "subtitle"` 和 `sections` 数组。每个片段提供以秒为单位的起止时间，以及通用字符串数组或语言到数组的字典。字典内容先取当前游戏语言，仅在该键缺失时回退 `en_GB`；已存在的空数组表示不显示字幕。字幕跟随视频时钟，使用默认字体、白字黑描边，在视口底部居中显示。

## 限制

shader 是否可用由运行时图形环境决定；编辑器预览成功并不保证目标硬件具备同等支持。

大地图光照使用大地图坐标，因此 Actor 灯光可以跨子地图边界照明或投影。Tile mask 仍裁剪到各自的摆放范围，空洞既不贡献 surface 也不贡献 blocker。固定地图光源记录及其地图管理 API 已移除；通过给 Actor 附加 `LightComponent` 创建灯光。

编辑器显示选项见 [PreviewHost：地图与世界预览](<../../PreviewHost/地图与世界预览.md>)。
