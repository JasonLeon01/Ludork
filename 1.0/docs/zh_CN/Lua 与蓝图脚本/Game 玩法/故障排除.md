# 故障排除

## 项目无法打开

检查 `Main.proj` 以及 `Data` 下每个已加载文件是否为合法 JSON。路径必须留在项目内。应恢复必需的目录，而不是把编辑器指向一个残缺的包。

## 蓝图无法保存

蓝图保存失败时，错误会指出无效的父类、循环继承、节点、连线、引脚或默认值。Script Mixin 还需要符合要求的相对路径、返回表和同名元数据文件。对应规则见 [Script Mixin 编写工作流](<../脚本 Mixin/编写工作流.md>)。

## 游戏无法启动

从控制台的第一个错误开始阅读。按需先编译，再导出；运行按此顺序检查。导出校验、插件失败和 before-Run Hook 失败都会阻止启动。检查生成的 UI 与语言文件、`Assets/Shaders/MaterialGenerated`、原生模块、[启动脚本](<../Lua 运行时与模块.md#入口与模块顺序>)、Core 模块顺序与运行时协议诊断。

## 节点缺失

确认它的 metadata 文件是纯数据、返回 `_METADATA`、把成员声明为 `type = "function"` 或 `"event"`，并且不位于 `Scripts/Mixins` 下。C++ 声明需要重新构建，让 bindgen 重新生成 metadata。

## 资产或数据引用损坏

打开引用树，找到失效的已保存键或路径，手工更新它。重命名与删除都不保证自动修复引用。

## 本地化文本缺失

语言文件中的 ID、当前语言及 `LOC` 格式必须与项目文本匹配。工作簿与导出设置见[游戏本地化工作流](<../../插件开发与安装/Official 插件/游戏本地化工作流.md>)。

## 打包后行为不同

检查包内的资产、脚本、原生模块、FFmpeg 变体、[可写的游戏配置位置](<../../编辑器用户指南/项目设置与资产布局.md#游戏配置>)，以及平台相关的路径处理。绝不要通过路径分隔符推断平台，而应使用注入的 `PLATFORM` 值。

Android 打包仅供 C++ Source 项目使用，并需要本机安装 Android Studio 及相应工具。缺少所需工具时，打包错误会列出缺失项；安装位置与版本要求见[运行、调试与打包](<../../编辑器用户指南/运行、调试与打包.md>)。

如果 Android 签名失败，检查 JKS 或 PKCS12 路径是否为绝对路径且可读、alias 是否存在、两个密码是否正确。在对话框中修正过期的已保存值，并重新输入未保存的值。失败的运行既不会发布未签名的中间产物，也不会发布不完整的已签名 APK。后续每个需要更新已安装应用的版本都必须使用同一把密钥。

## 限制

原生崩溃、绑定生成失败与插件加载失败，都需要各自开发专题中的专用诊断方法。
