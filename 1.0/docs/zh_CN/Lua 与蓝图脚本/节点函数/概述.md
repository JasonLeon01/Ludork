# 节点函数总览

本章每个页面都记录 `GlobalFunctions` 命名空间下的一个蓝图节点模块，也就是该模块以蓝图节点形式提供的功能。每个页面都在 `Metadata 来源：` 一行中标明自己的 metadata 来源，即对应模块的 `Scripts/GlobalFunctions/<Name>_meta.lua` 文件；页中的函数表列出该 metadata 所声明的内容。

## 模块

| 模块 | 职责 | 页面 |
|---|---|---|
| `GlobalFunctions.Container` | 以蓝图节点形式提供的循环结构，以及字典与列表操作。 | [Container.md](<Container.md>) |
| `GlobalFunctions.GameMap` | Actor 查找节点。 | [GameMap.md](<GameMap.md>) |
| `GlobalFunctions.Math` | 标量、向量、角度与运算符节点。 | [Math.md](<Math.md>) |
| `GlobalFunctions.Mota` | 怪物图鉴、区域与楼层传送节点。 | [Mota.md](<Mota.md>) |
| `GlobalFunctions.Movement` | 切换移动、设置移动路线与启动自动寻路的节点。 | [Movement.md](<Movement.md>) |
| `GlobalFunctions.Player` | 读取与修改 Player 状态、物品栏和装备的节点。 | [Player.md](<Player.md>) |
| `GlobalFunctions.Save` | 存档、读档与存档路径节点。 | [Save.md](<Save.md>) |
| `GlobalFunctions.Scene` | 地图传送、对话、窗口、摄像机、地形与持久化记录节点。 | [Scene.md](<Scene.md>) |
| `GlobalFunctions.Gameplay` | 读取玩法事件上下文，以及施加属性、State 与事件的节点。 | [Gameplay.md](<Gameplay.md>) |

## 查找节点

先从蓝图中的节点还原它的 metadata 标识符，再用上表的职责说明选定模块页面，查阅该标识符所在的行。

节点的显示标签由编辑器根据标识符推导：按 camel case、Pascal case 与下划线边界拆分，再把每个显示单词的首字母大写，因此 `GetActorByTag` 这样的 `Name` 在蓝图中显示为按单词分隔、首字母大写的形式。`ADD`、`IADD` 等运算符节点是例外：它们可以使用直接字面量 `Meta.DisplayName`，这正是 `+` 节点对应 `Math.ADD`、`+=` 节点对应 `Math.IADD` 的原因。参见[编辑器名称与 decorator](<../蓝图脚本/Metadata 结构与 Decorator.md#编辑器名称与-decorator>)。

这些页面的函数表使用以下列：

- `Name` —— 函数或事件的 metadata 标识符。
- `Kind` —— 声明的 metadata `type`，例如 `function` 或 `event`。少数页面（包括 [GlobalFunctions.Gameplay](<Gameplay.md>)）省略该列。
- `Parameters` —— 按顺序排列的输入引脚，形式为 `name: type`；metadata 声明默认值时追加 `= value`，节点没有参数时为 `—`。
- `Returns` —— 同样形式的输出引脚；声明没有输出时为 `—`。
- `Execution and metadata` —— 从 metadata 复制的 `Pure`、`ExecSplit`、`Latent`、`LatentStates`、`LoopNode` 与 `Meta` 条目。[执行声明](<../蓝图脚本/Metadata 结构与 Decorator.md#执行声明>)说明了每一项向蓝图运行时作出的承诺。

部分页面会在表格之后补充正文，用于说明列本身无法表达的节点行为。

## 与 GlobalFunctions Lua API 的关系

这些模块不是原生的 `GlobalFunctions` Lua 根模块。该根模块通过 `Components`、`Manager`、`NodeGraph` 与 `UI` 四个分组 table 暴露原生自由函数，而 `Scripts/GlobalFunctions_meta.lua` 为空，因此这些函数属于 Lua API，而不是蓝图节点。分组函数只出现在各自的分组 table 中。参见 [GlobalFunctions Lua API](<../全局与 Core 模块/Core Modules/GlobalFunctions.md>)。

本页记录的模块是 `Scripts/GlobalFunctions` 中的 Lua 蓝图函数库。它们以独立模块加载，例如 `require("GlobalFunctions.Math")`，不会加入这个原生根表。模块加载顺序以及适用于 `Scripts/GlobalFunctions` 的 `require` 限制，见 [Lua 运行时与模块](<../Lua 运行时与模块.md>)。
