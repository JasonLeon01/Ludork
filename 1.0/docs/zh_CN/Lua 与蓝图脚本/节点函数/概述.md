# 节点函数总览

本章列出 `GlobalFunctions` 命名空间下的 Lua 蓝图节点及其输入、输出和执行规则。

## 查找节点

按上表的功能找到模块，再按节点标识符查阅对应行。例如，`+` 节点对应 `Math.ADD`。

这些页面的函数表使用以下列：

- `Name` —— 函数或事件的 metadata 标识符。
- `Kind` —— 声明的 metadata `type`，例如 `function` 或 `event`。
- `Parameters` —— 按顺序排列的输入引脚，形式为 `name: type`；metadata 声明默认值时追加 `= value`，节点没有参数时为 `—`。
- `Returns` —— 同样形式的输出引脚；声明没有输出时为 `—`。
- `Execution and metadata` ——  `Pure`、`ExecSplit`、`Latent`、`LatentStates`、`LoopNode` 与 `Meta` 条目。[执行声明](<../蓝图脚本/Metadata 结构与 Decorator.md#执行声明>)介绍这些执行规则。

## 与 GlobalFunctions Lua API 的关系

这些模块不是原生的 `GlobalFunctions` Lua 根模块。该根模块通过 `Components`、`Manager`、`NodeGraph` 与 `UI` 四个分组表暴露原生自由函数，而 `Scripts/GlobalFunctions_meta.lua` 为空，因此这些函数属于 Lua API，而不是蓝图节点。分组函数只出现在各自的分组表中。参见 [GlobalFunctions Lua API](<../全局与 Core 模块/Core Modules/GlobalFunctions.md>)。

本页记录的模块是 `Scripts/GlobalFunctions` 中的 Lua 蓝图函数库。它们以独立模块加载，例如 `require("GlobalFunctions.Math")`，不会加入这个原生根表。模块加载顺序以及适用于 `Scripts/GlobalFunctions` 的 `require` 限制，见 [Lua 运行时与模块](<../Lua 运行时与模块.md>)。
