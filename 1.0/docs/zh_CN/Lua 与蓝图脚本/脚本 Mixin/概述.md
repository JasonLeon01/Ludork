# 脚本 Mixin 总览

Script Mixin 把一张 Lua 行为 table 直接挂到蓝图类上：蓝图保留由编辑器编写的默认值与继承关系，事件逻辑则留在 Lua 中。运行时把选中的模块按 `Mixins.<点分路径>` 加载，并将其中的函数变成生成蓝图类上的方法。mixin 源码位于 `Scripts/Mixins` 下，每个运行时文件配一个同名 `_meta.lua`；`Scripts/stub/Mixins` 下有对应的 `.d.lua` 声明，供 Lua 工具使用。

## 推荐阅读顺序

写第一个 mixin 时：

1. 先读 [Script Mixin 编写工作流](<编写工作流.md>)，在 `Scripts/Mixins` 下建立文件对并挂到蓝图上。
2. 再读 [Script Mixin Metadata](<Metadata.md>)，声明蓝图实例暴露的可编辑字段。
3. 写方法之前读 [Script Mixin 运行时契约](<运行时契约.md>)，让返回的 table 符合保留名称与 `super()` 规则。
4. 把结果与 [Game Script Mixins](<Game Mixins.md>) 对照。
5. 最后按 [Script Mixin 校验与打包](<校验与打包.md>) 校验，然后在地图上放置实例，在运行中的游戏里验证行为。

校验失败时，从 [Script Mixin 校验与打包](<校验与打包.md>) 入手。该页按编辑器报告的顺序说明路径、模式继承链与同名 metadata 检查，并要求先解决第一个报出的路径或 metadata 错误，再看下游的字段错误。报出的是 metadata 规则时，继续查 [Script Mixin Metadata](<Metadata.md>)。
