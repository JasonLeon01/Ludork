# Script Mixin 编写工作流

Script Mixin 把一张 Lua 行为 table 直接挂到蓝图类上。蓝图需要由编辑器编写默认值与继承关系，而事件逻辑用 Lua 表达比用节点图更清楚时，就用 Script Mixin。

同一条蓝图继承链中，图模式与 Script Mixin 模式互斥。脚本来自链上第一个 Script Mixin 蓝图。后代可以继承这个脚本，也可以提供另一个兼容的 mixin，但不能把继承链切回图模式。

Script Mixin 蓝图的事件来自 Lua，因此可以省略 `graph`。若保存了 `graph` 字段，该字段仍必须是结构合法的 graph object，运行时只是不执行它。图模式蓝图则必须始终保存 graph object。

## 目标

把新的 Lua 行为挂到编辑器编写的蓝图上。

## 前置条件

- 父蓝图提供 mixin 用到的全部生命周期回调与原生成员。
- 运行时文件、metadata 类型与暴露字段都有稳定名称。
- 同一条继承链中没有图模式的祖先或后代。

## 步骤

1. 创建或打开一个蓝图，其父类提供 mixin 用到的生命周期与原生成员。
2. 在继承链的第一个蓝图上启用 **Script Mixin**。
3. **Script Path** 为空且可编辑时，点击 **...** 前面的 **+**。在 `Scripts/Mixins` 下选择目录并输入文件名，例如 `Doors/KeyDoor.lua`。未输入扩展名时，编辑器会补上 `.lua`。
4. 保存后生成脚本及同名 `_meta.lua`，编辑器自动选中新脚本并隐藏 **+**。挂接已有脚本时使用 **...**。保存的路径相对于 `Scripts/Mixins`。
5. 编辑生成的事件方法，并按需添加可编辑默认值和 metadata 字段。修改文件后刷新或重新打开蓝图，然后校验并保存。
6. 在地图上放置实例，在运行中的游戏里验证行为。

去掉 `.lua` 后的脚本名就是返回的 table 名。名称必须以英文字母或下划线开头，仅包含英文字母、数字和下划线，且不能是 Lua 关键字。创建时不会覆盖已有脚本或 metadata 文件。取消不改变脚本选择；撤销和重做只恢复选择，不删除已创建文件。继承得到的脚本路径非空时，也不显示 **+**。

模板包含当前 Actor 解析类型的全部 Event，包括继承事件，并采用最派生类型的签名。各方法通过 `super()` 将参数转发给父类事件，有返回值时一并返回。不会生成普通方法或 `init`。配套 metadata 仅声明同名类型和空的 `attrs` 表，可按需添加可编辑字段。

## 文件对

```text
Scripts/
└── Mixins/
    └── Doors/
        ├── KeyDoor.lua
        └── KeyDoor_meta.lua
```

metadata 文件是编辑器声明，不提供运行时方法。运行时文件才是行为的来源，且不得加载配套的 metadata 文件。

生成的空 metadata 已可直接加载：

```lua
local _METADATA = {
    KeyDoor = {
        attrs = {}
    }
}

return _METADATA
```

也可以手动创建这一文件对：脚本返回普通定义 table，配套文件返回一个同名 `_METADATA` 类型。

## 继承脚本

子蓝图可以省略 `scriptPath`，直接继承当前的 mixin。填写另一个路径时，兼容的子 mixin 会叠加到继承成员之上。替换脚本前，先确认字段与函数的种类仍然兼容，并清理已经不属于解析后类的过期已存 attribute。

## 限制

Script Mixin 不能声明 `init`、metadata 基类，也不能声明第二个 metadata 类型。
