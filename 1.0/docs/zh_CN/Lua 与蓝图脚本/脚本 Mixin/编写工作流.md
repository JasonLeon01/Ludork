# Script Mixin 编写工作流

Script Mixin 使用 Lua 表定义蓝图行为。创建方法如下。

同一条蓝图继承链中，图模式与 Script Mixin 模式互斥。脚本来自链上第一个 Script Mixin 蓝图。后代可以继承这个脚本，也可以提供另一个兼容的 mixin，但不能把继承链切回图模式。

Script Mixin 蓝图的事件来自 Lua，因此可以省略 `graph`。若保存了 `graph` 字段，该字段仍必须是结构合法的 `graph` 对象，运行时只是不执行它。图模式蓝图则必须始终保存 `graph` 对象。

## 步骤

1. 创建或打开一个蓝图，其父类提供 mixin 用到的生命周期与原生成员。
2. 在继承链的第一个蓝图上启用 **Script Mixin**。
3. **Script Path** 为空且可编辑时，点击 **...** 前面的 **+**。在 `Scripts/Mixins` 下选择目录并输入文件名，例如 `Doors/KeyDoor.lua`。未输入扩展名时，编辑器会补上 `.lua`。
4. 保存后生成脚本及同名 `_meta.lua`，编辑器自动选中新脚本并隐藏 **+**。挂接已有脚本时使用 **...**。保存的路径相对于 `Scripts/Mixins`。
5. 编辑生成的事件方法，并按需添加可编辑默认值和 metadata 字段。修改文件后刷新或重新打开蓝图，然后保存。

脚本名必须以 ASCII 字母或下划线开头，仅包含 ASCII 字母、数字和下划线，且不能是 Lua 关键字。创建时不会覆盖已有文件。撤销和重做只恢复脚本选择，不删除已创建的文件。

模板包含当前 Actor 类型及其继承链声明的全部事件，并采用最派生类型的签名。各方法通过 `super()` 将参数转发给父类事件，有返回值时一并返回。不会生成普通方法或 `init`。配套 metadata 仅声明同名类型和空的 `attrs` 表，可按需添加可编辑字段。

## 脚本与元数据

`scriptPath` 是相对于 `Scripts/Mixins` 的已有 `.lua` 文件路径，使用正斜杠。路径不能包含空段、`.`、`..`、驱动器前缀、绝对根或 `_meta.lua` 后缀。继承方式见[继承脚本](<#继承脚本>)。

```text
Scripts/
└── Mixins/
    └── Doors/
        ├── KeyDoor.lua
        └── KeyDoor_meta.lua
```

metadata 文件是编辑器声明，不提供运行时方法。运行时文件才是行为的来源，且不得加载配套的 metadata 文件。

也可参照[运行时表规则](<运行时契约.md#表的规则>)与 [metadata 示例](<Metadata.md>)手动创建文件对。空的 `attrs` 表同样有效。

## 继承脚本

子蓝图可以省略 `scriptPath`，直接继承当前的 mixin。填写另一个路径时，兼容的子 mixin 会叠加到继承成员之上。替换脚本前，先确认字段与函数的种类仍然兼容，并清理已保存但不再属于当前类的属性。
