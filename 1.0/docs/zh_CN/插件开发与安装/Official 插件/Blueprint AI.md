# Official Blueprint AI

配置官方 Blueprint AI 插件，围绕一个蓝图讨论改动，并在应用前审阅修改提案。

插件 ID 为 `Ludork.OfficialBlueprintAI`，仓库源码位于 `Plugins/OfficialBlueprintAI`。通过 **游戏 → Blueprint AI** 打开插件。

## 工作流

1. 按[安装与管理插件](<../安装与管理插件.md#发行版官方插件>)安装插件。
2. 打开项目，选择 **游戏 → Blueprint AI**。
3. 在 **Blueprint AI 设置** 中配置服务提供方、模型、接口地址与密钥。
4. 为一个已有蓝图新建会话，检查暂存的提案与生成的差异。
5. 只有校验成功后才能选择 **应用**；改动准备写入磁盘时，再执行普通的项目保存命令。

## 本地数据

设置与会话历史存放在全局插件根目录下的 `.data/Ludork.OfficialBlueprintAI` 中。卸载插件会保留这些数据，具体路径和移除方式见[数据与卸载](<../安装与管理插件.md#数据与卸载>)。

## 范围与权限

每个会话绑定一个项目和一个已有蓝图。助手可以查看其他蓝图、Lua metadata 以及白名单内的 Lua/C/C++ 源码文件，以理解可用 API，也可以搜索和读取官方引擎文档。它不能创建、重命名或删除蓝图，不能一次修改多个蓝图，不能编写源码，不能运行 shell，也不能启动进程。

模型只能暂存一份蓝图提案。编辑器校验候选内容并显示生成的差异。用户选择 **应用** 之前不会有任何改动。应用时会重新读取编辑器的工作副本，并比较当前版本与提案所依据的版本。应用成功只产生一个普通 Undo 步骤，项目标记为尚未保存，并刷新该蓝图所有已打开的编辑器。只有执行普通的项目保存操作，蓝图才会写入磁盘。

插件是进程内的可信代码，不是操作系统沙箱。上述限制由官方助手向模型开放的操作及会话和应用接口共同约束。

## 服务提供方与凭据

在 Blueprint AI 窗口中打开 **Blueprint AI 设置**，选择服务提供方、模型与接口地址。OpenAI 使用 Responses API。DeepSeek、Google OpenAI-compatible 与 Custom 配置使用兼容 OpenAI 的 Chat 接口。模型与接口地址字段始终可编辑，因此不必为每次模型发布更新插件。

接口地址必须是绝对 HTTPS URL，不得包含凭据、查询参数或片段。只有本地开发使用的回环地址可以使用 HTTP。

API 密钥使用[宿主凭据存储](<../Avalonia UI、密钥与本地化.md#保存密钥>)，不会写入 `settings.json`。设置窗口把已保存的密钥 显示为前三个字符、一段固定掩码和最后三个字符。较短的密钥 完全隐藏。只有输入新值或明确选择移除时，凭据才会变化。服务可用性由提供方决定。

## 会话历史

插件数据目录下的本地索引与只追加 JSONL 记录是会话历史的权威数据。它们保存消息、模型快照、精简的工具活动与提案决定，从不保存 API 密钥，也不保存完整的源码读取内容。

OpenAI Responses 请求使用 `store:false`，插件不依赖 提供方的的会话存储。会话较长时，下一次请求仅携带会话摘要和最近的消息。这种请求上下文压缩不会删除或替换完整的本地历史。

未完成的请求会被记录为 interrupted。它已完成的本地记录在重启后仍可查看，但进行中的请求不会自动恢复。

## 项目源码读取

项目搜索与文件读取只接受项目相对路径，且这些路径必须位于所配置的运行时与 API 源码根目录之下，扩展名也必须在支持列表内。构建输出、日志、版本控制数据、INI/plist 配置文件、插件数据、凭据以及项目之外的路径都会被拒绝。从目标到项目根目录的路径中，符号链接、断链与重解析点都会被拒绝。读取或搜索遇到文件系统错误时会返回工具错误。文件内容按数据处理，不能当作扩大助手权限的指令。

## 官方文档

助手可以搜索和阅读与当前编辑器主、次版本号及语言匹配的官方文档。例如，编辑器 `1.0.7` 使用 `1.0` 文档。结果附带原文页面链接。

对应文档不可用时，助手会报告问题，不会改用其他版本或语言。具体节点、类型、序列化名称和引脚仍以当前项目的 API 清单与 metadata 为准。公开的文档查询方法见[注册点与 Hook 参考](<../注册点与 Hook 参考.md#蓝图助手>)。

## 故障排除

- **游戏菜单中没有 Blueprint AI：** 按[安装与管理插件](<../安装与管理插件.md#发行版官方插件>)完成安装并重启，在**插件 → 插件管理**中检查注册或加载诊断。
- **没有项目或蓝图可用：** 先打开项目。项目窗口之外不提供宿主桥。项目还必须至少包含一个已有蓝图。打开插件不会自动选择目标，只有选择 **新会话** 后才会出现目标选择器。
- **目标被重命名或删除：** 旧会话仍可读取，但目标无法静默切换。为已有蓝图新建会话。
- **API 密钥 缺失或服务器返回 401：** 在设置中更换密钥，并确认它属于所选服务提供方或配置。同时检查接口地址和 OpenAI 组织、项目设置。界面只显示掩码值，从不显示完整的已存密钥。
- **连接或接口地址错误：** 使用不含凭据、查询参数或片段的绝对 HTTPS 基础地址。检查 DNS、代理、防火墙与 TLS 设置。HTTP 仅用于本地开发的回环地址。
- **应用时报告版本冲突：** 生成提案后，蓝图又发生了变化，编辑器会拒绝覆盖。放弃该提案，检查当前蓝图，然后新建会话或重新发起请求。
- **历史显示 interrupted：** 编辑器、窗口或请求在完成前被停止。本地历史仍然是权威数据。准备好后发送新请求，上一次请求不会自动恢复。
