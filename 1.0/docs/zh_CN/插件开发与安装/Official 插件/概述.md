# 官方插件总览

Ludork 随编辑器提供四个官方 C# 插件：Official Locale Tools、Official Random Map、Official Blueprint AI 和 Official Resource Cleanup。开发插件时，也可以参考它们使用公开插件 API 的方式。

## 官方插件

| 插件 | 作用 |
|---|---|
| [Official Locale Tools](<Locale Tools.md>) | 通过 **数据库** 菜单命令打开项目的 `Data/Locale/Locale.xlsx` 工作簿，为 `{ID}` 字段提供编辑器文本提示，通过 before-Export hook 为每种语言写出一个 Lua 目录文件，并用独立的 before-Pack hook 排除创作工作簿。 |
| [Official Random Map](<Random Map.md>) | 提供一条地图项右键菜单命令，打开插件自有的 Avalonia 窗口，读取不可变的地图与图块集快照，并在 revision 保护下替换单个图层。 |
| [Official Blueprint AI](<Blueprint AI.md>) | 暴露 **游戏 → Blueprint AI**：配置 provider、模型、endpoint 与密钥，围绕一个已存在的 Blueprint 进行会话，并把校验通过的提案连同生成的 diff 作为一次 Undo 步骤应用。插件 ID 为 `Ludork.OfficialBlueprintAI`。 |
| [Official Resource Cleanup](<Resource Cleanup.md>) | 打开 **插件 → 资源清理**，扫描找不到静态引用的项目资源，用保留清单保护通过动态路径加载的资源，并把确认后的候选移到操作系统回收站或垃圾篓。 |

四者作为同一组官方插件安装在 `~/Ludork/Plugins`，注册记录保存在 `~/Ludork/plugins.json`。Windows MSI 与 EXE 默认安装，也可以跳过；macOS 用户需运行 DMG 中的 **Install Official Plugins**。从仓库运行时，还会扫描检出目录中已注册的源码，并优先于用户目录中的同 ID 副本。便携包中的插件载荷需要显式安装；启动编辑器不会复制或替换已安装的插件。

[游戏本地化工作流](<游戏本地化工作流.md>) 是本组的第五页。它不是独立插件，而是 Official Locale Tools 的编写任务页，覆盖工作簿、导出与 `{ID}` 字符串的运行时解析。

## 安装与管理

安装命令、跳过选项、重启要求、插件状态和数据保留规则见[安装与管理插件](<../安装与管理插件.md>)。所有平台的官方插件安装都会替换现有的全部全局与项目插件、注册记录及其数据；继续之前请关闭 Ludork，并备份需要保留的内容。
