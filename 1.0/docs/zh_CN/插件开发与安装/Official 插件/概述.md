# 官方插件总览

Ludork 随编辑器提供五个官方 C# 插件：Official Locale Tools、Official Random Map、Official Mota Map Fill、Official Blueprint AI 和 Official Resource Cleanup。开发插件时，也可以参考它们使用公开插件 API 的方式。

## 官方插件

| 插件 | 作用 |
|---|---|
| [Official Locale Tools](<Locale Tools.md>) | 打开翻译工作簿，提供文本提示并导出游戏语言表。 |
| [Official Random Map](<Random Map.md>) | 生成地图区域，并通过版本检查保存单个图层。 |
| [Official Mota Map Fill](<Mota Map Fill.md>) | 根据存档玩家的战斗伤害，在已有地图范围内填充门、怪物和奖励。 |
| [Official Blueprint AI](<Blueprint AI.md>) | 围绕一个已有蓝图讨论修改，将校验并审阅后的提案作为一次撤销步骤应用。 |
| [Official Resource Cleanup](<Resource Cleanup.md>) | 查找无引用资源候选，保护保留清单中的路径，并回收确认后的文件。 |

[游戏本地化工作流](<游戏本地化工作流.md>)介绍如何用 Official Locale Tools 编写工作簿、导出并在运行时解析 `{ID}`。

## 安装与管理

安装命令、跳过选项、重启要求、插件状态和数据保留规则见[安装与管理插件](<../安装与管理插件.md>)。所有平台的官方插件安装都会替换现有的全部全局与项目插件、注册记录及其数据；继续之前请关闭 Ludork，并备份需要保留的内容。
