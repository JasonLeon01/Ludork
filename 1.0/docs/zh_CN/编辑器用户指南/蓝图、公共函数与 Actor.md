# 蓝图、公共函数与 Actor

蓝图是 `Data/Blueprints` 下的 JSON 类定义。它选择一个原生或 Lua 父类，保存可编辑属性；处于图模式时还包含事件图。地图上放置的 Actor 实例引用这些类。

## 创建蓝图

使用 **游戏 → 新建蓝图**，或文件浏览器中的相应命令。选择一个最终继承 `BPBase` 的父类，再选择 `Data/Blueprints` 下的路径。编辑器沿继承链解析父类默认值与支持的事件。新建图模式蓝图时，每个继承事件默认连接为 `Event → Parent`，同时连接对应的事件参数。

蓝图键是相对 `Data/Blueprints` 的路径，保留大小写，使用 `/` 分隔且不含 `.json` 扩展名，例如 `Actors/Guard`；对应的类引用是 `Data.Blueprints.Actors.Guard`。键输入允许可选的 `.json` 扩展名，并统一处理反斜杠和首尾空白。完整类引用中的每个点都分隔一个模块段：`Data.Blueprints.Actors.json` 对应键 `Actors/json`。

## 类值与实例值

类属性为所有实例提供默认值，地图上的 Actor 可以覆盖其中单个值。组件由 metadata 声明，以结构化字段呈现。被 `InvalidVars` 隐藏的字段不算普通可编辑属性。

蓝图编辑器沿完整继承链解析变量与组件声明，子类显式设置的值优先于继承默认值。可用组件、添加与编辑流程以及实例覆盖见 [Actor 组件](<Actor 组件/概述.md>)。

在蓝图编辑器与 **角色信息** 中，普通变量按灰色虚线框分组，排列在组件列表下方。每个框标明首次声明这些字段的类，把鼠标停在灰色标题上可查看完整类引用。继承来的字段只出现在它最初所在的分组里，即使子类覆盖了字段值也不变。Script Mixin 带来的字段与蓝图自定义字段，归到首次声明它们的那个 Script Mixin 或蓝图名下。

蓝图的 `ID` 选中通用数据成员后，`attributes` 会以只读方式显示该成员的属性。需要修改时，请到通用数据中编辑。

### 添加带类型的属性

使用 **添加属性** 输入名称、选择类型并设置初始值。选择 `enum` 时，通过 **kind** 选择现有的 `Enums.*` 模块，再选择一个键作为值；列表元素和字典值也支持枚举。文件字段还可通过基础目录限定资源选择范围。

新增字段将声明保存到 `attrDefs`，初始值保存到 `attrs`。名称若已属于继承字段且尚无本地值，对话框会固定为该声明的类型，只添加 `attrs` 覆盖。子蓝图继承类型与默认值，不能重复声明继承字段。删除继承字段的覆盖值会恢复继承默认值；删除当前蓝图新增的字段会同时删除声明与本地值，派生类或地图 Actor 覆盖仍依赖该字段时会拒绝删除。

每个保存的属性都需要在 metadata、当前启用的 Script Mixin 或继承/本地 `attrDefs` 中声明。声明无效时，蓝图无法加载或保存，错误会指出蓝图和属性名称。更换父类或删除字段时，不能让派生蓝图或地图实例留下不兼容的覆盖值。**保存无效蓝图**仅允许保留未完成的图，不能跳过属性错误。JSON 格式见[蓝图属性声明](<../Lua 与蓝图脚本/蓝图脚本/Metadata 结构与 Decorator.md#蓝图属性声明>)。

## Actor 库与角色信息

**Actor 库**以图标或列表显示 Actor 蓝图。选择条目用于放置，双击打开蓝图。外观检查见 [Actor 预览](<../PreviewHost/UI、Actor、粒子与字幕预览.md#actor-预览>)。

可按顶层文件夹和**全部**、**收藏**或**最近使用**筛选，最近使用保留最近选择或放置的 20 个 Actor。搜索忽略大小写，按名称或蓝图路径匹配全部 Actor；搜索期间禁用类别与范围筛选，清空后恢复。

右键条目可打开或定位蓝图、切换收藏状态，或从最近使用中移除。收藏保存在 `Main.proj` 的 `editor.actorFavorites` 中，跟随文件移动和重命名，蓝图删除后自动移除。

在角色模式下，右键地图上的 Actor 并选择**定位到蓝图**，即可切换到文件浏览器并选中对应的蓝图文件。右键空白处，或 Actor 没有对应的项目蓝图时，该操作禁用。

选中地图上的 Actor 后，**角色信息** 显示它的蓝图引用以及 **打开** 和 **定位** 操作、网格位置 X/Y、tag 和公开的类字段。持续的聚焦编辑中，位置与文本的改动合并为一步撤销。覆盖过的字段旁有重置按钮，用于删除该实例的这项覆盖；**全部重置** 会删除该实例的全部类字段覆盖，重新显示继承自蓝图的默认值。Actor 所在图层被隐藏时，**角色信息** 仍可用于查看和跳转蓝图，但 tag、位置、重置操作与类字段都变为只读。

放置和删除 Actor 实例可以在所属地图文档中撤销；删除蓝图文件本身立即生效且无法撤销。如果先删除实例并保存，再删除它使用的蓝图，那么蓝图缺失期间不能通过撤销恢复该实例。蓝图字段变化，包括撤销和重做，都会按当前继承的默认值刷新 Actor 外观。

## 图模式

启用 **Script Mixin** 会隐藏右侧整个图与预览区域，变量区填满可用宽度；停用后立即恢复该区域和原先的分栏宽度。继承模式、撤销/重做和重新加载都会保持同样的布局，已有的图数据继续保留。

每张图都有一个红色 **事件** 入口，将执行输出连接到起始节点后才会执行。未连接的入口呈半透明并显示提示；蓝图会尝试沿继承链调用实现，公共函数与通用数据图则不执行。事件参数与 Parent 调用规则见[执行流、事件与变量](<../Lua 与蓝图脚本/蓝图脚本/执行流、事件与变量.md#事件>)。

通过 **新增事件** 创建本地图。名称输入框提供尚无本地图的继承事件供选择；已有本地图即使为空也不能重复新增。父类链存在同名事件时，新图默认包含棕色 **Parent: 事件名** 节点，并连接入口执行输出及对应参数。整个新增操作可一步撤销。仅打开继承事件页签不会初始化覆盖图，也不会修改已保存的数据。

Parent 节点只在图模式的类蓝图中提供，可从节点选择器添加，也可像其他节点一样移动、复制或删除。右键节点可断开所有输入或输出、复制或删除；右键空白处可添加节点、粘贴或整理图。

右键可编辑节点，选择 **转换为普通输入框**，即可把该节点全部可编辑参数控件替换为文本框；已连接输入沿用原有显示方式与引脚类型。选择 **恢复类型输入框** 可切回按类型显示的控件。蓝图、公共函数和通用数据图均支持此操作。

普通输入框仍按参数声明类型转换数值。字符串和文件值原样保留文本；数字和布尔值转换为对应字面量；容器、向量及复合值使用原有 JSON 结构，包括联合类型的 `$type`/`$value`。对象与函数输入保留原有表达式语义，不会给数字等字面量参数增加表达式能力。存储结构参见[Metadata 结构与 Decorator](<../Lua 与蓝图脚本/蓝图脚本/Metadata 结构与 Decorator.md>)。

无效文本作为未保存草稿保留在输入框中并显示错误，不会替换最后一个有效参数值。恢复类型输入框或保存前必须修正草稿；**保存无效蓝图** 也不能绕过草稿错误。保存提示会指出图和参数。输入模式与草稿只在当前编辑窗口内保留，切换图与刷新控件时不丢失，关闭窗口后清除；它们不会写入项目或随节点复制。新建和复制的节点默认使用类型输入框。

新建、粘贴和复制的节点放在鼠标位置；鼠标位于图外时，放在当前视口中心。复制一组选中节点时，会保留它们的相对布局和内部连接。

Windows 上的主修饰键是 `Ctrl`，macOS 上是 `Command`。

| 快捷键 | 操作 |
|---|---|
| `Ctrl/Command+N` | 在鼠标位置打开节点选择器 |
| `Ctrl/Command+A` | 选中当前图中全部可编辑节点 |
| `Ctrl/Command+C` | 复制选中节点及其内部连线 |
| `Ctrl/Command+V` | 在鼠标位置粘贴 |
| `Ctrl/Command+D` | 在鼠标位置重复选区 |
| `方向键` | 把选中的可编辑节点移动 1 个图单位 |
| `Delete` | 删除选中的可编辑节点 |
| 空白处 `Ctrl+拖拽` | 框选节点；拖拽划定范围，松开后选中与选框相交的节点 |

自带入口是自动定位的虚拟节点，不参与全选、手动移动、重复和删除；Parent 调用节点仍可编辑。参数编辑器或其他输入控件获得焦点时，图快捷键不会取代它们的键盘输入；只读图会禁用一切产生修改的快捷键。

通用数据成员图使用类型中声明的事件列表，不包含类属性，也不能使用 latent 节点。运行规则见[通用数据与文本配置](<通用数据与文本配置.md>)。

## 继承

子蓝图继承字段与行为。改动已保存的父类路径会连带改变继承字段、事件和兼容的组件数据，务必谨慎。同一条蓝图继承链必须自始至终使用图模式或 Script Mixin 模式，参见 [Script Mixin 编写工作流](<../Lua 与蓝图脚本/脚本 Mixin/编写工作流.md>)。
