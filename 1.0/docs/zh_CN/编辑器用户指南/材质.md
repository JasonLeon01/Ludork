# 材质

2D 材质用于控制精灵颜色、透明度、局部自发光、受光程度、遮光、反射强度和顶点位移。Actor、CharacterView、图块、自动图块及图块图层通过路径引用 `Data/Materials` 下的材质资源。空引用使用内置默认材质：原始纹理正常受光，没有自发光、反射、遮光或位移。

标准材质位于 `Data/Materials/Global/Standard.json`。`Global` 目录用于标识这份公共标准资源；效果示例和 `Surfaces` 表面预设仍放在该目录之外。

## 创建与使用

在项目文件浏览器或文件菜单中选择**新建材质**，将文件放在 `Data/Materials` 下；双击已有材质即可打开。Actor 的 `material` 为空时也可从属性旁创建材质，已有引用旁的打开操作可直接打开资源。材质属于项目资源，可由多个实例共用。

编辑器默认打开**预览**页。左侧常驻参数列表，下方显示选中参数的详情；右侧包含**预览**和**节点图**两个页签，可拖动分隔条调整各区域大小。切换页签会保留选择、画布缩放与位置、预览设置及播放时间。修改参数默认值会影响所有未覆盖该参数的使用者。保存、撤销和重做使用常规快捷键；编辑和重命名遵循受管理文档流程。能识别的材质与纹理引用会参与引用查看、重命名重写和删除检查，脚本中动态拼接的路径仍须手动维护。

在 `material` 中选择完整的 `Data/Materials/...json` 路径。Actor 和 CharacterView 用 `materialParameters` 保存实例覆盖：勾选参数后可单独设置，取消勾选则使用资源默认值。更换材质会在同一次编辑中清空旧覆盖。子蓝图改用另一材质时会写入显式的空覆盖字典，避免继承前一材质的参数；重置整个实例仍遵循蓝图原有的继承规则。

图块集只在稀疏的 `materials` 对象中保存已指定的材质，键是从零开始的图块索引，例如 `{"7":"Data/Materials/Water.json"}`。缺少条目表示默认材质，清除选择会删除对应键。自动图块保存单个 `material` 引用。图块图层先执行图块或自动图块材质，再在所得表面上执行图层材质；同层 Actor 使用自身材质。

## 公开参数

两个页签都可以操作左侧参数列表。列表显示参数名称和类型，悬停提示包含稳定 ID 和分组。右键点击参数项或列表空白处，选择**添加参数**；在对话框中输入非空且唯一的稳定 ID，并从下拉框选择类型：`float`、`vec2`、`vec3`、`vec4`、`color`、`bool` 或 `texture`。确认后创建并选中新参数，取消则不修改材质。删除时右键点击目标参数并选择**删除**，也可以在列表项获得焦点后按 Delete。删除后会选中相邻参数，新增和删除均支持撤销与重做。向量使用数字数组，颜色使用 `[0,1]` 范围内的四个通道，纹理使用规范的 `/Game/Assets/...` 路径。

在列表下方直接编辑选中参数的默认值、显示名称、分组和可选的数值范围。修改显示名称不会改变节点引用和实例覆盖使用的 ID。数值范围也会逐分量应用于向量，最小值不能大于最大值；颜色通道仍须处于 `[0,1]`。创建后 ID 和类型只读。布尔值使用勾选框，颜色使用颜色选择器，纹理通过资源选择器选择并以只读方式显示路径。删除仍被引用的参数会产生诊断，需要重新连接或删除对应的 Parameter 节点；实例面板提供删除未知参数覆盖的操作。

## 编辑节点图

打开**节点图**页，右键点击画布空白处，会直接打开以**添加节点**为标题的分类菜单。选择分类及节点类型，即可在该位置创建节点。拖动标题移动节点，拖动端口建立连接。未连接的输入常量直接在对应 Pin 下方编辑，节点属性也在节点内部编辑；已连接输入会隐藏数值控件。声明的默认值只用于显示，不会因此写入覆盖；隐式输入和继承输入显示**默认输入**或**透传输入**。右键点击未连接的输入 Pin，选择**设置常量**可指定数值，选择**恢复默认输入**可移除显式常量。最大顶点位移等材质整体设置位于左侧参数区下方、默认收起的**渲染配置**中。

右键点击输入 Pin 可断开其连接，右键点击输出 Pin 可断开该 Pin 的全部连线。节点右键菜单还提供**断开所有输入连线**和**断开所有输出连线**，仅作用于该节点。没有对应连接时，断线操作不可用；一次批量断线可通过一步撤销恢复。断线后输入恢复声明默认值或隐式／透传行为，不会找回连接前的旧常量。

右键点击节点可执行删除。如果该节点已在多选范围内，会保留多选；否则先选中被点击的节点。`Surface` 输出不可删除。按住右键拖动可平移画布，松开后不会弹出菜单。也支持常规选择、Delete、复制粘贴、撤销和重做。数值控件获得焦点时，文本编辑和数值调整作用于该控件。粘贴后的节点使用新 ID，并保留所复制节点之间的连接。

受限的节点属性使用下拉框：Parameter 引用显示参数名称、保存稳定 ID；数值提供支持的标量或向量维度；Compose 只能选择 2、3 或 4 个分量。Swizzle 提供输出长度选择，以及每个分量的通道下拉框（`X/R`、`Y/G`、`Z/B`、`W/A`）。编译器仍会检查所选通道是否存在于输入中，已保存的无效值在修正前会明确显示错误。数值控件遵循声明的上下限，不额外限制未指定范围的值。

材质图是纯数据流图，只有一个不可删除的 `Surface` 输出，不包含玩法事件，也不执行 Blueprint。可用节点提供输入表面、公开参数、时间、位置、精灵与纹理采样、算术、向量组合、分量选择和色相调整。例如，将 `SurfaceInput.BaseColor` 和一个浮点 Parameter 接入 `HueShift`，再将其 `Value` 输出连接至 `Surface.BaseColor`；色相使用角度。冻结、燃烧、全息等效果由这些通用节点组合，并通过普通公开参数调整。

| Surface 输入 | 含义 |
| --- | --- |
| `BaseColor`、`Alpha` | RGB 颜色与透明度。 |
| `Emission` | 不受场景照明衰减的局部 RGB 自发光；需要照亮周围对象时使用 Light 组件。 |
| `LightingWeight` | 原色与场景受光颜色的混合权重。 |
| `LightBlock` | 每穿透一个 `CellSize` 的光不透明度，详见[光照](<图块集、自动图块与地图.md#灯光与-actor>)。 |
| `ReflectionStrength` | 对地图反射表面的贡献强度。 |
| `VertexOffset` | 以像素为单位的局部附加顶点位移。 |

未连接的表面通道保留输入表面值，未连接的 `VertexOffset` 则不增加位移。因此图层可以只改一个通道，而保留图块材质的其他结果。将 `rendering.maxVertexOffset` 设为非负的 `[x,y]` 边界，覆盖所有可能的位移，包括参数范围。渲染器据此执行裁剪并扩展预览帧。纹理采样只用于片元阶段，阶段不兼容的连接会产生编译诊断。可用节点及端口以项目原生运行时提供的 registry 为准。

## 预览与排错

在**预览**页选择**预览贴图**，通过 X、Y、Width 和 Height 四个整数输入框设置目标精灵帧。X 和 Y 不得为负，Width 和 Height 至少为 1。调整预览环境光和可选点光源，可以检查受光与自发光。这些预览设置只在窗口会话中生效。预览读取未保存的材质资源，Actor、地图和 UI 预览也会收到同一份未保存材质快照。

编译错误显示在右侧两个页签共用的底部区域，能确定节点时会高亮对应节点；点击错误会切换至**节点图**并定位。节点图页的**查看生成着色器**以只读方式显示生成的顶点和片元 GLSL。请在图中修复缺少的参数、非法连接、不兼容的值或不支持的阶段。图由原生编译器生成 GLSL，不接受原始着色器源码。本版不包含法线贴图、图继承或子图。

## 导出运行文件

材质修改后使用**导出**。导出插件 Hook 完成后，原生编译器会校验已保存的节点图，将 GLSL 源码和运行元数据写入 `Data/MaterialGenerated`。普通保存与编译不会生成这些文件。预览仍通过与导出相同的编译器，在内存中编译未保存的快照，不会修改已导出的文件。

`Data/Materials/Surfaces/Water.json` 对应 `Data/MaterialGenerated/Materials/Surfaces/Water.json/`。空材质引用对应 `Data/MaterialGenerated/Builtin/Default/`，与 `Global/Standard.json` 相互独立。每个基础材质目录包含：

| 条目 | 内容 |
|---|---|
| `resource.json` | 参数定义、默认值与最大顶点位移。 |
| `single/` | 不叠加图层的基础材质。 |
| `layers/<相对 Data/Materials 的路径，包含 .json>/` | 先执行基础材质，再叠加指定图层材质的组合。 |

导出覆盖全部有序的基础材质／图层材质组合，包括同一材质叠加自身，以及每个基础材质单独使用的情况；空图层表示不叠加图层。每个程序目录包含一个共用的 `vertex.vert`，四个片元文件 `color.frag`、`surface.frag`、`transmission.frag`、`source.frag`，以及运行元数据 `program.json`。着色器文件以 `Automatically generated by Ludork Material Export. Do not edit.` 注释开头，并标注来源材质、图层和用途。内容不变的文件保留原内容与时间戳。

游戏直接加载生成文件，绑定实例参数并执行导出的数值分析指令，不再解析材质图或拼接 GLSL；目标设备仍由显卡驱动编译和链接着色器。生成文件缺失、损坏或格式不受支持时会明确报错。材质引用和 Lua 参数接口保持不变。

生成目录及其中的 `export.json` 记录被版本管理忽略，也不包含在模板中，由导出重新生成。游戏发行包保留源材质和生成文件，支持着色器／数据加密及 `Data.ldpak`。导出过期检查和命令行校验见[运行、调试与打包](<运行、调试与打包.md>)。

## 文件格式

资源格式固定为版本 `1`，新建材质采用以下结构：

```json
{
  "type": "material",
  "version": 1,
  "parameters": [],
  "graph": {
    "nodes": [{"id": "surface", "type": "Surface", "inputs": {}, "properties": {}}],
    "output": "surface"
  },
  "rendering": {"maxVertexOffset": [0, 0]},
  "editor": {"positions": {"surface": [400, 200]}}
}
```

每个输入是常量，或 `{"node":"tint","port":"Value"}` 形式的连接。节点位置和画布 `editor.view`（缩放与偏移）会作为编辑信息保存，连续平移或缩放手势合并为一步撤销。参数定义包含 `id`、`type`、`default` 以及可选的 `displayName`、`group`、`min`、`max`；实例字典只保存 ID 到值的覆盖。材质及引用纹理随正常项目流程打包，支持加密 Data 和 `.ldpak`。
