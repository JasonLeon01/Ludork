# 通用数据参考总览

本组页面记录 Game 项目自带的 General Data 类型。表中每个取值都是项目数据，而不是引擎枚举，因此项目可以自由重定义同名类型。每页依据 `Data/General` 下当前的 schema 生成，标明来源文件，并列出该 schema 的字段、默认值与成员事件。

## 数据存放位置

General Data 保存在项目的 `Data/General` 目录下，每个类型一个 JSON 文件。Game 项目恰好包含下面七个文件。

| 文件 | 页面 |
|---|---|
| `Data/General/Class.json` | [Class](<Class.md>) |
| `Data/General/Enemy.json` | [Enemy](<Enemy.md>) |
| `Data/General/Equip.json` | [Equip](<Equip.md>) |
| `Data/General/Item.json` | [Item](<Item.md>) |
| `Data/General/Player.json` | [Player](<Player.md>) |
| `Data/General/Special.json` | [Special](<Special.md>) |
| `Data/General/State.json` | [State](<State.md>) |

每个文件用 `params` 存放有序的字段定义，用 `members` 存放命名记录，并可选地声明 `events`。类型结构、受支持的字段类型与引用声明见 [通用数据与文本配置](<../通用数据与文本配置.md#类型结构>)。

## 各页内容

| 页面 | 内容 | 成员事件 |
|---|---|---|
| [Class](<Class.md>) | 玩家职业预设：显示名称与说明，以及把装备槽位名映射到该槽位初始装备的 `slot`。 | — |
| [Enemy](<Enemy.md>) | 敌人属性（`MAXHP`、`ATK`、`DEF`、`EXP`、`GOLD`）、以 Blueprint 类路径加地图格偏移表示的 `drops`、`special` 参数与攻击动画。 | — |
| [Equip](<Equip.md>) | 装备：图标、所占用的 `Class` 槽位键，以及装备期间生效的 `attrPlus` 属性修正值。 | `onEquip`、`onUnequip` |
| [Item](<Item.md>) | 背包物品：`usable`、商店 `price` 与由此推导的售价、图标与 `cost`。 | `onDrop`、`onUse` |
| [Player](<Player.md>) | 玩家预设：引用的 `CLASS` 成员，以及初始 HP、属性、经验、金币与等级取值。 | — |
| [Special](<Special.md>) | 仅负责表现的记录（名称、说明与图标），其参数仍保存在 `Enemy.special` 中。 | — |
| [State](<State.md>) | 状态，包括 `stackable` 是否提升已有状态的叠加层数。 | `onWalk`、`onHookTriggered` |

部分 schema 通过字符串字段引用另一个类型，例如 `Player.CLASS` 指向某个 `Class` 成员，`Enemy.special` 的键指向 `Special` 成员。每页 schema 表的引用列会给出该目标。

## 带花括号的显示字符串

General Data 原样保存每个字符串，Game 项目的显示字段存放的是带花括号的本地化 key，例如 `{WARRIOR}`。加载时不会解析这些标记：目录文本在 `Data/Locale/Locale.xlsx` 中编写，导出到 `Scripts/Source/Locale/<language>.lua`，玩法侧使用 `Locale.ApplyStringLocaleFormat`（通常绑定为局部 `LOC`）解析裸 key 或字符串中的每个 `{ID}`。缺失的 key 保持原样，成对的 `{{` 与 `}}` 输出字面花括号，语言不可用时尽可能回退到 `en_GB`。当字段的完整去空格文本恰好是一个 `{ID}` 标记时，编辑器还可以显示提示；空格与嵌套花括号会使该标记失效。`Locale.SetLanguage` 会发布 `LocaleChanged`，因此长期存在的 UI 需要重新解析自己保存的 key。目录格式与格式化函数契约见 [游戏本地化工作流](<../../插件开发与安装/Official 插件/游戏本地化工作流.md#运行时>)。

## 与 General Data 编辑器的关系

这些页面是参考输出，不是编辑界面。schema、成员与成员能力图在 **数据库 → 通用数据**（`F10`）中编辑，其 Form 与 Table 视图、搜索行为、引用选择器和共享的 Undo 历史见 [通用数据与文本配置](<../通用数据与文本配置.md>)。在该窗口保存会重新生成 `Source.Configs.GeneralEnum` 与 `Source.Configs.GeneralDataTypes`，运行时通过 `Source.Gameplay.GeneralDataGraphAbility` 显式激活成员能力图。
