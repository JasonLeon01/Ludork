# 通用数据参考总览

本组页面记录 Game 项目自带的 General Data 类型。表中每个取值都是项目数据，而不是引擎枚举，因此项目可以自由重定义同名类型。每页依据 `Data/General` 下当前的 schema 生成，标明来源文件，并列出该 schema 的字段、默认值与成员事件。

## 数据存放位置

每个类型保存在 `Data/General/<Type>.json`。通过**数据库 → 通用数据**（`F10`）编辑类型、成员和能力图；字段选项及生成文件见[通用数据与文本配置](<../通用数据与文本配置.md#类型结构>)。

## 各页内容

| 页面 | 内容 | 成员事件 |
|---|---|---|
| [Class](<Class.md>) | 玩家职业预设：显示名称与说明，以及把装备槽位名映射到该槽位初始装备的 `slot`。 | — |
| [Enemy](<Enemy.md>) | 敌人属性（`MAXHP`、`ATK`、`DEF`、`EXP`、`GOLD`）、以 Blueprint 类路径加地图格偏移表示的 `drops`、`special` 参数与攻击动画。 | — |
| [Equip](<Equip.md>) | 装备：图标、所占用的 `Class` 槽位键，以及装备期间生效的 `attrPlus` 属性修正值。 | `onEquip`、`onUnequip` |
| [Item](<Item.md>) | 背包物品：`usable`、商店 `price` 与由此推导的售价、图标与 `cost`。 | `onDrop`、`onUse` |
| [Player](<Player.md>) | 玩家预设：引用的 `CLASS` 成员，以及初始 HP、属性、经验、金币与等级取值。 | — |
| [Special](<Special.md>) | 仅负责表现的记录（名称、说明与图标），其参数仍保存在 `Enemy.special` 中。 | — |
| [State](<State.md>) | 状态，包括 `stackable` 是否提升已有状态的叠加层数。 | `onWalk`、`onHookTriggered` |

项目引用直接写在枚举 schema 中：`Player.CLASS` 使用 `Enums.GeneralData.Class`，`Enemy.special` 的字典键使用 `Enums.GeneralData.Special`，攻击动画使用 `Enums.Animation`。保存值仍然是字符串。

成员事件由 `Source.Gameplay.GeneralDataGraphAbility` 显式激活；没有起始节点时返回 `NoGraph`。各类型特有的触发方与上下文见对应页面。

## 带花括号的显示字符串

显示字段可以保存 `{WARRIOR}` 等本地化键，在显示文本时解析。格式化和语言切换规则见[游戏本地化工作流](<../../插件开发与安装/Official 插件/游戏本地化工作流.md#运行时>)。
