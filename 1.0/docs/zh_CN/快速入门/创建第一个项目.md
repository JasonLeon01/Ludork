# 创建第一个项目

创建一个 Standalone 项目，打开初始地图并运行。

### 创建项目

1. 在启动页选择 **新建项目**。

![Ludork 启动页：最近项目与创建新项目的入口](../../../images/getting-started/start-page.png)

*启动页是创建新项目或重新打开已有项目的入口。*

2. 选择 **Standalone**。
3. 除非游戏需要播放视频，否则保持 **启用视频播放（FFmpeg）** 关闭。
4. 选择一个已存在的目标目录，并输入新的项目名称。
5. 确认目标路径后点击**创建**，完成后会自动打开 `Main.proj`。

首次下载需要网络连接，且当前编辑器版本的模板已发布。点击**取消**可停止创建并清理未完成文件。下载和离线使用方式见[获取模板](<项目模板.md#获取模板>)。

![新建项目窗口：已选中 Standalone 模板](../../../images/getting-started/new-project.png)

*Standalone 自带可直接运行的原生运行时，因此是第一个项目的推荐模板。*

### 保存与运行

1. 在 **地图列表** 中选择一张地图。
2. 点击 **导出**，保存、校验并生成 UI 与语言文件。若有错误，先全部处理完再继续；首次成功导出之前，运行按钮不可用。
3. 点击工具栏上的 **运行**。游戏运行在内嵌面板还是 **独立窗口**，由 **编辑 → 开发工具与设置 → 独立窗口** 决定。该设置只在 Windows 上可用，其他平台上游戏始终在 **独立窗口** 中打开。
4. 打开**控制台**查看运行输出。游戏运行时默认不能编辑项目；需要修改运行中的地图时，请在运行前开启[实时调试](<../编辑器用户指南/运行、调试与打包.md#实时调试>)。
5. 点击同一位置的 **停止**，停止游戏并恢复编辑。

新项目不包含 `Main.ini`，首次运行时会自动创建。各文件和目录的用途见[项目设置与资产布局](<../编辑器用户指南/项目设置与资产布局.md>)。
