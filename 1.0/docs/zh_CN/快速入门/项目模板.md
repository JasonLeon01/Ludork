# 项目模板

## 模板参考

新建项目窗口提供两张模板卡片 **Standalone** 与 **C++ Source**，以及一个独立的 **启用视频播放（FFmpeg）** 开关。

| 模板 | 原生源码 | 是否需要原生编译器 | 适用场景 |
|---|---|---|---|
| Standalone | 无 | 否 | 用随附的运行时编写 Lua、蓝图、数据与资产。 |
| C++ Source | 有 | 是 | 修改原生服务、绑定，或构建 iOS、HarmonyOS、Android 目标。 |

模板决定项目的初始结构，创建后不能通过编辑器开关更换。C++ Source 项目首次运行前需要先**编译**再**导出**，Standalone 只需导出。后续操作见[运行、调试与打包](<../编辑器用户指南/运行、调试与打包.md>)。C++ Source 模板还在项目根目录提供用于格式化原生源码的 `.clang-format`。

## 获取模板

开发版编辑器附带本地模板。缺少模板时，新建项目会显示错误，不会联网下载替代模板。

正式版编辑器从对应的 GitHub Release 获取模板。Windows x64 使用 ZIP，macOS ARM64 使用 tar.gz；每个正式版本提供八个独立模板资产：

| 模板 | Windows x64 | macOS ARM64 |
|---|---|---|
| C++ Source | `game-source.zip` | `game-source.tar.gz` |
| C++ Source + FFmpeg | `game-source-ffmpeg.zip` | `game-source-ffmpeg.tar.gz` |
| Standalone | `game-standalone.zip` | `game-standalone.tar.gz` |
| Standalone + FFmpeg | `game-standalone-ffmpeg.zip` | `game-standalone-ffmpeg.tar.gz` |

模板与编辑器的完整版本号匹配，包括补丁版本。对应版本或模板尚未发布时，新建项目会提示模板不可用。

下载的模板缓存在 Windows 的 `<Ludork 安装目录>/Templates/v<基础版本>/` 或 macOS 的 `~/Ludork/Templates/v<基础版本>/`，之后可离线复用。每个项目都会解压到独立目录。

新建窗口显示下载或复制进度及解压进度。点击 **取消**，或在创建期间关闭窗口，会取消操作并清理本次未完成的项目和下载文件；已完成的有效缓存保留，供以后复用。

新项目使用编辑器当前的主次版本，例如编辑器 `1.0.7` 创建 `v1.0` 项目，不提供旧版本创建选项。可打开的项目版本见[项目版本](<../编辑器用户指南/项目设置与资产布局.md#mainproj>)。

## FFmpeg 选项

**启用视频播放（FFmpeg）**增加本地 MOV 和 MP4 播放能力，支持 H.264 视频和 AAC 音频，同时会增大包体。不包含其他编解码器、网络播放或硬件加速。

Windows 和 macOS 使用 FFmpeg 动态库，iOS、HarmonyOS 和 Android 使用静态库。发行要求，包括静态构建所需的 LGPL 重链接材料，见 `Licenses/FFmpeg/README.md`。在 macOS 上选择 FFmpeg 时还会显示兼容性提示。

## 模板目标

- [Ludork 简易服务器](<../简易服务器/部署与编辑器设置.md>)要求 C++ Source；Standalone 不显示 Game 测试服务器菜单或打包配置。生成的所有模板都默认禁用服务器，不携带测试或正式凭据。
- 导出移动端包体（iOS、Android、HarmonyOS）必须使用 C++ Source（源码）模板。
- 脚本编译、Shader 加密、数据加密、存档加密，以及 **将 Assets、Data 和 Scripts 打包为 .ldpak** 都属于打包选项，不是模板类型。完整的选项行为见[运行、调试与打包](<../编辑器用户指南/运行、调试与打包.md>)。

四种模板均不包含导出产物：`Scripts/Internal/UI/`、`Scripts/stub/Internal/UI/`、`Scripts/stub/Internal/UIWindows/`、生成的语言 Lua 文件和 `EditorCache/ProjectExport.json`。项目 `.gitignore` 也会忽略这些生成文件。模板保留 UI JSON、手写 Controller 和声明、`Scripts/Source/Locale/Core.lua`、通用数据和变量 Lua 及其声明，以及原生绑定声明；新项目通过导出生成 UI 和语言文件。

保留的 `Scripts/stub/**/*.d.lua` 用于 Lua 语言工具，[游戏打包](<../编辑器用户指南/运行、调试与打包.md#散放与归档>)时会移除。

运行时许可证文本位于 `Licenses`，FFmpeg 变体另附 `Licenses/FFmpeg`；资产声明保留在对应资产旁。打包会包含现有许可证文本，但发行者仍需负责材料的完整性。
