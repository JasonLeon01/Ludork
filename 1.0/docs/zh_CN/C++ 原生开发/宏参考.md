# 宏参考

本页列出绑定和原生 UI 适配器支持的声明标记。具体用法见绑定类、函数绑定与高级绑定模式各页。

| 宏 | 用途 |
|---|---|
| `BIND_CLASS` | 声明绑定类及唯一的模块根名称；`callbacks = true` 选择该类的已绑定的非静态虚方法用于 C++ 到 Lua 分派 |
| `BIND_ENUM` | 把 C++ 作用域枚举 公开为一个模块根 Lua 表 与 LuaLS 类型 |
| `BIND_FUNCTION` | 绑定自由函数；`outpins(...)` 与 `latent(...)` 为内联选项 |
| `BIND_FUNCTION_GROUP` | 把头文件中的绑定自由函数放入同一张表 |
| `BIND_METHOD` | 绑定方法或 getter 属性；方法默认进入 metadata，除非 `metadata = false`；`callback = false` 会把虚方法排除在所属类的自动 callback 选择之外 |
| `BIND_PROPERTY` | 绑定实例数据属性 |
| `BIND_INIT` | 绑定构造函数 |
| `BIND_REGISTER_EVENT` | 注册蓝图事件入口 |
| `BIND_INJECT` | 在支持位置注入声明式绑定代码 |
| `BIND_MODULE_PROPERTY` | 公开模块级属性 |
| `BIND_CLASS_PROPERTY` | 公开类级属性。`readonly = true` 禁止 Lua 写入；`type` 控制生成的 Lua 声明类型，不改变 C++ 存储或运行时绑定 |
| `BIND_LUA_REVERSE` | 描述反向 Lua/C++ 适配 |
| `BIND_LUA_HELPER` | 声明可复用的 Lua 绑定辅助函数 |
| `BIND_MODULE_INIT` | 添加模块初始化行为 |

无需公开的声明不写绑定标记。类的转换选项见[绑定类](<绑定类.md#值转换契约>)。`invalid_vars(...)`、`rect_range_vars(...)` 等类装饰器写在 `BIND_CLASS` 内；循环协议使用内联 `loop_node(...)`，`BIND_REGISTER_EVENT()` 则单独声明。

可变参数 `BIND_*` 标记在 C++ 编译时展开为空。Bindgen 读取 `outpins(...)`、`latent(...)`、`nil`、`function` 等原始 token，这些 token 不能为了通过 C++ 解析而加引号。协议值一律使用小写 `nil`、`true` 与 `false`；`defaults` 与 `parameter_types` 使用花括号列表，结构化 `meta(...)` 与属性 `default` 使用可嵌套的花括号，而不是带引号的 JSON。字符串标量默认值须加引号，包括 `default = "None"`，并保留字符串原值。类属性可通过 `BIND_CLASS_PROPERTY(readonly = true, type = "'Add'")` 声明精确的 Lua 字符串类型，同时仍用 C++ `std::string` 存储。

基类推断与 `cast_bases` 的写法见[绑定类](<绑定类.md#声明类>)。

`BIND_ENUM` 与 `BIND_MODULE_PROPERTY(enum = true)` 会生成枚举模块。声明示例、支持的映射值及 `name` 规则见[绑定作用域枚举](<绑定类.md#绑定作用域枚举>)，输出细节见[生成枚举模块](<生成 Metadata 与 Stub.md#生成枚举模块>)。

`metadata_type`、`metadata_parameters` 与 `metadata_returns` 只覆盖蓝图 schema，不改变原生绑定或 LuaLS 类型。规则见[仅覆盖 Metadata 签名](<函数、事件与执行.md#仅覆盖-metadata-签名>)，属性示例见[绑定作用域枚举](<绑定类.md#绑定作用域枚举>)。

运行时路径见[绑定类](<绑定类.md#声明类>)与[指定函数组](<函数、事件与执行.md#指定函数组>)。`global`、`variadic` 等注入选项见[高级绑定模式](<高级绑定模式.md#初始化注入与值类型特征>)。

`nonnull_return = true` 的用法见[函数、事件与执行](<函数、事件与执行.md#声明执行行为>)。

## 原生转换声明

在类的 public 区域，查询根类型声明 `LUDORK_CAST_ROOT(Type)`，派生类型声明 `LUDORK_CAST_DERIVED(Type, Bases...)` 并列出参与查询的直接基类。每个动态转换目标和每个多态绑定类都必须声明自身的宏；继承祖先的声明不会登记新类型。非多态值类型无需声明转换协议。生成的 Lua 适配器 自动声明该协议，其公开宿主类仍须自行声明。

这些宏生成查询子对象地址的虚方法，以及 `std::string_view ludorkDynamicTypeKey() const noexcept`，不改变 Lua 名称或绑定基类。头文件要求与指针语义见[原生指针转换](<构建与模块布局.md#原生指针转换>)；Lua 包装遵循[原生对象包装](<运行时值边界.md#原生对象包装>)。
