# 高级绑定模式

本页模式覆盖普通类、属性、方法与自由函数工作流无法表达的引擎基础设施。

## 类 Metadata decorator

类 decorator 嵌套在所属类的注解里：

```cpp
BIND_CLASS(callbacks = true,
           invalid_vars(defaultRect, internalState),
           rect_range_vars(defaultRect = texturePath))
class Character : public Actor {
public:
  BIND_METHOD(metadata = false)
  virtual void _applyDirection(float x, float y);
};
```

`invalid_vars(...)` 隐藏字段，`rect_range_vars(...)` 把矩形关联到资源字段或范围字段。两者都只接受有序标识符，并且只能写在 `BIND_CLASS` 内。属性自己的矩形语义仍在 `BIND_PROPERTY` 中写作 `meta(RectRangeVars = "texturePath")`。`metadata = false` 不会禁用 callback，需要禁用时应改用 `callback = false`。见[绑定类](<02.绑定类.md>)。

成员级的编辑器 decorator 留在其所属注解内。结构化值使用花括号数据，而不是完整的 JSON 字符串：

```cpp
BIND_PROPERTY(
    meta(Rely = {source = "autoSound", op = "!=", value = ""}))
float autoSoundInterval = 0.0f;

BIND_METHOD(defaults = {{}},
            meta(MoveRouteVars = {"route"}),
            outpins(default = nil))
void setRoute(
    const std::optional<std::vector<sf::Vector2i>>& route = {});
```

第一个值含命名项，因此是对象；第二个值只有位置项，因此是数组。完整的花括号语法与拒绝带引号 JSON 的规则见[宏参考](<04.宏参考.md>)。

## 事件、Latent 与循环

```cpp
BIND_REGISTER_EVENT()
BIND_METHOD()
virtual void onCreate();

BIND_METHOD(latent(TimeUp = true),
            defaults = {nil, nil, {}, false},
            parameter_types = {float, function, any[], bool})
TimerHandle addTimer(float interval,
                     RuntimeIdentityPtr task = {},
                     RuntimeValue::Array params = {},
                     bool blocking = false);

BIND_METHOD(loop_node(ForEach))
void forEach(const RuntimeValue::Array &values);
```

Event、内联 latent 与 loop 注解会生成执行 metadata。C++ 或 Lua 实现仍必须兑现所承诺的运行时协议（见[函数、事件与执行](<03.函数、事件与执行.md>)）。

## 值、反向表与 Helper

```cpp
BIND_MODULE_PROPERTY()
extern std::string LANGUAGE;

class FocusTransition {
public:
  BIND_CLASS_PROPERTY(readonly = true)
  static const std::string DIRECTIONAL;
};

BIND_LUA_REVERSE(path = "Input.KeyName", source = "sf.Keyboard.Key")
BIND_LUA_HELPER(kind = "cast", path = "Cast")
```

模块属性公开在模块根，类属性公开在所属类上。已有的 Lua 值不会被 bindgen 重复挂到另一条运行时路径。reverse 声明会在它声明的规范路径上新建一套反向名称查找。helper 使用通用的原生支持。`eval` helper 只求值调用方传入的表达式，可选 locals 优先于运行时全局变量。表达式缺失或为空时返回 `nil`。非空表达式的求值是同步的，在可挂起的协程中调用会直接报错。

## 初始化、注入与值 Trait

```cpp
BIND_MODULE_INIT()
void initialiseRuntimeServices(lua_State *state);

BIND_INJECT(global = "_LUDORK_BLUEPRINT_EVENT_VALIDATOR")
void setBlueprintEventValidator(BlueprintEventValidator validator);

BIND_CLASS(opaque_identity = true)
class RuntimeIdentity {};

BIND_CLASS(dynamic_value = true)
class RuntimeValue {};
```

`BIND_MODULE_INIT` 在打开模块期间运行。`BIND_INJECT` 把一个 Lua 全局 callback 接到 C++ setter 上，只在该 Lua state 仍然可用时有效。启用 `variadic = true` 时，setter 必须接收 `std::function<std::vector<T>(Fixed..., const std::vector<T>&)>`。零返回值与中间、末尾的 `nil` 依然彼此可辨，无需封装 table。上面两个 `BIND_CLASS` 标志选择转换 trait 与身份 trait，不能与不兼容的 table 取值模式组合。引擎子系统使用带类型的 runtime facade 与固定 provider 槽位，而不是通用的字符串操作分发器。

## 限制

Bindgen 必须保持声明驱动。不得为某个玩法模块、类或成员名专门增设生成器分支，也不得用基础设施标记绕过不受支持的转换。
