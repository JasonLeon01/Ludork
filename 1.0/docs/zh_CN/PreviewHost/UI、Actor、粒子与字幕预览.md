# UI、Actor、粒子与字幕预览

打开对应的资产编辑器可检查外观与时序。这些预览遵循[预览与游戏运行的边界](<概述.md#预览与游戏运行>)。宿主可用性、重新构建与错误处理见[构建、发布与排错](<构建、发布与排错.md>)。

## UI 预览

[UI 资产编辑器](<../编辑器用户指南/UI 资产编辑器.md>)显示资产内容，但不运行 Lua Controller。点击**刷新预览**可显示尚未刷新的编辑结果。修改原生控件后，先重新构建项目，再检查效果。

为依赖模型的区域放置有代表性的占位内容。由运行时代码填充的文本使用 `previewText`，它属于节点中仅供设计使用的 `editor` 数据。`#TAB`、`#ITEM` 样例与 Game 视觉资源让标签、列表和角色显示便于检查，但不能用于填补缺失的游戏数据。显示前，业务代码必须提供本地化标签并填充动态集合。运行时职责见[声明式 UI 编写工作流](<../Lua 与蓝图脚本/声明式 UI/编写工作流.md>)。

在 Timeline 中选中动画后，使用播放、暂停、停止和拖动时间轴检查效果，不会改变已保存的 Slot 布局。未选中动画时，设计区显示资产原本的外观。动画定义、继承的 Global 动画及实例覆盖的编辑方式见 [UI 时间轴](<../编辑器用户指南/UI 资产编辑器.md#timeline>)。

嵌套资产与重复模板的编辑方式见 [UI 资产编辑器](<../编辑器用户指南/UI 资产编辑器.md>)。控件属性、子节点与 Slot 规则见 [Palette 控件](<../编辑器用户指南/Palette 控件.md>)。

## Actor 预览

在文件选择器中选中 Blueprint JSON，可预览包含未保存修改的当前外观与动画；缺少外观或纹理时显示文件图标。

Actor 库与蓝图编辑界面使用解析后的 Actor 外观。纹理区域、角色帧动画、`material` 与 `materialParameters` 来自当前蓝图值，地图实例还应用自身的属性覆盖。修改继承默认值，包括撤销与重做，都会刷新受影响的外观。

Actor 库、类与实例的编辑方式见[蓝图、公共函数与 Actor](<../编辑器用户指南/蓝图、公共函数与 Actor.md>)；地图光照、选择辅助和 Live Debug 显示见[地图与世界预览](<地图与世界预览.md>)。

## 材质预览

材质、Actor、地图和 UI 预览接收未保存的材质快照，原生宿主在内存中编译，不改写已导出的着色器；游戏运行时加载导出文件。预览失败时显示错误，不保留过期的成功画面。共用编译器、预览控件、错误定位和 GLSL 查看方式见[预览与排错](<../编辑器用户指南/材质.md#预览与排错>)。

## 粒子预览

从**数据库 → 通用粒子总览**（`F6`）或项目文件浏览器打开粒子。预览可以单独显示选中轨道。使用播放/暂停、停止、重播、单步、输入时间、拖动时间轴、播放速度和缩放检查效果。

单步推进 `1 / simulationRate` 秒。跳转时间会暂停播放，目标时刻越靠后，可能需要等待越久。这些控件不改变已保存的资源；轨道与属性编辑仍遵循常规保存和撤销流程。固定资源种子支持同一运行时和 GPU 上的重复检查，不保证跨设备模拟结果完全一致。

资源缺失或 GPU 能力不受支持时会显示错误。粒子预览使用原生 GPU 实现，没有 CPU 回退。资源字段、发射与归属规则、GPU 要求及功能限制见[通用粒子](<../编辑器用户指南/通用粒子.md>)。

## 字幕预览

在[字幕编辑器](<../编辑器用户指南/视频字幕.md>)打开 `Data/Subtitles` 下的文档。通过播放/暂停、停止、当前时间、时间轴播放头和预览语言检查时序。没有参考视频时使用纯色背景，播放到最后一个片段的结束时间。空字幕文档仍可编辑。

选择项目视频作为临时参考，或清除视频恢复纯色背景。视频保持宽高比，同步播放音频，并提供静音控制。定位时暂停音频，完成后恢复原播放状态。预览时长取视频和字幕时长的较大值；视频结束后，剩余字幕显示在纯色背景上。

非 FFmpeg 工程选择视频时提示“当前不是 FFmpeg 工程”，仍可编辑字幕并使用纯色背景预览。参考视频、预览语言、播放位置和静音设置只属于窗口会话，不写入字幕文档。

原生预览与运行时播放共用字幕布局。字幕数据、语言编辑、字体、换行及布局规则仍见[视频字幕](<../编辑器用户指南/视频字幕.md>)。
