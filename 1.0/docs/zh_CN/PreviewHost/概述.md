# PreviewHost

PreviewHost 为编辑器中的地图、大地图、Actor、UI、粒子和字幕预览提供原生渲染。本章介绍预览的使用方法、运行时准备，以及编辑器获取画面的方式。

## 选择预览入口

| 预览内容 | 入口 | 指南 |
|---|---|---|
| 地图、大地图及子地图缩略图 | 主工作区的地图视口与大地图画布 | [地图与世界预览](<地图与世界预览.md>) |
| UI 资产及其动画 | UI 资产编辑器的 Designer 与 Timeline | [UI 预览](<UI、Actor、粒子与字幕预览.md#ui-预览>) |
| Actor 外观 | 蓝图预览、Actor 库及地图上的 Actor | [Actor 预览](<UI、Actor、粒子与字幕预览.md#actor-预览>) |
| 通用粒子 | 通用粒子编辑器 | [粒子预览](<UI、Actor、粒子与字幕预览.md#粒子预览>) |
| 视频字幕 | 字幕编辑器 | [字幕预览](<UI、Actor、粒子与字幕预览.md#字幕预览>) |

## 预览与游戏运行

编辑器预览显示正在制作的内容。地图和 Actor 外观预览解析视觉数据，不执行 Actor 创建、Tick 或蓝图玩法事件；UI Designer 显示编写的资产，不运行其 Lua Controller。粒子与字幕播放各有预览控制，见上表中的指南。

使用 **Play** 测试玩法。**Live Debug** 检查已经运行的游戏，并保留自身的编辑权限；其中的地图画面遵循[地图预览显示规则](<地图与世界预览.md>)。游戏运行及实时编辑操作见[运行、调试与打包](<../编辑器用户指南/运行、调试与打包.md>)。
