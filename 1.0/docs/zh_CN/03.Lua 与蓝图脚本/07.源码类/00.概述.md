# 源码类总览

`Source.*` 是默认玩法项目模板中的 Lua 玩法类，每个类都通过自身的编辑器 metadata 暴露给 Blueprint。它们位于 Game 项目的 `Scripts/Source/` 目录下，本节每个页面都会在 `Metadata 来源：` 一行中标明该类同名的 `*_meta.lua` 文件；页中的属性、函数与事件表列出该 metadata 所声明的内容。

```text
Scripts/Source/
├── Battler.lua                Battler_meta.lua
├── Components/
│   └── ChildActorComponent.lua                ChildActorComponent_meta.lua
├── MapActors/
│   └── ConditionalActor, DoorBase, Enemy, EnemyDamageText,
│       Equip, Item, Player, Teleporter        (each .lua + _meta.lua)
└── Scenes/
    └── SceneMap.lua           SceneMap_meta.lua
```

`Scripts/Source/` 还包含 `Configs/`、`Data/`、`Gameplay/`、`Locale/`、`SceneComponents/`、`Utils/` 与 `Windows/` 目录，以及根模块 `Data.lua`、`GameInstance.lua`、`Save.lua` 与 `System.lua`。这些模块不属于本节的类页面。同名的 `_meta.lua` 文件只包含编辑器 metadata，从不作为玩法脚本运行，详见 [Lua 运行时与模块](<../01.Lua 运行时与模块.md#运行时声明与-metadata>)。

## 命名空间

本节的类页面使用四个命名空间。每个命名空间都与存放该类及其 metadata 文件的目录一致。

| 命名空间 | 目录 | 归类内容 |
|---|---|---|
| `Source` | `Scripts/Source/` | 根模块层。这里只有 `Source.Battler` 一个类页面，由两个战斗 Actor 共享。 |
| `Source.Components` | `Scripts/Source/Components/` | 可复用的 Actor 组件，包含 `ChildActorComponent`。 |
| `Source.MapActors` | `Scripts/Source/MapActors/` | 地图 Actor 类，是数量最多的一组：`ConditionalActor`、`DoorBase`、`Enemy`、`EnemyDamageText`、`Equip`、`Item`、`Player` 与 `Teleporter`。 |
| `Source.Scenes` | `Scripts/Source/Scenes/` | Scene 类。这里只有 `SceneMap` 一个类页面。 |

这些页面还会引用 `Source.Gameplay`、`Source.Configs` 与 `Source.Utils` 模块，它们改由 [Source Gameplay API](<07.Gameplay.md>) 记录；此外也会引用 `Source.GameInstance` 与 `Source.Windows`，这两者在本节没有类页面。

## 类

职责是一句话概要，完整的属性、函数与事件参考由各自页面负责。

| 类 | 直接 metadata 基类 | 职责 | 页面 |
|---|---|---|---|
| `Source.Battler` | 未声明 | `Enemy` 与 `Player` 的 Lua 玩法基类，这两个类都依据通用数据构造各自生成的 Attribute Set | [01.Battler.md](<01.Battler.md>) |
| `Source.Components.ChildActorComponent` | `{ "Engine", "Component" }` | 声明子 Actor 的类名与相对位置 | [02.ChildActorComponent.md](<02.ChildActorComponent.md>) |
| `Source.MapActors.DoorBase` | `{ "Source.MapActors.ConditionalActor", "ConditionalActor" }` | 声明门的碰撞、开启间隔、门音效与门状态属性，以及开门与关门节点 | [03.DoorBase.md](<03.DoorBase.md>) |
| `Source.MapActors.Enemy` | `{ "Source.MapActors.ConditionalActor", "ConditionalActor" }`、`{ "Source.Battler", "Battler" }` | 可见性受条件控制的 Battler Actor，绑定 Enemy 通用数据的 `ID`，带有伤害文本子组件以及碰撞与战败事件 | [04.Enemy.md](<04.Enemy.md>) |
| `Source.MapActors.EnemyDamageText` | `{ "Engine", "Actor" }` | 声明 Enemy 伤害读数所需的 Item、文本配置与偏移 | [05.EnemyDamageText.md](<05.EnemyDamageText.md>) |
| `Source.MapActors.Equip` | `{ "Source.MapActors.ConditionalActor", "ConditionalActor" }` | 声明装备 Actor 的通用数据标识与音效 | [06.Equip.md](<06.Equip.md>) |
| `Source.MapActors.Item` | `{ "Source.MapActors.ConditionalActor", "ConditionalActor" }` | 可见性受条件控制的拾取 Actor，依据 `ID` 构造 Item Attribute Set，碰撞时把 `count` 个物品交给 Player | [08.Item.md](<08.Item.md>) |
| `Source.MapActors.Player` | `{ "Engine", "Character" }`、`{ "Source.Battler", "Battler" }` | 声明可操控 Actor 的 Character 属性，以及背包、装备与属性命令 | [09.Player.md](<09.Player.md>) |
| `Source.Scenes.SceneMap` | `{ "Source.Gameplay.GameplayScene", "GameplayScene" }` | 声明地图 Scene 的玩法命令、对话窗口、菜单入口与持久化记录 | [10.SceneMap.md](<10.SceneMap.md>) |
| `Source.MapActors.Teleporter` | `{ "Source.MapActors.ConditionalActor", "ConditionalActor" }` | 声明楼梯偏移、音效、转场与计时属性，以及上下楼与选定地图节点 | [11.Teleporter.md](<11.Teleporter.md>) |
| `Source.MapActors.ConditionalActor` | `{ "Engine", "Actor" }` | 声明控制 Actor 可见性的条件变量、运算符与比较值 | [12.ConditionalActor.md](<12.ConditionalActor.md>) |

## 继承结构

仅从表格的 `Direct metadata base(s)` 一列可以读出：

- 四个类以 `Engine` 为根：`ConditionalActor` 与 `EnemyDamageText` 为 `{ "Engine", "Actor" }`，`Player` 为 `{ "Engine", "Character" }`，`ChildActorComponent` 为 `{ "Engine", "Component" }`。
- `Source.MapActors.ConditionalActor` 是本组中复用最多的基类，`DoorBase`、`Enemy`、`Equip`、`Item` 与 `Teleporter` 都把它列为直接 metadata 基类。
- `Source.Battler` 是第二个共享基类，由 `Enemy` 与 `Player` 列出；这也是本组中唯一两个声明了两个直接 metadata 基类的类。`01.Battler.md` 自身没有 `Direct metadata base:` 一行，`Battler_meta.lua` 也未声明 `bases`。
- `SceneMap` 是唯一基类来自本组之外的类：`Source.Gameplay.GameplayScene`，见 [Source Gameplay API](<07.Gameplay.md#gameplayscene>)。
- 本组中没有任何类把 `EnemyDamageText` 或 `ChildActorComponent` 列为直接 metadata 基类。`Enemy` 只是把 `ChildActorComponent` 作为其 `childActorComp` 属性的类型引用。

### 继承的可见性条件

`03.DoorBase.md`、`04.Enemy.md`、`06.Equip.md`、`08.Item.md` 与 `11.Teleporter.md` 都带有一行 `Inherited visibility conditions:`，指向 `12.ConditionalActor.md`。这一行表示这些类没有声明自己的可见性属性：条件变量、运算符与比较值来自 `ConditionalActor`，后者持续驱动 `setVisible(result, false)`，并在 `onCreate()` 中订阅 `GameInstance:getVariables()`。`12.ConditionalActor.md` 的继承一节列出的正是这五个类，并说明 `EnemyDamageText` 保留其原有父类——这也是该页面显示 `{ "Engine", "Actor" }` 且没有可见性一行的原因。

## 推荐阅读顺序

初次阅读默认玩法模板时，先从 [默认模板概述](<../05.Game 玩法/01.默认模板概述.md>) 了解项目结构，再按以下顺序阅读类页面：

1. [Source.MapActors.ConditionalActor](<12.ConditionalActor.md>) —— 五个地图 Actor 的共享基类，也是它们共同继承的可见性规则。
2. [Source.Battler](<01.Battler.md>) —— 共享的战斗基类及其属性访问方法。
3. [Source.MapActors.Player](<09.Player.md>)，随后是 [Source.MapActors.Enemy](<04.Enemy.md>) —— 两个 Battler；先读 Player 是因为 Enemy 的战斗结算以 Player 为对象。
4. [Source.MapActors.Item](<08.Item.md>) 与 [Source.MapActors.Equip](<06.Equip.md>) —— 为 Player 背包与装备提供来源的拾取物。
5. [Source.MapActors.DoorBase](<03.DoorBase.md>) 与 [Source.MapActors.Teleporter](<11.Teleporter.md>) —— 地图通行及其 latent 节点。
6. [Source.Components.ChildActorComponent](<02.ChildActorComponent.md>) 与 [Source.MapActors.EnemyDamageText](<05.EnemyDamageText.md>) —— 配套的组件与伤害读数 Actor。
7. [Source.Scenes.SceneMap](<10.SceneMap.md>) 配合 [Source Gameplay API](<07.Gameplay.md>) —— 持有地图、记录与传送请求的 Scene。
