# Source.MapActors.Enemy

Metadata 来源：`Scripts/Source/MapActors/Enemy_meta.lua`

直接 metadata 基类：`{ "Source.MapActors.ConditionalActor", "ConditionalActor" }`、`{ "Source.Battler", "Battler" }`

继承的可见性条件见 [Source.MapActors.ConditionalActor](<12.ConditionalActor.md>)。

Meta：`{ GeneralDataVars = { { "ID", "Enemy" } } }`

Blueprint 编辑器会合成 `Source.Configs.GeneralDataTypes.EnemyAttributeSet` 的只读 `attributes` 预览。该预览不会序列化到 Blueprint JSON 中。

## 属性

| 名称 | 类型 | 默认值 | Metadata |
|---|---|---|---|
| `ID` | `string` | `"FILL_IT_BY_YOURSELF"` | GeneralDataVars = `Enemy` |
| `childActorComp` | `Source.Components.ChildActorComponent` | 伤害文本子 Actor | component |
| `collisionEnabled` | `bool` | `true` | — |
| `animatable` | `bool` | `true` | — |
| `animateWithoutMoving` | `bool` | `true` | — |
| `afterBattleVarChanges` | `Dict[string, Tuple[string, any]]` | `{}` | 数值游戏变量选择器与固定运算符选择器 |

运行时类设置项 `DefeatShatterEffectEnabled` 默认为 `true`。`attributes` 字段保存生成的 Enemy Attribute Set。

Enemy 继承 Actor 默认的 `tickable = false`。

## 函数与事件

| 名称 | 种类 | 参数 | 返回 | 执行语义与 metadata |
|---|---|---|---|---|
| `onCollision` | event | `other: Engine.Actor[]` | — | 默认执行输出 |
| `onDefeat` | event | — | — | 默认执行输出 |

`init(texture?, rect?, tag?)` 构造 Attribute Set、Ability System、Mota ability 以及配置好的 special Effect。碰撞会在提交反击伤害之前，先预校验战斗与必需的结算。战败时，会在动画结束后应用已准备好的 Game Over Effect。

胜利动画结束后，先执行 Actor Blueprint 的 `onDefeat` hook，再执行强制销毁、Reborn/掉落、奖励与 State。这些数值取自预先准备好的快照，`afterBattleVarChanges` 在 hook 之后求值。Enemy 通用数据不定义 `onDefeat` 成员图。
