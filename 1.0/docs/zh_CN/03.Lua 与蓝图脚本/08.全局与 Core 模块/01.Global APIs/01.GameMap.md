# Global.GameMap

Metadata 来源：`Scripts/Global/GameMap_meta.lua`

## GameMap

直接 metadata 基类：`{ "GlobalCore", "GameMapBase" }`

`getGameMap` 的输出可以连接到声明为 `GlobalCore.GameMapBase` 的参数，例如 `Camera.setMap`。下列方法使用显式的 GameMap 接收者。`setTerrainTile` 与 `setTerrainTiles` 会修改地形，因此带有执行输入与执行输出；结果引脚用于返回改动情况。

### 组合式大地图门面（facade）

面对大地图清单时，`WorldGameMap` 对外提供大地图坐标。原生稀疏区域索引为已摆放的子地图提供通行性、Dir4、材质与地形。空洞可以通行，查询也不会加载远处的子地图。

`getTilemap()` 返回稀疏的底层存储，而不是扁平化的大地图。`getActorByTag` 不执行 I/O，只在 Active 或曾经激活的驻留 root 中查找。

`getGameplayCellRect()` 返回一份格子矩形副本，不触发区域加载。普通地图的结果是完整边界；大地图的结果是 Active 边界，Active 区域尚未建立时退回可见边界。

`prepareViewportAt` 同步准备并绘制所需的 Camera 邻域，外围摆放仍保持异步。必需子地图、Actor 或发布环节失败时，错误会向外传播。

### Actor 可见性

`getAllActors` 与 tag 查询会保留隐藏实例。位置查询、范围查询、碰撞、Overlap 与寻路都会排除被自身或祖先的 `visible` 标记隐藏的 Actor。绘制同样排除它们附带的光源与遮光。Game 会把这类 Actor 从敌人列表和移动危险中过滤掉。可见性变化后，下一次查询之前就会刷新危险缓存，不必等待 Tick。

### 非连通区域隐藏

`GameMap.HideDisconnectedRegions` 为普通有限地图启用原生区域隐藏。在系统初始化、构造地图之前设置这个模块默认值；已有地图由 `setHideDisconnectedRegions(enabled)` 控制。`GameMap` 对 `sparseWorldConfig` 跳过这个默认开关；直接对稀疏大地图调用原生 setter 并传入 `true` 会报错，因此组合式大地图保留原有绘制行为。

区域仅根据 tile 通行性按四方向连通划分：每格由最上层可见且包含 tile 内容的图层决定通行性。地图边缘限制连通，门和其他 Actor 不参与划分。玩家所在区域保持可见，其他可通行格显示为最近不可通行格的 tile 图层。距离采用曼哈顿距离，同距按从上到下、从左到右选取，保留源格纹理、自动图块形态和动画。不可通行格保持原样。没有有效观察位置时（无玩家、位置越界或观察格不可通行），隐藏所有可通行格，墙格仍可见。预览显式提供观察格。

进入区域时显示，离开后重新隐藏，存档不记录探索状态。绘制会跳过隐藏区域的 Actor 及其后代、附属粒子和光源，以及隐藏格上的伤害文字。这项显示规则不修改 Actor 的 `visible` 标记、地形数据、碰撞、寻路或事件。怪物手册在分组前通过 `isActorVisibleOnMap(actor)` 过滤，只要某种怪物仍有可见实例，就保留对应条目。

地形或观察位置变化后，可见性查询立即刷新，无需等待绘制。原生观察位置及可见性接口见 [GameMapBase](<../02.Core Modules/02.GlobalCore/02.地图与雾效.md#gamemapbase>)。
