# 视频字幕

在项目资源浏览器的 `Data/Subtitles` 下新建字幕数据，或双击已有的字幕 JSON 文件打开编辑器。支持子目录。字幕文档沿用常规的保存、撤销重做、未保存标记与关闭确认流程。

## 编辑与预览

左上区域预览画面和字幕，右上区域编辑所选片段，底部为跨栏时间轴。片段按数组序号显示，没有独立名称或标识。

![字幕编辑器的视频预览、多语言文本操作与时间轴](../../../images/editor/subtitle-edit.png)

在时间轴上新增、选择、删除或移动片段，拖动边界调整时长；缩放时间轴并拖动播放头检查指定时刻。属性区也可精确输入以秒为单位的起止时间。保存时按开始时间排序，非法时间或重叠片段会阻止保存。

每个片段有独立的多语言开关，新片段默认关闭。开启时，原文本归入 `en_GB`，文档中的其余语言填入空文本；关闭时保留当前选中的语言，丢弃该片段的其他译文前需要确认。

所有多语言片段共用语言键。语言列表底部的 `+`、`−` 按钮在整份文档中同步增删语言，右键点击语言可重命名。语言名不能为空或重复，新增语言的文本初始为空。

同一片段内，各语言的文本条数一致，不同片段可以不同。点击文本框或将焦点移入其中以选中一行，再用文本列表底部的 `↑`、`↓`、`+`、`−` 移动该行、在末尾追加空行或删除该行，操作同步到该片段的所有语言；输入文本只修改当前译文。切换语言保留选中行，切换片段选中首行。允许空文本列表和空语言列表；没有语言时禁用文本操作。

打开已有数据时，编辑器合并各多语言片段的语言键，并按每个片段的最大文本条数，为缺失语言和较短数组补齐空字符串，保留已有文本。补齐记为一笔可撤销的未保存修改；撤销后恢复原数据，直到下次内容编辑时才重新补齐，并与该次编辑共用一笔撤销记录。

通过播放/暂停、停止、当前时间和预览语言检查时序。没有参考视频时使用纯色背景，播放到最后一个片段的结束时间。空字幕数据仍可编辑。

可选择项目视频作为临时参考，或清除视频恢复纯色背景。视频保持宽高比，同步播放音频，并提供静音控制。定位时暂停音频，完成后恢复原播放状态。预览时长取视频和字幕时长的较大值；视频结束后，剩余字幕显示在纯色背景上。非 FFmpeg 工程选择视频时弹窗提示“当前不是 FFmpeg 工程”，仍可编辑字幕并使用纯色背景预览。

参考视频、预览语言、播放位置和静音设置只属于窗口会话，不写入字幕数据。

## 数据格式

在 `Data/Subtitles` 下保存 UTF-8 JSON，并用区分大小写的项目相对 `Data/Subtitles/...json` 路径引用。松散文件和 `Data.ldpak` 内的条目使用相同路径；加密的 `.ldc` 数据也使用对应的 `.json` 引用读取。路径必须位于 `Data/Subtitles` 内，不接受绝对路径或目录越界。字幕数据包含 `type: "subtitle"` 和 `sections` 数组：

```json
{
  "type": "subtitle",
  "sections": [
    {
      "startTime": 0.5,
      "endTime": 3.0,
      "content": {
        "en_GB": ["Speaker 1's content", "Speaker 2's content"],
        "zh_CN": ["角色一的内容", "角色二的内容"]
      }
    },
    {
      "startTime": 3.0,
      "endTime": 5.5,
      "content": ["所有语言共用的内容"]
    }
  ]
}
```

时间为以秒为单位的有限数值，满足 `0 ≤ startTime < endTime`。片段从开始时刻起生效，到结束时刻前截止，即 `[startTime, endTime)`。片段可首尾相接，但不能重叠；空隙期间不显示字幕。允许空的 `sections` 数组。

`content` 可以是直接使用的字符串数组，也可以是语言键到字符串数组的字典。字典先取当前游戏语言；缺少该键时回退到 `en_GB`，两者均缺失则不显示。已存在的空数组明确表示不显示，不触发回退。原生 C++ 使用 `std::variant<std::vector<std::string>, std::unordered_map<std::string, std::vector<std::string>>>` 表示这两种形式。

## 播放与布局

将字幕路径作为 [Video.PlayVideo](<../03.Lua 与蓝图脚本/06.节点函数/13.Video.md>) 的可选第四个参数传入。省略参数或传空字符串时只播放视频。指定的资源必须加载和校验成功，格式错误的字幕数据会报错。

字幕跟随视频播放时钟，播放结束或跳过时消失。渲染使用游戏默认字体和字号、白字黑描边，按数组顺序从上到下排列，按需换行，每个视觉行水平居中。整体位于逻辑视口底部，左右各保留 5%、底部保留 3% 边距。总高度超出可用区域时统一缩小至可容纳。运行时播放和编辑器原生预览共用字幕布局。
