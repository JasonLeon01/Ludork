# 脚本与玩法

## 什么时候使用蓝图、Lua 或 Script Mixin？

蓝图用于可视化地描述事件与执行流程，Lua 类用于编写可复用的系统和玩法类型，Script Mixin 则把 Lua 行为直接附加到蓝图类。同一条蓝图继承链必须统一使用图模式或 Script Mixin 模式，不能混用。详见 [Lua 运行时与模块](<../Lua 与蓝图脚本/Lua 运行时与模块.md#lua-运行时与模块>)。

## 可以不重启游戏就重载 Lua 吗？

游戏由编辑器启动且使用散放的 Lua 源文件时，保存改动后在控制台输入 `$r`。重载会更新已有函数，并保留场景、对象和运行时状态；不会重新执行 Entry，也不重载 JSON、UI 资产、Metadata、声明或原生代码。结构或数据变化可能需要重启。归档脚本或只有编译结果的脚本不支持此操作。详见 [Lua 热更新](<../Lua 与蓝图脚本/Lua 运行时与模块.md#lua-热更新>)。
