# 存档与服务器

## 为什么修改游戏变量的默认值后，旧存档没有变化？

已保存的变量声明为新游戏提供初始值。读档时，存档中的变量表会替换新实例的变量表，不会合并新增声明或迁移已有值。可以开始新游戏使用这些改动，或自行提供存档迁移。详见[游戏变量](<../Lua 与蓝图脚本/Game 玩法/运行时数据、配置与存档.md#游戏变量>)。

## 必须使用 Ludork Server 吗？它提供联机或云存档吗？

Ludork Server 是可选的 HTTP 账户数据字典存储服务，不提供多人状态同步或 RPC，也不会自动上传、下载或替换本地存档。游戏自行决定读写哪些字段。配置客户端集成需要 C++ Source 项目。详见[简易服务器](<../简易服务器/部署与编辑器设置.md#简易服务器部署与编辑器设置>)与[配置](<../Lua 与蓝图脚本/Game 玩法/运行时数据、配置与存档.md#配置>)。
