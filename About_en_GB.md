Ludork is a game editor and runtime framework for creating 2D RPGs.

It provides a cross-platform editor built with Avalonia/.NET, gameplay authoring through Lua and Blueprints, and a native runtime powered by C++20, LuaSF, and SFML. Ludork brings maps, assets, data, and game logic into one consistent visual workflow so creators can focus on building and iterating their games.
