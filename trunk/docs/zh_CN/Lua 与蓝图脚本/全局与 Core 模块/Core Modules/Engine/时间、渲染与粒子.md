# Engine：时间、渲染与粒子

本页记录帧计时器（`Clock`）、渲染状态辅助类（`RenderStates`）、CPU 精灵与文字粒子（`Particle`、`ParticleInfo`、`ParticleBase`、`ParticleSystem`、`TextParticle`），以及 GPU 粒子播放与配置 API（`Emitter`、`EmitterConfiguration`、`EmitterTrack`、`EmitterCurves`、`EmitterBurst`、`EmitterStatistics`、`EmitterComponent`、`EmitterView`）。

实例方法表省略隐式 `self` 接收者（蓝图节点将其公开为首个目标引脚，未连接时默认指向图所属对象）；构造函数与静态方法无接收者。

`clear()` 会移除所有精灵与文字粒子、解绑其归属，并释放纹理、几何、UV 与待更新缓存；清空后可继续添加新粒子。在粒子 tick 回调中调用 `clear()` 是安全的（当前更新快照中其余已解绑粒子会被跳过）。

UI 中的 CPU 粒子请使用 [Canvas.getParticleSystem](<运行时值与功能控件.md#canvas-中的-cpu-粒子>)（由 Canvas 驱动更新与绘制，独立系统则需自行管理宿主）。通用 GPU 粒子资产与 `EmitterView` 使用下文独立的 GPU 播放管线。

## Emitter

`Engine.Emitter` 独立于 `ParticleSystem`，负责驱动[通用粒子](<../../../../编辑器用户指南/通用粒子.md>)资产的 GPU 粒子播放。通常由 Actor 组件或 UI 视图持有；单独构造 `Emitter` 不会将其挂载到场景中。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `new` | `resourceKey: string = ""` | `Engine.Emitter` | 静态方法。可选 `Data/Particles` 下的无扩展名键；非空时立即加载并播放。 |
| `load` | `resourceKey: string` | — | 校验并替换资源，清空先前 GPU 状态并重新开始播放。 |
| `setConfiguration` | `configuration: Engine.EmitterConfiguration` | — | 仅限 Lua/原生（`metadata = false`）。校验轨道与曲线、烘焙采样表、替换配置并重播。 |
| `getConfiguration` | — | `Engine.EmitterConfiguration` | 仅限 Lua/原生（`metadata = false`）。返回独立快照（C++ 按值返回，Lua 返回字段表）；修改后须调用 `setConfiguration` 生效。 |
| `play` | — | — | 处于停止或暂停状态时从头启动；已在播放时保持运行。 |
| `pause` | — | — | 暂停模拟并保留存活粒子。 |
| `resume` | — | — | 沿用现有时间线继续播放并重置宿主运动历史。 |
| `restart` | — | — | 清空播放状态、将时间归零并重新执行预热（prewarm）。 |
| `stop` | `clear: bool = true` | — | `true` 清空并停止；`false` 停止新增发射与回收，继续推进时让存活粒子自然播完。 |
| `emit` | `trackName: string`, `count: int` | — | 为指定发射轨道排队非负手动发射量并开启播放。无效轨道名或常驻轨道会抛出错误；数量限幅至轨道容量。 |
| `setSpeed` | `speed: float` | — | 设置有限播放倍速，范围 `[0, 100]`（`0` 冻结时间线推进）。 |
| `getSpeed` | — | `float` | — |
| `setColour` | `colour: sf.Color` | — | 将渲染 RGBA 乘以 `colour`（`EmitterView` 绘制时自动传入 UI 表现色）。 |
| `getTime` | — | `float` | 返回已模拟秒数。 |
| `isPlaying` | — | `bool` | 返回播放标记（宿主隐藏时场景调度冻结，该标记可能仍为 `true`）。 |
| `getCapacity` | — | `int` | 返回所有启用轨道的总容量（并非实时存活粒子数）。 |
| `setProfiling` | `enabled: bool` | — | 仅限 Lua/原生。开启或关闭异步 GPU 计时。 |
| `getStatistics` | — | `Engine.EmitterStatistics` | 仅限 Lua/原生。返回统计快照，不可用的可选字段保持 `nil` 而非 `0`。 |

在 Lua 中修改活动发射器的标量配置时，先读取快照，修改后再写回：

```lua
local configuration = emitter:getConfiguration()
configuration.seed = 42
emitter:setConfiguration(configuration)
```

- **原生宿主 API**：C++ 宿主调用 `tick(float deltaTime)`、`draw(sf::RenderTarget&, sf::RenderStates = {})`、`setHostTransform(const sf::Transform&)`、`resetHostMotion()`、`shutdown() noexcept` 及静态方法 `collectGarbage() noexcept`（`deltaTime` 须为有限非负数）。
- **场景调度**：`EmitterScheduler` 每帧执行 `beginFrame()`，为活跃宿主调用 `registerEmitter(shared_ptr<Emitter>, transform)`（弱引用去重，重新进入时重置位移历史），并统一推进一次 `advance(deltaTime)`。`shutdown()` 停止已知实例并在有效上下文下回收退役图形资源。运行时脚本应通过所属组件或视图控制发射器，避免重复 tick。

## EmitterConfiguration

可复制的配置记录（`metadata = false`，不导出至蓝图元数据）。C++ 按值传递（`setConfiguration(const EmitterConfiguration&)` / `getConfiguration() const`）；Lua 读取返回普通字段表，`setConfiguration` 同时接受原生值或 Lua 表。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `name` | `string` | `""` | 编写的配置名称。 |
| `simulationRate` | `int` | `60` | 整数模拟频率，范围 `1–240`。 |
| `seed` | `int` | `1` | 整数随机种子，范围 `0–16,777,215`。 |
| `tracks` | `Engine.EmitterTrack[]` | `{}` | 有序轨道列表，轨道名须唯一。 |

该结构不包含 `type` 字段（`"type": "particle"` 仅存在于资源 JSON 中）。加载资源时已将曲线键解析为具体数值，因此 `getConfiguration()` 中不含未解析的曲线资源键。

## EmitterTrack

**继承**：`Engine.EmitterTrackParameters`

在 `Engine.EmitterTrackParameters`（C++ 中为 `ludork::runtime::graphics::EmitterTrackParameters`）基础上扩展 `curves: Engine.EmitterCurves`。计时、力场、纹理图集与变换参数沿用[通用粒子](<../../../../编辑器用户指南/通用粒子.md#资源标识与-schema>)中的名称、单位与范围，以下字段在强类型表示中有所差异：

| 资源 JSON | 强类型属性 |
|---|---|
| `mode: "emission"` / `"resident"` | `resident: false` / `true` |
| `space: "local"` / `"world"` | `world: false` / `true` |
| `blend: "alpha"` / `"add"` | `additive: false` / `true` |
| `shape: "point"`、`"line"`、`"rectangle"`、`"disk"`、`"ring"` | `Engine.EmitterShape`：`Point = 0`、`Line = 1`、`Rectangle = 2`、`Disk = 3`、`Ring = 4` |
| `scaleMode: "hierarchy"`、`"local"`、`"shape"` | `Engine.EmitterScaleMode`：`Hierarchy = 0`、`Local = 1`、`Shape = 2` |
| `colourMin`、`colourMax`：四个 `[0, 255]` RGBA 通道 | 四个 `[0, 1]` 浮点数（JSON 通道除以 `255`），均默认 `{ 1, 1, 1, 1 }`。 |
| 二维向量与最小/最大范围 | `sf.Vector2f`（范围下限为 `x`，上限为 `y`）。 |
| `textureRect: [x, y, width, height]` | 带 `position` 与 `size` 的 `sf.IntRect`。 |
| `bursts` 数组 | `Engine.EmitterBurst[]` |
| 内联曲线或曲线资源键 | 已解析的 `Engine.EmitterCurves`（包含 8 条 `Engine.CurveData`）。 |

在 Lua 中请使用原生枚举成员（或 `Enums.Engine.EmitterShape`、`Enums.Engine.EmitterScaleMode`）。强类型默认值为 `resident = world = additive = false`、`shape = Engine.EmitterShape.Point`、`scaleMode = Engine.EmitterScaleMode.Hierarchy`、`count = 32`。

将 `capacity` 调低至 `32` 以下时须显式设置有效的 `count`（JSON 加载器会单独把省略的 `count` 默认为 `min(32, capacity)`）。应用完整配置时会执行统一校验：数值范围须有限且有序、颜色通道须归一化且枚举整数有效。

## EmitterCurves

包含 8 条按归一化粒子生命周期 `[0, 1]` 采样的 `Engine.CurveData`（C++ 为 `Curve::CurveData`）属性：

- **乘法通道（默认常量 `1`）**：`speed`、`sizeX`、`sizeY`、`red`、`green`、`blue`、`alpha`。
- **叠加旋转（默认常量 `0`）**：`rotation`（以度为单位叠加）。

调用 `setConfiguration` 时会校验并应用曲线并重新开始播放。

## EmitterStatistics

`Emitter:getStatistics()` 返回的统计快照（C++ 按值返回 `ludork::runtime::graphics::EmitterStatistics`，Lua 返回普通字段表）。不可用的渲染器、计数或计时字段保持 `nil`（不填 `""` 或 `0`），连续轮询可能返回同一份已完成的采样。

| 属性 | 类型（C++ / Lua） | 说明 |
|---|---|---|
| `capacity` | `int` / `integer` | 始终存在；所有启用轨道的总容量（非实时存活数）。 |
| `time` | `double` / `number` | 始终存在；当前播放时间（秒）。 |
| `renderer` | `std::optional<std::string>` / `string \| nil` | 可用时提供渲染器标识。 |
| `aliveCount` | `std::optional<std::int64_t>` / `integer \| nil` | 位于 `sampledTime` 时刻的延迟 GPU 存活计数。 |
| `sampledTime` | `std::optional<double>` / `number \| nil` | 存活计数采样对应的模拟时间。 |
| `gpuSimulationMs`、`gpuDrawMs` | `std::optional<double>` / `number \| nil` | 最近一次可用的异步 GPU 模拟与绘制耗时（毫秒）。 |
| `simulationSample`、`drawSample` | `std::optional<std::int64_t>` / `integer \| nil` | 计时采样 ID；合并统计模拟与绘制耗时前，应按各通道去重并配对相同 ID。 |

## EmitterComponent

**继承**：`Engine.Component`

挂载于 `Actor.emitterComp`，用于在 Actor 上播放 GPU 粒子特效（仅接受 `Actor` 宿主，遵循标准组件挂载协议）。编辑器配置详见 [Emitter 组件](<../../../../编辑器用户指南/Actor 组件/Emitter.md>)。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `resource` | `string` | `""` | `{ enum = "Enums.Particle", valueType = "string" }`；来自实时项目目录的 `Data/Particles` 无扩展名键，留空禁用特效。 |
| `anchor` | `sf.Vector2f` | `[0.5, 0.5]` | Actor 本地边界内的归一化锚点。 |
| `offset` | `sf.Vector2f` | `[0, 0]` | 附加本地偏移（逻辑像素）。 |
| `rotation` | `float` | `0` | 本地旋转角度（度）。 |
| `scale` | `sf.Vector2f` | `[1, 1]` | 本地缩放。 |
| `beforeActor` | `bool` | `false` | `true` 时紧随 Actor 之前绘制，`false` 时紧随之后绘制。 |

所有权与生命周期规则：

- `getEmitter()` 按需懒创建并返回 `Engine.Emitter`；修改或清空 `resource` 会立即释放旧实例。运行时粒子状态不参与存档序列化。
- 替换 `actor.emitterComp` 或赋值 `nil` 会立刻清理旧组件的播放状态，即使 Actor 处于休眠态或别处仍持有旧组件/发射器引用亦然。常规地图生成会自动调用 `onAttach(actor)`；生成后动态安装的组件同样须通过组件协议挂载才能加入场景调度。
- 地图渲染遵循常规 Actor 列表与图层顺序。不可见或休眠的 Actor 会冻结播放但不改变暂停标记；销毁、区域卸载、地图切换与场景关闭均会清空并释放播放实例。组件仅持有宿主 Actor 的弱引用，只负责管理自身播放实例。

## EmitterView

**继承**：`Engine.ControlBase`

无子节点的视觉 UI 控件，用于在 `Canvas` 或 `ListView` 中播放 GPU 粒子特效，遵循标准 Slot 布局、父级绘制顺序与裁剪规则。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `new` | `particle: string = ""`, `size: sf.Vector2f = sf.Vector2f.new(100, 100)`, `anchor: sf.Vector2f = sf.Vector2f.new(0.5, 0.5)`, `autoPlay: bool = true` | `Engine.EmitterView` | 静态方法。`size` 决定 UI 逻辑像素布局尺寸，`anchor` 定位内部发射器位置。 |
| `getEmitter` | — | `Engine.Emitter` | 返回共享的 `Emitter` 播放对象。 |
| `getParticle` | — | `string` | — |
| `setParticle` | `key: string` | — | 切换粒子资源键并清空先前特效。 |
| `getSize` | — | `sf.Vector2f` | — |
| `setSize` | `size: sf.Vector2f` | — | — |
| `getAnchor` | — | `sf.Vector2f` | — |
| `setAnchor` | `anchor: sf.Vector2f` | — | — |
| `getAutoPlay` | — | `bool` | — |
| `setAutoPlay` | `value: bool` | — | 设置加载资源或切换 Canvas 时的自动播放策略；不会立即启动或暂停。 |

其 `world` 粒子空间对应所属 Canvas 的逻辑坐标系（与地图视口独立），UI 合成仅应用一次全局缩放。迁移到其他 Canvas 会重置特效；隐藏或卸载时冻结并保留存活粒子，恢复显示时保留手动暂停状态。生成的 UI View 为已编写的粒子节点暴露强类型引用（例如 `view.sparkNode:getEmitter():pause()`）。
