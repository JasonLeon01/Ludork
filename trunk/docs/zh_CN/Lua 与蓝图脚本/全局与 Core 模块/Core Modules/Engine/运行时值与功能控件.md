## Button

**继承**：`Engine.Image`、`Engine.FunctionalBase`

支持悬停/按下着色状态及可选手柄快捷提示的交互图像按钮。

- **背景**：声明式 `Button` 的 `texture` 留空时，自动绘制当前窗口皮肤的选择框图像。无论默认背景还是自定义纹理，在所有输入设备上均保持可见，且不改变控件尺寸、全局边界、命中区或独立文字控件。
- **手柄绑定**：`gamepadButton`（逻辑按键名如 `"X"`，默认 `""` 表示未绑定）与 `gamepadLongPress`（默认 `false`）用于绑定手柄快捷触发。Lua 中调用 `button:setGamepadButton(Engine.JoystickButton.getX())`（传 `nil` 清除）与 `button:setGamepadLongPress(true)`。
- **手柄提示外观**：当 `Engine.Input.getInputHintDevice()` 为 `Engine.InputHintDevice.Gamepad` 时，绑定按键以 `16` 逻辑像素圆形垂直居中绘制在按钮内侧右缘（不受背景拉伸影响），与 [`GamepadHintBar`](<交互与声明式 UI 控件.md#gamepadhintbar>) 共用白底、黑色字形与顺时针绿色长按进度扇形。禁用按钮的提示呈灰色显示。
- **手柄触发**：短按触发一次 `onConfirm` / `addConfirmCallback`；长按满 1 秒触发一次，须松开后才能再次触发。按钮无需获得焦点即可响应，但按钮自身与所属窗口均须处于可见且可交互状态（隐藏、禁用、窗口失活或手柄断开均会清空进度）。

### 属性

除常规纹理与颜色配置外，声明式属性包含 `gamepadButton`（默认 `""`）与 `gamepadLongPress`（默认 `false`）。

### Canvas 中的 CPU 粒子

- **归属与更新**：`getParticleSystem()` 懒创建并返回该 Canvas 独立的 CPU `ParticleSystem`。`Canvas` 自动驱动其 tick、late-tick 与 fixed-tick 阶段（切勿在 Lua 中重复 tick）；隐藏或卸载的 Canvas 树遵循常规 UI 生命周期暂停。
- **绘制与坐标**：粒子在普通子控件与动画之后、浮层之前绘制，采用 Canvas 逻辑坐标与裁剪。创建 `TextParticle` 时请设 `logicalCoordinates = true`。Canvas 合成仅应用一次显示缩放、变换、着色与淡入淡出（勿将窗口透明度重复复制到粒子上）；文本配置独立于粒子的变换与颜色修改。
- **清理**：关闭或重置特效宿主时应调用 `clear()`（系统清空后可复用；Canvas 销毁时即使别处仍持有引用也会自动清空）。`ScrollBox` 继承了此集成能力；`Engine.Window` 仅作窗口皮肤视觉控件，不作为 Canvas 宿主。

## FunctionalBase

**继承**：`Engine.FocusableMixin`

交互行为基础 Mixin，提供指针、触摸、键盘与手柄输入分发、捕获以及逐帧更新钩子。

### 输入事件数据

输入方法与回调均接收 `Engine.UiInputEventArguments`。指针事件填充 `position: sf.Vector2f`；鼠标按键事件附加 `button: sf.Mouse.Button`；滚轮事件附加 `delta: number`。所有字段均可选，键盘事件中省略。以代码触发确认或取消时请构造 `Engine.UiInputEventArguments.new({})`。

### 交互资格

仅当 `FunctionalBase` 自身及其全部 `FunctionalBase` 祖先均处于激活态，且自身及其全部 `ControlBase` 祖先均可见时，控件才会接收焦点与输入（`getActive` 与 `getVisible` 仅查询本地状态）。失去交互资格会清除整棵子树的指针与触摸捕获，并在松开前持续消费已取消手势，但逐帧更新与绘制照常进行。

### 触摸捕获

- `setTouchHitBounds(bounds)` 设置可选的本地逻辑坐标触摸专用命中矩形（要求有限坐标与非负尺寸；传 `nil` 恢复默认）。`getAbsoluteTouchHitBounds()` 返回经显示缩放与层级变换后的屏幕轴对齐矩形（混入 `ControlBase` 时默认取其绝对边界，独立 `FunctionalBase` 返回 `nil`）。
- 具备交互资格的控件会捕获起始于其绝对触摸命中区内的主触点，并在手指移出区域后继续接收移动与抬起事件。在区域外松开会清除按下态、不触发点击或确认，但仍消费该次轻触以防穿透激活下层控件。多指取消同样释放捕获。触摸命中区不影响鼠标命中测试。

### 指针点击

鼠标按下仅启动指针捕获，不立即触发 `onClick`。仅当按下的按键在悬停于同一控件时松开才触发 `onClick`（在外部松开只清除按下态），并传入松开的 `button` 供左键回调筛选。触摸轻触遵循上述触摸捕获规则，存在确认回调时优先触发 `onConfirm`。
