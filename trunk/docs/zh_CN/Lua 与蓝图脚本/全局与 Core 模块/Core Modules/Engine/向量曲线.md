# Engine：向量曲线

本页记录 `Engine` 下的二维、三维与四维动画曲线类型（`Vector2Curve`、`Vector3Curve`、`Vector4Curve`）及其关键帧与可序列化数据记录。向量曲线与标量曲线共用[插值常量](<标量曲线.md#curvekey>)与[外推模式常量](<标量曲线.md#curve>)。实例方法表格省略作为首个蓝图目标引脚暴露的隐式 `self` 接收者；静态方法不接收调用对象。

## Vector2CurveKey

定义 `Vector2Curve` 上的单个二维关键帧。

### 属性

| 属性 | 类型 | 默认值 | 说明 |

| `time` | `float` | `0` | — |
| `value` | `float[]` | — | — |
| `interpolation` | `string` | `"linear"` | — |
| `arriveTangent` | `float[]` | — | — |
