# Engine：动画数据与图形

本页记录 `Engine` 下的图形辅助函数（`BuildPixelGridVertices`、`compressAnimation`）、动画数据记录（`AnimationKeyFrame` 至 `AnimationData`）以及渲染图元（`RectBase`、`TileLayerGraphics`）。实例方法表格省略作为首个蓝图目标引脚暴露的隐式 `self` 接收者；自由函数不接收调用对象。

## 模块图形函数

| 函数 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `BuildPixelGridVertices` | `origin: sf.Vector2f`, `size: sf.Vector2u` | `sf.VertexArray` | 仅限 Lua（不生成蓝图节点）。为每个像素构建六个三角形顶点，并使用该像素中心的纹理坐标。输入尺寸为零时返回空三角形数组，顶点数溢出时抛出错误。 |
| `compressAnimation` | `source: Engine.AnimationSourceData \| nil`, `imageFormat: string = "png"` | `Engine.AnimationData` | 压缩 `source.assets` 中列出的帧图像。不接受资产根目录参数。 |
