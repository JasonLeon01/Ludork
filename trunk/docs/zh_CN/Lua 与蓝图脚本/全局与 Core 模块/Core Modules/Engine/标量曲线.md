## CurveKey

`Engine.CurveInterpolation` 为键的 `interpolation` 提供只读字符串：`CONSTANT = "constant"`、`LINEAR = "linear"`、`CUBIC = "cubic"`。标量曲线与向量曲线共用这些值。

## Curve

`Engine.CurveInfinityMode.CONSTANT`（`"constant"`）在键范围外保持端点值；`LINEAR`（`"linear"`）沿最前两个或最后两个键之间的斜率延伸。标量曲线、向量曲线及其数据记录的 `preInfinity` 和 `postInfinity` 都使用这些只读字符串；外推模式不包含 cubic。
