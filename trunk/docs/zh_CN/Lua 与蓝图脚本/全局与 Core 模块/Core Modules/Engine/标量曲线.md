# Engine：标量曲线

本页记录 `Engine` 下的压缩帧动画精灵播放器（`AnimSprite`）以及标量动画曲线类型（`CurveKey`、`CurveData`、`Curve`）。实例方法表格省略作为首个蓝图目标引脚暴露的隐式 `self` 接收者；静态方法不接收调用对象。

## CurveKey

定义标量曲线上的单个关键帧。`Engine.CurveInterpolation` 为 `interpolation` 提供只读字符串常量：`CONSTANT = "constant"`、`LINEAR = "linear"` 与 `CUBIC = "cubic"`，标量曲线与向量曲线共用这些值。

### 属性

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `time` | `float` | `0` | — |
| `value` | `float` | `0` | — |
| `interpolation` | `string` | `"linear"` | — |
| `arriveTangent` | `float` | `0` | — |
| `leaveTangent` | `float` | `0` | — |

## Curve

可求值的标量动画曲线。`Engine.CurveInfinityMode` 为标量曲线、向量曲线及其数据记录的 `preInfinity` 与 `postInfinity` 提供只读字符串常量：`CONSTANT`（`"constant"`）在关键帧范围外钳制为端点值，`LINEAR`（`"linear"`）沿首尾两个关键帧之间的斜率线性延伸。外推模式不包含三次（cubic）外推。

|---|---|---|---|

| `defaultValue` | `float` | `0` | — |

| `keys` | `Engine.CurveKey[]` | — | — |
