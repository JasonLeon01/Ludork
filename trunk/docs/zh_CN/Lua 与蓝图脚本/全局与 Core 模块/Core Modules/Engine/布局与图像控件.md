# Engine：布局与图像控件

本页记录 `Engine` 下的图像、角色预览、布局容器与矩形控件：`Image`、`CharacterView`、`ListView`、`WrapBox`、`ScrollBox`、`Rect`、`SolidRect` 与 `SpriteBase`。实例方法表格省略作为首个蓝图目标引脚暴露的隐式 `self` 接收者。

## Image

**继承**：`Engine.SpriteBase`

显示拉伸或平铺图像（`FunctionalImage` 继承此 API）。

- **`drawAs` 模式**：使用已绑定的 `Engine.ImageDrawAs` 枚举（`Image` 或 `Tile`，默认 `Engine.ImageDrawAs.Image`），通过 `getDrawAs()`、`setDrawAs(mode)` 或 `drawAs` 属性访问。Lua 必须传入枚举成员（例如 `image:setDrawAs(Engine.ImageDrawAs.Tile)`），不可传数字或字符串；声明式 JSON 序列化为 `"Image"` 或 `"Tile"` 并解码还原为枚举值。
- **缩放与平铺**：`Image` 随局部缩放增大而拉伸图像；`Tile` 通过 SFML 纹理重复按源尺寸平铺并裁剪边缘不足一块的部分。两种模式下全局 UI Scale 均整体缩放最终结果。
- **独立重复纹理**：每个 `Image` 各自持有重复纹理，切换模式不会影响共享源纹理的其他控件。可选 `textureRect` 定义平铺单元，并在纹理或矩形变化时刷新独立纹理。

## CharacterView

**继承**：`Engine.FunctionalImage`

通过 2D 材质管线在固定 `size` 边界内渲染逐帧动画角色与敌人图集。

- **构图与动画**：`textureRect` 选取初始帧，`characterScale` 先对其进行缩放，随后居中并在超出边界时缩小适配（不放大）。`animatable` 为 `true` 且 `switchInterval` 为正时推进等宽横向帧序列（非正值暂停动画）。`setFrameRect` 更新复位帧，更改声明式 `texture` 会将其重置为完整纹理。不可见的 `CharacterView` 跳过渲染（包括直接调用 `draw`）。
- **材质与运行时数据**：`material` 为空或完整 `Data/Materials/...json` 路径，`materialParameters` 持有逐控件独立覆盖（不与 Actor 共享）。更改材质后须再设置参数。资产属性（`size`、`texture`、可选 `textureRect`、`characterScale`、`animatable`、`switchInterval`、`material`、`materialParameters`、`colour`）提供编辑器预览值；运行时代码将实时 Actor 资源与参数快照传给 `setCharacter`。

## ListView

**继承**：`Engine.ControlBase`、`Engine.FunctionalBase`

支持为超宽子控件开启水平跑马灯滚动的多列纵向布局容器。不可见的 `ListView` 跳过绘制及绘制阶段的布局准备；可见列表仅绘制可见子控件。各更新阶段（`update`、`lateUpdate`、`fixedUpdate`）均先更新可见的功能子控件，再运行列表自身的 tick 钩子。

布局查询与子项滚动行为：

- **布局查询**：`getDefaultItemSize()` 以逻辑像素返回原生列宽与资产定义的默认行高。`getItemLayoutRect(index)` 返回从 0 开始的单元格在列表局部坐标下的矩形（列宽及固定行高或该行最高子项高度），结算待处理布局并拒绝越界索引。动态行尺寸、选中框与命中测试应直接使用这些值，而无需在 Lua 中重复实现列表间距计算。
- **内容边界**：禁用子项滚动时，`getContentBounds()` 返回可见子控件布局后的并集（而非仅返回声明尺寸），使外层 `ScrollBox` 仅在布局范围严格超过视口时才可滚动。
- **水平子项滚动**：`childScrollingEnabled` 默认为 `false`（可在 Inspector 或通过 `setChildScrollingEnabled(true)` 启用）。缩放后局部宽度超过 `(size.x - 32) / columns` 的可见子项从左对齐开始，停顿 `1` s 后以 `30` 逻辑像素/秒向左滚动至右边缘完全可见，再停顿 `1` s 并重置（未超宽子项保持居中并遵循原点与缩放；速度与停顿均为固定原生常量）。
- **滚动生命周期**：仅 `update(deltaTime)` 推进滚动；隐藏子项、列表或任一祖先会暂停滚动。局部边界、原点、缩放或列宽变化会在下次测量（或调用 `invalidatePositions()` 与 `applyPositions()`）后重新开始滚动；禁用该选项会立即恢复居中排布，移除子项则丢弃其滚动状态。
- **滚动时的裁剪与边界**：启用期间，子项绘制与后代命中区域在水平方向裁剪至所在列（弹出覆盖层沿用正常行为），选中单元格位置保持固定，`getContentBounds()` 水平方向报告声明宽度，纵向仍按布局后子项高度计算。

## WrapBox

从左向右重复实例化单个已编辑的子模板（含其完整子树），下一项超出可用宽度时自动换行。原生资产实例化直接构造相互独立的实例，无需 Lua 克隆。

声明式属性包括 `size`（默认 `[100, 100]`）、`count`（默认 `1`）与 `spacing`（默认 `[0, 0]`），空 List Slot 内最多包含一个模板。单元尺寸取决于布局完成后的模板；负间距允许重叠，前提是水平与垂直排布步长仍保持为正。重新布局会保留现有实例及其状态。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `getSize` | — | `sf.Vector2f` | — |
| `setSize` | `size: sf.Vector2f` | — | — |
| `getCount` | — | `int` | — |
| `setCount` | `count: int` | — | 非负数量；增大时追加实例，减小时仅释放被移除的尾部实例。 |
| `getSpacing` | — | `sf.Vector2f` | — |
| `setSpacing` | `spacing: sf.Vector2f` | — | — |
| `get` | `i: int` | `Engine.ControlBase` | 从 1 开始索引；越界抛出错误。 |

`count` 为 `0` 或未设置模板时不创建任何实例。`WrapBox` 持有各重复控件的更新、输入与释放生命周期。生成的 View 仅暴露 `WrapBox` 本身，模板后代位于各实例边界之内，通过 `get(i)` 及该控件的子控件 API 访问。编辑器预览全部重复项，编辑任一项均直接修改资产中的唯一模板。

## ScrollBox

**继承**：`Engine.Canvas`

各滚动轴依据可见直接子控件的内容边界判定，仅当内容超出视口时激活（否则偏移量与最大偏移量均为零）。写入偏移、调整尺寸或缩小内容后均自动钳制偏移量；渲染与后代命中测试均裁剪至视口范围。

普通滚轮刻度每次滚动 `32` 逻辑像素，精确滚轮增量按轴直接应用。触摸拖动超过输入阈值后生效且无惯性；选择列表点击、Config Slider 方向归属与 DropBox 弹出列表输入均保持原有语义。

### 窗口皮肤溢出提示

系统窗口皮肤必须在 `(144, 16)` 处包含完整的 `32×32` 提示图集（尺寸更小的皮肤会抛出错误）。`ScrollBox` 忽略中央 `(156, 28, 8, 8)` 与四个角，以最近邻方式采样以下区域：

| 方向 | 源矩形 | 视口位置 | 显示条件 |
|---|---|---|---|
| 上 | `(156, 16, 8, 12)` | 顶边水平居中 | `offset.y > 0` |
| 下 | `(156, 36, 8, 12)` | 底边水平居中 | `offset.y < maximum.y` |
| 左 | `(144, 28, 12, 8)` | 左边垂直居中 | `offset.x > 0` |
| 右 | `(164, 28, 12, 8)` | 右边垂直居中 | `offset.x < maximum.x` |

提示图标随全局 UI `Scale` 缩放、采用最近邻采样并绘制在内容之上，不影响滚动、边界或命中测试。
