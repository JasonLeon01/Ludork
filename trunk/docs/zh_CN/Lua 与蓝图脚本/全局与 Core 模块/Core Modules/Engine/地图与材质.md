# Engine：地图与材质

本页记录地图雾效配置（`MapFogSettings`）、图块图层与图块地图（`TileLayer`、`Tilemap`、`TileLayerData`）、图块集/自动图块定义（`AutoTile`、`Tileset`）以及 2D 材质图与图形缓存准备 API。实例方法表格省略作为首个蓝图目标引脚暴露的隐式 `self` 接收者；构造函数与静态方法不接收调用对象。

材质引用使用完整的 `Data/Materials/...json` 路径，`AutoTile.fileName` 与 `Tileset.fileName` 分别使用 `/Game/Assets/Autotiles/...` 与 `/Game/Assets/Tilesets/...` 纹理路径。

## MapFogSettings

`Engine.MapFogSettings.new(table)` 创建供地图与原生渲染器使用的强类型雾配置。省略的字段保留以下默认值：

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | `bool` | `false` | 启用雾层。 |
| `colour` | `sf.Color` | `[255, 255, 255, 255]` | 雾颜色与 Alpha（不透明白色）。 |
| `density` | `float` | `0.5` | `[0, 1]` 范围内的密度；`0` 无可见效果。 |
| `scale` | `float` | `256` | 世界像素单位的正数噪声尺度。 |
| `velocity` | `sf.Vector2f` | `[15, 15]` | 每秒飘移的世界像素速度。 |
| `turbulence` | `float` | `0.5` | `[0, 1]` 范围内的噪声扭曲强度。 |
| `seed` | `int` | `0` | 有符号 32 位确定性种子。 |

所有数值字段必须有限。原生 Lua 构造接受 `sf.Color` 与 `sf.Vector2f` 值；序列化地图与大地图 JSON 保存包含全部七个字段的完整 `fog` 对象，其中 `colour` 为四个 `[0, 255]` 整数通道，`velocity` 为二元数值数组。地图数据解析器拒绝未知字段与旧版纹理雾格式。

```lua
local settings = Engine.MapFogSettings.new({
    enabled = true,
    colour = sf.Color.new(210, 225, 240, 255),
    density = 0.4,
    scale = 256,
    velocity = sf.Vector2f.new(15, 15),
    turbulence = 0.5,
    seed = 42
})
gameMap:setFogSettings(settings)
```

## 材质资源

源材质文件位于 `Data/Materials/<名称>.json`，包含 `type: "material"` 与 `version: 1`。

- **默认材质与路径**：共享标准材质为 `Data/Materials/Global/Standard.json`，Actor 材质引用为空时自动选用它。效果示例与 `Surfaces` 预设分别位于 `Data/Materials` 与 `Data/Materials/Surfaces`。图块或自动图块的基础材质为空时使用内置中性表面；非空引用无效时会失败。辅助纹理使用规范的 `/Game/Assets/...` 路径，精灵纹理、当前帧、变换与时间由宿主提供。
- **已准备的运行时缓存**：初始化阶段会在用户数据目录生成着色器与运行时元数据，渲染阶段加载这些已准备文件（含加密形式）。准备范围覆盖所有单独材质，以及从已保存地图与编辑器[额外组合](<../../../../编辑器用户指南/材质.md#材质组合>)中收集到的基础/图层材质组合。
- **动态组合**：若某组合仅出现在动态构造地图或运行时更换图层材质中，须预先登记（Actor/UI 切换材质与参数修改无需额外登记）。绘制未准备的组合会直接失败，不会在渲染期间编译。
- **原生 C++ 预览覆盖**：`MaterialResource::load` 加载已准备的运行时资源，`MaterialResource::fromData` 从节点图定义构造资源以供缓存生成或预览编译使用。预览集成可保留 `MaterialResource::Overrides` 快照并在同一预览线程通过 `ScopedOverrides` 按请求激活（文档变更时替换快照；作用域不跨请求持久生效）。详见[运行时生成](<../../../../编辑器用户指南/材质.md#运行时生成>)。

| 文件部分 | 内容 |
|---|---|
| `parameters` | 参数数组，包含稳定 `id`、`type`、`default` 以及可选 `displayName`、`group`、`min` 与 `max`。 |
| `graph.nodes` | 包含 `id`、官方 `type`、`inputs` 与 `properties` 的节点列表。每项输入为字面量或 `{ "node": "id", "port": "output" }`。 |
| `graph.output` | `Surface` 输出节点的 ID。 |
| `rendering.maxVertexOffset` | 局部像素坐标下的最大绝对位移 `[x, y]`，默认为 `[0, 0]`。 |
| `editor.positions` | 节点 ID 到画布位置的映射，仅供编辑器使用。 |

参数类型包括 `bool`、`float`、`vec2`、`vec3`、`vec4`、`color` 与 `texture`（向量为数值数组，颜色为 `[0, 1]` 范围内的四个归一化通道）。可选 `displayName` 仅更改编辑器显示标签，不改变稳定 `id`。类型无效、参数 ID 未知或值越界均会失败。材质图是强类型无环数据流图，不含玩法执行引脚或自定义 GLSL 节点。

### 规划图形缓存

设置应用名后，调用 `Engine.planGraphicsCaches()` 可一并检查材质产物与默认着色器程序。该方法返回仅限 Lua 的 `Engine.GraphicsCachePlan`（同一运行时内的重复调用共享当前活动计划）。逐帧轮询 `getStatus()`：

| 状态 | 操作 |
|---|---|
| `"planning"` | 等待输入与缓存检查完成。 |
| `"planned"` | 读取 `needsMaterialExport()` 与 `needsShaderCompilation()` 选择进度文案，随后即使缓存命中也须调用 `startMaterials()`。 |
| `"materials"` | 正在发布材质产物。 |
| `"materialsReady"` | 调用 `startShaders()`（缓存命中仍需恢复已准备的着色器程序）。 |
| `"shaders"` | 正在恢复或编译着色器。 |
| `"ready"` | 调用 `getResult()` 收尾。 |
| `"failed"` 或 `"cancelled"` | `getResult()` 抛出保存的失败错误或取消状态错误。 |

`getProgress()` 返回当前活动阶段 `0–1` 范围内的进度。请仅在对应的等待状态启动下一阶段，并仅在规划成功后读取两个工作标志。

> **重要**：计划处于 `"planned"` 与 `"materialsReady"` 等待状态时会持有图形准备锁，阻塞其他准备任务。若放弃计划或提前离开场景，务必调用 `cancel()` 停止工作线程并释放锁。需要自定义阶段组合时，请使用[着色器准备接口](#mrb-着色器准备)。

### 材质缓存准备

`Engine.prepareMaterialCache()` 启动后台材质准备并返回仅限 Lua 的 `Engine.MaterialCacheRequest`（不生成蓝图节点）。请在设置应用名之后、创建依赖材质的图形之前调用并完成准备；该阶段生成 GLSL 与运行时元数据，不预编译 GPU 程序。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `getStatus` | — | `string` | 仅限 Lua。不等待，返回 `"pending"`、`"ready"`、`"failed"` 或 `"cancelled"`。 |
| `getProgress` | — | `float` | 仅限 Lua。返回 `0–1` 范围内的准备进度。 |
| `getResult` | — | — | 仅限 Lua。Ready 时无返回值，Failed 时重抛保存的错误，Pending/Cancelled 时抛出状态错误。 |
| `cancel` | — | — | 仅限 Lua。请求取消并等待工作线程结束。 |

请在后续帧中轮询以保持初始化界面刷新，在 Ready 或 Failed 时调用 `getResult()` 传播错误，离开初始化场景时取消请求。缓存策略与加密设置见[运行时生成](<../../../../编辑器用户指南/材质.md#运行时生成>)。

### MRB 着色器准备

`Engine.prepareShaderCache(additionalPrograms = {})` 返回仅限 Lua 的 `Engine.ShaderCacheRequest`（不生成蓝图节点），并与[材质缓存准备](#材质缓存准备)共用 `getStatus`、`getProgress`、`getResult` 与 `cancel` 契约。须在设置应用名且完成材质缓存之后，加载游戏着色器或构造依赖它们的图形之前调用（默认 `SceneInit` 使用[规划图形缓存](#规划图形缓存)）。

- **程序清单格式**：`additionalPrograms` 为路径数组组成的数组，每个内部数组声明一个程序，使用 `.vert`、`.geom` 与 `.frag` 的 `/Game/Assets/...` 路径（加密资产仍保留源文件后缀）。
- **自动与显式条目**：默认准备涵盖引擎程序、材质 Pass、独立资产与同名顶点/片段配对。非同名配对、完整几何着色器程序，或需独立于同名配对单独加载的阶段均须在此登记。显式条目中的路径会从自动配对与单阶段推断中排除，因此须列出计划加载的每个完整程序或独立阶段。
- **去重与冲突**：重复条目会自动去重。请求挂起期间，以相同程序集合再次调用（不计顺序与重复项）会复用当前请求，而传入不同程序清单会被拒绝而非合并。目标后端不支持的几何着色器阶段会失败。

```lua
local request = Engine.prepareShaderCache({
    { "/Game/Assets/Shaders/Custom/Shared.vert", "/Game/Assets/Shaders/Custom/Tint.frag" }
})
```

进入 Ready 且 `getResult()` 成功后，对应的 `ShaderManager.loadFull` 即可加载该程序；未准备的组合会直接失败，不会在渲染期间编译。平台格式、加密与缓存归属见 [MRB 渲染](<../../../../C++ 原生开发/构建与模块布局.md#mrb-渲染>)。

### Surface 输出

| 输出 | 含义与默认值 |
|---|---|
| `BaseColor` | 从当前精灵采样得到的 RGB。 |
| `Alpha` | 控制最终可见轮廓的精灵透明度。 |
| `Emission` | 局部 LDR RGB 自发光（默认为零），不照亮其他对象。 |
| `LightingWeight` | `1` 接受场景光照，`0` 不受光，中间值在两者间混合。 |
| `LightBlock` | 逐像素阻光量（默认 `0`），与最终 `Alpha` 共同决定光线穿过可见轮廓的透光率。 |
| `ReflectionStrength` | 格子镜面反射强度（默认 `0`）。 |
| `VertexOffset` | 局部二维位移（默认为零）。 |

节点图求值与节点规则：

- **表面合成**：未连接的输出保留其 Surface 输入（默认为接受完整 `LightingWeight` 且零自发光、零阻光、零反射的原始精灵）。宿主着色与展示透明度由渲染器统一应用一次；光照、自发光与反射在标准透明混合前完成合成，确保前景对象能正常遮挡自发光表面。不支持 HDR、Bloom、法线贴图与 PBR。
- **官方节点**：`Constant`、`Parameter`（`properties.id` 指定引用的暴露参数）、`Time`、`LocalUV`、`LocalPosition`、`WorldPosition`、`FrameSize`、`SurfaceInput`、`SampleSprite`、`SampleTexture`、标量/向量算术、`Dot`、`Abs`、`Floor`、`Fract`、`Sin`、`Clamp`、`Smoothstep`、`Lerp`、`Compose`、`Swizzle` 与 `HueShift`（角度制）。
- **精灵采样**：`SampleSprite` 接收帧局部 UV 并输出 `Color`、`Alpha` 与 `RGBA`，超出当前帧边界返回透明。像素偏移须先除以 `FrameSize` 再加到 `LocalUV` 上；自动图块采样作用于拼合后的完整格子，可跨越内部半格接缝。
- **顶点位移与图层叠加**：`VertexOffset` 分支可使用坐标、时间、参数与数学运算，但不可采样纹理；结果受 `maxVertexOffset` 钳制，可见性剔除也会计入该余量。图块材质先于图层材质运行，两者均按原始坐标计算位移后相加。图层材质仅修改已连接的输出，绝不影响同层 Actor（因此 `WaterWind` 可仅位移图块而保留各图块的表面属性）。

### Actor 实例参数

`actor.material` 与 `actor:getMaterial()` 返回实际生效的资源路径；赋值 `""` 或调用 `actor:setMaterial("")` 会选用 `Standard`。`Actor.materialParameters` 是兼容 JSON 的实例覆盖字典。

- 切换至其他材质会清空旧覆盖，因此须先设置材质路径再设置参数。
- `getMaterialParameter(id)` 返回实际生效值，`setMaterialParameter(id, value)` 仅覆盖当前 Actor，`resetMaterialParameter(id)` 恢复资源默认值。直接为字典赋值可替换整套覆盖（仅修改返回的副本不会更新 Actor）。

```lua
actor:setMaterial("Data/Materials/Frozen.json")
actor:setMaterialParameter("opacity", 0.65)
actor:setMaterialParameter("hue", 20)
actor:resetMaterialParameter("hue")
```

蓝图默认值与地图实例覆盖会持久化材质路径与参数字典，临时运行时修改如需随存档保留须显式记录。移动速度属于 Actor 玩法状态，不属于材质参数。

默认项目内置 `Standard`、`Rainbow`、`Frozen`、`Burning`、`Petrify`、`Ghost`、`Poison`、`Crystallize`、`Hologram` 与 `WaterWind` 节点图材质；标准材质与角色示例暴露 `opacity`、`hue`、`lightBlock`、`reflectionStrength` 与 `lightingWeight`。着色器生成与绑定由引擎托管，Actor 不暴露原始着色器路径或句柄。

## Tileset
