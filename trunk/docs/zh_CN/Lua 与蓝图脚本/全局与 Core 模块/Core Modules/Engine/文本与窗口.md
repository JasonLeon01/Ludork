# Engine：文本与窗口

本页记录文本配置构建器与测量辅助库（`Engine.TextConfig`、`Engine.TextLayout`）、文本样式记录（`TextOutlineConfig`、`TextGlowConfig`、`TextGradientConfig`、`TextStyle`、`PlainTextConfig`、`RichTextConfig`）、文本控件（`PlainText`、`RichText`）以及九宫格窗口控件（`Window`）。实例方法表格省略作为首个蓝图目标引脚暴露的隐式 `self` 接收者；自由函数不接收调用对象。

## Engine.TextConfig

为 `Global.Data` 与声明式 UI 构建经过校验的纯文本与富文本配置。输入表必须兼容 JSON，函数、原生对象与循环引用均会被拒绝。编辑器编辑方式见[文本配置](<../../../../编辑器用户指南/通用数据与文本配置.md#文本配置>)。

| 函数 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `buildPlain` | `data: table`, `sourceName: string` | `Engine.PlainTextConfig` | — |
| `buildRich` | `data: table`, `sourceName: string` | `Engine.RichTextConfig` | — |

## Engine.TextLayout

在不修改传入文本控件的前提下，对 UTF-8 文本执行测量、截断与换行；`maxWidth` 必须为正的有限数。

| 函数 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `measurePlainText` | `control: Engine.PlainText`, `text: string` | `number` | — |
| `measureRichText` | `source: Engine.RichText`, `text: string` | `number` | — |
| `fitPlainText` | `text: string`, `maxWidth: number`, `control: Engine.PlainText` | `string` | 文本可容纳时原样返回；否则按字素边界截断并在 `maxWidth` 内追加 `.`（若连 `.` 也无法容纳则返回 `""`）。 |
| `wrapPlainText` | `text: string`, `maxWidth: number`, `control: Engine.PlainText` | `string` | — |
| `wrapRichText` | `text: string`, `maxWidth: number`, `source: Engine.RichText` | `string` | — |

富文本测量与换行使用传入控件的已编辑配置（包括具名标签样式），且不会更改其文本或播放状态。

**继承**：`Engine.SpriteBase`
