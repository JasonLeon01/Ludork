# Engine：事件与模块根

本页记录异步操作（`AsyncOperation`）、发布/订阅消息总线（`EventBus`）、`Engine` 模块根查询与常量、资源文件常量、编辑器实时调试、原生网页视图、类型化/JSON/LDC 数据读写以及异步存档预览（`SavePreviewReader`）。实例方法表格省略作为首个蓝图目标引脚暴露的隐式 `self` 接收者；构造函数、静态方法与模块级函数不接收调用对象。

## AsyncOperation

`Engine.AsyncOperation` 表示 Lua 与蓝图共用的异步操作。Lua 调用方在协作任务中通过 `asyncio.await(operation)` 等待，蓝图潜伏节点则按其声明的阶段恢复执行。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `new` | `poll?: function(operation: Engine.AsyncOperation)` | `Engine.AsyncOperation` | 静态方法。创建挂起状态的操作。可选 `poll(operation)` 在每次逻辑更新执行一次，直至完成或取消。 |
| `emit` | `value: any` | — | 发布中间蓝图阶段，不会完成 Lua 等待方。 |
| `complete` | `result?: any` | — | 以单个保留结果完成操作，同时作为最终蓝图阶段值（`nil`、`false` 与 `0` 均为有效结果）。 |
| `cancel` | — | — | 取消操作及其等待中的执行。已完成或已取消的操作保持不变。 |
| `getStatus` | — | `string` | 返回只读常量 `AsyncOperation.PENDING`（`"pending"`）、`COMPLETED`（`"completed"`）或 `CANCELLED`（`"cancelled"`）。 |
| `getResult` | — | `any` | 读取已完成的结果；挂起或已取消的操作会抛出错误。 |

执行与清理语义：

- 多个等待方可共享同一个操作而不会互相消耗阶段通知。已完成的操作可重复等待；新注册的蓝图等待方仅接收最终结果。
- `poll` 回调在逻辑线程执行，禁止 yield，错误会向宿主传播。
- 操作所有者负责资源清理，仅取消操作不会撤销业务副作用。详见 [Lua 任务用法与取消](<../../../../快速入门/Ludork Lua 进阶.md#协作任务与文件批次>)与[蓝图取消](<../../../蓝图脚本/执行流、事件与变量.md#取消-latent-执行>)。

运行时常量与查询语义：

- **只读查询**：`Engine.GetCellSize()` 返回 C++ 编译期格子尺寸（当前为 `32`，无运行时设置接口），`GetGameSize()` 返回独立的逻辑尺寸值，`GetScale()` 返回有效渲染缩放，`IsGameRunning()` 读取生命周期状态。如需变更运行时状态，请调用 `GlobalCore.Display` 与 `GlobalCore.System.exit()`。
- **方向枚举**：`Engine.Direction` 与 `require("Enums.Engine.Direction")` 暴露相同的原生枚举值：`DOWN = 0`、`LEFT = 1`、`RIGHT = 2`、`UP = 3`。设置 Actor 朝向时使用具名成员，调用 `Engine.OppositeDirection(direction)` 可获取反方向。
- **缩放下限**：`Engine.DisplayScaleLimits` 暴露只读数值常量：`MINIMUM_RENDER_SCALE`（`0.01`）为有效渲染缩放下限，`MINIMUM_INVERTIBLE_SCALE`（`0.000001`）用于防止除以接近零的显示缩放。

## EditorLiveDebug

`Engine.EditorLiveDebug` 为内建编辑器桥接服务（`metadata = false`，仅限 Lua，不生成蓝图节点）。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `install` | `handler: function` | — | 静态方法。仅限 Lua（`metadata = false`）。安装或替换当前 VM 的请求处理函数。 |
| `uninstall` | — | — | 静态方法。仅限 Lua（`metadata = false`）。释放处理函数，可安全重复调用。 |

处理函数接收一个请求表，且必须恰好返回一个可序列化为 JSON 的表。未安装处理函数、Lua 运行错误、返回值数量不正确或编码失败时，均产生 `success = false` 及 `error` 错误字符串。注册归属当前 Lua VM 并在关闭时释放；无编辑器桥接时安装操作不生效。

> **注意**：默认 Game 模块负责实时调试处理函数的注册，项目脚本在正常运行中不应替换它。编辑器侧操作见[实时调试](<../../../../编辑器用户指南/运行、调试与打包.md#实时调试>)。

## 原生网页

`Engine.OpenWebView(url)` 在游戏画面上方的独立原生层中打开 HTTP 或 HTTPS 网页。返回值仅表示请求是否被接受，不代表网络加载成功；无效 URL 或宿主不可用时返回 `false`。对应蓝图节点具有普通执行引脚，不会等待网页关闭。

- **展示与控制**：覆盖层提供关闭按钮、加载/错误状态与可交互页面（支持 JavaScript、链接、滚动与文本输入）。新窗口链接与重复调用都在当前层内导航。不暴露文件下载、额外设备权限或 JavaScript 到游戏的桥接。替换窗口或关闭应用时会关闭覆盖层。输入屏蔽规则见 [WebView 输入捕获](<输入与服务.md#webview-输入捕获>)。
- **平台实现**：macOS 与 iOS 使用 WKWebView，Android 使用系统 WebView，HarmonyOS 使用 ArkWeb，Windows 使用已安装的 Evergreen WebView2 Runtime（缺失时显示安装链接，游戏既不自动安装也不随包携带浏览器引擎）。

## 类型化数据值

- `resolveTypedDataValue(value, type, environment?, declaringModule?, evaluateAnyExpressions?)` 依据[元数据结构与 Decorator](<../../../蓝图脚本/元数据结构与 Decorator.md>) 架构还原并校验存储值，包含 `Union` 分支标签。`evaluateAnyExpressions` 默认为 `true`；传入 `false` 时保留嵌套 `any` 字符串为字面量。
- `resolveRuntimeTypedValue(value, type, declaringModule?)` 校验已有运行时值并原样返回，不对字符串求值也不重建原生对象。
- `setRuntimeTypedAttribute(owner, name, value)` 依据所属对象的元数据校验并赋值属性。普通脚本字段上的显式 `nil` 会覆盖继承默认值。

## JSON 数据

JSON API 严格操作未归档目录或打包 `Data` 中的精确路径，从不查找或解码 LDC 替代文件：

- `Engine.getJSONData(path)` 解析 JSON，`Engine.getJSONText(path)` 读取文件文本，`Engine.jsonExists(path)` 仅检查精确路径。`Engine.writeJSON(path, value)` 无论后缀如何始终写入 JSON 文本。
- **纯数据写入边界**：`Engine.writeJSON(filePath, value)` 接受已注册的 JSON 数组标记（含 Standard 容器 `toTable()` 产生的空数组）与 `cjson.null`，拒绝原生对象、函数、循环引用及未识别元表；写入前须先显式转换 Standard 容器。
- **Lua 读取表示**：数组附带非负整数 `n` 记录逻辑长度；数组中的 null 槽位为缺失键，对象中的 null 字段则保留 `cjson.null`。数组校验器须计入 `n`，使用方应检查所需元素而非将 `n` 当作数组项。

## 数据文件

游戏资源与存档请使用以下函数：

| 函数 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `Engine.loadData` | `path: string` | `any` | 读取 JSON 或二进制 LDC。优先访问精确路径；仅当 `.json` 路径缺失时回退至同名 `.ldc`。显式 `.ldc` 路径绝不回退至 JSON。 |
| `Engine.saveData` | `path: string`, `value: any` | — | `.json` 写入 JSON，`.ldc` 写入二进制 LDC。拒绝其他后缀，且绝不改写传入路径。 |
| `Engine.dataExists` | `path: string` | `bool` | 按与 `loadData` 相同的路径规则检查文件是否存在。 |
| `Engine.decodeData` | `bytes: string` | `any` | 解码完整的 JSON 或 LDC 文件字节（含文件批读取的原始内容）。检测到 `LDDC` 文件头时仅按 LDC 解码，无效 LDC 不回退至 JSON。 |

这些 API 与 JSON API 共用纯数据边界及 Lua 数组/null 表示。LDC 直接解码为 `RuntimeData` 再转为 Lua 值，不经过中间 JSON 文本。其载荷经过压缩与混淆，编码与限制见 [LDC 二进制数据](<../../../../C++ 原生开发/构建与模块布局.md#ldc-二进制数据>)。载荷为压缩 JSON 的旧版 LDC 文件不再受支持，须从源数据重新生成。

## SavePreviewReader

`Engine.SavePreviewReader` 提供异步存档槽扫描与缩略图解码。所有公开调用与轮询必须在游戏线程执行。该 API 仅限 Lua 使用，不生成蓝图节点。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `new` | — | `Engine.SavePreviewReader` | 静态方法。仅限 Lua。创建异步存档预览读取器。 |
| `requestScan` | `paths: string[]` | — | 仅限 Lua。在后台扫描最多 10,000 条路径；自动替代先前扫描。 |
| `pollScan` | — | `bool` | 仅限 Lua。每次扫描完成时返回一次 `true`。 |
| `getLatestSlot` | — | `int` | 仅限 Lua。返回已完成扫描中从 1 开始的最新槽位，不存在时返回 `0`。 |
| `getScanError` | — | `string` | 仅限 Lua。返回扫描错误字符串，成功时为 `""`。 |
| `requestPreview` | `path: string`, `width: int`, `height: int` | — | 仅限 Lua。请求元数据与原生缩略图（宽高均须在 `1–1024` 内），按实际存在的 JSON 或 LDC 路径读取；自动替代先前预览。 |
| `pollPreview` | — | `bool` | 仅限 Lua。每次预览完成时返回一次 `true`。 |
| `getState` | — | `string` | 仅限 Lua。返回 `Engine.SavePreviewState` 常量。无截图的就绪存档不包含图像。 |
| `getModificationTime` | — | `int` | 仅限 Lua。返回已发布的 Unix 修改时间戳。 |
| `getImage` | — | `sf.Image \| nil` | 仅限 Lua。返回已解码的缩略图图像或 `nil`。仅可在游戏线程创建纹理。 |
| `getError` | — | `string` | 仅限 Lua。返回已发布的预览错误文本。 |
| `cancelPreview` | — | — | 仅限 Lua。使挂起预览失效，不等待工作线程。 |
| `cancel` | — | — | 仅限 Lua。同时使扫描与预览失效，不等待工作线程。 |
| `invalidate` | `path: string` | — | 静态方法。仅限 Lua。文件写入成功后立即使其预览缓存失效。 |

`Engine.SavePreviewState` 暴露只读状态字符串：`IDLE = "idle"`、`LOADING = "loading"`、`EMPTY = "empty"`、`READY = "ready"` 与 `FAILED = "failed"`。

原生服务按路径、修改时间、大小与请求尺寸缓存最多 8 张缩略图。所属对象关闭时请主动取消读取器（析构会自动取消）；引擎关闭时会丢弃排队任务并在释放资源存储前等待工作线程结束。
