# Engine：玩法类型

本页记录 `Engine` 下的核心玩法对象类型：`Actor`、`BPBase`、`Character`、`Component`、`BillboardComponent` 与 `LightComponent`。实例方法表省略隐式 `self` 接收者（蓝图节点将其公开为首个目标引脚）；静态方法与事件无接收者。

## Actor

基础地图实体，持有变换、精灵、材质、移动路线、父子层级、蓝图图与挂载组件。

- **材质**：`material` 引用正式 2D 材质资源，`materialParameters` 保存单实例参数覆盖。切换至其他材质会清空旧覆盖，参数写入按目标资源校验；路径、默认值、光照与遮罩规则详见[材质资源](<地图与材质.md#材质资源>)。
- **材质边界**：仅限 Lua 的 `getMaterialBounds()`（`metadata = false`）返回包含材质声明最大顶点位移与 Actor 变换的世界空间视觉边界。抓屏特效使用该边界避免裁切位移像素，不改变碰撞边界或占用地图格。
- **层级与蓝图图**：`collectTree()`（`metadata = false`）按根优先广度遍历返回保留子节点顺序与归属的快照，遇重复或循环时抛出错误。`setGraph` 存储 `Engine.Graph` 实例（由 `getGraph` 读取），传入 `nil` 清除。
- **可见性**：`visible` 默认为 `true`（`getVisible()` 读取自身标记，`isVisibleInHierarchy()` 同时检查全部祖先）。不可见 Actor 仍保留实例、生命周期与 Tick 行为，但跳过绘制、挂载光源与遮光、碰撞、重叠检测及寻路阻挡。
- **层级可见性写入**：`setVisible(value, applyToChildren = true)` 默认同步更新所有后代自身标记；传 `false` 可保留后代各自标记，同时仍受父级可见性总控。直接给属性赋值仅更新 Actor 自身标记。
- **占格查询**：`getOccupiedMapCellsAtMapPosition(mapPosition)` 计算 Actor 置于 `mapPosition * CellSize` 时的占格范围，保留当前原点、偏移、旋转与缩放，排除格内移动偏移（空边界返回请求格本身）。无参 `getOccupiedMapCells()` 返回包含移动途中所跨格子的实时占格范围。
- **编辑器纹理路径**：`texturePath` 保存 `/Game/Assets/...` 路径，默认打开 `Assets/Characters`。**从图块集选择**复选框反映路径是否位于 `/Game/Assets/Tilesets`：勾选时将 `/Game/Assets/Characters/...` 改写为 `/Game/Assets/Tilesets` 下对应相对路径，取消勾选时恢复 `/Game/Assets/Characters`，重新打开 Actor 时按已保存路径还原勾选状态。

### 路线与操作生命周期

`actor:setRoute(route)` 返回 `Engine.AsyncOperation`，路线启动时发出 `0`，路线与当前移动全部结束后以 `1` 完成。原生 `setRoute` 蓝图节点会立即沿 `default` 引脚继续执行；需要 `Started` / `Finished` 分支请使用[移动节点函数](<../../../节点函数/Movement.md>)。

- **取消条件**：启动新路线、调用 `stop()`、禁用移动、销毁 Actor 或切换地图均会取消尚未完成的路线操作。
- **中断步进**：`stop()` 与 `setMoveEnabled(false)` 会吸附至最近地图格。若中断步进落点与出发格不同，会先清空移动并更新占格，再按序触发一次到达流程：移动中 Actor 的 `onOverlap`、每个仍有效接触对象的 `onOverlap`，最后执行 `_onArrivedAtMapCell()`。停在出发格、停止未启动路线或重复调用 `stop()` 均不触发到达通知。
- **重入回调**：若回调销毁或隐藏移动中的 Actor、切换其地图或将其移离到达格，正常与中断到达流程均立即停止分发旧格通知（正常移动同时丢弃剩余帧时间）。`stop()` 会在取消回调执行前清理旧移动状态，因此回调中启动的新路线会被保留。

以下仅限 Lua 的方法用于管理附加的 Actor 作用域异步操作（如开门动画）：

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `trackAsyncOperation` | `operation: Engine.AsyncOperation` | — | 仅限 Lua。注册随 Actor 销毁、释放或切换地图自动取消的操作；若 Actor 已销毁则立即取消。 |
| `cancelAsyncOperations` | — | — | 仅限 Lua。取消当前路线及所有已注册操作，不停止底层动画本身。 |

## Character

**继承**：`Engine.Actor`

四方向四帧动画角色 Actor（通过 `InvalidVars: { "defaultRect" }` 从蓝图可编辑属性中排除 `defaultRect`）。

## BillboardComponent

**继承**：`Engine.Component`

挂载于 `Actor.billboardComp`，在 Actor 头顶纵向显示保持正向直立的文字与图片标签。编辑器配置详见 [Billboard 组件](<../../../../编辑器用户指南/Actor 组件/Billboard.md>)。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `items` | `Engine.BillboardItem[]` | `[]` | 按从上到下排列的图片与文字条目。 |
| `showRange` | `float` | `128` | 玩家与 Actor 世界坐标之间的最大显示距离（地图逻辑像素，含边界）。 |

### BillboardItem

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `kind` | `string` | `"text"` | `"text"` 或 `"image"`。 |
| `text` | `string` | `""` | 文本内容。 |
| `fontSize` | `uint` | `12` | 字号。 |
| `color` | `sf.Color` | `[255, 255, 255, 255]` | 文本 RGBA 颜色。 |
| `image` | `string` | `""` | 图片资源路径。 |

文本采用系统默认字体绘制，图片按原始像素尺寸绘制。所有条目（含多行文本的每一行）沿 Actor 头顶水平中线居中对齐且无额外间距；静止时最底部条目紧贴 Actor 图像边界顶部中心。无论 Actor 如何旋转或翻转，标签组始终保持直立。

### 可见性与动画

仅当玩家处于 `showRange` 内、Actor 边界与摄像机视野相交，且满足 Actor/祖先可见性、地图区域活跃状态及图层可见性时才会显示（`tickable` 不影响显示）。标签组在其所属 Actor 及挂载发射器之后绘制（可被后续 Actor 与图层遮挡），并裁剪至地图窗口范围内。

入场与退场动画通过四条系统曲线在 `0.35` 秒内完成上浮与淡入淡出（默认关键帧使用线性插值与常量外推）：

| 曲线资源 | `0–0.35` 秒内变化范围 |
|---|---|
| `Global/BillboardYIn` | `16` → `0` 逻辑像素 |
| `Global/BillboardAlphaIn` | `0` → `255` |
| `Global/BillboardYOut` | `0` → `-16` 逻辑像素 |
| `Global/BillboardAlphaOut` | `255` → `0` |

动画不透明度与条目自身 alpha 相乘。中途反转过渡会从当前位置与不透明度平滑衔接并重新计时 `0.35` 秒；离开摄像机视野、隐藏或休眠会重置状态，再次出现时从头播放入场动画。

## LightComponent

**继承**：`Engine.Component`

挂载于 `Actor.lightComp`，由 Actor 发射动态点光源。编辑器配置详见 [Light 组件](<../../../../编辑器用户指南/Actor 组件/Light.md>)。

### 属性

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `lightColour` | `sf.Color` | `[255, 255, 255, 255]` | — |
| `lightRadius` | `float` | `16` | — |
| `lightOffset` | `sf.Vector2f` | `[0, 0]` | 从 Actor 本地边界中心起算的偏移，随完整 Actor 变换同步。 |

> **注意**：墙面火把等壁挂光源需要独立的 Actor，并通过 `lightOffset` 将光源置于房间一侧；渲染器不会自动搜索相邻可通行格。
