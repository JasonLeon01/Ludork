# GlobalCore：地图与雾效

本页记录原生地图服务、雾效与远景控制器、寻路结果、共用与静态预览地图渲染器以及组合式大地图流送状态。实例方法表格省略作为首个蓝图目标引脚暴露的隐式 `self` 接收者；静态方法与构造函数不接收调用对象。

## FogController

每个地图会话通过 `GlobalCore.FogController.new()` 构造一个独立的雾控制器。控制器持有雾配置，共用渲染器持有 GPU 资源。Game 项目为每个 `GameMap` 各自挂载一个控制器，因此配置单张地图的雾效不会覆盖其他地图。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `new` | — | `GlobalCore.FogController` | 静态方法。 |
| `applyFromMapData` | `settings: Engine.MapFogSettings` | — | 替换基础配置，同时保留已有大地图区域配置。 |
| `applyWorldFromMapData` | `settings: Engine.MapFogSettings` | — | 仅限 Lua。清除原有区域并初始化大地图雾配置。 |
| `setWorldRegionFog` | `key: string`, `cellRect: sf.IntRect`, `settings: Engine.MapFogSettings` | — | 仅限 Lua。设置裁剪至 `cellRect` 的区域雾配置。 |
| `removeWorldRegionFog` | `key: string` | — | 仅限 Lua。 |
| `clearFog` | — | — | 同时清除基础配置与区域雾配置。 |
| `getSettings` | — | `Engine.MapFogSettings` | 返回基础配置的副本。 |
| `getWorldRegionSettings` | `key: string` | `Engine.MapFogSettings \| nil` | 仅限 Lua。返回区域配置副本或 `nil`。 |

雾效没有全局 `update` 或 `drawOverlay` 调用：

- **程序化渲染**：地图合成在材质与光照合成之后、前景天气与粒子之前，按当前帧的绝对时间在世界坐标中采样 GPU 程序噪声，无需指定雾纹理路径。
- **大地图分层**：先合成基础大地图雾，再按稳定的摆放顺序合成裁剪至各自摆放范围的驻留子地图雾。相同配置与时间在相邻摆放之间呈现连续无缝的噪声。
- **光照响应**：受光（Lit）雾采样场景环境光与直接光；不受光（Unlit）雾直接使用配置颜色。字段与默认值见 [Engine.MapFogSettings](<../Engine/地图与材质.md#mapfogsettings>)。

## PanoramaController

管理绘制在地图底层的远景背景。所有方法均为静态方法。

### 函数与事件

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `applyFromMapData` | `mapData: GlobalCore.MapPanoramaSettings` | — | 静态方法。 |
| `clear` | — | — | 静态方法。 |
| `isActive` | — | `bool` | 静态方法。纯函数（Pure）。 |

`MapPanoramaSettings` 接受包含字符串字段 `panorama` 的 Lua 表：

- `panorama` 缺失或为 `nil` 时默认取 `""`，关闭底层远景。
- 表中多余的地图字段会被忽略；字段类型无效时抛出错误。
- `applyFromMapData` 与 `applyWorldFromMapData` 共用此配置。路径非空时会立即加载纹理并向上传播加载失败错误。

`getPath()` 返回当前远景路径。远景由共用合成器按 Cover 缩放与跟随摄像机的滚动规则绘制。

## GameMapBase

为地图提供原生通行性缓存、Actor 占用追踪、寻路与非连通区域可见性支持。

- **独立缓存**：地形通行性与活动 Actor 占用分别独立缓存。Actor 创建与销毁、视图同步以及大地图休眠或唤醒只更新占用，不重建地形网格。
- **增量同步**：同步会移除离开活动视图的 Actor，仅更新新增或占用范围发生变化的 Actor，同时保持未变更占用及保留 Actor 的相对顺序。隐藏 Actor 仍保持登记，在查询时按其当前可见性过滤。
- **缓存维护**：`rebuildPassabilityCache(size)` 重建地形通行性、刷新 Actor 占用并返回地形布尔网格（稀疏大地图返回空网格）。`invalidatePassabilityCache()` 将地形通行性与非连通区域可见性标记为待刷新而不清空 Actor 占用，Game 项目的地形编辑 API 会自动调用它。
- **手动更新占用**：手动修改活动 Actor 的地图位置或边界后，调用 `updateActorOccupancy(actor)` 刷新其占用格子。此方法不会登记不在活动视图中的 Actor（包括休眠的大地图 Actor）。生命周期与批处理更新会在后续 Actor 查询前自动提交待处理的占用变更。

### 区域可见性

对于普通有限地图，可见性 API 遵循以下行为：

- `setHideDisconnectedRegions(enabled)` 开启或关闭区域隐藏（`getHideDisconnectedRegions()` 为运行时专用读取器）。
- `setVisibilityObserver(position)` 接受 `sf.Vector2i` 格子坐标供预览使用；传入 `nil` 恢复跟随玩家。
- `isCellVisible(position)` 查询图块显示掩码（不可通行格始终保持可见）。
- `isActorVisibleOnMap(actor)` 按可见性标记与区域规则检查 Actor 及其全部祖先：可通行锚点按所在区域判断，不可通行锚点要求变换后的图像矩形与可见可通行格重叠。
- `getVisibilityRevision()` 返回供显示与预览缓存使用的当前版本号，即便关闭隐藏也会持续跟踪地形编辑。所有可见性查询都会在返回前刷新待处理更新。

地形编辑会重建连通性与替换源。在同一区域内移动复用当前掩码，跨区域移动则更新渲染与光照。渲染器使用独立的显示图层，不修改底层图块地图。选取规则与玩法效果见 [Global.GameMap](<../../Global APIs/GameMap.md#非连通区域隐藏>)。

## 共用地图渲染

`GlobalCore.GameMapRenderer` 将实时地图与 Actor 状态适配到 Core `MapRenderer`：

- `renderFrame(ambientLight, time, applyPlayerCover, materialRevision, drawLayerEffects, drawOverlay)` 完成材质、光照、反射、远景与雾效渲染。
- `drawLayerEffects(layerName, target, states)` 每帧对每个图层仅调用一次；需要反射时，渲染器捕获并复用其输出。`drawOverlay()` 每帧调用一次用于组件叠加绘制。两个回调仅负责绘制，玩法状态仍在正常更新阶段推进。
- `drawContent` 保留外部传入的渲染状态以支持离屏绘制。
- `prewarm(ambientLight, time)` 预热同一渲染路径；`setFogController(controller)` 绑定地图雾控制器；`setLayerOrder(names)` 同步大地图图层顺序变化。

共用渲染器与编辑器预览数据流见 [PreviewHost：架构与数据流](<../../../../PreviewHost/架构与数据流.md>)；编辑器显示选项见 [地图与世界预览](<../../../../PreviewHost/地图与世界预览.md>)。

## 静态预览绘制

`GlobalCore.PreviewSprite` 与 `GlobalCore.GameMapRenderer` 均为仅限运行时 Lua 的 API（`metadata = false`），不生成蓝图节点。`PreviewSprite.new(table)` 接受以下字段：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `layer` | `string` | — | 目标图层名。 |
| `texture` | `sf.Texture \| nil` | `nil` | 持有的纹理；为 `nil` 时不绘制图像，但保留几何信息与父节点作用。 |
| `rect` | `sf.IntRect` | — | 纹理像素坐标系下的源矩形。 |
| `position` | `sf.Vector2f` | — | 地图坐标中的像素锚点。 |
| `mapPosition` | `sf.Vector2i` | — | 用于区域可见性检查的格子坐标。 |
| `translation` | `sf.Vector2f` | — | 像素显示偏移。 |
| `rotation` | `float` | `0` | 旋转角度（度）。 |
| `scale` | `sf.Vector2f` | `[1, 1]` | 缩放系数。 |
| `origin` | `sf.Vector2f` | — | 像素原点。 |
| `visible` | `bool` | `true` | 该记录自身的可见性标记。 |
| `parentIndex` | `int` | `-1` | 前序父记录的从 0 开始索引，根记录为 `-1`。 |
| `material` | `string` | `""` | 材质资源路径。 |
| `materialParameters` | `Dict[string, any]` | `{}` | 逐实例材质参数覆盖表。 |

静态预览的安装与更新遵循以下规则：

- `renderer:setPreviewSprites(records)` 要求渲染器构造时指定了 `previewOnly = true`。它会保留显示资源，并在每个已配置图层内维持记录顺序。父记录必须排在子记录之前；非法父索引会抛出错误且不替换已安装记录。传入空数组将不绘制任何静态精灵；在安装记录之前，渲染器按普通 Actor 渲染契约工作。
- `renderer:setPreviewVisibility(flags)` 要求已安装记录，并按相同顺序为每条记录提供恰好一个布尔值。它更新各记录自身的可见性，而有效可见性还会叠加祖先与地图区域规则。几何坐标已预先解析到地图坐标系；`parentIndex` 仅控制可见性，不组合父子变换。
- 静态材质绘制使用当前帧、实例参数与传入绝对时间（楼层预览为 `0`），并组合精灵变换与调用者变换（含世界偏移）。无效材质会抛出错误。仅原生接口 `GameMapBase::isSpriteVisibleOnMap(position, bounds, transform)` 与实时 Actor 共用几何可见性判定，不绑定到 Lua。

## WorldStreamingState

使用从 1 开始的区域索引，追踪组合式大地图的需求队列、按摄像机距离的排序、LRU 缓存核算、淘汰与流送统计。所有方法均仅限运行时使用（`metadata = false`）；蓝图侧使用带上下文的大地图节点。

- **枚举**：`WorldRegionState` 暴露 `Unloaded`、`Reading`、`Prepared`、`Active` 与 `Dormant`；`WorldRegionDemand` 暴露 `None`、`Prepared` 与 `Active`。
- **优先级排序**：按摄像机顺序将 Active 区域排在最前，其余按区域中心到摄像机的平方距离排序，等距时按区域索引打破平局。
- **Lua 循环集成**：Lua 调用 `updateCameraCenter` 与 `updateDemand`，消费 `takeReadBatch` 与 `takePublishItem`，上报读取和发布的完成或取消，标记激活、停用与淘汰，并查询 `getEvictionList` 与 `getStats`。文件、构建器与数据载荷仍由 Lua 持有。
