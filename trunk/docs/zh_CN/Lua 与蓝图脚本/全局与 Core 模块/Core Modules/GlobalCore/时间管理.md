# GlobalCore：时间管理

## TimerEntry

`isReady()` 表示到期或已取消，不表示回调已完成。`cancel()` 取消关联操作，并阻止到期回调执行。需要等待完成时，使用 [SceneBase.addTimer](<场景与系统.md#场景计时器>) 返回的操作。

| 名称 | 类型 | 默认值 | Metadata |

| `params` | `any[]` | — | — |
| `blocking` | `bool` | — | — |
