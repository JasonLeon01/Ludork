# 全局与 Core 模块总览

本章介绍三个原生 Lua 模块（`Engine`、`GlobalCore` 与 `GlobalFunctions`）以及默认玩法提供的共享 `Global.*` 模块。

| 模块 | 用途 |
|---|---|
| `Engine` | Actor、组件、输入、图形、数据与 UI 控件。 |
| `GlobalCore` | 场景、地图、摄像机、资源管理器与能力系统。 |
| `GlobalFunctions` | 按 `Components`、`Manager`、`NodeGraph` 与 `UI` 分组的原生 Lua 辅助函数。 |
| `Global.*` | Game 项目提供的共享模块，例如 `Global.GameMap`。 |

原生模块按根名称加载（如 `require("Engine")`），项目模块按完整点分路径加载（如 `require("Global.GameMap")`）。`GlobalFunctions.Math` 等 [Lua 节点函数库](<../节点函数/概述.md>)作为独立模块加载，不属于原生 `GlobalFunctions` 根表的成员。启动加载顺序见[Lua 运行时与模块](<../Lua 运行时与模块.md>)。
