# 节点函数总览

## 查找节点

先按上表用途定位对应模块，再按标识符检索节点。例如，`+` 运算符节点对应 `Math.ADD`。

本节各参考页的函数表均采用以下四列：

- **`函数`** —— 蓝图节点函数的元数据标识符。
- **`参数`** —— 按顺序排列的输入引脚，形式为 `name: type`；元数据声明默认值时追加 `= value`；无参数时写作 `—`。
- **`返回值`** —— 输出引脚，形式为 `name: type`（未命名返回值直接写 `type`）；无数据输出时写作 `—`。
- **`说明`** —— 执行标记（`纯函数（Pure）。`、`潜伏节点（Latent）。`、`循环节点（Loop）。`）、命名执行分支、编辑器元数据（下拉列表、路径选择器、枚举选择器、显示名称）与行为概要。既非纯函数也非潜伏或循环的普通节点，如未特别列出分支，均默认具有单个执行出口；详见[执行声明](<../蓝图脚本/元数据结构与 Decorator.md#执行声明>)。

## 与 GlobalFunctions Lua API 的关系

原生 `GlobalFunctions` 根模块在 `Components`、`Manager`、`NodeGraph` 与 `UI` 下暴露 Lua API；其空元数据不声明任何蓝图节点，详见 [GlobalFunctions Lua API](<../全局与 Core 模块/Core Modules/GlobalFunctions.md>)。

本章列出的节点函数库需单独加载（例如 `require("GlobalFunctions.Math")`），不属于原生根表的成员。加载顺序与依赖规则见 [Lua 运行时与模块](<../Lua 运行时与模块.md#入口与模块顺序>)。
