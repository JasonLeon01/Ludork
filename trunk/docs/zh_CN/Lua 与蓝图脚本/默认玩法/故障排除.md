# 故障排除

本指南用于排查默认玩法项目中的常见项目打开、蓝图保存、启动、资产、本地化与打包问题。原生 C++ 崩溃、绑定生成失败或插件加载错误，请查阅对应的 C++ 原生开发或插件开发章节。

## 项目无法打开

检查 `Main.proj` 与 `Data` 下每个已加载文件的 JSON 语法。确认所有路径均位于项目根目录之内，遇到残缺项目包时应恢复缺失的项目目录，切勿直接打开不完整的目录。

## 蓝图无法保存

保存错误会直接指出无效的父类、继承循环、节点、连线、引脚或默认值。Script Mixin 蓝图还要求提供合法的相对 `scriptPath`、返回普通 Lua 表的脚本以及同名 `_meta.lua` 文件，参见 [Script Mixin 编写工作流](<../脚本 Mixin/编写工作流.md>)。

## 游戏无法启动

请从控制台报告的第一条错误入手排查：

- **编译与导出顺序**：**运行**会先按需检查**编译**，再执行**导出**。导出校验失败、插件错误以及 before-Run 钩子失败均会阻止启动。
- **脚本与模块**：核对生成的 UI 与本地化文件、原生模块、[启动脚本](<../Lua 运行时与模块.md#入口与模块顺序>)、Core 模块加载顺序与运行时协议诊断信息。
- **材质缓存失败**：若 `SceneInit` 停滞在材质准备阶段，请检查首个生成或缓存错误。运行时缓存位于游戏的用户数据目录，参见[运行时生成](<../../编辑器用户指南/材质.md#运行时生成>)。

## 节点缺失

确认对应的元数据文件是纯数据、返回 `_METADATA`、将成员声明为 `type = "function"` 或 `"event"`，且不位于 `Scripts/Mixins` 目录下。涉及 C++ 绑定时，请重新构建项目以便 bindgen 重新生成元数据。

## 资产或数据引用损坏

使用引用树定位失效的键或路径。资产重命名与路径规则见 [Assets](<../../编辑器用户指南/项目设置与资产布局.md#assets>)，带类型的通用数据引用见[类型结构](<../../编辑器用户指南/通用数据与文本配置.md#类型结构>)。

## 本地化文本缺失

确认语言文件 ID、当前游戏语言以及 `LOC` 格式化参数与项目文本一致。工作簿与导出配置见[游戏本地化工作流](<../../插件开发与安装/官方插件/游戏本地化工作流.md>)。

## 打包后行为不同

- **运行时环境与路径**：核对打包后的资产、脚本、原生模块、FFmpeg 变体以及[可写游戏配置位置](<../../编辑器用户指南/项目设置与资产布局.md#游戏配置>)。切勿通过路径分隔符推断平台，应读取注入的全局变量 `PLATFORM`。
- **Android 打包**：仅支持 C++ Source 项目，需要本机安装 Android Studio 及其所需工具。打包错误会列出缺失的前置项；预期路径与版本见[运行、调试与打包](<../../编辑器用户指南/运行、调试与打包.md>)。
- **Android 签名**：确认 JKS 或 PKCS12 密钥库路径为绝对路径且可读、密钥别名存在且两个密码均正确。在对话框中修正过期的已保存值并重新输入未保存的密码。失败的构建既不会发布未签名中间产物，也不会输出残缺 APK。同一已安装应用的所有后续更新必须复用同一把签名密钥。
