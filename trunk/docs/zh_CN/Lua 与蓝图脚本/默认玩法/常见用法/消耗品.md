# 消耗品

使用默认玩法提供的 Script Mixin，可以快速创建由碰撞触发的生命回复药水或属性提升宝石。使用此流程前，请先准备继承自 `ConditionalActor` 且启用碰撞的蓝图，并确保生成的 Player 属性集中包含对应的数值字段、音频配置中存在有效的回退音效。

## 配置消耗品蓝图

1. 创建继承自 `Source.MapActors.ConditionalActor.ConditionalActor` 的蓝图，启用碰撞并开启 **Script Mixin**。
2. 挂载 `Consumables/Bottle.lua`（回复药水）或 `Consumables/Gem.lua`（属性宝石）。
3. 药水配置 `HP_plus`；宝石配置 `ATTR_key` 与 `plus`。
4. 在 `getSE` 中指定拾取音效，或保留默认值以自动使用音频配置中的 `Audio.getSE`。

触发碰撞时，共用拾取流程会定位玩家并施加 Instant Add 效果（`Bottle` 增加 `HP`，`Gem` 增加 `ATTR_key` 指定的 `int` 或 `float` 玩家属性），随后将该拾取物记录为已销毁并销毁该 Actor。

## 默认模板示例

- **`BP_Bottle_200.json`**：直接继承 `Source.MapActors.ConditionalActor.ConditionalActor`，启用 `scriptMixin`，挂载 `Consumables/Bottle.lua`，开启碰撞，设置 `HP_plus = 200` 并指定药水纹理。
- **`BP_Gem_1_1.json`**：挂载 `Consumables/Gem.lua`，设置 `ATTR_key = "ATK"` 与 `plus = 1`，并指定宝石纹理。
- 两份蓝图均保留 `getSE` 的元数据默认值，运行时统一解析 `Audio.getSE`。

> **注意**：默认模板中的 Mixin 依赖各自声明的父类能力、元数据字段以及通用数据或配置键；若项目采用自定义背包或属性体系，请按需改造或替换。
