# 敌人

将敌人的物理蓝图与通用数据战斗属性解耦，便于独立复用和调整。关联前请先确认引用的物品蓝图路径、特殊效果 ID 与动画键均已存在。

## 创建敌人蓝图与数据记录

1. 在 Enemy 通用数据中新增成员，配置战斗数值、奖励、掉落、特殊效果与动画键。
2. 创建或派生继承自 `Source.MapActors.Enemy`（或兼容子类）的敌人蓝图，将 `ID` 设为该数据成员键。
3. 在蓝图上配置移动、碰撞与外观默认值。
4. 如需自定义击败演出，请在敌人 Actor 的 `onDefeat` 事件或子类授予的玩法能力中实现；Enemy 通用数据不包含成员事件，固定战斗结算会等待 `onDefeat` 执行完毕。

可复用的战斗计算逻辑应统一放在玩法能力、玩法效果或共享 Lua 模块中。

## 默认模板示例

- **`BP_Enemy_Slime.json`**：继承 `Source.MapActors.Enemy` 并设置 `ID = "Slime"`，关联 `Data/General/Enemy.json` 中的 `Slime` 成员。蓝图负责物理与外观默认值（纹理、源矩形、材质速度），通用数据负责 `MAXHP`、`ATK`、`DEF`、`EXP`、`GOLD`、`drops`、`special` 与 `ANIMATION_KEY`。
- **掉落与击败粉碎特效**：在 `drops` 中将物品蓝图路径映射至 `sf.Vector2i` 格子偏移（掉落激活、持久化与结算顺序见[敌人](<../Actor、敌人、物品与装备.md#敌人>)）。全局[敌人击败粉碎特效](<../资源、音频、视频与特效.md#2d-材质与着色器>)可在[系统配置 → Gameplay](<../../../编辑器用户指南/项目设置与资产布局.md#系统配置>) 中开关。
- **重生替换（`GhostSoldier`）**：设置 `special.Reborn = "Data.Blueprints.Enemies.BP_Enemy_Skeleton_01"`。击败后，结算流程会在同一格子和图层生成替换敌人，并分配新的地图摆放标签，使其在地图重建和存读档后持久生效。

> **重要**：未知的敌人 ID 或缺失的引用记录会在运行时直接触发明确错误，引擎不会自动生成回退战斗定义。
