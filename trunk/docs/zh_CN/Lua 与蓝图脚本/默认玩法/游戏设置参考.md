# 游戏设置参考

**游戏配置**用于编辑[当前平台的游戏配置](<../../编辑器用户指南/项目设置与资产布局.md#游戏配置>) `Main` 节中受支持的键。本页列出默认玩法使用的全部配置键、默认值、画质预设与平台显示限制。

## 支持的键

| 键 | 类型 | 默认值与说明 |
|---|---|---|
| `language` | 字符串 | 游戏本地化目录键（参见[游戏本地化工作流](<../../插件开发与安装/官方插件/游戏本地化工作流.md>)）。 |
| `scale` | 浮点 | 显示缩放偏好；默认 `0` 在支持该设置的显示器上表示全屏。 |
| `maxrenderscale` | 浮点 | 最大内部渲染倍率；默认 `2.0`。不限（`0`）表示取消上限。 |
| `lightingrenderscale` | 离散浮点 | 直接光照渲染倍率：`0.5`、`0.75` 或 `1.0`（默认 `1.0`，无效值回退为 `1.0`）。 |
| `framerate` | 整数 | 目标帧率；默认 `60`。不限（`0`）表示取消上限。 |
| `antialiasinglevel` | 非负整数 | 请求的 SFML 多重采样抗锯齿等级；默认 `8`。 |
| `verticalsync` | 布尔 | 启用或禁用垂直同步。 |
| `musicon`、`soundon`、`voiceon` | 布尔 | 各音频通道开关。 |
| `musicvolume`、`soundvolume`、`voicevolume` | 浮点 | 各音频通道音量，范围限制在 `0`–`100`。 |

编辑器会保留未知的配置节与键。受支持键的值无效时，各读取器会回退至安全默认值，但仍建议直接修正源文件而非依赖回退。保存仅写入已更改设置；新建用户配置与缺失键默认采用**高**画质预设（`2`、`60`、`8`、`1`）与 `scale = 0`，不会覆盖已有值。

> **注意**：只有具备对应运行时读取器的配置键才会生效；向配置文件添加自定义键时需配套实现运行时读取逻辑。

项目与工具标志保存在 `Main.proj` 中，而非可变用户偏好：`Cpp` 控制 C++ Source 项目行为，`ffmpeg` 启用视频打包，`IndividualWindow` 保存编辑器首选启动模式，`packaging.version` 与 `packaging.dev` 配置发行包参数（参见[发行包与开发包](<../../编辑器用户指南/运行、调试与打包.md#发行包与开发包>)）。

## 显示缩放、渲染上限与帧率

- **缩放（`scale`）**：在可配置显示器上立即生效。桌面窗口与处于自由多窗模式的 HarmonyOS 平板使用正数表示固定窗口尺寸、`0` 表示全屏；其他移动设备显示器与 WebGL 不提供**缩放**（含全屏），但保留**渲染上限**。新建配置会写入 `scale = 0`，而缺失键仅在内存中采用 `0`；负数或非有限值解析为 `1`。运行时 API 见 [Display](<../全局与 Core 模块/Core Modules/GlobalCore/场景与系统.md#display>)。
- **桌面端与 HarmonyOS 2-in-1 缩放过滤**：启动时按主显示器工作区过滤正数预设（`1`、`1.25`、`1.5`、`1.75`、`2`、`3`、`4`），每次打开设置界面时重新检查当前显示器。全屏（`0`）与可容纳的非预设值保持可用；超出上限的值会收敛到可容纳的最大预设（若均无法容纳则回退至全屏），移至更大显示器后不会自动调高。尺寸查询失败时，选项与当前值均保持不变。
- **HarmonyOS 平板自由多窗上限**：自由多窗模式取显示器可用区域与 Stage 最大值中的较小者。该最大值在原生宿主初始化、启用自由多窗模式以及应用切回前台时采样——应用持续处于前台时跨屏移动窗口不会重新采样。HarmonyOS 2-in-1 沿用常规桌面显示查询。
- **渲染上限（`maxrenderscale`）**：在所有平台上立即限制内部 Graphics 画布及其依赖渲染目标的分辨率，不改变窗口尺寸、逻辑游戏尺寸或 `scale`。倍率按物理可绘制像素相对于逻辑游戏尺寸计算（含 Retina 像素密度）；在 macOS 上，`scale` 以 Cocoa 逻辑点控制窗口大小，选择不限时则以完整可绘制分辨率渲染。设置界面提供 `0.5`、`0.75`、`1`、`1.5`、`2`、`3`、`4` 与不限（`0`），保留其他有限非负值，并将负数或非有限值解析为 `2`。
- **光照渲染倍率（`lightingrenderscale`）**：自下一帧地图画面起调整直接光照分辨率，不改变窗口或画布尺寸；低于 `1.0` 时平滑放大。缺失、非有限或不支持的值解析为 `1.0`。参见 [Graphics](<../全局与 Core 模块/Core Modules/GlobalCore/场景与系统.md#graphics>)。
- **帧率（`framerate`）**：提供 `30`、`60`、`90`、`120` 与不限（`0`）。选择不限时关闭主动帧率上限但保留**垂直同步**。不限时固定更新步长为 `1/60` 秒，正数帧率下步长为 `1/framerate` 秒。
- **抗锯齿等级（`antialiasinglevel`）**：请求多重采样等级（SFML 会选择最接近的受支持上下文；`0` 表示关闭抗锯齿，负数或越界值回退至 SFML 默认值）。由于抗锯齿在上下文创建时生效，修改会立即保存，并在下次重新初始化显示（通常为下次启动）后生效。

## 画质预设

设置界面按以下顺序根据 `(maxrenderscale, framerate, antialiasinglevel, lightingrenderscale)` 推导当前显示的**画质预设**：

| 预设 | `(maxrenderscale, framerate, antialiasinglevel, lightingrenderscale)` |
|---|---|
| 低 | `(0.75, 30, 0, 0.5)` |
| 中 | `(1, 60, 2, 0.75)` |
| 高 | `(2, 60, 8, 1)` |
| 超高 | `(3, 90, 8, 1)` |
| 原画 | `(0（不限）, 120, 8, 1)` |

若当前组合不匹配任何预设，设置界面会在列表末尾追加并选中**自定义**（选择自定义不会修改数值）；当数值重新匹配某预设时，自动切换至该预设并移除**自定义**。预设均为动态推导，不会写入独立预设键，`scale` 与 `verticalsync` 也不参与判定。
