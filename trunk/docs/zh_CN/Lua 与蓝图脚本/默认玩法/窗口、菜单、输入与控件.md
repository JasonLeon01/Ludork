# 窗口、菜单、输入与控件

本页说明默认玩法的窗口架构、HUD 快捷入口、转场动画、本地化刷新、楼层传送器预览以及输入与焦点行为。如需构建自定义 UI 资产与 Controller，请参见[声明式 UI 编写工作流](<../声明式 UI/编写工作流.md>)。

## 窗口与菜单

默认窗口遵循[声明式 UI 运行时契约](<../声明式 UI/运行时契约.md>)：每个界面拥有单一顶层资产与嵌套子窗格，同级输入宿主复用嵌套列表与滚动框，菜单将稳定的命令键与显示文本分离，内容溢出的列表使用 [`Engine.ScrollBox`](<../全局与 Core 模块/Core Modules/Engine/布局与图像控件.md#scrollbox>)。

- **立即构造与按需构造**：进入地图时立即创建玩家 HUD 与区域标题。标题界面的存读档和设置窗口，以及所有地图可选窗口（菜单、物品、装备、商店、商店记录、存读档、设置、怪物手册、敌人图鉴、楼层传送器、玩家改名与对话消息）均持有独立的 [`LazyWindow` 句柄](<../声明式 UI/运行时契约.md#首次使用时创建可选窗口>)并在首次显示时构造（消息窗口在首次弹出消息或选项时构造）。打开主菜单不会实例化未使用的子窗口。
- **游戏内菜单**：列出**物品**、**装备**、**存档**、**设置**与**返回标题**。`WindowMenu.new(player, windows, onExit)` 在关闭动画结束后执行 `onExit`，目标跳转由场景自身掌控，并为菜单及其子窗口分配同一堆叠层级。打开**设置**会叠加在菜单之上并停用命令列表，关闭后焦点返回菜单。
- **模板与预览占位**：默认资产包含 `#TAB` 与 `#ITEM` 预览子项。怪物手册与敌人图鉴使用 [`CharacterView`](<../全局与 Core 模块/Core Modules/Engine/布局与图像控件.md#characterview>) 及资产定义的单元格尺寸，Controller 负责测量本地化标签与特殊能力标记。标题界面的 `WindowCommand` 绑定 `Parts/Title/CommandWindow` 中的行（由 `Title` 布局定位），并遵循[标题场景的平台规则](<新游戏、标题与场景流程.md#新游戏标题与场景流程>)。

### 窗口转场动画

顶层窗口转场采用线性插值（默认 `0.2` 秒），内部窗格与页签则立即切换。动画播放期间锁定输入，关闭回调在 `FadeOut` 隐藏根节点后执行，初始化与释放阶段则立即隐藏。关联的 `FadeOut` 转场可并行播放；使用背包物品时，物品窗口隐藏后即触发回调，若主菜单仍处于打开状态，则随后关闭菜单并在无阻挡窗口后恢复移动。

| 界面 | 时间轴行为 |
|---|---|
| 默认窗口与设置窗口 | `FadeIn`：中心缩放 `0.5` 到 `1` 并渐变颜色；`FadeOut`：仅渐变颜色。 |
| 标题命令窗口 | `FadeIn`：局部 Y 从 `80` 到 `0` 并渐变颜色。打开设置或存读档窗口时保持可见。 |
| 地图菜单 | `FadeIn`/`FadeOut`：局部 X 在 `-192` 与 `0` 之间往返并渐变颜色。 |
| 物品与装备窗口 | 仅使用 Menu 动画。存读档窗口同时支持默认与 Menu 两套；设置窗口始终使用默认动画。 |
| 消息窗口 | 仅 `Panel` 颜色渐变。 |
| Game Over | 纯颜色 `FadeIn`（`0.5` 秒）与 `FadeOut`（`1` 秒）。场景切换等待 `FadeOut` 结束，并在释放前保持透明末帧。 |
| 区域标题 | `Display` 保持颜色 `1` 秒，随后用 `1` 秒淡出。 |

打开物品、装备或存读档窗口时，可传入 `Enums.WindowTransitionProfile.DEFAULT`（`"Default"`）或 `.MENU`（`"Menu"`）。

### 选择、窗口装饰、触摸与本地化

- **选择与滚动**：可选择列表获得焦点时（打开窗口、切换窗格或返回上级列表），会自动将当前选中项滚动至可见范围且不移动鼠标指针。在菜单、物品、装备、商店、设置或怪物手册开启新的打开会话时，选择器重置为 `0`（空列表为 `nil`）并滚动至顶部；同一会话内的焦点切换与原地刷新会保留当前选中项。
- **移动端与 Web 列表触摸**：在移动端与 Web 上，点击未选中的行仅移动选中项而不确认，再次点击已选中行才确认，拖动则仅滚动列表而不确认（适用于标题命令、存读档槽位与所有可选择窗口；Web 同时支持鼠标选择，参见 [Web 输入](<../全局与 Core 模块/Core Modules/Engine/输入与服务.md#web-输入>)）。在标题界面打开设置或存读档窗口时，底层命令窗口不会收到同一触摸手势的任何部分。
- **窗口返回按钮**：`Parts/Shared/WindowChrome` 在左上边框（`Content` 外部）放置 `16 × 16` 返回按钮。对设置了 `windowOptions.returnButton = true` 且实现 `Controller:onReturn()` 的窗口，`WindowBase` 自动绑定该按钮并播放一次系统 `CancelSE`（其他 Cancel 来源不得重复播放）。多窗格窗口仅在当前活动的可交互窗格显示该按钮；隐藏、未激活或被抑制的窗口不显示。
- **手柄提示与暂停标记**：`WindowChrome` 同时在底边放置 `Engine.GamepadHintBar`，仅在连接手柄时显示至多三条 `Engine.GamepadHint`（通过 `setGamepadHints`、`setGamepadHintEnabled`、`getGamepadHintCount`、`isGamepadConnected`、`setOnGamepadHintTriggered` 控制，参见 [GamepadHintBar](<../全局与 Core 模块/Core Modules/Engine/交互与声明式 UI 控件.md#gamepadhintbar>)）。`Parts/Shared/WindowPauseMark` 定义暂停标记边界，`WindowBase` 驱动其动画与显隐。
- **静态行与动态行**：静态命令行存储 `localeKey`，动态行存储字面量 `text`（不得同时设置），确保语言切换时可原地刷新控件而不丢失回调或光标状态。
- **实时本地化刷新**：`SceneMap` 为长生命周期地图窗口维护单条 `LocaleChanged` 订阅。活跃对话会保留原始说话者、消息/选项、显式 `localeArgs` 以及节点局部变量与实例变量快照，刷新时原地重跑模板本地化与字符串 `localeArgs`；物品/装备详情、商店、属性商店、怪物手册、`WindowEnemyEncyclopedia`、`WindowFloorTeleporter`、标题命令、菜单、存读档页签与可见区域标题均原地刷新，同时保留选择、模式、焦点与预览。隐藏窗口在下次打开时刷新；设置、存档槽与玩家 HUD 的 Controller 各自管理订阅。

### 商店与对话

- **物品商店**：通过 `Enums.ShopMode`（`BUY = "buy"`、`SELL = "sell"`）调用 `WindowShop:setMode(mode)`。两列物品列表始终保持焦点，**Q**/**E**、**LB**/**RB**、鼠标或触摸切换买卖页签（重置光标与滚动；交易后保留有效选择）。单元格显示图标与持有数，详情区展示本地化名称、描述、`Price` 标签与右对齐价格。出售返还 `floor(price / 2)` GOLD 且隐藏零价商品。仅购商店隐藏页签并居中其余窗格。Cancel 关闭商店、恢复移动并屏蔽一帧地图输入。
- **属性商店**：通过 `getOffers()` 暴露展示快照，通过 `purchaseAttribute(key)` 校验购买。标量价格引用由全部条目共享，数组则按项独立定价；每次购买会递增对应价格。
- **对话（`WindowMessage`）**：借助全屏 Canvas 与透明 `FunctionalImage` 消费单次点击/触摸以确认普通消息；选项模式（至多四项，无需 ScrollBox）禁用该层，防止点击空白处误选。`SceneMap` 仅在对话激活期间阻断地图输入。对话、教程与窗口 API 均返回 `Engine.AsyncOperation`（参见 [Lua 等待与结果](<../节点函数/Scene.md#lua-等待与结果>)）。

### 楼层传送器与静态预览

- **可用条件与单地图模式**：列出当前区域内存在传送点记录的地图（无所属区域的地图不提供传送点）。若无符合条件的地图，即便玩家持有道具也会播放提示音并拒绝打开（不锁定移动、不抢占焦点、不构建预览）。仅有一张地图时直接进入其传送点列表并预选首项（仍需显式确认，Cancel 关闭窗口）。
- **多地图模式**：存在多张地图时先打开楼层列表，选中当前地图并滚入视口（若不在列表中则选首项），左侧窗格在楼层列表与传送点列表之间切换（传送点从第 1 项开始，Cancel 返回楼层列表）。打开时先确定初始模式与选择，再执行单次预览渲染。
- **滚动与命名**：过长的地图名与传送点名在固定选框内采用 [ListView 子项滚动](<../全局与 Core 模块/Core Modules/Engine/布局与图像控件.md#listview>)，不会偏移右侧预览。组合式大地图清单作为单个楼层展示，各子地图按世界偏移拼合。标签经 `LOC` 解析（空白或自动标签回退至本地化 `POINT` 编号，未翻译标签保留原文）。
- **发现与楼梯配对**：为各楼梯蓝图设置 `stairDirection` 以匹配反方向楼梯；楼梯传送或 `Teleporter:goToMap` 在获得楼层传送器之前就会记录传送点（打开窗口或靠近楼梯不触发记录）。参见 [Teleporter](<../源码类/Teleporter.md>) 与[存档](<运行时数据、配置与存档.md#存档>)。
- **预览渲染**：键盘、鼠标或触摸切换焦点时以固定缩放刷新预览，视口限制在地图/清单边界内，小于视口的轴自动居中。预览依据[Actor 静态显示数据](<运行时数据、配置与存档.md#actor-静态显示数据>)渲染并将材质时间固定为 `0`，不包含仅由玩法脚本产生的视觉效果。
- **预览持久化与缓存失效**：已销毁标签及其子代在创建记录或加载纹理前即被过滤；新增、移动与地形改动以及声明式 `childActorComp` 子对象无需运行回调即可恢复，普通地图遵守区域隐藏规则。`ConditionalActor` 依据实时变量求值可见性且不注册订阅（变量修改会使缓存纹理失效，重新打开窗口会清空预览模型、纹理与类模板）。

### 玩家 HUD 快捷入口

玩家 HUD 在钥匙下方 `8` 逻辑像素处挂载原生 `WrapBox`，按从左到右的顺序紧凑排列可用快捷按钮（无空位），宽度不足时自动换行：

1. **怪物手册**（玩家持有 `Item.EnemyBook` 时显示，复用物品图标）。
2. **楼层传送器**（玩家持有 `Item.Teleport` 时显示，复用物品图标）。
3. **已访问商店**（`GameInstance` 至少含一条商店记录时显示，使用 `Assets/System/mting-495.png`，并遵守[已访问商店](<#已访问商店>)的打开规则，包括持有楼层传送器）。

图标尺寸为 `32 × 32`，间距 `8` 像素；移动端与 Web 通过原生[触摸命中边界 API](<../全局与 Core 模块/Core Modules/Engine/运行时值与功能控件.md#触摸捕获>) 将点击热区扩至 `40 × 40` 而不缩放图像。按钮不会抢占键盘焦点，也不替代快捷键。

- **绑定与事件驱动刷新**：`Source.Windows.HUDPlayerAttr.new(instance, openMenuCallback?, shortcutCallbacks?)` 绑定至 `GameInstance`（`SceneMap` 负责接入可选的 `enemyBook`、`floorTeleporter` 与 `shopRecords` 回调）。读档或切换主玩家后请调用 `setInstance(instance)`。快捷按钮仅在初始化、重新绑定、当前玩家触发 `PlayerChanged` 背包事件以及当前实例发生[商店记录变更](<运行时数据、配置与存档.md#存档>)时重建，绝不逐帧轮询。
- **HUD 事件订阅**：订阅 `LocaleChanged`、`AbilitySystemChanged` 与 `PlayerChanged`（`Enums.EventKey`），忽略 `owner` 非当前玩家的通知，并仅更新发生变化的控件。载荷类型使用 `Source.Configs.EventChangePayload` 下的 `Enums.AbilitySystemChangeKind`（`Attribute`、`State`）或 `Enums.PlayerChangeKind`（`Inventory`、`Name`、`Map`）。订阅与回调随 HUD 释放一并清理。

### 已访问商店

- **打开条件**：在商店记录开启、玩家持有楼层传送器、至少存在一条商店记录且当前场景允许开窗时，松开 **V** 键即可打开 `WindowShopRecords`。
- **列表展示**：以单列展示全区域的商店记录，每行依次显示本地化的 `mapName`（大地图为 `worldName`）、空格与本地化的记录标签，过长文本行内滚动。重新打开时选中第 1 行并滚回顶部；切换语言仅刷新文本，保留选中项与滚动位置。
- **记录规则**：从带有地图身份的 Actor 成功打开物品商店或属性商店时均会记录访问（参见[商店 Actor](<../节点函数/Scene.md#商店-actor>)与[存档](<运行时数据、配置与存档.md#存档>)）。
- **远程执行**：确认某一行会关闭列表，并以当前玩家作为 `other` 完整执行该商店的 `onCollision` 事件，玩家停留在当前地图。商店 Actor 依据原地图摆放数据（`BPClassVarChanged` 与世界坐标）独立构造，既不加载目标地图场景，也不修改共享类默认值或执行 `onCreate`——因此商店图应依赖配置字段与实时游戏变量，而非目标地图归属或 `onCreate` 状态。对话、条件分支与后续逻辑照常执行。
- **关闭与缺失记录**：关闭商店后直接返回地图操作，不重开列表；取消列表会恢复移动。目标地图或标签缺失时播放提示音，同时保留列表与存档记录（过期条目可用 `removeShop` 移除）。远程打开不会将商店重复记入玩家当前所在地图。

### 地图新手引导

`Map_01` 摆放了一个不可见的 `BP_MapIntroduction` Actor，在入场转场结束后按顺序播放新手引导，随后记录并销毁自身。

- **配置方式**：`Source.Configs.Tutorial` 将引导键映射为 `{ rect: sf.IntRect, text: string }`，采用固定逻辑屏幕坐标（调整 UI 布局时请同步更新矩形）。`BP_MapIntroduction` 通过 `ForEach` 按序将引导键传给 `ShowTutorial`，场景组件按传入键渲染，不硬编码地图名或标签（参见[新手引导](<../节点函数/Scene.md#新手引导>)）。
- **视觉表现**：聚光开口在 `0.25` 秒内收缩至 `rect` 并阻断输入，其余画面（含 HUD 与留边）覆盖 `40%` 不透明度灰幕，边框闪烁一次后开放[确认输入](<../全局与 Core 模块/Core Modules/Engine/输入与服务.md#inputcapture>)。说明文字采用 12 号描边本地化文本（随语言切换刷新），先按屏幕宽度自动换行，左对齐锚定于 `rect` 底边中点；右侧越界时自动左移，下方空间不足时翻转至顶边中点上方。

### 玩家改名窗口

`Map_01` 出生点旁的 NPC 会打开 `WindowPlayerName`，关闭前暂停地图输入。使用 **Tab** / **Shift+Tab** 与方向键在文本输入框和**确认**按钮（全平台始终可见）之间切换焦点。

- **鼠标与触摸**：可直接激活输入框或**确认**按钮；在移动端/Web 提交系统输入弹窗仅更新草稿而不关闭窗口。
- **键盘**：**确认**按钮获得焦点时按 **Enter** / **Space** 应用名称，否则开始编辑。**Escape** 首次按下退出编辑，再次按下丢弃草稿并关闭窗口。
- **手柄**：**A** 键始终进入编辑（即使焦点位于**确认**按钮）。无论当前焦点何在，长按 **X** 一秒（按钮资产配置 `gamepadButton = "X"`、`gamepadLongPress = true`，不填充 `GamepadHintBar`，参见 [Button](<../全局与 Core 模块/Core Modules/Engine/运行时值与功能控件.md#button>)）即可应用名称。**B** 键（或返回按钮）首次按下退出编辑，再次按下丢弃并关闭。
- **校验与 HUD**：名称无效时禁用**确认**按钮（参见 [Source.MapActors.Player](<../源码类/Player.md>)）。HUD 在玩家等级上方显示确认后的名称，超出宽度时自动截断。

### 按区域隐藏的地图预览

启用 `GameMap.HideDisconnectedRegions` 后，怪物手册会在分组与去重前过滤掉当前玩家所在区域隐藏的 Actor。楼层传送器预览应用相同可见性遮罩（当前楼层取玩家所在格，其他楼层取选定落点格）；切换目标区域或修改地形会使预览缓存失效。区域隐藏纯属视觉效果，不改动传送点记录或目的地（参见[非连通区域隐藏](<../全局与 Core 模块/Global APIs/GameMap.md#非连通区域隐藏>)）。

## 输入

运行时输入统一来自 C++ 输入服务，而非编辑器状态（Windows 嵌入模式通过运行时协议转发兼容输入，独立构建直接读取原生窗口）。

- **快捷键**：`Source.Configs.HotKey` 将原生按键绑定到 `Scene`、`Filter` 以及可选的 `FunctionWhenPressed` / `FunctionWhenReleased` 回调，回调接收场景实例。
- **键盘与手柄动作**：物理 **Enter** 与 **Space** 映射为确认，**Escape** 映射为取消（按下与释放均为边沿事件）。手柄使用 `Engine.JoystickButton.getA()` 至 `getShare()` 逻辑按钮，**A**/**Cross** 为确认，**B**/**Circle** 为取消（参见 [Engine：输入与服务](<../全局与 Core 模块/Core Modules/Engine/输入与服务.md>)）。
- **方向输入**：移动与菜单导航仅读取左摇杆 `X`/`Y` 与十字键 `PovX`/`PovY`（右摇杆与扳机轴不会抢占方向）。无论单步导航还是按住移动，只要 `|X| >= |Y|` 均判定为水平方向（严格 45 度角归水平），否则判定为垂直方向。
- **移动端与 HarmonyOS 手势**：在 Android 与 HarmonyOS 上，系统返回键/返回手势发出单次 Cancel/Escape 脉冲而非关闭或切到后台——这与 HarmonyOS 外接键盘转发（发送 SFML 扫描码边沿、可解析的逻辑键边沿与修饰键状态）及双指触摸（右键取消手势）相互独立。系统返回与双指触摸均会触发焦点窗口的 `onReturn()`，但仅双指触摸产生鼠标右键输入。
- **窗口取消关闭**：`WindowSelectable` 负责默认的取消键与鼠标右键关闭逻辑；派生窗口应将未处理输入向上传递，确保每个输入边沿只触发一次 `CancelSE` 与一次关闭转场。

## 焦点与导航

键盘与手柄导航需定义明确的焦点顺序，并确保已禁用或已隐藏的控件不会继续保有活动焦点。

## 设置控件

- **设置页签与导航**：打开时默认位于**图形**页并聚焦第 1 行。**Q**/**E**、**LB**/**RB**、鼠标悬停与触摸点击均可切换页签并播放 `CursorSE`。同一打开会话内及语言刷新时，各页签保持各自的光标与滚动位置；重新打开窗口会重置所有页签。选项含义见[游戏设置参考](<游戏设置参考.md>)。
- **DropBox 控件**：切换页签会静默收起已展开的 DropBox；Cancel 与返回按钮会先收起它，再次按下才关闭设置窗口。展开的 DropBox 覆盖设置行、高度受限时内部滚动、收起前独占输入，并在移动端/Web 触摸上采用先预览后确认（参见 [Engine：交互与声明式 UI 控件](<../全局与 Core 模块/Core Modules/Engine/交互与声明式 UI 控件.md>)）。
- **移动端与 Web Slider**：点击 Slider 在松开时设置数值。拖动超过阈值后，水平拖动归属 Slider，垂直或相等幅度的拖动归属设置列表滚动（内容溢出时），且在松手前锁定手势归属。
- **存读档窗口**：读取与保存页签共用同一槽位列表，切换页签保留光标、滚动与详情。重新打开默认进入读取页并选中最新存档（无存档时为 `0` 号槽）；地图快捷键 **S** 直接以保存模式打开。Cancel 关闭窗口；标题界面的仅读取模式隐藏页签并居中其余窗格。

底层 UI 与输入 API 可从 [GlobalFunctions.Container](<../节点函数/Container.md>) 开始查阅；文本本地化键见[游戏本地化工作流](<../../插件开发与安装/官方插件/游戏本地化工作流.md>)。
