# 资源、音频、视频与特效

本页介绍默认玩法的逻辑资源路径、动画缓存、地图音频与 DSP 音效、2D 材质、程序化雾效、远景、组合式大地图环境以及 FFmpeg 视频播放。

## 资源路径

持久化资产采用大小写精确的 `/Game/Assets/...` 逻辑路径，使用 `/` 分隔并附带扩展名。通用资源管理器要求完整路径；`loadCharacter("actors/Hero.png")`、`playSE("cursor.ogg")` 等类别辅助函数接受类别相对路径并自行补全前缀。

运行时通过相同逻辑路径读取未归档文件与 `.ldpak` 归档条目，包括音乐与视频的流式播放及跳转。Standard Lua 文件系统 API 与 LuaSF 文件构造函数不会解析归档内部路径。

## 动画缓存

动画源数据位于 `Data/Animations`。无论数据存储于未归档目录还是归档，`Engine.getAnimationCacheRoot()` 均在 `Engine.getUserDataPath()` 下解析并创建 `Cache/Animations`，在所有启动模式下遵循[应用用户数据位置](<../../编辑器用户指南/项目设置与资产布局.md#游戏配置>)。

- **构建与失效**：启动时自动生成缺失的 `.anim.json`/`.anim.ldc` 缓存，并在源定义或引用的帧资产变更时重建，保留相对于 `Data/Animations` 的路径。缓存可随时丢弃，不包含在模板与玩家发行包中。
- **二进制格式**：源数据经 `Engine.decodeData` 解码，缓存经 `Engine.saveData` 写入。`.anim.ldc` 直接存储二进制数据，不经中间 JSON；请删除旧版压缩 JSON 格式的缓存以便启动时重新生成。
- **相关模块**：`Source.Utils.AnimationCache` 为 `SceneInit` 提供键提取、帧资产查找与过期检测；`Global.Data.LoadAnimations()` 负责加载已准备的缓存。

## 音频

音乐、音效与语音在[游戏配置](<../../编辑器用户指南/项目设置与资产布局.md#游戏配置>)中各自拥有独立的启用开关与音量。玩法音频通过 [GlobalFunctions Manager 辅助函数](<../全局与 Core 模块/Core Modules/GlobalFunctions.md#manager>) 播放。

### 地图 BGM 与 BGS（`Global.Audio.MapAudio`）

`Global.Audio.MapAudio` 借助 `Global.Audio.MapAudioState` 实现地图 BGM/BGS 播放、过滤器管理、声源复用与淡入淡出。自定义场景使用 `MapAudio.new()` 创建实例，通过 `playMapAudio(mapData, transitionSeconds?)` 触发音轨、在 `onTick(deltaTime)` 中推进淡变，并调用 `stopMapAudio()` 停止播放。

用户的音乐开关与音量设置在淡变期间立即生效，更新曲目过滤器音量不会重置淡变进度。重新请求正在播放的同一文件会复用声源、重新应用过滤器并取消当前淡变。场景栈返回行为见[脚本操作与生命周期](<../源码类/SceneMap.md#脚本操作与生命周期>)。

### Lua DSP 音频效果

`Source.Utils.AudioEffects` 定义了玩法 Manager 与蓝图音频节点使用的大小写敏感 DSP 预设：

| 预设 | 默认参数 |
|---|---|
| `Echo` | `0.3` 秒延迟、`0.5` 衰减 |
| `Distortion` | `2.0` 驱动（drive）、`0.7` 阈值（threshold） |
| `Underwater` | `0.7` 深度（depth）、`0.3` 气泡（bubble） |
| `BehindWall` | `900` Hz 截止频率、`0.35` 透射率（transmission） |

- **选择预设**：`GlobalFunctions.Audio.SetEffect(audioType, effect)` 通过 `AudioEffects.Get` 解析 `effect`，并为 `Sound`、`Voice` 或 `Music` 独立保存挂接器（两参数在元数据中均为下拉框）。选择预设不会立即实例化处理器或影响正在播放的声源；后续新建的每个声源会在隔离的音频 Lua 状态机中调用挂接器并创建全新处理器。传入字面量字符串 `"nil"` 可清除后续播放效果，其他未知名称会立即抛出错误。
- **注册表归属**：`Source.Utils.AudioEffects` 是唯一预设注册表——增改预设时需同步更新 `SetEffect` 的元数据下拉项。项目挂接器向 [`AudioEffectControl.attachLuaProcessor`](<../全局与 Core 模块/Core Modules/GlobalCore/资源管理器.md#audiomanager>) 传入 `"Source.Utils.AudioEffects"`、`"Get"` 与预设名；替换注册表模块时须同步修改该调用。效果选择独立于 `SoundFilter` 与 `MusicFilter`。
- **采样率、热重载与尾音排空**：非空预设在声源创建时捕获当前播放设备的采样率（活动声源在设备切换后保留原有系数；需通过 Manager 重新发起播放以适配新采样率或启用[热重载](<../Lua 运行时与模块.md#lua-热重载>)后的音频代码）。预设之间不串联也不混合。`Echo` 在流自然结束后排空缓冲尾音，而通过 Manager 显式停止、跳过对话或关闭应用会直接丢弃尾音。直接调用 `sf.SoundSource:setEffectProcessor` 会绕过 Manager 的隔离、流结束处理与取消协议。
- **对话语音生命周期**：`GlobalFunctions.Scene.ShowVoiceMessageByTag` 与 `ShowVoiceMessage` 会追踪本次调用启动的语音句柄，在对话结束时先停止该句柄，再由 `FinishedDialogue` 恢复下游节点（确保紧随其后的 `SetEffect` 作用于下一段语音）。离开或销毁地图场景同样会停止当前全局语音；普通消息节点不影响语音播放。

## 着色器、雾与转场

### 2D 材质与着色器

Actor 与图块图层通过 Ludork 2D 材质系统渲染。`SceneInit` 在进入玩法前于用户数据目录中生成材质着色器与运行时元数据，随后执行独立的[平台着色器缓存](<../../C++ 原生开发/构建与模块布局.md#mrb-渲染>)准备阶段；缓存校验与归属规则见[运行时生成](<../../编辑器用户指南/材质.md#运行时生成>)。

- **材质组合**：启动阶段会准备所有独立材质，并扫描已保存地图中的图块/图层材质组合。若运行时脚本动态构造地图或切换图层材质产生新组合，请在准备前先在[游戏 → 材质组合](<../../编辑器用户指南/材质.md#材质组合>)中登记。Actor 与 UI 的材质切换及参数修改无需额外登记。
- **资源共享与求值**：材质资源与编译后的程序全局共享，实例参数彼此独立。角色效果均为标准 `Data/Materials` 节点图（例如色相偏移使用 HueShift 节点与参数）。Alpha、遮光与顶点位移基于同一张图求值，使溶解轮廓自动同步更新阴影遮罩。自发光在各自表面内合成，既不照亮邻近物体也不绕过前景遮挡。
- **内置管线与平台支持**：内置天气与雾效使用跨平台着色器管线，加载与编译错误会向外传播。进入大地图时会针对当前视口预热共享渲染器，并在区域几何变更后重新预热。HarmonyOS 在首次常规绘制绑定渲染状态与 uniform 后编译程序。着色器可用性取决于目标运行时 GPU——编辑器预览正常不代表目标硬件必然支持。
- **粒子**：可将 GPU [通用粒子](<../../编辑器用户指南/通用粒子.md>)发射器挂载至 Actor 组件与 UI，默认玩法中由代码驱动的粒子可与之并存。

### 敌人击败粉碎特效

默认玩法的项目级敌人击败粉碎特效在[共享玩法配置](<运行时数据、配置与存档.md#共享玩法配置>)中通过 `Enemy.DefeatShatterEffectEnabled` 统一开关，而非按单个 Enemy 蓝图控制。该着色器对敌人画面进行快照，并在约 `0.65` 秒内将世界空间逻辑像素碎片向外径向散射。由于此时敌人已被记录并销毁，特效纯属视觉表现，不阻挡移动、碰撞或光线。关闭开关或 `sf.Shader.isAvailable()` 返回 `false` 时，被击败的敌人立即消失。

### 程序化雾效与远景

- **GPU 雾效**：基于世界坐标、绝对时间与确定性种子，由四层噪声程序化生成（无需雾纹理）。密度控制覆盖率，颜色 Alpha 缩放雾团不透明度而不叠加均匀灰幕，较小尺度产生更细密的雾团（黑雾亦然）。地图数据保存 `enabled`、`colour`、`density`、`scale`、`velocity`、`turbulence` 与 `seed`（参见 [FogController](<../全局与 Core 模块/Core Modules/GlobalCore/地图与雾效.md#fogcontroller>)）。雾效在材质与光照之后、前景天气与粒子之前合成，响应场景光照，并在每次进入地图会话时重置。
- **地图远景**：`panorama` 为可选的规范 `/Game/Assets/...` 字符串（缺失、`nil` 或空白时禁用）。纹理保持宽高比以 Cover 模式缩放铺满 `GameMap.MapViewRect`，溢出部分按各轴摄像机原点在 `(mapPixels - viewPixels)` 中的比例裁剪（不可滚动轴取 `0.5`）。透明图块与画布边距露出的远景仅受环境光染色，点光源作用于不透明图块。远景纹理缺失会导致加载失败。

### 组合式大地图环境

- **雾效与远景**：大地图清单可定义全局雾效（覆盖包括空洞在内的整个大地图）与全局远景（沿完整世界边界滚动）。子地图雾效裁剪至其摆放范围，采样同一世界坐标与时间，在全局雾效之后按稳定摆放顺序合成（相同配置的相邻区域无缝衔接），子地图逐出后消失直至重新加载。子地图自身的 `panorama` 仅在其作为独立地图加载时生效。
- **音频与环境光**：大地图清单不可定义 BGM、BGS、音频过滤器或环境光——这些属性随玩家当前所处子地图切换，音频与后续环境光过渡均淡变 `0.5` 秒。空洞不播放地图音频并使用白色环境光，同时保持全局雾效与远景生效。
- **大地图光照**：光源工作在世界坐标系中，因此 Actor 的 `LightComponent` 光源可跨子地图边界照明并投射阴影。图块遮光遮罩裁剪至各自摆放范围，空洞既不提供受光表面也不提供遮挡体。编辑器预览控制见 [PreviewHost：地图与世界预览](<../../PreviewHost/地图与世界预览.md>)。

## 视频

视频播放需要启用 FFmpeg 的项目或模板。视频文件存放于 `Assets/Videos`，以 `/Game/Assets/Videos/...` 引用（未归档文件与 `Assets.ldpak` 条目遵循相同的可跳转播放契约）。构建与打包详情见 [FFmpeg 选项](<../../快速入门/项目模板.md#ffmpeg-选项>)。

- **Android**：支持 MOV、H.264/AAC、`swscale` 与 `swresample`；不包含网络流、JNI、MediaCodec 与硬件加速。
- **WebGL**：复用同一 FFmpeg 软件解码器、资源路径、静音、跳过与字幕功能，不依赖浏览器 HTML 编解码器。音频遵循[浏览器启动策略](<../../编辑器用户指南/运行、调试与打包.md#webgl>)，失焦时暂停视频时钟；解码运行于主线程，流畅分辨率取决于设备性能。

通过 `GlobalFunctions.Video.PlayVideo(videoFileName, mute, skipable, subtitleFileName?)` 播放视频，可选第四参数为项目相对路径 `Data/Subtitles/...json`（省略或传 `""` 则无字幕播放）：

```lua
local Video = require("GlobalFunctions.Video")
Video.PlayVideo("/Game/Assets/Videos/intro.mp4", false, true, "Data/Subtitles/intro.json")
```

[字幕文件](<../../编辑器用户指南/视频字幕.md>)声明 `type: "subtitle"` 与 `sections` 数组，每段指定起止时间（秒）及共享字符串数组或按语言键索引的字典。字典条目优先取当前游戏语言，仅在键缺失时回退至 `en_GB`（显式空数组表示隐藏字幕）。字幕同步视频时钟，使用默认字体以白字黑描边居中渲染于视口底部。
