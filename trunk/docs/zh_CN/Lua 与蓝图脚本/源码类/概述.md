# 源码类总览

`Source.*` 是默认玩法模板中的 Lua 类，位于 `Scripts/Source/`。下表链接到各类的属性、函数和事件参考。

## 类

| 类 | 直接 metadata 基类 | 职责 | 页面 |
|---|---|---|---|
| `Source.Battler` | 未声明 | `Enemy` 与 `Player` 的 Lua 玩法基类，这两个类都依据通用数据构造各自生成的 Attribute Set | [Battler.md](<Battler.md>) |
| `Source.Components.ChildActorComponent` | `{ "Engine", "Component" }` | 声明子 Actor 的类名与相对位置 | [ChildActorComponent.md](<ChildActorComponent.md>) |
| `Source.MapActors.DoorBase` | `{ "Source.MapActors.ConditionalActor", "ConditionalActor" }` | 声明门的碰撞、开启间隔、门音效与门状态属性，以及开门与关门节点 | [DoorBase.md](<DoorBase.md>) |
| `Source.MapActors.Enemy` | `{ "Source.MapActors.ConditionalActor", "ConditionalActor" }`、`{ "Source.Battler", "Battler" }` | 可见性受条件控制的 Battler Actor，绑定 Enemy 通用数据的 `ID`，带有伤害文本子组件以及碰撞与战败事件 | [Enemy.md](<Enemy.md>) |
| `Source.MapActors.EnemyDamageText` | `{ "Engine", "Actor" }` | 声明 Enemy 伤害读数所需的 Item、文本配置与偏移 | [EnemyDamageText.md](<EnemyDamageText.md>) |
| `Source.MapActors.Equip` | `{ "Source.MapActors.ConditionalActor", "ConditionalActor" }` | 声明装备 Actor 的通用数据标识与音效 | [Equip.md](<Equip.md>) |
| `Source.MapActors.Item` | `{ "Source.MapActors.ConditionalActor", "ConditionalActor" }` | 可见性受条件控制的拾取 Actor，依据 `ID` 构造 Item Attribute Set，碰撞时把 `count` 个物品交给 Player | [Item.md](<Item.md>) |
| `Source.MapActors.Player` | `{ "Engine", "Character" }`、`{ "Source.Battler", "Battler" }` | 声明可操控 Actor 的 Character 属性，以及背包、装备与属性命令 | [Player.md](<Player.md>) |
| `Source.Scenes.SceneMap` | `{ "Source.Gameplay.GameplayScene", "GameplayScene" }` | 声明地图 Scene 的玩法命令、对话窗口、菜单入口与持久化记录 | [SceneMap.md](<SceneMap.md>) |
| `Source.MapActors.Teleporter` | `{ "Source.MapActors.ConditionalActor", "ConditionalActor" }` | 声明楼梯偏移、音效、转场与计时属性，以及上下楼与选定地图节点 | [Teleporter.md](<Teleporter.md>) |
| `Source.MapActors.ConditionalActor` | `{ "Engine", "Actor" }` | 声明控制 Actor 可见性的条件变量、运算符与比较值 | [ConditionalActor.md](<ConditionalActor.md>) |
