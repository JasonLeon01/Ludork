# 源码类总览

`Source.*` 类属于默认玩法模板中的 Lua 类，位于 `Scripts/Source/` 目录。下表列出了各类的继承关系、核心职责及对应的属性、方法与事件参考页。

## 类

| 类 | 继承 | 职责 | 页面 |
|---|---|---|---|
| `Source.Battler` | — | `Enemy` 与 `Player` 的 Lua 玩法基类，两者均依据通用数据构造生成的 Attribute Set | [Battler.md](<Battler.md>) |
| `Source.Components.ChildActorComponent` | `Engine.Component` | 声明子 Actor 的类名与相对位置 | [ChildActorComponent.md](<ChildActorComponent.md>) |
| `Source.MapActors.DoorBase` | `Source.MapActors.ConditionalActor` | 声明门的碰撞、开启间隔、门音效与开关状态属性，以及开门与关门节点 | [DoorBase.md](<DoorBase.md>) |
| `Source.MapActors.Enemy` | `Source.MapActors.ConditionalActor`、`Source.Battler` | 可见性受条件控制的战斗 Actor，绑定 Enemy 通用数据的 `ID`，附带伤害文本子组件以及碰撞与战败事件 | [Enemy.md](<Enemy.md>) |
| `Source.MapActors.EnemyDamageText` | `Engine.Actor` | 声明敌人伤害读数所需物品、文本配置与显示偏移 | [EnemyDamageText.md](<EnemyDamageText.md>) |
| `Source.MapActors.Equip` | `Source.MapActors.ConditionalActor` | 声明装备 Actor 的通用数据标识与拾取音效 | [Equip.md](<Equip.md>) |
| `Source.MapActors.Item` | `Source.MapActors.ConditionalActor` | 可见性受条件控制的拾取 Actor，依据 `ID` 构造 Item Attribute Set，碰撞时向 Player 发放 `count` 个物品 | [Item.md](<Item.md>) |
| `Source.MapActors.Player` | `Engine.Character`、`Source.Battler` | 声明可操控 Actor 的 Character 属性，以及背包、装备与属性操作命令 | [Player.md](<Player.md>) |
| `Source.Gameplay` | 因模块而异 | 基于 `GlobalCore` 构建的 Game 项目玩法 Scene、Actor、能力与效果模块 | [Gameplay.md](<Gameplay.md>) |
| `Source.Scenes.SceneMap` | `Source.Gameplay.GameplayScene` | 声明地图 Scene 的玩法命令、对话窗口、菜单入口与持久化记录 | [SceneMap.md](<SceneMap.md>) |
| `Source.MapActors.Teleporter` | `Source.MapActors.ConditionalActor` | 声明楼梯方向、落点偏移、音效、转场与计时属性，以及上下楼与指定地图传送节点 | [Teleporter.md](<Teleporter.md>) |
| `Source.MapActors.ConditionalActor` | `Engine.Actor` | 声明控制 Actor 可见性的条件变量、运算符与比较值 | [ConditionalActor.md](<ConditionalActor.md>) |
