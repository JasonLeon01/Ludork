# Script Mixin 元数据

Script Mixin 的配套 `_meta.lua` 文件用于向蓝图编辑器暴露可编辑字段。该文件必须返回 `_METADATA`，且仅包含一个与脚本文件同名的类型；它不声明运行时方法、蓝图节点入口或继承层级。

```lua
local _METADATA = {
    KeyDoor = {
        attrs = {
            "needKeyID",
            "needKeyCount",
        },
        needKeyID = {
            type = { enum = "Enums.GeneralData.Item", valueType = "string" },
            default = "",
        },
        needKeyCount = {
            type = "int",
            default = 1,
        },
    },
}

return _METADATA
```

## 规则

- `attrs` 是稠密、有序的数组，其中字段名互不重复且非空。
- 列出的每个字段都是包含有效 `type` 的表。
- `default`（若提供）必须是有限、无环、可转换为 JSON 的纯数据。既未出现在已保存属性中又未提供 `default` 的字段仅作为 Schema 声明存在。
- `bases` 必须省略或为空表；基类由蓝图继承决定。
- 根表中不得包含第二个类型、函数、userdata、协程或对外部状态的访问。
- 编辑器 Decorator 仅细化 Inspector 控件，不改变运行时值；资源与游戏变量选择器见[编辑器名称与 Decorator](<../蓝图脚本/元数据结构与 Decorator.md#编辑器名称与-decorator>)。

Mixin 元数据直接为蓝图声明其字段。本地值覆盖应写入 `attrs`，切勿在 `attrDefs` 中重复声明 Mixin 字段。`attrDefs` 仅用于蓝图额外新增的字段（后代蓝图会继承其类型与默认值）。缺少声明或与继承字段、Mixin 字段冲突均会导致加载失败，参见[蓝图属性声明](<../蓝图脚本/元数据结构与 Decorator.md#蓝图属性声明>)。
