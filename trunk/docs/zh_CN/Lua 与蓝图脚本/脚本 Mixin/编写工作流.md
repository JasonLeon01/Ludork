# Script Mixin 编写工作流

使用 Script Mixin 可通过 Lua 表而非可视化节点图实现蓝图类的事件行为。

同一条蓝图继承链中，图模式与 Script Mixin 模式互斥。脚本由链上第一个 Script Mixin 蓝图提供；后代蓝图可以继承该脚本或指定另一个兼容的 Mixin，但不能切换回图模式。

由于 Script Mixin 蓝图的事件由 Lua 执行，因此可以省略 `graph` 字段；若保留了 `graph` 字段，即使运行时不会执行它，该字段仍必须是结构合法的图对象。图模式蓝图则必须始终保存 `graph` 对象。

## 创建并挂载 Script Mixin

1. 创建或打开一个蓝图，确保其父类提供 Mixin 所需的生命周期事件与原生成员。
2. 在继承链的第一个蓝图上启用 **Script Mixin**。
3. 当 **Script Path** 为空且可编辑时，点击 **...** 旁的 **+**，在 `Scripts/Mixins` 下选择目录并输入文件名（例如 `Doors/KeyDoor.lua`）。若省略扩展名，编辑器会自动补全 `.lua`。
4. 保存以生成脚本及其同名 `_meta.lua` 配套文件。编辑器会自动选中新脚本并隐藏 **+**。如需挂载已有脚本，请点击 **...**。保存的路径均相对于 `Scripts/Mixins`。
5. 实现生成的事件方法，按需添加可编辑默认值与元数据字段，然后刷新或重新打开蓝图并保存。

- **命名与文件安全**：脚本名必须以 ASCII 字母或下划线开头，仅包含 ASCII 字母、数字和下划线，且不得使用 Lua 关键字。创建操作不会覆盖已有文件；撤销/重做仅恢复路径选择，不会删除已创建的文件。
- **生成模板**：生成的脚本包含解析后的 Actor 类型所声明的全部事件（继承事件采用最派生签名），通过 `super()` 转发参数并返回结果。模板不会生成普通方法或 `init`。配套元数据文件仅声明对应类型与空的 `attrs` 表。

## 文件对

`scriptPath` 指向 `Scripts/Mixins` 目录下已有的 `.lua` 文件，路径分隔符固定为正斜杠。空路径段、`.`、`..`、盘符前缀、绝对路径根以及 `_meta.lua` 后缀均无效。

```text
Scripts/
└── Mixins/
    └── Doors/
        ├── KeyDoor.lua
        └── KeyDoor_meta.lua
```

元数据文件仅用于向编辑器声明可编辑字段，不提供运行时方法。运行时脚本负责全部行为，且不得加载其配套元数据文件。

也可以参照[表的规则](<运行时契约.md#表的规则>)与 [Script Mixin 元数据](<元数据.md>)手动创建这一对文件；空的 `attrs` 表合法。

## 继承脚本

子蓝图可以省略 `scriptPath` 直接继承父类的 Mixin，也可以指定另一个路径，在继承成员之上叠加兼容的子 Mixin。替换脚本前，请先确认字段与函数的成员种类与继承类兼容，并清理已保存但不再属于解析后 Schema 的过期属性。
