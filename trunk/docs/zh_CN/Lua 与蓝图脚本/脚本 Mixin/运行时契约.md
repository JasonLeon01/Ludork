# Script Mixin 运行时契约

运行时按 `Mixins.<点分路径>` 加载 Script Mixin，并要求其返回一个不带元表的普通 Lua 表。本契约定义了生成蓝图类的成员规则、实例默认值、保留名称、父方法调用与热重载行为。

## 表的规则

- 每个表键都必须是字符串。
- 函数条目成为生成蓝图类上的方法。
- 非函数值会深复制到类默认值与实例默认值中。
- 继承成员不能在字段与函数之间切换种类。
- 已保存的蓝图属性不能替换 Mixin 方法。

以下成员名称为系统保留名称：

```text
__*  init  new  scriptMixin  scriptPath
_GENERATED_CLASS  _graph  _hasImplementationOwner
```

> **注意**：由于 `init` 属于保留名称，Script Mixin 不能声明构造函数。请在所属类型的生命周期回调（如 `onCreate`）中初始化私有实例状态，并在对应的清理回调中释放订阅或资源。

## 调用父方法

在 Mixin 方法内调用 `super()` 可继续沿蓝图与原生继承链向上分派：

```lua
local Door = {}

function Door:onCollision(other)
    if self.opening then
        return
    end
    super().onCollision(other)
    self:openDoor()
    self.opening = true
end

return Door
```

父类必须提供 Mixin 访问的全部原生属性与方法；引用缺失成员会抛出错误。

## 热重载

[Lua 热重载](<../Lua 运行时与模块.md#lua-热重载>)适用于已使用的 Script Mixin：输入 `$r` 会更新兼容的方法，不会重新执行生命周期回调，也不会覆盖默认值或存活实例的状态。涉及结构性变更时仍需重启游戏。

Lua 编译与 `.ldpak` 打包会保留 Mixin 的模块路径以及每次执行重新加载的行为。打包选项见[运行、调试与打包](<../../编辑器用户指南/运行、调试与打包.md>)。
