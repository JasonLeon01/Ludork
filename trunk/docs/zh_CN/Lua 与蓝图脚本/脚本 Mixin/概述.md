# 脚本 Mixin 总览

Script Mixin 将 Lua 行为直接附加到蓝图类，使蓝图保留原有默认值与继承层级，同时用 Lua 实现事件逻辑。

| 页面 | 内容 |
|---|---|
| [编写工作流](<编写工作流.md>) | 创建脚本与配套元数据文件，将其挂载到蓝图并配置继承。 |
| [运行时契约](<运行时契约.md>) | Lua 表与成员规则、默认值、父方法调用及热重载。 |
| [Game 项目示例](<Game Mixins.md>) | 默认玩法中提供的消耗品与门 Mixin 示例。 |
| [元数据](<元数据.md>) | 为 Script Mixin 声明蓝图可编辑字段。 |
