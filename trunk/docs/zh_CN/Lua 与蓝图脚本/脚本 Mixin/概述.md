# 脚本 Mixin 总览

Script Mixin 将 Lua 行为附加到蓝图类：蓝图保留原有默认值与继承关系，事件逻辑则由 Lua 编写。

| 页面 | 内容 |
|---|---|
| [编写工作流](<编写工作流.md>) | 创建脚本及配套 metadata 文件，将脚本挂载到蓝图，并配置继承。 |
| [运行时契约](<运行时契约.md>) | Lua 表、成员、默认值、父方法调用和热更新规则。 |
| [Game 项目示例](<Game Mixins.md>) | 默认玩法中的消耗品与门脚本。 |
| [Metadata](<Metadata.md>) | 声明蓝图中可编辑的字段。 |
