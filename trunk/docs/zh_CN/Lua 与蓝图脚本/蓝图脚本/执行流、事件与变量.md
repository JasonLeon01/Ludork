# 执行流、事件与变量

蓝图在 `Data/Blueprints` 中定义类默认值和事件图；公共函数提供可复用的图。编辑操作见[蓝图、公共函数与 Actor](<../../编辑器用户指南/蓝图、公共函数与 Actor.md>)。Script Mixin 蓝图的事件由 [Lua 脚本](<../脚本 Mixin/编写工作流.md>)定义，不执行图。

## 事件

事件以 `type = "event"` 声明。事件入口提供按顺序排列的参数输出和一个执行输出。执行连线指定开始节点；没有连线时，本地图不执行。类蓝图会沿父类链查找事件实现，继续跳过空的祖先图。公共函数和通用数据图没有继承事件的回退行为。

通用数据的成员图是同步 ability，不参与继承，也不是隐式的蓝图事件。`Source.Gameplay.GeneralDataGraphAbility` 以 `GameplayEventData` 作为 parent 激活选定的图。start 为 `null` 时返回 `NoGraph`。latent 节点无效，错误向调用方传播。

## 父事件调用

新建图模式蓝图，以及显式新增本地事件图时，若父类链声明了同名事件，就初始化为 `Event → Parent`，并逐一连接事件参数到对应的 Parent 输入。父蓝图自定义事件没有 metadata 签名时，Parent 不带参数输入。已有图不会自动补写，Script Mixin 图仍不执行。

Parent 节点有一个执行输入和一个执行输出，以及按事件签名排列的参数输入；没有接收者或返回值引脚。它从当前图所属类的父类开始查找事件实现。

每个输入传递当前连线值或普通未连接默认值。参数数组遵循 SUPER 的长度与回填规则：缺失或 nil 参数可能从调用方事件上下文补回。nil 输入不表示显式清空原事件参数；nil 空洞后面的值也受原有数组长度边界限制。在该边界内的非 nil 参数（包括 `false`）覆盖对应事件值。

[GlobalFunctions.Utils.SUPER](<../节点函数/Utils.md>) 通过 `SUPER(obj, params)` 调用父事件。普通实例方法使用下文的 `self` 输入。

## 公共函数

公共函数与调用方共享局部上下文和图的所属对象，嵌套调用时也一样。因此，`SELF` 与实例方法的默认接收者都指向该对象。

## 执行语义

- `Pure = true` 会移除执行输入引脚与执行输出引脚。有返回值并不代表节点是 pure。
- `ExecSplit` 把具名执行输出映射到结果值。
- `Latent` 节点返回 `Engine.AsyncOperation`，挂起图，之后通过已声明的状态恢复。
- 只要当前执行还有未完成的 latent 节点，蓝图事件就会丢弃同一个图实例、同一个事件键的重复触发。该次执行的全部潜伏操作结束后，才接受新的触发。不同的图实例与事件键彼此独立。
- `LoopNode` 描述循环体与完成时的行为。
- 数据连线连接类型兼容的引脚，执行连线连接流程引脚。
- 每个执行输出只能连接一条线，执行输入可连接多条；数据输出可连接多条线，每个数据输入只能连接一条。

运行时的事件查询与执行使用原生 `Engine.Graph` userdata。原始 GraphData 用于定义阶段的事件检查。本地执行上下文保存调用状态，本身不是可执行的图。构造没有继承类的图时，把只读字符串 `Engine.Graph.NO_PARENT_CLASS`（`"NOT_WRITTEN"`）传给 `Graph.new` 的 `parentClassName`。图的所属对象仍由独立的 `parent` 参数提供。

### 取消 latent 执行

`operation:cancel()` 或 `Engine.latentManager:cancel(operation)` 取消等待该操作的事件执行及其待完成节点和循环，不执行后继输出或完成回调。Lua 与蓝图共用的操作契约见 [AsyncOperation](<../全局与 Core 模块/Core Modules/Engine/事件与模块根.md#asyncoperation>)。

## 实例方法的接收者

每个实例方法节点都保留有类型的 `self` 输入，包括当前蓝图继承的方法。显式连线或填写的值决定接收者；未连接且未填写时，声明的 `"self"` 默认值选择图的所属对象。连入 nil、接收者类型不匹配或所属对象缺失时，在调用方法前报错。

短方法名、`self.method` 与完整路径使用相同的参数顺序，接收者只传递一次。保存的 `params` 按该顺序排列，接收者位于索引 0；保存 `"self"` 表示使用所属对象，未设置的值采用声明的默认值。参数连线使用相同的零起始索引。静态函数与事件载荷没有接收者槽位。

通用数据图的所属对象是 `GameplayEventData`。调用 Actor 方法时，需连接它的 `target` 或另一个预期对象。

## 连线的类型规则

只要联合类型中至少有一个分支接受该值的类型，这个值就能连到该联合类型。联合类型的输出要连出去，则必须让目标接受所有可能分支。列表、字典与元组按同样的规则递归判断。派生类型可以连到已声明的基类。`int` 可以连到 `float`，但 `float` 连到 `int`、以及不同 SFML 向量类型之间的转换都会被拒绝。`any` 允许动态连线，实际值在运行时检查。

枚举引脚保留自己的枚举结构定义，但使用枚举模块的底层 `string`、`bool`、`int` 或 `float` 判断兼容性。它可以连接兼容的标量引脚，或底层类型兼容的其他枚举；容器与联合类型内部也按此递归判断。整数枚举可以连到浮点输入，浮点枚举不能连到整数输入。实际值无需属于当前的具名选项集合。

加载或粘贴图之后，类型不兼容的连线仍会保留并显示为红色，悬停提示会说明原因。修正后才能正常保存。

## 默认值与引用

新输入采用已声明的默认值，或该类型的一个有效字面量。对象与函数输入两者都没有时保持未设置。已保存的字面量必须符合声明类型，即使该输入已经连线。无效值会保留显示并阻止正常保存，连线传入的值在运行时检查。默认值与返回值的 metadata 写法见[函数与事件](<Metadata 结构与 Decorator.md#函数与事件>)。

枚举选择器显示键并保存标量值。重新打开下拉框或返回字段时会重新读取枚举文件。未知的已保存值会保留并提示；底层标量类型错误的值则无效。普通输入框接受标量值，不接受显示的键。模块与 metadata 示例见[枚举结构定义](<Metadata 结构与 Decorator.md#枚举-schema>)。

## 类属性

蓝图的 `attrs` 保存值；新增变量还必须在同级 `attrDefs` 中通过 `type` 显式声明类型，**添加属性** 会同时写入两者。继承自 metadata、Script Mixin 和祖先蓝图的字段保留已有声明，子类只覆盖值。字段读写节点与角色信息都使用继承得到的类型，包括枚举身份和嵌套容器类型。

缺少声明、值不符合类型和重复声明都会使编辑器及运行时拒绝读取。全局保存与 **保存无效蓝图** 均不能绕过类结构定义校验，地图 Actor 覆盖也按解析后的类结构定义校验。存储示例见[蓝图属性声明](<Metadata 结构与 Decorator.md#蓝图属性声明>)。

## 类定义与会话生命周期

同一个 Lua VM 中的 ClassDict 实例共享已解析的类、定义表与已编译的图模板。改动 JSON 类定义或图模板后需要重启。[Lua 热更新](<../Lua 运行时与模块.md#lua-热更新>)只更新兼容的脚本函数。

`ClassDict:getData(path)`（Game 项目中也以 `Global.Data.GetClassData(path)` 暴露）先用与 `get` 相同的加载路径解析，然后返回解析后的 JSON 定义表。未知路径会抛错，没有 JSON 定义的模块类返回 nil。同一个 VM 内重复读取会得到同一个 Lua 表；需要独立的 Lua 表时用 `copy` 或 `deepcopy`。

改动这个 Lua 表会影响后续的定义读取，但不会更新已生成的类、实例默认值记录或已编译模板。新实例与可执行事件查询继续使用已生成的结果。
