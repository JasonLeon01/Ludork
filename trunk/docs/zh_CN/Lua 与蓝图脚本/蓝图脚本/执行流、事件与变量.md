# 执行流、事件与变量

蓝图在 `Data/Blueprints` 中定义类默认值与可视化事件图，公共函数则提供可跨蓝图复用的图。编辑器操作见[蓝图、公共函数与 Actor](<../../编辑器用户指南/蓝图、公共函数与 Actor.md>)。Script Mixin 蓝图的事件直接在 [Lua](<../脚本 Mixin/编写工作流.md>) 中定义，不执行节点图。

## 事件

事件使用 `type = "event"` 声明。事件入口节点暴露按顺序排列的参数输出引脚以及单个执行输出引脚。

- **本地执行与父类回退**：执行连线决定首个运行的节点。若未连接，本地图不会执行；类蓝图随后沿父类链向上查找实现，跳过空的祖先图。公共函数与通用数据图不具备继承事件回退行为。
- **通用数据成员图**：通用数据图作为同步能力运行，而非继承式蓝图事件。`Source.Gameplay.GeneralDataGraphAbility` 以 `GameplayEventData` 作为所属对象激活选定图。起始节点为 `null` 时返回 `NoGraph`。通用数据图中禁止使用 Latent 节点，运行时错误会直接向调用方传播。

## 父事件调用

新建图模式蓝图或新增本地事件图时，只要祖先类声明了同名事件，就会自动初始化 `Event → Parent` 执行连线，并添加初始数据连线将各事件参数转发至对应的 Parent 输入。若父蓝图的自定义事件未声明元数据签名，Parent 节点不带参数输入。既有图不会自动补充这些连线，Script Mixin 图保持不执行。

Parent 节点包含一个执行输入、一个执行输出、与事件参数匹配的类型化数据输入，不含接收者或返回值数据引脚。它会从当前图所属类的上一级开始解析事件实现。

- **参数解析**：各输入提供当前连线值或未连接默认值。参数数组遵循 `SUPER` 的长度与回退规则：缺失或 `nil` 参数可能回退取用调用方事件上下文中的值。
- **`nil` 空洞与覆盖**：传入 `nil` 不会清空原事件参数，且 `nil` 空洞之后的值同样受数组长度边界约束。位于该边界内的非 `nil` 参数（包括 `false`）会覆盖对应的事件值。

在 Lua 或蓝图中可通过 [GlobalFunctions.Utils.SUPER](<../节点函数/Utils.md>) 以 `SUPER(obj, params)` 调用父事件。普通实例方法则使用下文[实例方法的接收者](<#实例方法的接收者>)中的 `self` 输入。

## 公共函数

公共函数与调用方共享局部上下文及图所属对象，嵌套调用时亦然。因此，`SELF` 与实例方法的默认接收者均指向该同一所属对象。

## 执行语义

节点元数据与图连线共同决定节点图的执行流转：

- **`Pure = true`**：移除执行输入与输出引脚。存在返回值并不隐含节点为 Pure。
- **`ExecSplit`**：将具名执行输出映射到运行时返回值。
- **`Latent`**：返回 `Engine.AsyncOperation`，挂起节点图，并在随后沿已声明的状态输出恢复执行。
- **重入抑制**：只要当前执行仍有未完成的 Latent 节点，蓝图事件就会丢弃同一图实例、同一事件键的重复触发；待所有 Latent 操作结束后，才接受新的触发。不同图实例与事件键彼此独立运行。
- **`LoopNode`**：声明循环体与完成时的执行输出。
- **引脚基数**：数据连线连接类型兼容的数据引脚，执行连线连接流程引脚。每个执行输出仅允许连接一条线，执行输入允许连接多条；数据输出允许连接多条线，每个数据输入仅允许连接一条。

运行时事件查询与执行均基于原生 `Engine.Graph` userdata。原始 `GraphData` 仅支持定义阶段的事件检查，局部执行上下文仅保存单次调用状态而非可执行图。构造无父类的图时，请将只读字符串 `Engine.Graph.NO_PARENT_CLASS`（`"NOT_WRITTEN"`）传给 `Graph.new` 的 `parentClassName`；图的所属对象由 `parent` 参数独立提供。

### 取消 Latent 执行

调用 `operation:cancel()` 或 `Engine.latentManager:cancel(operation)` 可取消等待中的事件执行（含挂起节点与循环），且不会触发下游输出或完成回调。Lua 与蓝图共享的操作契约见 [AsyncOperation](<../全局与 Core 模块/Core Modules/Engine/事件与模块根.md#asyncoperation>)。

## 实例方法的接收者

每个实例方法节点均暴露类型化的 `self` 输入，当前蓝图继承的方法也不例外。显式连线或填写的值决定接收者；二者均未设置时，声明的 `"self"` 默认值解析为图的所属对象。连入 `nil`、接收者类型不兼容或所属对象缺失时，方法调用前即会抛出错误。

- **参数布局**：短方法名、`self.method` 与完整限定路径共享同一参数顺序，接收者仅传递一次。保存的 `params` 将接收者置于索引 `0`：存储 `"self"` 选择所属对象，未设置则使用声明默认值。参数连线使用相同的零起始索引。静态函数与事件载荷不含接收者槽位。
- **通用数据图**：通用数据图的所属对象是 `GameplayEventData`。调用 Actor 方法时，需将其 `target`（或其他目标对象）连接至 `self`。

## 连线的类型规则

节点图校验器按声明类型检查数据引脚连线：

- **联合类型**：只要联合类型中至少有一个分支接受源类型，值即可连入该联合类型；联合类型输出仅在目标接受其所有分支时才能连接。
- **容器**：列表、字典与元组递归应用兼容性规则。
- **继承**：派生类型可连入已声明的基类。
- **数值与向量**：`int` 可连入 `float`，但 `float` 连入 `int` 以及不同 SFML 向量类型之间的转换均会被拒绝。
- **`any`**：允许动态连线，实际运行时值在调用时检查。
- **枚举**：枚举引脚保留自身枚举 Schema，但按模块的底层 `string`、`bool`、`int` 或 `float` 类型判断兼容性。它可连接兼容的标量引脚或其他兼容枚举（含容器与联合类型内部）。整数枚举可连入 `float` 输入，`float` 枚举不可连入 `int` 输入。实际值无需属于当前具名选项列表。

> **注意**：加载或粘贴图后，类型不兼容的连线会显示为红色，悬停提示会说明不匹配原因。执行常规保存前请先修复这些连线。

## 默认值与引用

新输入初始化为声明的默认值或所属类型的有效字面量；二者皆无的对象与函数输入保持未设置。即使引脚已连线，已保存的字面量仍须匹配声明类型。无效字面量会显示错误并阻止常规保存，连线传入的值则在运行时校验。元数据默认值与返回值声明见[函数与事件](<元数据结构与 Decorator.md#函数与事件>)。

枚举选择器显示键名并保存底层标量值，每次打开选择器或重新获得焦点时都会重读枚举文件。未知的已保存值会保留并附带提示信息，而底层标量类型错误的值则无效。普通文本输入接受底层标量值而非显示键名。模块与元数据示例见[枚举 Schema](<元数据结构与 Decorator.md#枚举-schema>)。

## 类属性

蓝图在 `attrs` 中保存属性值，并在同级 `attrDefs` 对象中以显式 `type` 声明新增变量；**添加属性**会同时写入两处。继承自元数据、Script Mixin 与祖先蓝图的字段已具备声明，因此子蓝图只需在 `attrs` 中覆盖值。字段访问节点与**角色信息**均沿用继承类型，包括枚举身份与嵌套容器类型。

> **重要**：缺失声明、不兼容的值与重复声明均会导致编辑器与运行时加载失败。全局保存与**保存无效蓝图**均无法绕过类 Schema 校验。

地图 Actor 覆盖值按同一解析后的类 Schema 校验。JSON 示例见[蓝图属性声明](<元数据结构与 Decorator.md#蓝图属性声明>)。

## 类定义与会话生命周期

同一 Lua VM 中的 `ClassDict` 实例共享已解析的类、定义表与已编译图模板。修改 JSON 类定义或图模板后需要重启游戏；[Lua 热重载](<../Lua 运行时与模块.md#lua-热重载>)仅更新兼容的脚本函数。

`ClassDict:getData(path)`（默认玩法中也暴露为 `Global.Data.GetClassData(path)`）使用与 `get` 相同的解析路径，返回解析器的 JSON 定义表。未知路径会抛出错误，无 JSON 定义的 Lua 模块类返回 `nil`。同一 VM 内重复读取返回同一张表，需要独立副本时请使用 `copy` 或 `deepcopy`。

修改返回的表会影响后续定义读取，但不会重建已生成的类、实例默认值记录或已编译模板；新实例与可执行事件查询继续沿用此前生成的结果。
