# 官方插件总览

Ludork 随编辑器提供用于游戏本地化、地图生成、蓝图制作与资源管理的官方 C# 插件。它们位于 `Plugins/` 下的源码目录同时也是公开插件 API 的参考实现。

## 内置官方插件

| 插件 | 用途 |
|---|---|
| [Locale Tools](<Locale Tools.md>) | 打开翻译工作簿、提供编辑器文本提示并导出 Lua 语言目录 |
| [Random Map](<Random Map.md>) | 在选定区域内程序化生成地形，并在 revision 校验保护下保存单个图层 |
| [Mota Map Fill](<Mota Map Fill.md>) | 依据存档玩家的战斗伤害，在地图区域内填充门、怪物与奖励 |
| [Blueprint AI](<Blueprint AI.md>) | 围绕单个已有蓝图讨论修改，并将经校验与审阅的提案作为一步撤销应用 |
| [Resource Cleanup](<Resource Cleanup.md>) | 查找未检测到静态引用的资源，保护保留清单中的路径，并将确认后的候选移至系统回收站／垃圾篓 |
| [通用数据蓝图导出](<通用数据蓝图导出.md>) | 为通用数据成员批量创建缺失的 Actor 蓝图 |

关于使用 Locale Tools 编写工作簿、接入导出流程以及在运行时解析 `{ID}` 的完整说明，请参阅[游戏本地化工作流](<游戏本地化工作流.md>)。

## 安装与管理

安装器选项、命令行安装方式、重启要求、插件状态诊断与数据保留规则见[安装与管理插件](<../安装与管理插件.md>)。

> **警告**：在所有平台上，安装官方插件都会整体替换现有的全部全局插件与项目插件、注册表及插件数据。安装前请先关闭 Ludork 并备份需要保留的内容。
