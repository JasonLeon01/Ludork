# Blueprint AI

配置官方插件 Blueprint AI（插件 ID 为 `Ludork.OfficialBlueprintAI`，源码位于 `Plugins/OfficialBlueprintAI`），可检视当前项目、围绕单个已有蓝图讨论修改方案，并在应用前审阅经校验的差异。在编辑器中通过 **游戏 → Blueprint AI** 打开助手窗口（窗口标题为**蓝图 AI**）。

## 工作流

1. 按[发行版官方插件](<../安装与管理插件.md#发行版官方插件>)完成安装。
2. 打开项目，选择 **游戏 → Blueprint AI**。
3. 打开 **Blueprint AI 设置**，配置**提供商**、**模型**、**接口地址**与 **API Key**。
4. 点击**新会话**创建绑定到单个已有蓝图的会话，随后审阅暂存提案及生成的差异。
5. 校验通过后点击**应用**；准备将修改写入磁盘时，再执行常规的项目保存命令。

## 本地数据

设置与会话历史存放在 `~/Ludork/Plugins/.data/Ludork.OfficialBlueprintAI`。卸载插件会保留该目录；存储路径与手动清除方式见[数据与卸载](<../安装与管理插件.md#数据与卸载>)。

## 范围与权限

- **读取范围**：每个会话固定绑定到一个项目与一个已有蓝图。助手可以查阅其他蓝图、Lua 元数据、白名单内的 Lua/C/C++ 源码文件以及 Ludork 官方文档以了解可用 API。
- **写入边界**：助手不能创建、重命名或删除蓝图，不能同时编辑多个蓝图，也不能修改源码、执行 Shell 命令或启动外部进程。
- **审阅与应用**：模型只能暂存蓝图提案；编辑器会校验候选内容并渲染生成差异，在用户点击**应用**前不会产生任何修改。点击**应用**后，编辑器会重新读取当前工作副本、核验基础 revision、记录一步常规撤销、将项目标记为未保存，并刷新该蓝图所有已打开的编辑器窗口，但不直接落盘。

> **注意**：插件以受信任的进程内代码运行，而非处于操作系统沙箱中。上述约束由官方助手向模型暴露的工具接口以及编辑器的会话与应用边界共同实施。

## 提供商设置与凭据

在 Blueprint AI 窗口中打开 **Blueprint AI 设置**以配置提供商、模型与接口地址：

- **支持的提供商**：OpenAI 使用 Responses API；DeepSeek、Google OpenAI-compatible 与 Custom 配置使用兼容 OpenAI 的 Chat Completions 接口。**模型**与**接口地址**字段保持可编辑，新模型发布时无需更新插件。
- **接口地址校验**：接口地址必须是不含内嵌凭据、查询参数与片段的绝对 `https://` URL；明文 `http://` 仅允许用于本地开发时的回环地址。
- **API Key 管理**：密钥保存在[宿主密钥存储](<../Avalonia UI、密钥与本地化.md#保存密钥>)中，绝不写入 `settings.json`。界面仅显示前三个与后三个字符并以固定掩码隔开（较短密钥完全隐藏），且仅在输入新值或显式移除时才会更新已存凭据。服务可用性取决于所选提供商，不受 Ludork 控制。

## 本地会话与提供商状态

插件数据目录下的本地索引与只追加 JSONL 文件是会话历史的权威存储，记录消息、模型快照、精简工具活动与提案决策，从不保存 API Key 或完整的源码读取内容。

OpenAI Responses 请求默认设置 `store:false`，避免依赖服务端的会话状态。面对较长会话时，后续请求仅发送滚动摘要与近期消息；此类请求上下文压缩不会删除或修改完整的本地历史。

被中断的请求会标记为中断状态：已完成的本地记录在重启后仍然保留，但进行中的网络请求不会自动恢复。

## 项目源码读取

项目搜索与文件读取仅接受位于配置好的运行时与 API 源码根目录下的项目相对路径，且文件扩展名须位于支持列表内。构建产物、日志、版本控制元数据、INI/plist 配置文件、插件数据、凭据及项目外路径一律拒绝；路径上（含项目根目录本身）的任何符号链接、失效链接与重解析点同样被拒绝。文件系统失败会返回工具错误，且读取的文件内容严格作为数据处理，绝不会被视为可扩展权限的指令。

## 官方文档

助手按编辑器当前语言搜索并阅读编辑器选定的开发文档或发布快照，遵循与[在线文档](<../../编辑器用户指南/启动页、工作区与快捷键.md#在线文档>)一致的版本选择规则，并在结果中返回原页面链接。

当匹配的文档索引不可用时，助手会直接报告失败，不会回退到其他版本或语言。具体的蓝图节点、类型、序列化名称与引脚仍以当前项目的 API 目录与元数据为准。底层宿主接口见[蓝图助手](<../注册点与 Hook 参考.md#蓝图助手>)。

## 故障排除

- **游戏菜单中缺少 Blueprint AI**：请按[发行版官方插件](<../安装与管理插件.md#发行版官方插件>)完成安装并重启 Ludork，随后在**插件 → 插件管理**中检查注册或加载诊断。
- **没有可用的项目或蓝图**：请先打开至少包含一个已有蓝图的项目（宿主桥仅在项目窗口中可用）。打开窗口时不会自动选定目标，请点击**新会话**选择目标蓝图。
- **目标蓝图被重命名或删除**：既有会话仍可只读查阅，但目标无法静默切换，请为已有蓝图新建会话。
- **缺少 API Key 或返回 HTTP 401**：请在 **Blueprint AI 设置**中重新输入 API Key，并核对所选提供商、接口地址以及 OpenAI 的**组织**与**项目标识**配置。界面从不显示完整的已保存密钥。
- **连接或接口地址错误**：请填写不含内嵌凭据、查询参数或片段的绝对 `https://` 基础地址，并检查 DNS、代理、防火墙与 TLS 设置（明文 `http://` 仅支持本地回环地址）。
- **应用时提示版本冲突**：提案捕获基础 revision 后蓝图发生了修改。请点击**放弃**，检查当前蓝图后再发起新请求或新会话。
- **历史显示请求已中断**：请求、窗口或编辑器在完成前已停止。本地历史保持完整，请重新发送新请求，而非等待上次响应自动续传。
