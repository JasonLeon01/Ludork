# 插件分发

分发单个源码插件目录，使用者可以将它引入全局或当前项目作用域。

## 目录内容

包含 `plugin.json`、运行所需的 `.cs` 文件、插件资源和许可声明，并说明支持的编辑器版本及引入后的配置步骤。清单中的 `minimumEditorVersion` 不得低于 `1.0.0`。

不要包含构建产物、本机设置、凭据或 `.data`，也不要包含外层的 `__ProjectPlugins` 目录及其注册文件。使用者自行选择安装作用域；官方编辑器发行包不包含项目插件。

源码编译与可选 IDE 项目的作用见 [Manifest 与最小插件](<Manifest 与最小插件.md#源码目录>)。

## 安装

使用者引入完整源码目录后重启 Ludork。作用域、更新和数据保留规则见[安装与管理插件](<安装与管理插件.md>)。
