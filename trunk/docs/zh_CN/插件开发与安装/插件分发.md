# 插件分发

将第三方插件打包为单个自包含的源码目录，供使用者按需引入全局作用域或当前项目作用域。

## 目录内容

- **应包含**：`plugin.json`（`minimumEditorVersion` 至少设为 `1.0.0`）、全部必需的 `.cs` 源码文件、插件资源（如本地化 JSON 文件）以及许可声明，同时注明支持的编辑器版本与引入后的配置步骤。
- **应排除**：构建产物（`bin/`、`obj/`）、本机设置、凭据、`.data` 目录，以及外层 `__ProjectPlugins` 目录树或 `plugins.json` 注册表。安装作用域由使用者在引入时自行选择；官方编辑器发行包不包含项目插件。

关于源码编译规则及可选 `.csproj` 文件的作用，请参阅[源码目录](<Manifest 与最小插件.md#源码目录>)。

## 安装

使用者直接引入完整的源码目录并重启 Ludork 即可。作用域选择、更新与数据保留规则见[安装与管理插件](<安装与管理插件.md>)。
