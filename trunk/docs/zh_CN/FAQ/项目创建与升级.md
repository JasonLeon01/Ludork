# 项目创建与升级

## 应该选择哪种项目模板？

使用随附运行时编写 Lua、蓝图、数据与资产时，选择 **Standalone**，无需安装原生编译器。需要修改原生服务或绑定，或者打包 iOS、HarmonyOS、Android 游戏时，选择 **C++ Source**。视频播放是独立的模板选项。详见[模板参考](<../快速入门/项目模板.md#模板参考>)。

## 为什么提示项目模板不可用？可以离线创建项目吗？

正式版编辑器会下载与自身完整版本号匹配的模板，包括补丁版本；对应 Release 或模板尚未发布时，会提示不可用。已完成并通过校验的模板缓存可以离线复用。开发版编辑器使用附带模板，缺少文件时会报错，不会联网下载替代模板。详见[获取模板](<../快速入门/项目模板.md#获取模板>)。

## 更新 Ludork 会自动更新已有项目吗？

Game 项目和默认模板的变化不会更新已经创建的项目，需要自行把改动应用到各项目。`Main.proj.version` 记录引擎兼容版本，本版使用 `v1.0`；它与游戏发行版本、存档格式相互独立。详见[模板变体](<../Lua 与蓝图脚本/Game 玩法/默认模板概述.md#模板变体>)与 [Main.proj](<../编辑器用户指南/项目设置与资产布局.md#mainproj>)。
