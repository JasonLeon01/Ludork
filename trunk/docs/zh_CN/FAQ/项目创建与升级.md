# 项目创建与升级

## 应该选择哪种项目模板？

若希望基于预构建运行时使用 Lua、蓝图、数据与资产构建玩法且无需安装原生编译器，请选择 **Standalone**。若需要修改原生服务或绑定，或面向 iOS、HarmonyOS、Android、Web 打包发布，请选择 **C++ Source**。视频播放为独立的模板选项。详见[模板参考](<../快速入门/项目模板.md#模板参考>)。

## 为什么提示项目模板不可用？可以离线创建项目吗？

正式版编辑器会下载与自身完整版本号（含补丁号）一致的模板；若对应 Release 或模板尚未发布，创建项目时会提示模板不可用。已完成且校验通过的模板缓存支持离线复用。开发版编辑器使用随包内置的本地模板，若缺少文件会直接显示错误，不会联网下载替代模板。详见[获取模板](<../快速入门/项目模板.md#获取模板>)。

## 更新 Ludork 会自动更新已有项目吗？

Game 项目与默认模板的更新不会自动修改已创建的项目，如需引入变更请手动合并至各项目。`Main.proj.version` 记录引擎兼容版本（当前版本为 `v1.0`），与游戏发行版本和存档格式相互独立。详见[模板变体](<../Lua 与蓝图脚本/默认玩法/默认模板概述.md#模板变体>)与 [Main.proj](<../编辑器用户指南/项目设置与资产布局.md#mainproj>)。
