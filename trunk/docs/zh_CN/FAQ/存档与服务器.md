# 存档与服务器

## 为什么修改游戏变量的默认值后，旧存档没有变化？

已保存的变量声明仅为新游戏提供初始值。加载存档槽位时，存档中的变量表会直接替换新实例的变量表，不会合并新增声明或迁移已有数值。如需应用默认值的变更，请开始新游戏或自行实现存档迁移逻辑。详见[游戏变量](<../Lua 与蓝图脚本/默认玩法/运行时数据、配置与存档.md#游戏变量>)。

## 必须使用 Ludork Server 吗？它提供联机或云存档吗？

Ludork 服务器是可选的 Node.js 服务，提供服务端 Lua 逻辑、显式快照代理、无返回值 RPC 与在线事件。游戏玩法代码自行决定何时拉取或刷新数据以及发送哪些业务操作；该服务既不会自动同步多人联机状态，也不会自动上传、下载或替换本地存档。配置客户端集成需要 **C++ Source** 项目。详见[简易服务器](<../简易服务器/部署与编辑器设置.md#简易服务器部署与编辑器设置>)与[配置](<../Lua 与蓝图脚本/默认玩法/运行时数据、配置与存档.md#配置>)。
