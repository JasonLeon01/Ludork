# 脚本与玩法

## 什么时候使用蓝图、Lua 或 Script Mixin？

蓝图节点图用于以可视化方式定义事件与执行流程；Lua 类适用于构建可复用的系统与玩法类型；Script Mixin 则用于将 Lua 行为直接附加到蓝图类上。同一条蓝图继承链必须统一采用节点图模式或 Script Mixin 模式，不可混用。详见 [Lua 运行时与模块](<../Lua 与蓝图脚本/Lua 运行时与模块.md#lua-运行时与模块>)。

## 可以不重启游戏就重载 Lua 吗？

对于由编辑器启动且使用未归档 Lua 源文件的游戏，保存修改后可在**控制台**输入 `$r`。热重载会更新现有函数，同时保留当前场景、对象与运行时状态；不会重新执行 `Entry.lua`，也不会重载 JSON、UI 资产、元数据、声明文件或原生代码。涉及结构或数据变更时需重启游戏。已归档或仅包含字节码的脚本不支持热重载。详见 [Lua 热重载](<../Lua 与蓝图脚本/Lua 运行时与模块.md#lua-热重载>)。
