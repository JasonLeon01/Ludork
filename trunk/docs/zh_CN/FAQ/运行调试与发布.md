# 运行调试与发布

## 可以在哪些平台开发和发布游戏？

编辑器支持 Windows x64 与 Apple Silicon macOS。游戏除上述桌面平台外，还可发布至 iOS、HarmonyOS、Android 与 Web。移动端与 Web 打包需要 **C++ Source** 项目；移动端发行包在 Apple Silicon macOS 上构建，**Standalone** 则使用编辑器所在平台的预构建运行时。最低系统版本请参阅[支持的平台](<../Ludork 文档.md#支持的平台>)，所需工具请参阅[打包](<../编辑器用户指南/运行、调试与打包.md#打包>)。

## 为什么不能运行游戏？什么时候需要编译或导出？

首次点击**运行**前必须先成功完成**导出**；**C++ Source** 项目还需通过**编译**或 `tools/build_cpp` 完成一次成功的 Debug 构建。**编译**负责构建原生代码，**导出**负责生成 UI 与本地化运行时文件，而 `SceneInit` 负责准备材质；仅修改 Lua、UI JSON、游戏数据或本地化内容无需重新编译原生代码。若准备阶段失败，请先排查报告的首个错误。详见[编译、导出与运行](<../编辑器用户指南/运行、调试与打包.md#编译导出与运行>)。

## 实时调试会把修改保存回项目吗？

**实时调试**仅修改当前运行时实例，不会写入项目文档，也不提供撤销与重做。请在点击**运行**前启用该选项，并使用**独立窗口**。在游戏内保存进度时，存档会保留受实时编辑影响的玩法状态。有关可编辑范围与实例生命周期，请参阅[实时调试](<../编辑器用户指南/运行、调试与打包.md#实时调试>)。

## 为什么打包项目的确认按钮是灰色的？

将鼠标悬停在禁用的按钮上可查看具体原因。入口脚本必须声明有效的静态 `APP_NAME`（初始值在[新建项目](<../快速入门/项目模板.md#模板参考>)时填写）。有关声明规则及其他打包要求，请参阅[打包](<../编辑器用户指南/运行、调试与打包.md#打包>)。
