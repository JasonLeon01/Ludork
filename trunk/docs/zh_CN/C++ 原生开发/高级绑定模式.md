# 高级绑定模式

当常规类、属性、方法与自由函数绑定无法表达所需的引擎基础设施契约时，请使用以下高级绑定模式。

## 类元数据装饰器

将类级装饰器嵌套写在所属类的 `BIND_CLASS` 注解内：

```cpp
BIND_CLASS(callbacks = true,
           invalid_vars(defaultRect, internalState),
           rect_range_vars(defaultRect = texturePath))
class Character : public Actor {
public:
  BIND_METHOD(metadata = false)
  virtual void _applyDirection(float x, float y);
};
```

- `invalid_vars(...)` 用于在编辑器元数据中隐藏字段，`rect_range_vars(...)` 用于将矩形字段关联到资源或范围字段。两者均接受有序标识符列表，且仅在 `BIND_CLASS` 内有效。
- 属性级的矩形语义须写在 `BIND_PROPERTY` 内的 `meta(RectRangeVars = "texturePath")` 中。
- `metadata = false` 仅从蓝图元数据中隐藏方法，不会关闭虚函数回调；如需退出回调分派，请改用 `callback = false`。详见[绑定类](<绑定类.md>)与[声明属性](<绑定类.md#声明属性>)。

## 事件、Latent 操作与循环

```cpp
BIND_REGISTER_EVENT()
BIND_METHOD()
virtual void onCreate();

BIND_METHOD(loop_node(ForEach))
void forEach(const RuntimeValue::Array &values);
```

事件与循环注解仅生成蓝图执行元数据，对应的 C++ 或 Lua 实现仍须完整履行所声明的协议。Latent 操作、返回值约束与默认值规则见[声明执行行为](<函数、事件与执行.md#声明执行行为>)。

## 值、反向查找表与辅助函数

```cpp
BIND_MODULE_PROPERTY()
extern std::string LANGUAGE;

class FocusTransition {
public:
  BIND_CLASS_PROPERTY(readonly = true)
  static const std::string DIRECTIONAL;
};

BIND_LUA_REVERSE(path = "Input.KeyName", source = "sf.Keyboard.Key")
BIND_LUA_HELPER(kind = "cast", path = "Cast")
```

- **模块属性与类属性**：模块属性暴露在模块根，类属性暴露在所属类上。Bindgen 绝不会把已有 Lua 值重复挂载到第二条运行时路径。
- **反向查找表**：`BIND_LUA_REVERSE` 在声明的规范路径上生成反向名称查找表。
- **绑定辅助函数**：`BIND_LUA_HELPER` 用于挂载通用原生辅助函数。其中 `eval` 辅助函数仅对调用方传入的表达式求值，可选的局部变量表优先级高于运行时全局变量；表达式缺失或为空时返回 `nil`；非空表达式以同步方式求值，若在可挂起的协程中调用会直接抛出错误。

## 初始化、注入与值类型特征

```cpp
BIND_MODULE_INIT()
void initialiseRuntimeServices(lua_State *state);

BIND_INJECT(global = "_LUDORK_BLUEPRINT_EVENT_VALIDATOR")
void setBlueprintEventValidator(BlueprintEventValidator validator);

BIND_CLASS(opaque_identity = true)
class RuntimeIdentity {};

BIND_CLASS(dynamic_value = true)
class RuntimeValue {};
```

- **模块初始化**：`BIND_MODULE_INIT` 在打开原生模块期间执行。
- **回调注入**：`BIND_INJECT` 通过 `global` 指定 Lua 来源回调并将其连接至 C++ 设置函数，仅在所属 Lua 状态存活期间有效。启用 `variadic = true` 时，设置函数必须接收 `std::function<std::vector<T>(Fixed..., const std::vector<T>&)>`，零返回值以及中间或末尾的 `nil` 均保持彼此区分，无需额外包装表。
- **值与身份特征**：`opaque_identity = true` 与 `dynamic_value = true` 用于选择转换与身份特征，不能与不兼容的表值转换模式同时使用。引擎子系统依赖带类型的运行时门面与固定 Provider 槽位，而非通用的字符串操作分发器。

> **重要**：Bindgen 必须保持声明驱动。严禁在生成器中为特定玩法模块、类或成员名称增设特判分支，也不得使用基础设施标记绕过不受支持的类型转换。
