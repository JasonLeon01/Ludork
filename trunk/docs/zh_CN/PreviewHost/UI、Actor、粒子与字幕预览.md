# UI、Actor、粒子与字幕预览

各类资产编辑器均通过 PreviewHost 在[预览与游戏运行的边界](<概述.md#预览与游戏运行>)内呈现实时外观与时序。有关宿主可用性、重建与错误处理，请参阅[构建、发布与排错](<构建、发布与排错.md>)。

## UI 预览

[UI 资产编辑器](<../编辑器用户指南/UI 资产编辑器.md>)直接渲染已编写的资产，不运行其 Lua Controller。点击**刷新预览**即可查看待应用的修改；若修改了原生控件，须先重新构建项目再检查效果。

对于依赖数据模型的区域，应提供具有代表性的占位内容。由运行时填充的文本请使用 `previewText`（属于节点中仅供设计时使用的 `editor` 数据），并为 `#TAB`、`#ITEM` 提供示例条目及游戏视觉资源，使标签页、列表与角色展示在编辑期间清晰可读。

占位内容不能作为运行时的回退数据：业务代码在显示前必须提供本地化文本并填充动态集合。运行时归属规则请参阅[声明式 UI 编写工作流](<../Lua 与蓝图脚本/声明式 UI/编写工作流.md>)。

在 Timeline 中选中动画后，可使用播放、暂停、停止与拖动时间轴检查效果，不会修改已保存的 Slot 布局。未选中动画时，Designer 显示已编写的 UI 静态外观。有关动画定义、继承的 Global 动画与实例覆盖，请参阅 [UI 时间轴](<../编辑器用户指南/UI 资产编辑器.md#timeline>)。

嵌套资产与重复模板的编辑方法请参阅 [UI 资产编辑器](<../编辑器用户指南/UI 资产编辑器.md>)；控件属性、子节点与 Slot 规则请参阅 [Palette 控件](<../编辑器用户指南/Palette 控件.md>)。

## Actor 预览

在文件选择器中选中蓝图 JSON 文件，即可预览其当前外观与动画（含未保存修改）。缺少外观或纹理时将显示默认文件图标。

**文件浏览器**缩略图与蓝图编辑视图展示解析后的 Actor 外观：纹理区域、角色帧动画、`material` 与 `materialParameters` 均取自当前蓝图值，地图上的实例则会叠加自身实例覆盖。修改继承默认值（含撤销与重做）会自动刷新受影响的预览。

蓝图选择与实例编辑请参阅 [Actor 摆放与角色信息](<../编辑器用户指南/蓝图、公共函数与 Actor.md#actor-摆放与角色信息>)；地图光照、选择辅助与实时调试画面请参阅[地图与世界预览](<地图与世界预览.md>)。

## 材质预览

材质、Actor、地图与 UI 预览均接收未保存的材质快照，由原生宿主在内存中编译，不会修改游戏的运行时材质缓存。无效材质会直接显示错误提示，而非沿用过期的成功画面。有关共用编译器、预览控件、错误定位与 GLSL 查看，请参阅[预览与排错](<../编辑器用户指南/材质.md#预览与排错>)。

## 粒子预览

通过**数据库 → 通用粒子总览**（`F6`）或**文件浏览器**打开粒子资产。预览支持独奏选中轨道，并提供播放/暂停、停止、重播、单步模拟、输入时间、定位跳转、播放速度与缩放控制。

每次单步推进 `1 / simulationRate` 秒。定位跳转会暂停播放，目标时刻越靠后可能耗时越长。这些预览控件不会修改已保存的资源；轨道与属性编辑遵循常规保存与撤销流程。固定资源种子可在相同运行时与 GPU 上复现创作结果，但不保证跨设备完全一致的确定性模拟。

资源缺失或 GPU 能力不支持时会显示错误；粒子预览采用原生 GPU 实现，不提供 CPU 回退。资源字段、发射与归属规则、GPU 要求及功能限制请参阅[通用粒子](<../编辑器用户指南/通用粒子.md>)。

## 字幕预览

在[字幕编辑器](<../编辑器用户指南/视频字幕.md>)中打开 `Data/Subtitles` 下的文档，可通过播放/暂停、停止、当前时间、时间轴播放头与预览语言检查字幕时序。未指定参考视频时，预览采用纯色背景并播放至最后一个片段的结束时间。空字幕文档同样可正常编辑。

可选择项目视频作为临时参考，或清除视频以恢复纯色背景。参考视频保持原始宽高比并同步播放音频，同时提供静音开关；拖动定位期间音频暂停，定位完成后恢复先前的播放状态。预览总时长取视频时长与字幕时长的较大值，超出视频结束时间的字幕将显示在纯色背景上。

在非 FFmpeg 项目中选择视频时会提示“当前不是 FFmpeg 项目”，但字幕编辑与纯色背景预览不受影响。参考视频、预览语言、播放位置与静音状态仅属于窗口会话状态，不会写入字幕文档。

原生预览与运行时播放共用同一套字幕排版。字幕数据结构、多语言编辑、字体、换行与布局规则请参阅[视频字幕](<../编辑器用户指南/视频字幕.md>)。
