# PreviewHost

PreviewHost 为编辑器中的地图、大地图、Actor、UI、粒子与字幕预览提供原生渲染。本章介绍如何使用各类预览视图、准备预览运行时，以及了解帧画面如何传输至编辑器。

## 选择预览入口

| 预览内容 | 入口 | 指南 |
|---|---|---|
| 地图、大地图及子地图缩略图 | 主工作区地图视口与大地图画布 | [地图与世界预览](<地图与世界预览.md>) |
| UI 资产及其动画 | UI 资产编辑器的 Designer 与 Timeline | [UI 预览](<UI、Actor、粒子与字幕预览.md#ui-预览>) |
| Actor 外观 | 文件浏览器缩略图、文件选择器、蓝图预览及地图上摆放的 Actor | [Actor 预览](<UI、Actor、粒子与字幕预览.md#actor-预览>) |
| 通用粒子 | 通用粒子编辑器 | [粒子预览](<UI、Actor、粒子与字幕预览.md#粒子预览>) |
| 视频字幕 | 字幕编辑器 | [字幕预览](<UI、Actor、粒子与字幕预览.md#字幕预览>) |

## 预览与游戏运行

编辑器预览用于呈现当前创作中的内容。地图与 Actor 外观预览仅解析视觉数据，不执行 Actor 创建、Tick 或蓝图玩法事件；UI Designer 渲染已编写的资产，不运行其 Lua Controller。粒子与字幕编辑器各自提供专用的播放控件，详见上表列出的指南。

如需测试玩法，请点击**运行**。**实时调试**用于检查运行中的游戏实例并拥有独立的编辑权限，其地图视口遵循[地图预览显示规则](<地图与世界预览.md>)。有关游戏运行与实时编辑，请参阅[运行、调试与打包](<../编辑器用户指南/运行、调试与打包.md>)。
