# Ludork 文档

Ludork 集可视化编辑器、蓝图、Lua 脚本与可扩展的 C++20 运行时于一体，用于开发以地图为核心的 2D 游戏。本手册介绍如何配置项目，制作地图、Actor、数据、动画与用户界面，以及如何运行和打包游戏。

可在 [Ludork 官网](https://jasonleon01.github.io/Ludork/?lang=zh_CN)获取下载包与项目信息；官网页脚同时提供[第三方声明](../THIRD_PARTY_NOTICES_zh_CN.md)的访问入口。

## 支持的平台

### 编辑器

| 平台 | 最低支持版本 |
|---|---|
| Windows | Windows 10，x64 |
| macOS | Apple Silicon，macOS 13.3 |

### 游戏

| 平台 | 最低支持版本 | 说明 |
|---|---|---|
| Windows | Windows 10，x64 | |
| macOS | Apple Silicon，macOS 13.3 | |
| iOS | iOS 16.3，arm64 | 需要 C++ Source 项目。 |
| HarmonyOS | HarmonyOS 6.0.2 / API 22，arm64-v8a | 支持手机、平板与二合一设备；需要 C++ Source 项目。 |
| Android | Android 7.0 / API 24，arm64-v8a | 需要 C++ Source 项目。 |
| Web | WebGL 2 | 需要 C++ Source 项目。 |

移动端发行包需在 Apple Silicon macOS 上构建。Standalone 项目使用编辑器所在平台的预构建运行时。有关平台工具链与签名选项，请参阅[运行、调试与打包](<编辑器用户指南/运行、调试与打包.md>)。

## 文档约定

- 除非页面另有说明，路径均相对于项目根目录。
- 菜单命令、按钮与字段名称与中文编辑器界面保持一致；界面中保留英文的专有名称沿用英文写法。

## 软件与内容许可

Ludork 的软件许可证、第三方声明与 Game 项目资产条款彼此独立。重新分发编辑器包或基于 Game 项目内容制作的游戏前，请逐一审阅上述三项条款。

> **警告**：安装插件会以编辑器进程的权限运行可信代码。引入插件前，请先检查其源代码与来源。
