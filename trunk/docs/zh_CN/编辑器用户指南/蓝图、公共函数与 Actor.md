# 蓝图、公共函数与 Actor

在 `Data/Blueprints` 下创建可复用的蓝图类，定义带类型的属性与组件，在地图上摆放 Actor 实例并编写可视化事件图。

## 创建蓝图

通过**游戏 → 新建蓝图**（或在文件浏览器中新建），选择一个最终继承自 `BPBase` 的父类并指定 `Data/Blueprints` 下的路径。编辑器会沿完整继承链解析父类默认值与事件。新建图模式蓝图时，每个继承事件均初始化为 `Event → Parent` 节点链并自动连好参数引脚。

蓝图键是相对于 `Data/Blueprints`、保留大小写、以 `/` 分隔且不含 `.json` 的路径（例如 `Actors/Guard`），对应类引用 `Data.Blueprints.Actors.Guard`。键输入框接受可选的 `.json` 后缀，并自动规范化反斜杠与首尾空白。完整类引用中的每个点号都分隔一个模块段（`Data.Blueprints.Actors.json` 对应键 `Actors/json`）。

## 类值与实例值

类属性为全部实例提供默认值，地图上的 Actor 可逐项覆盖字段。由元数据声明的组件以结构化字段呈现；列入 `InvalidVars` 的字段在常规编辑界面中隐藏。

蓝图编辑器沿完整继承链解析属性与组件，子类覆盖优先于祖先默认值（见 [Actor 组件](<Actor 组件/概述.md>)）。当蓝图的 `ID` 指向某个通用数据成员时，其 `attributes` 以只读方式展示，修改请在通用数据编辑器中进行。

在蓝图编辑器与**角色信息**中，普通变量位于组件列表下方的灰色虚线框内，并按首次声明该字段的类、Script Mixin 或蓝图分组。悬停分组标题可查看完整类引用；继承字段即使被覆盖也仍归属原声明分组。

### 添加带类型的属性

点击**添加属性**，输入名称、选择类型并设定初始值。选择 `enum` 时，在 **kind** 中选取现有的 `Enums.*` 模块并选定键值（列表元素与字典值同样支持枚举）；文件字段可通过基础目录限定选择范围。

- **存储与继承**：新增字段将声明写入 `attrDefs`，初始值写入 `attrs`。若名称命中尚无本地值的继承字段，对话框会锁定为继承声明的类型，仅添加 `attrs` 覆盖。子蓝图继承类型与默认值且不能重复声明继承字段；删除覆盖会恢复继承默认值。删除本蓝图声明的字段会同时移除声明与本地值；若任意派生蓝图或地图 Actor 覆盖依赖该字段，删除将被拒绝。
- **校验规则**：每个已保存属性均须在元数据、当前启用的 Script Mixin，或继承／本地 `attrDefs` 中声明。声明无效会阻止加载与保存（并指出蓝图与属性名）。更换父类或删除字段不得令派生类或地图覆盖出现类型不兼容；**保存无效蓝图**允许保存未完成的图，但绝不跳过属性错误。详见[蓝图属性声明](<../Lua 与蓝图脚本/蓝图脚本/元数据结构与 Decorator.md#蓝图属性声明>)。

## Actor 摆放与角色信息

在任意**文件浏览器**页签中选中 Actor 蓝图（继承自 `Engine.Actor`）即可进入待摆放状态，随后在角色模式下点击可编辑图层的空白格子摆放实例（双击文件打开编辑器）。选中地图上已有的单个 Actor 同样会将其蓝图设为待摆放状态。地图获得焦点时按 `Escape` 取消摆放。外观预览见 [Actor 预览](<../PreviewHost/UI、Actor、粒子与字幕预览.md#actor-预览>)。

- **待摆放状态保持**：切换页签、前后导航、刷新、定位资源或选中非 Actor 文件不会改变当前待摆放蓝图。待摆放引用会跟随编辑器内的重命名、移动及撤销／重做同步更新；删除该蓝图或将其改为非 Actor 类会自动取消摆放。
- **定位到蓝图**：在角色模式下右键地图上的 Actor 并选择**定位到蓝图**，即可在最近活动的[文件浏览器](<启动页、工作区与快捷键.md#文件浏览器与引用树>)中高亮对应蓝图文件（空白处或无对应项目蓝图的 Actor 禁用该项）。
- **角色信息**：展示所选 Actor 的蓝图引用（附**打开**与**定位**按钮）、网格位置 `X`／`Y`、tag 与公开类字段。聚焦时的连续位置或文本输入合并为一步撤销。点击字段旁的重置按钮可清除单项覆盖，点击**全部重置**清除全部类字段覆盖并恢复蓝图默认值。隐藏图层上的 Actor 在**角色信息**中仍可查看与跳转蓝图，但 tag、位置、重置操作与类字段均为只读。
- **撤销与删除**：摆放与删除地图实例由地图文档撤销管理。删除蓝图文件遵循[资源删除与恢复规则](<启动页、工作区与快捷键.md#文件浏览器与引用树>)：若实例在蓝图删除前已删除并保存，则蓝图缺失期间地图撤销无法恢复该实例。修改蓝图字段（含撤销／重做）会按最新继承默认值即时刷新 Actor 外观。

## 图模式

启用 **Script Mixin** 会隐藏右侧事件图与预览区，让变量区占满整个宽度；停用后立即恢复该区域及原有分栏宽度，同时在模式继承、撤销／重做与重载过程中完整保留已有图数据。

每张图均以红色**事件**入口节点为起点，须将其执行引脚连向起始节点后方可执行（未连接的入口呈半透明并显示提示；蓝图会回退至继承实现，公共函数与通用数据图则不执行）。详见[执行流、事件与变量](<../Lua 与蓝图脚本/蓝图脚本/执行流、事件与变量.md#事件>)。

### 事件、Parent 节点与拖线连接

- **新建本地事件**：点击**新建事件**创建本地图（下拉列出尚无本地图的继承事件；已有本地图即使为空也不可重复添加）。若父类链定义了该事件，新图默认生成棕色 **Parent: 事件名** 节点并与入口执行及参数引脚相连，整体记为一步撤销。仅查看继承事件页签不会生成覆盖或修改已保存数据。
- **节点操作**：Parent 节点仅在图模式类蓝图中提供，可从节点选择器添加并正常移动、复制或删除。右键节点可断开所有输入／输出、复制或删除；右键空白画布可添加、粘贴或整理节点。新建、粘贴与复制的节点位于指针处（指针在视口外时位于视口中心），并保留相对布局与内部连线。
- **拖线节点选择器**：在任意可编辑的蓝图、公共函数或通用数据图中，将执行或参数输出引脚拖至画布空白处即可打开按引脚筛选的选择器（执行引脚列出含执行输入的节点；参数引脚列出至少含一个[类型兼容输入](<../Lua 与蓝图脚本/蓝图脚本/执行流、事件与变量.md#连线的类型规则>)的节点，按引脚而非蓝图类筛选；普通右键选择器仍保留**上下文关联**开关）。
- **自动连接规则**：从拖线选择器选中节点会在落点创建节点并自动连线，记为一步撤销。参数连线优先选择类型完全一致的输入（并列时按声明顺序选择），新的执行连线会替换该输出原有连线。取消选择器不改动图；直接拖至目标输入引脚则连接已有节点。

### 普通文本参数输入

右键任意可编辑节点（蓝图、公共函数与通用数据图均适用）并选择**转换为普通输入框**，可将所有未连接参数切换为文本框（已连接输入保持常规引脚）；选择**恢复类型输入框**切回原控件。

- **类型转换**：字符串与文件输入保留原始文本；数字与布尔值按字面量解析；容器、向量与复合类型使用 JSON 语法（联合类型使用 `$type`／`$value`）；对象与函数引脚保持原有表达式语义（字面量参数不会因此获得表达式求值能力）。详见[元数据结构与 Decorator](<../Lua 与蓝图脚本/蓝图脚本/元数据结构与 Decorator.md>)。
- **校验与范围**：非法文本会作为未保存草稿保留并显示错误，不会覆盖最后一次有效值；恢复类型输入框或保存前须修正草稿（**保存无效蓝图**不能绕过草稿错误；保存提示会指明图与参数名）。输入模式与草稿仅在当前窗口打开期间跨图切换保留，关闭窗口即清除，绝不写入项目文件或随节点复制；新建与复制的节点默认使用类型输入框。

### 图快捷键

编辑器全局快捷键与平台主修饰键见[全局快捷键](<启动页、工作区与快捷键.md#全局快捷键>)。

| 快捷键 | 操作 |
|---|---|
| `Ctrl/Command+N` | 在指针位置打开节点选择器 |
| `Ctrl/Command+A` | 选中当前图中全部可编辑节点 |
| `Ctrl/Command+C` | 复制选中节点及其内部连线 |
| `Ctrl/Command+V` | 在指针位置粘贴 |
| `Ctrl/Command+D` | 在指针位置复制选区 |
| `方向键` | 将选中的可编辑节点微移 1 个图单位 |
| `Delete` | 删除选中的可编辑节点 |
| 空白处 `Ctrl+拖动` | 松开鼠标后框选所涵盖的节点 |

虚拟入口节点自动定位，不参与全选、微移、复制或删除（Parent 调用节点可正常编辑）。输入控件获得焦点时图快捷键自动让出，只读图会禁用一切修改快捷键。通用数据成员图仅暴露该类型声明的事件、不含类属性且禁止 Latent 节点（见[通用数据与文本配置](<通用数据与文本配置.md>)）。

## 继承

子蓝图继承父类的字段、组件与行为。修改已保存的父类路径可能改变继承字段、事件与组件兼容性，请仔细检查受影响的子蓝图与地图实例。同一条继承链中的所有蓝图必须统一使用图模式或 Script Mixin 模式；详见 [Script Mixin 编写工作流](<../Lua 与蓝图脚本/脚本 Mixin/编写工作流.md>)。
