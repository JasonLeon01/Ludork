# 通用数据参考总览

本节提供 Game 项目内置的七种通用数据 Schema 参考（`Class`、`Enemy`、`Equip`、`Item`、`Player`、`Special` 与 `State`）。通用数据属于项目数据而非固定引擎枚举，各项目可按需自由修改或扩展。

## 数据存放位置

每种类型对应 `Data/General/<Type>.json`。通过 **数据库 → 通用数据**（`F10`）可编辑 Schema、成员记录与成员能力图；字段类型与自动生成模块详见[通用数据与文本配置](<../通用数据与文本配置.md#类型结构>)。

## 内置 Schema

| Schema | 用途 | 成员事件 |
|---|---|---|
| [Class](<Class.md>) | 玩家职业预设：显示名称、说明，以及将装备槽位映射至初始装备的 `slot`。 | — |
| [Enemy](<Enemy.md>) | 敌人数值（`MAXHP`、`ATK`、`DEF`、`EXP`、`GOLD`）、`drops`（带地图格偏移的物品蓝图路径）、`special` 参数与攻击动画。 | — |
| [Equip](<Equip.md>) | 装备记录：图标、对应的 `Class` 槽位键，以及装备期间生效的 `attrPlus` 属性修正值。 | `onEquip`、`onUnequip` |
| [Item](<Item.md>) | 背包物品：`usable` 开关、商店 `price`（及推导售价）、图标与 `cost` 堆叠数量显示开关。 | `onDrop`、`onUse` |
| [Player](<Player.md>) | 玩家预设：引用的 `CLASS` 成员以及初始 HP、属性、经验、金币、等级与攻击动画。 | — |
| [Special](<Special.md>) | 敌人特殊能力的外观展示记录（名称、说明与图标），运行时参数保存在 `Enemy.special` 中。 | — |
| [State](<State.md>) | 持久状态效果，包含是否通过 `stackable` 叠加层数的配置。 | `onWalk`、`onHookTriggered` |

- **枚举引用**：跨类型引用采用以字符串 ID 为底层值的枚举 Schema——`Player.CLASS` 使用 `Enums.GeneralData.Class`，`Enemy.special` 键使用 `Enums.GeneralData.Special`，攻击动画使用 `Enums.Animation`。
- **成员事件**：由 `Source.Gameplay.GeneralDataGraphAbility` 显式激活（缺少起始节点时返回 `NoGraph`）。具体调用方与事件上下文见各类型页面。

## 带花括号的显示字符串

显示字段可填写 `{WARRIOR}` 等本地化键，在文本显示时而非加载时解析。格式化与语言切换规则详见[游戏本地化工作流](<../../插件开发与安装/官方插件/游戏本地化工作流.md#运行时>)。
