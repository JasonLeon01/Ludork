# Class

定义玩家职业预设，包括显示元数据、可用装备槽位名称及各槽位的初始装备。

**来源**：`Data/General/Class.json` · **成员事件**：无

## Schema

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `name` | `string` | `""` | 该职业的显示名称。 |
| `desc` | `string` | `""` | 该职业的显示说明。 |
| `slot` | `Dict[string, string]` | `{}` | 装备槽位名称到初始装备 ID 的映射（留空表示该槽位初始未装备）。 |
