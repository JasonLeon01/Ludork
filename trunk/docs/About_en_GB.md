Ludork is a game editor and runtime framework for creating 2D RPGs.

It combines a cross-platform Avalonia/.NET editor, Lua and Blueprint gameplay authoring and a native C++20 runtime powered by LuaSF and SFML. Ludork brings maps, assets, data and game logic into one visual workflow so you can build and iterate on your games efficiently.
