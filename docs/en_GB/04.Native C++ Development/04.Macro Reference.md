# Macro Reference

## Scope

Use this page to select the declaration marker for a supported binding or native UI adapter. Detailed option syntax remains on the task and advanced-pattern pages.

| Macro | Purpose |
|---|---|
| `BIND_CLASS` | Declare a bound class and its unique module-root name |
| `BIND_FUNCTION` | Bind a free function; `outpins(...)` and `latent(...)` are inline options |
| `BIND_FUNCTION_GROUP` | Put all bound free functions in a header into one table |
| `BIND_METHOD` | Bind a method or getter-backed property; methods enter metadata unless `metadata = false` |
| `BIND_PROPERTY` | Bind an instance data property |
| `BIND_INIT` | Bind a constructor |
| `BIND_IGNORE` | Exclude a declaration |
| `BIND_REGISTER_EVENT` | Register a Blueprint event entry |
| `BIND_INVALID_VARS` | Hide invalid/editor-inapplicable fields |
| `BIND_RECT_RANGE_VARS` | Add texture/range semantics to rectangle fields |
| `BIND_LOOP_NODE` | Describe a loop node protocol |
| `BIND_INJECT` | Inject declaration-driven binding code at a supported point |
| `BIND_MODULE_PROPERTY` | Expose a module-level property |
| `BIND_CLASS_PROPERTY` | Expose a class-level property |
| `BIND_LUA_REVERSE` | Describe reverse Lua/C++ adaptation |
| `BIND_LUA_HELPER` | Declare a reusable Lua binding helper |
| `BIND_MODULE_INIT` | Add module initialisation behaviour |
| `BIND_DYNAMIC_VALUE_TYPE` | Mark a type handled by dynamic-value conversion |
| `BIND_OPAQUE_IDENTITY_TYPE` | Mark a type whose identity must remain opaque |
| `BIND_UI_CONTROL` | Declare one native declarative-UI control adapter and its catalogue properties |

`BIND_METHOD(...)` and the other variadic annotation markers expand to nothing in the C++ compiler. Bindgen reads their raw token sequences, so annotation-only tokens such as `outpins(...)`, `nil`, `function` and `{nil, false}` do not need C++ expression or type meaning and must not be quoted merely to satisfy C++ parsing. Named execution branches use `outpins(...)`, latent states use `latent(...)`, and protocol values use lowercase `nil`, `true` and `false`. Ordered `defaults` and `parameter_types` values use brace-enclosed token lists for methods and free functions, and constructor `defaults` uses the same form. Structured `meta(...)` data and singular property `default` values also use braces: positional entries form arrays such as `default = {0.0, 0.0}`, and named entries form objects such as `meta(Rely = {source = "autoSound", op = "!=", value = ""})`; nesting is allowed. Complete arrays and objects must not be quoted as JSON. Use the annotation form already established by neighbouring declarations. Extra conversion capability belongs in generic `LudorkCoreBinding` traits, recursive adapters or declarations—not in a business-name special case inside bindgen.

Bound classes, ungrouped functions and module properties use exactly one
module-root path; grouped functions use their group table.
`BIND_INJECT(global = ...)` uses `global` as the injection-source identifier.

## Verification

Rebuild after adding a marker and confirm its declaration appears in every applicable generated consumer without an annotation diagnostic.

## Limitations

The table identifies supported markers, not every permitted option combination. `Pure`, execution protocols and property declarations remain subject to the validation rules on their dedicated pages.
