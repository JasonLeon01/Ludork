## Emitter

The Lua API signatures in this section omit the colon-call receiver. Blueprint instance-method nodes expose it as a visible `self: Engine.Emitter` input with the graph owner as its default.

`Engine.Emitter` owns GPU particle playback for a [Common Particle](<../../../../02.Editor User Guide/10.Common Particles.md>) asset. It is independent of the existing `ParticleSystem`. Actor Components and UI views own instances; construction alone does not attach one to a Scene.

| Lua API | Contract |
|---|---|
| `Engine.Emitter.new(resourceKey = "")` | Optional extensionless key relative to `Data/Particles`. A non-empty key loads and starts the resource. |
| `load(resourceKey)` | Validates and replaces the resource, clears the previous GPU state and restarts. |
| `setConfiguration(configuration)` | Accept an `Engine.EmitterConfiguration`, validate all tracks and curves, bake the curve samples, replace the configuration and restart playback. Lua/native only, omitted from Blueprint metadata. |
| `getConfiguration()` | Return an independent configuration snapshot: `EmitterConfiguration` by value in C++, or a Lua field table described by `Engine.EmitterConfiguration`. Apply changes explicitly with `setConfiguration`; reading or editing the copy does not change playback. Lua/native only. |
| `play()` | Starts from the beginning when stopped or paused; leaves an already playing instance running. |
| `pause()`, `resume()` | Pause preserves particles; resume continues the existing timeline and resets host-motion history. |
| `restart()` | Clears playback state and restarts at zero, repeating configured prewarm. |
| `stop(clear = true)` | Clears and stops by default. `false` disables further emission/recycling while existing particles finish if playback is advancing. |
| `emit(trackName, count)` | Queues a non-negative manual count on a named emission track and enables playback. Invalid names and resident tracks are errors; queued counts are capped by track capacity. |
| `setSpeed(speed)`, `getSpeed()` | Finite playback multiplier in `[0,100]`. Zero freezes timeline advancement. |
| `setColour(colour)` | Multiply rendered RGBA by an `sf.Color`. `EmitterView` supplies its UI presentation colour when drawing. |
| `getTime()`, `isPlaying()` | Simulated seconds and the playback flag; a hidden host may retain `true` while Scene scheduling is frozen. |
| `getCapacity()` | Sum of enabled-track capacities, not a live particle count. |
| `setProfiling(enabled)`, `getStatistics()` | Enable asynchronous GPU timing and read an `Engine.EmitterStatistics` snapshot. Statistics are Lua/native only; optional values without a result are `nil`, not zero. |

Configuration has fixed declared fields. The native signatures are `setConfiguration(const EmitterConfiguration&)` and `EmitterConfiguration getConfiguration() const`; the Lua getter returns an independent field table. For an existing emitter, a scalar configuration edit can be applied as follows:

```lua
local configuration = emitter:getConfiguration()
configuration.seed = 42
emitter:setConfiguration(configuration)
```

The native host API is `tick(float deltaTime)`, `draw(sf::RenderTarget&, sf::RenderStates = {})`, `setHostTransform(const sf::Transform&)`, `resetHostMotion()`, `shutdown() noexcept` and static `collectGarbage() noexcept`. Delta time is finite and non-negative. `EmitterScheduler` calls `beginFrame()`, `registerEmitter(shared_ptr<Emitter>, transform)` for active hosts, then `advance(deltaTime)` once per Scene frame. Registration is weak and deduplicated. Re-entry resets distance history. `shutdown()` stops known instances and collects retired graphics resources with an active context. Runtime scripts should use their owning Component or View rather than ticking an instance a second time.

## EmitterConfiguration

`Engine.EmitterConfiguration` describes a copyable configuration record, omitted from Blueprint metadata. C++ uses the struct; Lua getters produce ordinary field tables with this declared shape. A constructed native value or a Lua table initialized through its declared properties can be passed to `setConfiguration`.

| Property | Type | Default and contract |
|---|---|---|
| `name` | `string` | `""`; authored configuration name. |
| `simulationRate` | `int` | `60`; integer from 1 to 240. |
| `seed` | `int` | `1`; integer from 0 to 16,777,215. |
| `tracks` | `Engine.EmitterTrack[]` | Empty; ordered tracks with unique names. |

There is no `type` property on this structure. The `"type": "particle"` marker belongs to the resource JSON boundary. Loading a resource resolves its curve references into values; the returned configuration does not retain unresolved curve resource keys.

## EmitterTrack

`Engine.EmitterTrack` derives from `Engine.EmitterTrackParameters` and adds `curves: Engine.EmitterCurves`. In C++, the parameter base is `ludork::runtime::graphics::EmitterTrackParameters`. Timing, forces, texture-sheet settings and transforms keep the names, units and limits described in [Common Particles](<../../../../02.Editor User Guide/10.Common Particles.md#resource-identity-and-schema>), with these representation differences:

| Resource JSON | Typed property |
|---|---|
| `mode: "emission"` / `"resident"` | `resident: false` / `true` |
| `space: "local"` / `"world"` | `world: false` / `true` |
| `blend: "alpha"` / `"add"` | `additive: false` / `true` |
| `shape: "point"`, `"line"`, `"rectangle"`, `"disk"`, `"ring"` | `shape: 0`, `1`, `2`, `3`, `4` |
| `scaleMode: "hierarchy"`, `"local"`, `"shape"` | `scaleMode: 0`, `1`, `2` |
| `colourMin`, `colourMax`: four RGBA values in `[0,255]` | Four floats in `[0,1]`, each JSON component divided by 255; both default to `{1,1,1,1}`. |
| Two-component vectors and min/max ranges | `sf.Vector2f`; range minimum is `x`, maximum is `y`. |
| `textureRect: [x,y,width,height]` | `sf.IntRect` with `position` and `size`. |
| `bursts` array | `Engine.EmitterBurst[]` |
| Inline curves or curve resource keys | Resolved `Engine.EmitterCurves` with eight `Engine.CurveData` values. |

Typed defaults are `resident = world = additive = false`, `shape = scaleMode = 0` and `count = 32`. Lowering `capacity` below 32 requires setting a valid `count` explicitly. The JSON loader separately defaults an omitted `count` to `min(32, capacity)`. Validation occurs when applying the complete configuration; numeric ranges must be finite and ordered, colours normalized, and enum integers within their supported ranges.

## EmitterCurves

`Engine.EmitterCurves` has eight named properties: `speed`, `sizeX`, `sizeY`, `rotation`, `red`, `green`, `blue` and `alpha`. Every property is `Engine.CurveData` (`Curve::CurveData` in C++). The seven multiplier channels default to a constant 1; rotation defaults to a constant 0 and adds degrees. Curve key times use normalized lifetime `[0,1]`. `setConfiguration` validates the curves and bakes their GPU lookup samples before restarting; the backend receives the samples rather than Core curve objects or a dictionary.

## EmitterBurst

`Engine.EmitterBurst` is a fixed value record with `time: float = 0`, `count: int = 0`, `cycles: int = 1` and `interval: float = 0`. Time and interval are seconds. Its first time is within `[0, duration)`, count is 0–1,000,000, cycles is 1–10,000, and repeated bursts require a positive interval.

## EmitterStatistics

`getStatistics()` returns a snapshot described by `Engine.EmitterStatistics`. C++ returns `ludork::runtime::graphics::EmitterStatistics` by value; Lua receives an ordinary table containing the declared fields.

| Property | C++ type / Lua value | Meaning |
|---|---|---|
| `capacity` | `int` / integer | Always present; total enabled-track capacity, not live count. |
| `time` | `double` / number | Always present; playback time in seconds. |
| `renderer` | `std::optional<std::string>` / string or `nil` | Renderer identity when available. |
| `aliveCount` | `std::optional<std::int64_t>` / integer or `nil` | Delayed GPU count at `sampledTime`. |
| `sampledTime` | `std::optional<double>` / number or `nil` | Simulation time of the live-count sample. |
| `gpuSimulationMs`, `gpuDrawMs` | `std::optional<double>` / number or `nil` | Latest available asynchronous GPU timings, in milliseconds. |
| `simulationSample`, `drawSample` | `std::optional<std::int64_t>` / integer or `nil` | Timing sample identifiers; deduplicate each channel and pair equal identifiers when adding simulation and drawing time. |

An unavailable renderer, count or timing result stays `nil`; it is not filled with an empty string or zero. Repeated polling may return the same completed sample. The editor's JSON message boundary omits unavailable optional values while retaining its existing protocol.

## EmitterComponent

Blueprint instance-method nodes expose `self: Engine.EmitterComponent`; leaving it unset selects the graph owner.

`Engine.EmitterComponent` derives from `Component` and occupies `Actor.emitterComp`. It follows the existing Component attachment protocol and accepts only an Actor owner. `getEmitter()` lazily returns its `Engine.Emitter`; replacing or clearing `resource` releases the previous instance. Runtime particle state is not serialized.

Replacing `actor.emitterComp` or assigning `nil` immediately clears the previous component's playback, even if the Actor is dormant and another object still holds the old component or emitter. Normal map spawning invokes `onAttach(actor)` through the Component protocol. A component installed after spawning must also be attached through that protocol before it participates in Scene playback.

| Property | Default | Meaning |
|---|---|---|
| `resource` | `""` | `PARTICLE` resource selector; extensionless key under `Data/Particles`. Empty disables the effect. |
| `anchor` | `[0.5,0.5]` | Normalized point in the Actor's local bounds. |
| `offset` | `[0,0]` | Additional local offset in logical pixels. |
| `rotation` | `0` | Local rotation in degrees. |
| `scale` | `[1,1]` | Local scale. |
| `beforeActor` | `false` | Draw immediately before the owner when true, immediately after when false. |

Map rendering preserves the existing Actor-list and layer order. Invisible and dormant Actors freeze their effect without changing its pause flag. Destroy, region eviction, map replacement and Scene shutdown clear and release it. The Component keeps a weak Actor reference and owns only its playback instance.

## EmitterView

Blueprint instance-method nodes expose `self: Engine.EmitterView`; leaving it unset selects the graph owner.

`Engine.EmitterView` derives from `ControlBase`. Use it as a childless visual UI node under a Canvas or List container. It owns an `Emitter` independently of Actor and follows existing Slot layout, parent ordering and clipping.

| Lua API | Contract |
|---|---|
| `Engine.EmitterView.new(particle = "", size = sf.Vector2f.new(100, 100), anchor = sf.Vector2f.new(0.5, 0.5), autoPlay = true)` | Construct a particle view. `size` is its layout bounds in UI logical pixels; `anchor` locates the emitter within them. |
| `getEmitter()` | Return the shared `Emitter` playback object. |
| `getParticle()`, `setParticle(key)` | Read/change the particle resource key; changing it clears the previous effect. |
| `getSize()`, `setSize(size)` | Read/change layout bounds. |
| `getAnchor()`, `setAnchor(anchor)` | Read/change the normalized emission anchor. |
| `getAutoPlay()`, `setAutoPlay(value)` | Read/change the automatic playback policy used when loading a resource or changing Canvas. The setter itself does not start or pause playback. |
| `dispose()` | Idempotently release playback and stop future participation. |

Its `world` particle domain is the containing Canvas's logical space, separate from the map View. UI composition applies global scaling once. Moving to a different Canvas resets the effect. Hiding or unmounting freezes and retains particles; restoring the view preserves manual pause. Generated UI Views expose the node through their normal typed references; call `getEmitter():pause()` on the authored particle node.
