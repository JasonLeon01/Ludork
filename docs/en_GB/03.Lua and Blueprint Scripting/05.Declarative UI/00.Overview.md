## Ownership boundary

| Layer | Owns |
|---|---|
| JSON View | Hierarchy, asset-local node names, static control properties, Slots and design-only preview data |
| Lua Controller | Model access, callbacks, localised/formatted text, state refresh and dynamic composition |
| Native control | Rendering, measurement, hit testing, focus and primitive interaction state |
| UIManager | Mounting and removing prepared root controls |

Do not store Controller functions, expressions, event handlers or `LOC(...)` calls in a UI asset.
