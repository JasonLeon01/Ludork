# Declarative UI Validation and Packaging

## Goal

Validate path-based UI declarations, compare native preview with runtime, and package assets without editor-only preview data.

## Validate after external changes

When UI JSON changes outside the editor, run:

```text
ScriptTools ui-assets validate <project-root>
ScriptTools ui-adapter-check <project-root>
```

`ui-assets validate` checks assets against the project registry. `ui-adapter-check` and `ui-preview validate` are read-only; adapter validation compares the project JSON with its Host’s compiled descriptors.

Before a source project’s first preview build, and when saving before compilation, only descriptor-independent structure is checked; native validation remains pending. Use `ScriptTools ui-assets validate <project-root> --structure-only` for this check. Builds generate preview artifacts before full UI validation; invalid assets fail the build but leave the generated preview available for editing. Ordinary saves with an available registry perform full validation.

Standalone restores missing preview JSON from its included Host through `ScriptTools ui-preview ensure <project-root>`, normal UI validation or `ui-preview registry`. Corrupt or mismatched metadata and missing binaries remain errors. Source projects must rebuild unavailable preview artifacts; incomplete or failed native builds cannot be recovered automatically.

## Validation layers

Save, native preview, Run and Pack enforce the [asset schema](<04.Asset Schema and Control Registry.md>), rejecting unknown fields, duplicate asset-local node names and alias paths.

## Native preview and packaging

Preview requires a compatible protocol, system adapter fingerprint and complete registry hash.

Packaging validates a staging copy, removes `editor` data and applies configured compilation, encryption or archiving without modifying the project's gameplay assets. JSON, `.ldc` and packed Data keep the same extension-free UI keys; packed controllers keep their logical module paths.

Staging validation uses the source project registry through `--registry <source-project>/Temp/UiPreview.registry.json`. The registry is a development artifact and is excluded from player packages.
