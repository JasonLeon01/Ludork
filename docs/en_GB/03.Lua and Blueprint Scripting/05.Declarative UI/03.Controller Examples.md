# Declarative UI Controller Examples

## Goal

Implement repeatable Model-to-View refresh, native callbacks, nested-part ownership and update publication without leaking Lua closures.

## Prerequisites

- A saved UI asset with stable node names and a matching `Ui.define` key.
- A Model and owner that control Controller construction and disposal.
- Any localised keys generated before runtime use.

## Steps

1. Acquire controls and install callbacks once in `bind`.
2. Derive visible state from the Model in repeatable `refresh` calls.
3. Give every nested asset its own Controller.
4. Publish only the updates that every live instance should receive.
5. Clear native callbacks before inherited `dispose`.

## Localised and Model-derived text

```lua
local Ui = require("Source.UI.Ui")

local InventoryUI = {}

function InventoryUI:refresh()
    self:setText("Title", LOC("INVENTORY_TITLE"))
    self:setText("Count", tostring(self.model.itemCount))
end

return Ui.define("Inventory", InventoryUI)
```

Keep `properties.text` empty for this content. `editor.previewText` may provide Designer-only copy; the runtime never evaluates preview data.

## Bind a native control

```lua
function SettingRowUI:bind()
    self._dropBox = self:requireControl("DropBox")
    self._dropBox:setItems(self._items)
    self._dropBox:setOnSelectedIndexChanged(function(index)
        self:_onSelectedIndexChanged(index)
    end)
end

function SettingRowUI:dispose()
    self._dropBox:setOnSelectedIndexChanged(nil)
    super().dispose()
end
```

Programmatic value setters do not play interaction sounds. For `DropBox`, `open()` represents a user-triggered open; `setExpanded(...)` changes state silently.

## Own a nested part

```lua
local ItemRowUI = require("Source.UI.Parts.Inventory.ItemRow")

local rowInstance = self:requireAsset("ItemRow")
local rowUI = ItemRowUI.new(itemModel, rowInstance)
rowUI:prepare(self._viewLogicalSize)
```

Each nested instance owns an independent control tree. The parent controls only the nested instance's own name and parent Slot, not internal properties or children.

## Publish updates

`InventoryUI.publish(payload)` updates every live, prepared instance through the asset's EventBus channel. Override `onViewUpdate(payload)` to store the new state; the Controller then runs the normal refresh and reflow sequence. Add cross-cutting events such as locale changes to `refreshEvents` only when the UI needs them.

## Expected result

Prepared instances show current Model data, respond once to each native interaction, preserve nested ownership boundaries and release all subscriptions when disposed.

## Verification

- Call `refresh` repeatedly with unchanged and changed Models.
- Open and close the owning Scene/window multiple times and watch for duplicate callbacks.
- Create two nested instances and verify their control trees remain independent.
- Change locale and confirm only subscribed UIs refresh.

## Limitations

`publish` targets live prepared instances of one asset class; it is not a general project message bus. Preview text is never a runtime fallback.
