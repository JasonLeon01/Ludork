# Lua/native boundary benchmarks

Run a Release build from the Sample directory to measure the graphics, lighting and text-layout workloads without changing the game entry script:

```powershell
cd Sample
./bin/Release/Main.exe ../tools/benchmark_lua_native_boundaries.lua pixel
./bin/Release/Main.exe ../tools/benchmark_lua_native_boundaries.lua lighting
./bin/Release/Main.exe ../tools/benchmark_lua_native_boundaries.lua text
```

The script reports CPU time from `os.clock`; compare results only on the same machine and build configuration. Before timing the pixel-grid workload, it verifies every native vertex position, texture coordinate and colour against the Lua reference implementation.
