# Sample Usage Recipes

These short recipes trace one complete Sample feature from authored data to runtime behaviour.

| Recipe | Demonstrates |
|---|---|
| [Consumables](<01.Consumables.md>) | Collision, Script Mixins, sound fallback and Actor destruction |
| [Doors](<02.Doors.md>) | Parent behaviour, General Data requirements and variable-driven opening |
| [Enemies](<03.Enemies.md>) | General Data, Blueprint class, components and battle flow |
| [Equipment and Items](<04.Equipment and Items.md>) | Stable identifiers, inventory state and UI presentation |

For each recipe, test a successful path, an unmet-condition path and repeated activation.
