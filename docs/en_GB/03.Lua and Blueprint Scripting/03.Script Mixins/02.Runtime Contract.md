# Script Mixin Runtime Contract

The runtime loads the selected module as `Mixins.<path-with-dots>` and requires it to return a table with no metatable.

## Scope

This contract governs module loading, generated Blueprint-class members, instance defaults, reserved names and parent-method dispatch for every Direct Script Mixin.

## Table rules

- Every key must be a string.
- A function becomes a method on the generated Blueprint class.
- A non-function value is deep-copied into class and instance defaults.
- An inherited member cannot change from field to function or function to field.
- A saved Blueprint attribute cannot replace a mixin method.

The following names are reserved:

```text
__*  init  new  scriptMixin  scriptPath
_GENERATED_CLASS  _graph  _hasImplementationOwner
```

Because `init` is reserved, a Direct Script Mixin does not declare a constructor. Initialise private instance state from the lifecycle callback supplied by the owning type, such as `onCreate`, and release subscriptions or resources in the corresponding teardown callback.

## Parent method calls

Use `super()` inside a mixin method to continue the Blueprint/native inheritance chain:

```lua
local Door = {}

function Door:onCollision(other)
    if self.opening then
        return
    end
    super().onCollision(other)
    self:openDoor()
    self.opening = true
end

return Door
```

The parent class must actually provide every native property or method used by the mixin. The editor validates schema and path rules, while missing runtime members fail at the real call site.

## Verification

Construct at least two instances, mutate each copied default independently, and exercise every Mixin method with its declared parent. Confirm `super()` reaches the intended next implementation.
