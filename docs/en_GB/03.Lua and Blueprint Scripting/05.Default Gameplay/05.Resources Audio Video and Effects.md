# Resources, Audio, Video and Effects

## Resource paths

Stored resources use exact-case `/Game/Assets/...` paths with `/` separators and extensions. Generic managers require that complete form. Category helpers such as `loadCharacter("actors/Hero.png")` and `playSE("cursor.ogg")` accept only category-relative arguments and add their own prefix.

The runtime resolves logical paths to loose files or `.ldpak` entries, while standard filesystem APIs and direct LuaSF file constructors do not. Music and video stream seekable entries. Use `PLATFORM` only for real platform differences.

## Animation caches

Animation sources live in `Data/Animations`. `Engine.getAnimationCacheRoot()` creates `Cache/Animations` under `Engine.getUserDataPath()` for both loose and archived Data. On Windows, the user-data root is the runtime working directory. Other platforms use their application user-data location.

Initialisation generates missing `.anim.json`/`.anim.ldc` caches and rebuilds them when source data or referenced frame assets change, preserving paths relative to `Data/Animations`. Caches are disposable and excluded from templates and player packages.

## Audio

Music, sound effects and voices have independent enable flags and volumes in `Main.ini`. The GlobalFunctions Manager group provides the gameplay-facing helpers. Handle missing optional sound paths deliberately. Repeatedly loading the same resource under different path spellings defeats caching.

Audio effects used by the gameplay Manager and Blueprint nodes are Lua DSP processors defined by `Source.AudioEffects`. The Game project provides the case-sensitive `Echo`, `Distortion`, `Underwater` and `BehindWall` presets. Their defaults remain a 0.3-second/0.5-decay echo, a 2.0-drive/0.7-threshold distortion, a 0.7-depth/0.3-bubble underwater effect, and a 900-Hz/0.35-transmission behind-wall filter.

`NodeFunctions.Audio.SetEffect(audioType, effect)` resolves the name with `AudioEffects.Get` and stores the resulting attacher independently for the `Sound`, `Voice` or `Music` category. Metadata presents both parameters as drop-downs. Selection does not create a processor and does not modify a source that is already playing. Each later source invokes the attacher, which creates an isolated audio Lua state and a fresh processor for that source. Select the literal string `nil` to clear the preset for future playback. Any other unknown name raises immediately. `Source.AudioEffects` is the sole preset registry, so a change to the preset registry also requires an update to the `SetEffect` metadata drop-down. Effect selection is not part of `SoundFilter` or `MusicFilter`.

For a non-empty preset, source creation captures the current playback-device sample rate before play. An active source keeps those coefficients after device rerouting, so start a new Manager playback to use the new rate. The attacher must install exactly one non-empty processor, so a selected preset cannot play dry. SFML stores one processor per source. Presets are not chained or mixed.

After hot reload, start a new playback to use updated audio code; see [Lua Runtime and Modules](<../01.Lua Runtime and Modules.md#lua-hot-reload>). Playing sources and buffered tails continue unchanged.

`Echo` drains its buffered tail after a natural end of stream. An explicit Manager stop, a dialogue skip or shutdown discards the remaining tail. Direct `sf.SoundSource:setEffectProcessor` use is a separate low-level API, and it does not receive the Manager isolation, EOS or cancellation protocol.

`NodeFunctions.Scene.ShowVoiceMessageByTag` and `ShowVoiceMessage` capture the exact Voice handle started by that call for the lifetime of their dialogue. When the dialogue finishes, their latent condition stops that handle before `FinishedDialogue` resumes downstream Blueprint execution. A following `SetEffect` therefore configures the next Voice. Leaving or destroying a map scene also stops the current global Voice. Ordinary message nodes do not change Voice playback.

## Shaders, fog and transitions

User-authored Actor and layer shaders remain optional. Check `sf.Shader.isAvailable()` or `sf.Shader.isGeometryAvailable()` when gameplay can run without them. Built-in weather and fog instead require their shared cross-platform shader assets and propagate load or compilation failures. World entry warms each world or Active-layer shader once, and a rebuilt shader object warms again. HarmonyOS skips the artificial 1×1 prewarm and compiles each shader during its first normal draw, after the complete render state and uniforms are bound. HarmonyOS OpenGL ES treats unversioned shaders as ESSL 1.00 and preserves the public `setUniform("texture", ...)` name. Explicit versions must match the backend.

Actor fragment shaders are cached by exact shader path for the lifetime of the Engine runtime. Actors using the same path therefore receive the same `sf.Shader` from `Actor:getShader()`. The standard `texture`, `time`, `textureSize` and `textureRect` uniforms are rebound immediately before each Actor map or preview draw. Other uniforms remain shared mutable shader state and must not be treated as persistent per-Actor values. A shader that fails to load is not cached. The affected Actor reports `Actor:hasShaderError()` and continues through the existing fallback rendering path.

Fog textures use ordinary RGBA semantics: RGB supplies the colour, alpha supplies per-pixel density, and `fogPower` scales opacity. The same shader handles ordinary maps and clipped composite-world regions on every supported graphics backend.

Map fog data uses a strict optional-field protocol. `fog` is a string, and fog is disabled when it is missing, `nil` or blank. `fogPower`, `fogOx`, `fogOy` and `fogDistort` are finite numbers within the float range and default to `0` only when missing or `nil`. A `fogPower` at or below `0` also disables fog. Power and distortion are floored and clamped to `0..100`, while the two offset fields control scrolling. Numeric strings and other scalar coercions are not accepted.

Map panorama data uses the same optional-string protocol. `panorama` is a canonical `/Game/Assets/...` path, and panorama is disabled when it is missing, `nil` or blank. The image Cover-scales to fill `GameMap.MapViewRect` while preserving the aspect ratio, and then crops the overflow using the Camera origin as a fraction of `(mapPixels - viewPixels)` on each axis. An axis with no camera travel uses `0.5`. Transparent tiles and canvas margins reveal the panorama multiplied by ambient light only, while point lights still apply to opaque tiles. A missing texture is a required-resource failure.

### Composite-world environment

A world manifest may define global fog and a global panorama, but not BGM, BGS, audio filters or ambient light. Global fog covers the Camera. Child fog is clipped to its placement and sampled in world coordinates, and evicting a child removes its regional fog until reload. Global panorama covers the world Camera using the world size for scroll. A child's `panorama` applies only when that child is loaded as a standalone map.

BGM, BGS and ambient light follow the child beneath the player. Audio switches fade for 0.5 seconds, and returning during a fade-out restores that source. Later ambient changes also blend for 0.5 seconds, using white in holes. World fog and panorama remain active there.

The Game project's advanced enemy-defeat effect is controlled by the global class setting `Enemy.DefeatShatterEffectEnabled`, which defaults to `true` and is not a Blueprint field. Its shader renders a snapshot as world-space logical-pixel fragments scattering radially outward from the centre for about 0.65 seconds. The defeated enemy has already been recorded and destroyed, so the snapshot does not affect passability, collision or light blocking. When the setting is `false` or `sf.Shader.isAvailable()` is false, the enemy disappears immediately instead.

## Video

Video playback requires an FFmpeg-enabled project or template. Keep files beneath `Assets/Videos` and reference them as `/Game/Assets/Videos/...`. Loose files and entries in the root `Assets.ldpak` share the same seekable playback contract. Android supports MOV, H.264/AAC, swscale and swresample, but not network, JNI, MediaCodec or hardware acceleration. Build and distribution requirements are in [Project Templates](<../../01.Getting Started/02.Project Templates.md#ffmpeg-option>).

## Limitations

Shader availability is determined by the runtime graphics environment, and a successful editor preview does not guarantee equivalent target hardware support.

World lighting uses world coordinates, so Active Actor and child static lights can illuminate or cast shadows across child boundaries. Tile masks remain clipped to their placements, and holes contribute neither surfaces nor blockers. The editor composition preview omits fog, panorama and lighting.

Visible Tile blockers are merged natively into an occupancy texture and an integral mask, and Actor occlusion is analysed once per light batch. Owner exclusion, layer visibility, blocker bounds and transmission padding are unchanged.
