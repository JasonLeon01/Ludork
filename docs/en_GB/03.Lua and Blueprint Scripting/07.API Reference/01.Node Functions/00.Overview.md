# Node Functions

These modules provide project-authored Blueprint nodes from `Scripts/Source/NodeFunctions` and their metadata companions.

| Family | Purpose |
|---|---|
| Container, Math, String, Utils | General data transformation |
| GameMap, Movement, Scene | Map and Scene operations |
| Mota, Player, State | Sample gameplay and battle state |
| Save, System | Persistence and project-system operations |

Select the page matching the module name. Node signatures, ordered parameters, returns and execution metadata are transcribed from the current metadata.
