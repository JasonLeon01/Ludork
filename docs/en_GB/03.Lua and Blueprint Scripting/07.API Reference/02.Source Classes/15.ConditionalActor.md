# Source.ConditionalActor

Metadata source: `Scripts/Source/ConditionalActor_meta.lua`

Direct metadata base: `{ "Engine", "Actor" }`

## Properties

| Name | Type | Default | Metadata |
|---|---|---|---|
| `conditionVariable` | `string` | `""` | `InstVar` restricted to `int`, `float`, `bool` and `string` |
| `conditionOperator` | `string` | `"=="` | Drop-down: `==`, `~=`, `>`, `>=`, `<`, `<=` |
| `conditionValue` | `any` | `0` | `InstVarValue = "conditionVariable"`; runtime accepts number, boolean or string |

An empty variable name leaves the authored `visible` value unchanged. Otherwise, the current variable and comparison value must have matching scalar types. Numbers support all six operators; booleans and strings support only equality and inequality. Missing variables, unsupported operators and mismatched or unsupported types raise errors without implicit conversion.

The condition continuously controls `setVisible(result, false)`: a false result hides the Actor again. Child Actors retain their own visibility settings and follow their ancestors' effective visibility. Hidden Actors retain their instances and subscriptions, and Tick remains governed by `tickable` and world streaming.

## Lifecycle

`onCreate()` subscribes to `GameInstance:getVariables()` and immediately evaluates the condition. A subscription uses the current map path and non-empty `getMapTag()`; multiple Actors may watch the same field independently. Failed initial evaluation releases the subscription before propagating the error.

`onDestroy()` and `onWorldSleep()` unsubscribe; `onWorldWake(elapsedSeconds)` subscribes again and reevaluates current variables. Overrides in Lua or Script Mixins must call `super()`; Blueprint lifecycle graphs must continue the parent event. The Sample's empty lifecycle graphs inherit this automatically.

`releaseConditionMonitor()` performs repeatable subscription cleanup without changing visibility or persistent destruction records. `ConditionalActor.ReleaseMapMonitors(gameMap)` releases all condition subscriptions belonging to a departing map. `SceneMap` uses it before map replacement and destruction, and releases a suppressed world Actor tree before removing its identity. Temporarily covering a Scene preserves its subscriptions for reentry.

No subscription or derived visibility state is saved. Variables retain their current logical values in the save snapshot; map restoration removes destroyed placements before `onCreate`, so collected pickups do not reappear.

## Inheritance

Enemy, Item, Equip, DoorBase and Teleporter inherit this class. Bottle, Gem and the Sample's other direct map-Actor Blueprints use `Source.ConditionalActor.ConditionalActor` as their parent. `EnemyDamageText` retains its existing parent and hint logic.
