# Source.Item

Metadata source: `Scripts/Source/Item_meta.lua`

Direct metadata base: `{ "Engine", "Actor" }`

The editor shows a generated `ItemAttributeSet` preview for `ID`; `attributes` is read-only and not serialised into Blueprint JSON.

## Properties

| Name | Type | Default | Metadata |
|---|---|---|---|
| `ID` | `string` | `""` | GeneralDataVars = `Item` |
| `count` | `int` | `1` | — |
| `getSE` | `string` | `""` | Sounds path; `Audio.getSE` fallback |

## Runtime API

| Member | Signature | Behaviour |
|---|---|---|
| `init` | `(texture?, rect?, tag?)` | Constructs the generated Item Attribute Set from `ID` |
| `onCollision` | `(other)` | Adds `count` Items to Player inventory through the shared pickup flow |

Player grants `GeneralData.Item.<ID>.onUse` while the Item count is positive. Enemy drops explicitly activate `onDrop`.
