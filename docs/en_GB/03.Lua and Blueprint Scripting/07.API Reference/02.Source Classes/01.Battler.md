# Source.Battler

Metadata source: `Scripts/Source/Battler_meta.lua`

`Battler` is the Lua gameplay base for `Enemy` and `Player`; concrete types construct their generated Attribute Set from General Data.

## Runtime state

| Name | Type | Meaning |
|---|---|---|
| `attributes` | `Global.Gameplay.AttributeSet` | Live generated Attribute Set; concrete types narrow it to Enemy or Player |
| `_abilitySystemComponent` | `Global.Gameplay.AbilitySystemComponent` | Private owner of attributes, abilities, effects and tags |

## Runtime API

| Member | Signature | Behaviour |
|---|---|---|
| `init` | `(attributes)` | Requires an Attribute Set and creates its Ability System Component |
| `getAbilitySystemComponent` | `() -> AbilitySystemComponent` | Returns the live Ability System |
| `playAttackAnimationAt` | `(scene, targetPosition) -> number` | Plays `attributes.ANIMATION_KEY` at the target and returns visual duration; empty key returns `0` |

Use the Ability System for numeric Base/Current access. Numeric values must be finite and match the generated `int` or `float` schema; other data is read directly from `attributes`.
