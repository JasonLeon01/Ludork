# Source Classes

Editor-visible fields, functions and events declared by the Sample's Lua gameplay classes. The class name is the stable API identifier; translated editor labels do not change serialised references. Leaf pages are generated from the current pure-data metadata; LuaLS-only members are not Blueprint nodes.

The pages cover battler and component foundations, doors, enemies, items and equipment, Info data classes, Player, SceneMap and Teleporter. Check each page's declared bases before using a member from a Blueprint parent.
