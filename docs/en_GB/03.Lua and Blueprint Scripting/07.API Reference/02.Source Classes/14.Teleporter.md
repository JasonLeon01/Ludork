## Teleporter

Direct metadata bases: `{ "Engine", "Actor" }`

`goUpstairs` and `goDownstairs` record the triggering stair's `getTeleportPosition()` (including `Offset`) and raw `getMapTag()` after the transfer request is accepted; arrival records the destination stair. For discovery and display rules, see [Windows, Menus, Input and Controls](<../../06.Sample Gameplay/04.Windows Menus Input and Controls.md>).
