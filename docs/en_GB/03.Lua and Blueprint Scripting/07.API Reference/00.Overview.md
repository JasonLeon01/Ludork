# Blueprint API Reference

This reference is derived from every non-Mixin `*_meta.lua` file in the current Sample. It is the authoritative inventory of editor-visible properties, functions and events, grouped by NodeFunctions, Source classes, Global APIs and generated Core modules.

Signatures preserve parameter and output order. Execution modifiers and metadata are shown verbatim in compact Lua form. A member present only in `Scripts/stub` is a Lua scripting API, not a Blueprint node.

The generated pages should be regenerated or re-audited whenever metadata changes. Do not edit generated Core metadata to change this reference; change the C++ `BIND_*` declaration and rebuild.
