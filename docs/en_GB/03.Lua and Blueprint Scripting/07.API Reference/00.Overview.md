# Blueprint API Reference

Inventory of editor-visible properties, functions and events from every non-Mixin `*_meta.lua` in the current Sample, grouped by NodeFunctions, Source classes, Global APIs and generated Core modules.

Leaf pages are generated from the current pure-data metadata. LuaLS-only members that are absent from metadata are not Blueprint nodes. Signatures preserve parameter and output order. Execution modifiers and metadata are shown verbatim in compact Lua form.

Regenerate or re-audit generated pages whenever metadata changes. Change the C++ `BIND_*` declaration and rebuild rather than editing generated Core metadata.
