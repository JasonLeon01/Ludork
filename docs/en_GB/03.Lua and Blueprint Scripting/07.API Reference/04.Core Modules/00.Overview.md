# Core Module API

These pages inventory Blueprint-visible metadata generated from native binding declarations.

- [CoreSystem](<01.CoreSystem.md>) contains the current low-level metadata surface.
- [Engine](<02.Engine/00.Overview.md>) contains engine values, gameplay foundations, input, services and UI controls.
- [GlobalCore](<03.GlobalCore/00.Overview.md>) contains project-global gameplay classes and managers.
- [GlobalFunctions](<04.GlobalFunctions.md>) contains grouped `Components`, `UI`, `NodeGraph` and `Manager` functions.

A LuaLS-only member is a script API, not a Blueprint node. Change native declarations and rebuild rather than editing generated metadata.
