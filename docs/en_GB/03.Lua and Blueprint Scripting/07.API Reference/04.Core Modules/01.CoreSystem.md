# CoreSystem Lua API

## Scope

`CoreSystem` is a native Lua module for file-system checks, directory creation, zlib compression and Base64 conversion. This reference is derived from `Scripts/stub/CoreSystem.d.lua` and `Core/System/include/CoreSystem.hpp`.

`Scripts/CoreSystem_meta.lua` is empty, so these functions do not create Blueprint nodes. The empty metadata file does not mean that the Lua module is empty.

## Loading

```lua
local CoreSystem = require("CoreSystem")
```

`CoreSystem` is independent of the fixed `Engine` → `GlobalCore` → `GlobalFunctions` gameplay-root sequence. Require it only in code that uses this system-level API.

## Functions

| Name | Parameters | Returns | Purpose |
|---|---|---|---|
| `exists` | path: string | bool | Test whether a file-system path exists. |
| `currentPath` | — | string | Return the process's current working directory. |
| `createDirectories` | path: string | — | Create the directory and any missing parent directories. |
| `compress` | value: string | string | Compress a binary-safe Lua string with zlib. |
| `decompress` | value: string | string | Decompress a zlib-compressed binary-safe Lua string. |
| `encodeBase64` | value: string | string | Encode a binary-safe Lua string as Base64. |
| `decodeBase64` | value: string | string | Decode Base64 into a binary-safe Lua string. |

## Verification

Require the module in a native-runtime build, round-trip representative binary data through `compress`/`decompress` and `encodeBase64`/`decodeBase64`, and perform file-system tests only inside a disposable project-owned directory.

## Limitations

These functions operate with the runtime process's file-system permissions and do not provide an editor sandbox. Invalid compressed or Base64 input reports a runtime error. Do not use `currentPath` as a substitute for project-relative asset paths.
