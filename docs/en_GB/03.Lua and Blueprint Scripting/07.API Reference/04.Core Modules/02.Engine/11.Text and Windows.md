# Engine: Text and Windows

## Engine.TextConfig

`Engine.TextConfig` builds file-backed configs for `Source.Data` and declarative UI, enforcing field whitelist/requirements, numeric/colour ranges, reserved names, rich order and gradient curves. Inline properties keep their node shape and share leaf/resource validation.

| Name | Parameters | Returns |
|---|---|---|
| `buildPlain` | data: table; sourceName: string | `Engine.PlainTextConfig` |
| `buildRich` | data: table; sourceName: string | `Engine.RichTextConfig` |

## Engine.TextLayout

`Engine.TextLayout` measures, truncates and wraps without mutating the control. It uses UTF-8 units, cached widths and rich marker state; `maxWidth` must be positive and finite.

| Name | Parameters | Returns |
|---|---|---|
| `measurePlainText` | control: `Engine.PlainText`; text: string | number |
| `measureRichText` | textConfigKey: string; text: string | number |
| `fitPlainText` | text: string; maxWidth: number; control: `Engine.PlainText` | string |
| `wrapPlainText` | text: string; maxWidth: number; control: `Engine.PlainText` | string |
| `wrapRichText` | text: string; maxWidth: number; textConfigKey: string | string |

Use this function group directly; `Source.TextLayout` does not exist.
