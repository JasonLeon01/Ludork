# Engine: Runtime Values and Functional Controls

## RuntimeValue

Direct metadata bases: —

`RuntimeValue` carries owned dynamic values across the native/Lua bridge and
remains registered under the `Engine` Lua module. Native Array and Map copies
share read-only storage and detach only on explicit native mutation; Lua
receives ordinary tables. VM-local tables, functions and other relay-only
values use opaque `RuntimeIdentity` handles, preserving the original Lua
object without serialising and reconstructing it.

## FunctionalBase

Direct metadata bases: `{ "Engine", "FocusableMixin" }`

### Interaction eligibility

A `FunctionalBase` accepts focus and input only while it and every `FunctionalBase` ancestor are active and it and every `ControlBase` ancestor are visible. `getActive` and `getVisible` remain local-state queries. Losing eligibility clears pointer and touch capture throughout the subtree and keeps the cancelled gesture consumed until release; ticking and rendering continue.

### Touch capture

`setTouchHitBounds` sets an optional touch-only hit rectangle in the control's local logical coordinates. The rectangle must have finite coordinates and a non-negative size; passing `nil` restores the default. `getAbsoluteTouchHitBounds` returns its axis-aligned screen rectangle after the runtime display scale and control hierarchy transforms are applied. A `FunctionalBase` mixed into `ControlBase` defaults to the control's absolute bounds. A standalone `FunctionalBase` has no control coordinate space, so the getter returns `nil`.

An effectively enabled functional control captures a primary touch whose beginning position is inside its absolute touch hit bounds. The capturing control continues to receive movement and the final release even after the pointer leaves those bounds. Releasing outside clears the pressed state without invoking click or confirm, but any tap belonging to that capture is still consumed so it cannot activate a control underneath. Multi-touch cancellation also releases capture; touch hit bounds do not affect mouse hit testing.
