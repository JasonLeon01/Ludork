## Typed data values

`resolveTypedDataValue(value, type, environment?, declaringModule?, evaluateAnyExpressions?)` restores and validates stored values using the [metadata schema](<../../../04.Blueprint Scripting/02.Metadata Schema and Decorators.md>), including Union branch tags. `evaluateAnyExpressions` defaults to true; pass false to preserve nested `any` strings as literals.

`resolveRuntimeTypedValue(value, type, declaringModule?)` validates an existing runtime value and returns it without evaluating strings or reconstructing native objects.

`setRuntimeTypedAttribute(owner, name, value)` validates and assigns an attribute using the owner's metadata. An explicit nil overrides inherited defaults on ordinary script fields.
