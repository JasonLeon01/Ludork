# Engine: Animation Data and Graphics

## Module graphics functions

| Name | Parameters | Returns | Purpose |
|---|---|---|---|
| `BuildPixelGridVertices` | origin: sf.Vector2f; size: sf.Vector2u | sf.VertexArray | Lua-only helper that builds six triangle vertices per pixel and does not create a Blueprint node. Every vertex for a pixel uses its centre texture coordinate; zero-sized input returns an empty triangle array and vertex-count overflow reports an error. |
