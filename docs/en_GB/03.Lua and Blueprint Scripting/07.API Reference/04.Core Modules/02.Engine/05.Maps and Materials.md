# Engine: Maps and Materials

Resource fields store complete logical paths: `TileLayer.shaderPath` and `TileLayerData.shaderPath` use `/Game/Assets/Shaders/...`; `AutoTile.fileName` and `Tileset.fileName` use their `Autotiles` and `Tilesets` groups. Shader paths may be empty; category-relative values are invalid.

## TileLayer

Direct metadata bases: `{ "Engine", "TileLayerGraphics" }`

Tile geometry uses 32×32-cell chunks and draws only those intersecting the view. `deferred = true` enables incremental runtime construction.

Sparse-world streaming uses `isCellBuilt(position)` (`metadata = false`) to reuse Tile graphics chunk-readiness.

| Name | Type | Default | Metadata |

| `speedRate` | `float` | `1` | — |
| `ignoreLighting` | `bool` | `false` | — |

`lightBlock` must be in `[0, 1]` and describes the blocked fraction across one `CellSize` of material. Partial blockers compound according to penetration length; a value of `0.5` transmits approximately `0.707`, `0.5`, and `0.25` across half, one, and two cells.
