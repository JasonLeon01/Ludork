# Blueprint Scripting

Blueprints store class defaults and a visual graph in `Data/Blueprints`. Common Functions store reusable graphs. Both are validated against the current project metadata catalogue.

## Pages

- [Execution Flow, Events and Variables](<01.Execution Flow Events and Variables.md>) explains entry events, execution/data pins, Common Functions and defaults.
- [Metadata Schema and Decorators](<02.Metadata Schema and Decorators.md>) defines the pure-data declarations that produce fields and nodes.

## Workflow

Create a Blueprint with F3, select a valid parent, add supported event entries, connect execution and data pins, validate, then save. Open Common Functions with F10 when multiple graphs need the same operation. A Script Mixin Blueprint follows the separate [Script Mixin](<../03.Script Mixins/00.Overview.md>) contract and does not execute its graph.
