# Source.MapActors.Item

Metadata source: `Scripts/Source/MapActors/Item_meta.lua`

Direct metadata base: `{ "Source.MapActors.ConditionalActor", "ConditionalActor" }`

Inherited visibility conditions: [Source.MapActors.ConditionalActor](<12.ConditionalActor.md>).

The editor shows a generated `ItemAttributeSet` preview for `ID`. The `attributes` field is read-only and is not serialised into the Blueprint JSON.

## Properties

| Name | Type | Default | Metadata |
|---|---|---|---|
| `ID` | `string` | `""` | GeneralDataVars = `Item` |
| `count` | `int` | `1` | — |
| `getSE` | `string` | `""` | Sounds path; `Audio.getSE` fallback |

## Runtime API

| Member | Signature | Behaviour |
|---|---|---|
| `init` | `(texture?, rect?, tag?)` | Constructs the generated Item Attribute Set from `ID` |
| `onCollision` | `(other)` | Adds `count` Items to Player inventory through the shared pickup flow |

The Player grants `GeneralData.Item.<ID>.onUse` while the Item count is positive. Enemy drops explicitly activate `onDrop`.
