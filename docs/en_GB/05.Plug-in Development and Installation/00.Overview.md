# Plug-in Development and Installation

Ludork editor plug-ins are C# 13 source directories compiled and loaded in process. They can add commands, text hints and pre-operation hooks through a deliberately narrow public contract. They are fully trusted code, not sandboxed content.

## Trust and ownership

Import only source that you have reviewed and trust. A loaded plug-in receives the editor process's file, network and operating-system permissions. The API limits access to editor-owned objects, but it does not restrict ordinary .NET capabilities.

The plug-in owns its source, windows, labels, settings, retained data and third-party notices. The host owns registration, lifecycle, command contexts, the restricted map/Blueprint bridges and operation sequencing.

## Supported public surface

The five registrar methods cover ordinary menu commands, map-item context-menu commands, text hint providers, before-Run hooks and before-Pack hooks. There are no public registrations for docked panels, toolbars, arbitrary host controls, data types or general editor events.
