# Official Locale Tools Walkthrough

`Plugins/OfficialLocaleTools` is the reference implementation for an ordinary menu command, a text hint provider and shared before-Run/before-Pack operation logic. It does not register a map-item context-menu command.

Official Locale Tools is preinstalled and registered by the Windows release. The path above is the corresponding source directory in a repository checkout; on macOS, run **Install Official Plugins** from the DMG as described in [Installing and Managing Plug-ins](<01.Installing and Managing Plug-ins.md>).

## Registration

Its public entry type loads the plug-in's own `locale.json`, constructs one `LocaleTextHintProvider` and one shared `LocaleExportHook`, then registers:

- a Database command at order 900 to open `Data/Locale/Locale.xlsx`;
- the text-hint provider;
- the export hook before Run;
- the same export hook before Pack.

Reusing the hook ensures Run and Pack produce identical game locale files. After each export attempt it invalidates both its cache and editor text hints.

The workbook remains at `Data/Locale/Locale.xlsx`, while generated language modules are written to `Scripts/Source/Locale`. During Pack, the hook calls `Packaging.ExcludeFile("Data/Locale/Locale.xlsx")`, so the authoring workbook is not distributed. The plug-in does not participate in luac conversion; the packer compiles `Scripts` recursively.

## Menu behaviour

The menu handler requires an open project, checks that the workbook exists and asks the operating system to open it. It reports handled warnings/errors through `IPluginUserInterface`.

## Separation of languages

`Plugins/OfficialLocaleTools/locale.json` localises the plug-in's own menu and diagnostic messages using `EditorLanguage`. It is not the game's catalogue.

As a structural example: small entry type, explicit registrations, operation work in dedicated classes, errors returned as `PluginResult`, and no dependency on editor implementation types.

## Verification

Start Ludork, confirm **Loaded**, open the workbook command, then run and package the project. The package must contain the generated language modules and omit `Data/Locale/Locale.xlsx`.

## Limitations

The plug-in owns project game-text export only. It does not localise the editor, create a general spreadsheet editor, register Random Map functionality or compile selected Lua directories.
