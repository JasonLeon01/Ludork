# Official Locale Tools

`Plugins/OfficialLocaleTools` is the reference implementation for an ordinary menu command, a text hint provider and shared before-Run and before-Pack operation logic. It does not register a map-item context-menu command.

Official Locale Tools is preinstalled and registered by the Windows release. The path above is the corresponding source directory in a repository checkout. On macOS, run **Install Official Plugins** from the DMG as described in [Installing and Managing Plug-ins](<01.Installing and Managing Plug-ins.md>).

## Registration

The public entry type loads the plug-in's own `locale.json`, constructs one `LocaleTextHintProvider` and one shared `LocaleExportHook`, then registers:

- A Database command at order 900 that opens `Data/Locale/Locale.xlsx`
- The text-hint provider
- The export hook before Run
- The same export hook before Pack

Reusing one hook ensures that Run and Pack produce identical game locale files. The hook invalidates its own cache and the editor text hints after each export attempt.

The workbook remains at `Data/Locale/Locale.xlsx`, while generated language modules are written to `Scripts/Source/Locale`. During Pack, the hook excludes the authoring workbook before optional Data archiving. The packer, not the plug-in, compiles and optionally archives the runtime Scripts tree.

## Menu behaviour

The menu handler requires an open project, checks that the workbook exists and asks the operating system to open it. It reports handled warnings and errors through `IPluginUserInterface`.

## Separation of languages

`Plugins/OfficialLocaleTools/locale.json` localises the plug-in's own menu and diagnostic messages using `EditorLanguage`. It is not the game's catalogue.

The structural pattern is a small entry type, explicit registrations, operation work in dedicated classes, errors returned as `PluginResult`, and no dependency on editor implementation types.

## Limitations

The plug-in owns project game-text export only. It does not localise the editor, create a general spreadsheet editor, register Random Map functionality or compile selected Lua directories.
