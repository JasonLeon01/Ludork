# Official Random Map

## Goal

Use the official Random Map plug-in as the reference for a map-item command that reads immutable editor snapshots, opens its own Avalonia workflow and replaces one layer with revision protection.

## Prerequisites

- Install the editor release; on macOS also run **Install Official Plugins** from the DMG. Restart Ludork and confirm that Official Random Map is **Loaded**. `Plugins/OfficialRandomMap` is its source directory in a repository checkout.
- Open a project containing at least one map, layer and valid tileset.
- Save or consciously retain any unsaved edits in the target map; a successful plug-in write saves that map directly.

## Registration contract

`OfficialRandomMapPlugin` registers exactly one `PluginMapContextMenuCommand`. It does not register a normal menu command, text hint provider, before-Run hook or before-Pack hook. The command is displayed only when an actual map item is right-clicked.

The handler receives `PluginMapContextMenuContext`, checks for `IAvaloniaPluginUserInterface`, and opens the plug-in-owned `RandomMapWindow` with the host's real owner. The window uses only `IMapEditorHost`; it does not receive an editor view model, control or mutable JSON object.

## Steps

1. Right-click a map item and choose the Random Map command.
2. Select the target map and layer. The plug-in reads `PluginMapSnapshot` and `PluginTilesetSnapshot` values.
3. Select a valid wall tile, choose the generation mode, and place or clear required markers.
4. Generate and review the preview. The generator works on plug-in-owned matrices and does not mutate the editor during preview.
5. Confirm the result. The plug-in sends `PluginMapLayerWriteRequest` with the original `BaseRevision`, `ExpectedTilesetKey`, and complete `Height × Width` Tile and AutoTile matrices.

## Verification

- Confirm that the command is absent from blank map-list space and present for a real map item.
- Generate twice with the same seed and inputs and compare the preview.
- Change the map or tileset after opening the plug-in; confirmation must report a revision or tileset conflict instead of overwriting the new state.
- After a successful write, use Undo and then save normally.
- Run the map and inspect passability, Actor access and visual continuity.

## Limitations

`IMapEditorHost` cannot create maps, change dimensions, edit Actors, inject editor UI or bypass revision checks. Random Map has no packaging responsibility and must not use a Pack hook for map generation.
