# Installation and Updates

## Goal

Install a complete Ludork 1.0 release for the supported desktop host.

## Prerequisites

- A writable editor directory on Windows, because the plug-in registry, source and data remain beside the executable.

## Supported system minimums

- Windows editor and games: Windows 10 or newer, x64.
- macOS editor and games: macOS 13.3 or newer, Apple Silicon.
- iOS games: iOS 15.0 or newer, arm64.
- HarmonyOS games: HarmonyOS 6.0.1 / API 21 or newer, arm64-v8a.
- Android games: Android 7.0 / API 24 or newer, arm64-v8a; Android 12 and 12L are supported.

## Steps

### Install from a release package

1. Open the **Releases** page of `JasonLeon01/Ludork`. Download the Windows x64 distribution package or `Ludork-<version>-macos-arm64.dmg` for Apple Silicon macOS.
2. On Windows, extract the whole distribution into a new directory. Do not run the editor from inside the archive. The distribution includes three registered official plug-ins in `Plugins` and a generated `plugins.json` beside that directory.
3. On macOS, open the DMG and drag `Ludork.app` onto the volume's `Applications` link. The app is not signed or notarised, so approve it in macOS privacy and security settings if Gatekeeper asks you to confirm its origin.
4. Keep Ludork closed, then double-click **Install Official Plugins** in the DMG. Finder hides the installer's `.command` extension. Read the replacement warning and select **Replace and Install** to install the three official plug-ins in `~/Ludork`.
5. Start Ludork. The Start page lists up to three recently opened projects and provides New Project and Open Project actions. Entries whose `.proj` files are no longer available are removed when the page loads.

The macOS installer uses a hidden DMG payload; do not drag plug-in files to Applications. After confirmation it transactionally replaces `~/Ludork/Plugins` and `~/Ludork/plugins.json` as a complete set. An ordinary failure rolls back to the previous installation; if rollback itself cannot finish, follow the recovery details shown by the installer. A successful installation does not merge or retain a backup: it deletes installed third-party plug-in source, registrations and all `Plugins/.data`. Make your own backup before confirming if anything must be retained.

![Ludork Start page with recent-project and project-creation actions](../../_images/getting-started/start-page.png)

*The Start page is the entry point for creating or reopening a project.*

### Update an installation

1. Close the editor and any running game.
2. Back up active projects and any plug-in data that must be retained. Windows plug-in data is below the current editor directory's `Plugins/.data`; macOS plug-in data is below `~/Ludork/Plugins/.data`.
3. Install the new Windows distribution into a separate directory, or replace the macOS app and run **Install Official Plugins** by following the installation steps above.
4. Start the new editor and open a copy of an important project first.
5. Check **Help → About** for version `1.0.0`, then run and package the project before retiring the previous installation.

Do not copy new binaries over an active installation. A release contains matching editor resources, project templates, native preview components, documentation and legal notices; mixing versions can invalidate those contracts.

## Limitations

Building the editor is a contributor workflow, not an installation requirement. In a source checkout, `tools/init.bat` or `tools/init.sh` prepares dependencies and editor-owned tools; `tools/run_editor.bat` or `tools/run_editor.sh` starts the editor. Use the release package for ordinary project authoring.

The per-user Windows MSI location below `%LocalAppData%\Ludork` is writable. A portable Windows distribution placed in a read-only directory or on read-only media can start, but does not support plug-in import, uninstall, registry updates or writable plug-in data.

## Verification

- The Start page opens without missing-resource errors.
- **Help → About** reports `1.0.0`.
- **Plugins → Manage Plugins** reports Official Blueprint AI, Official Locale Tools and Official Random Map as **Loaded** after startup.
- F1 opens the local documentation and displays this page's image.
