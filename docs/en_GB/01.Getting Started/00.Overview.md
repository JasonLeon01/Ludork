# Getting Started

This section takes you from a release package to a saved, running and package-ready project. It assumes no knowledge of the editor source code.

## Learning objectives

After completing this section, you will be able to:

- install or update the editor without mixing files from different releases;
- select the correct project template;
- create, save and run a first project;
- identify the files that define project and runtime configuration;
- choose an appropriate packaging target.

## Recommended order

1. [Installation and Updates](<01.Installation and Updates.md>)
2. [Create Your First Project](<02.Create Your First Project.md>)
3. [Project Templates](<03.Project Templates.md>)

For a first project, use **Standalone** without FFmpeg. It has the fewest external requirements and is ready to run after creation. Choose C++ Source only when native development, iOS output or HarmonyOS output is part of the project requirements.

## Completion check

You have completed this section when the editor can open your project, save without validation errors, start the game, and open the Pack Options window.
