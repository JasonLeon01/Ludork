## Editing notes

Enemy has no member events; gameplay abilities handle defeat behaviour.

`Reborn` is a non-empty Blueprint class-path string. Special values are JSON literals, not Lua expressions.

Each `drops` key is a required Blueprint class path whose generated Actor derives from `Source.Item`; its `sf.Vector2i` value is added to the defeated enemy's map position. The spawned Actor tag is derived from the Blueprint path and absolute target coordinates. An existing identical tag skips that drop and writes a warning instead of creating a suffixed duplicate.
