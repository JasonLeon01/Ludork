## Editing notes

Applying a State creates an Infinite Gameplay Effect and grants its event abilities. `onWalk` listens for `Event.Movement.Step`; trigger `onHookTriggered` explicitly with `Event.State.Trigger.<stateID>`, or `NodeFunctions.Gameplay.SendEvent` inside a gameplay graph. Adding or stacking does not emit that hook; a missing graph start returns `NoGraph`.
