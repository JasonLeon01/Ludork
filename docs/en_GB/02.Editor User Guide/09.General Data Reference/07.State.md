# State

Source: `Data/General/State.json`

| Property | Value |
|---|---|
| Linked runtime type | `StateInfo` |
| Member events | `onWalk`, `onHookTriggered` |

## Schema

| Field | Type | Default | Description | Reference |
|---|---|---|---|---|
| `name` | `string` | `""` | The display name of this state. | `—` |
| `desc` | `string` | `""` | The display description of this state. | `—` |
| `icon` | `file` | `"Icons"` | The icon asset path relative to Assets. | `—` |
| `stackable` | `bool` | `false` | Whether adding this state again increases the existing state's stack count. | `—` |

## Editing notes

Add fields before populating many members. A reference controls the selector but the stored value remains the declared JSON shape. When events are listed, each member may store a graph under `_graph`; an absent start node means the optional event has no implementation.

`onHookTriggered` is explicit: call `NodeFunctions.State.TriggerStateHook` with a Battler and an active State ID. Adding, stacking, walking with or battling under a State does not trigger this hook automatically.
