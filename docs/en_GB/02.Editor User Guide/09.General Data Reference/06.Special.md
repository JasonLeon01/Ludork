## Editing notes

Add fields before populating many members. A reference controls the selector but the stored value remains the declared JSON shape. When events are listed, each member may store a graph under `_graph`; an absent start node means the optional event has no implementation.

Special records define presentation only; parameters remain in `Enemy.special`. Presence-only specials use `""`, and descriptions may contain one `{value}` placeholder. The Enemy Book localises `FixDmg` expression tokens before inserting its value.
