# General Data Reference

Generated from the current Sample schemas beneath `Data/General`: schema fields, member identifiers, linked runtime types and member events. Values are project data, not a fixed engine enumeration.

Each type uses `params` for field definitions and `members` for records. A `reference` narrows an editor selector. A `linkedType` connects member graphs to runtime metadata. Brace-wrapped display strings follow [Game Localisation Workflow](<../../05.Plug-in Development and Installation/06.Game Localisation Workflow.md>).
