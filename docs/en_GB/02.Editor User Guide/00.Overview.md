# Editor User Guide

This section describes user-visible behaviour and file contracts, not the editor implementation.

## Authoring sequence

1. Learn the [Start Page, Workspace and Shortcuts](<01.Start Page Workspace and Shortcuts.md>).
2. Confirm [Project Settings and Asset Layout](<02.Project Settings and Asset Layout.md>).
3. Build the world with [Tilesets, Autotiles and Maps](<03.Tilesets Autotiles and Maps.md>).
4. Add behaviour through [Blueprints, Common Functions and Actors](<04.Blueprints Common Functions and Actors.md>).
5. Edit [General Data, game variables and Text Config](<05.General Data and Text Config.md>), [Animations and Curves](<06.Animations and Curves.md>) and [UI Assets](<07.UI Asset Editor.md>).
6. Use [Run, Debug and Package](<08.Run Debug and Package.md>) to verify a distributable build.

The [General Data Reference](<09.General Data Reference/00.Overview.md>) documents the Sample data families shown by the General Data editor.

## Safe editing principles

- Save before Run or Pack, and resolve validation errors at their source.
- Create, rename, copy and move data-aware assets through the editor so stable identifiers and tracked paths remain valid.
- Treat the reference tree as an inspection tool. It does not rewrite or protect references.
- Keep file resources below `Assets`, authored project data below `Data`, and runtime code below `Scripts`.
- Review the Console whenever an operation invokes plug-in hooks, native builds or the game process.

## Result

After this section, you should be able to build a complete project without editing editor source or hand-editing generated catalogues.
