# Animations and Curves

## Goal

Create animation and curve assets, preview their timing and reference their stable project keys from data or scripts.

## Animations

Open **Database → Animation Overview** (`F5`) to browse animation data. **Game → New Animation** creates a JSON asset beneath `Data/Animations`. The editor exposes the frames, timing, visual resources and event data of the animation format.

Keep source images under `Assets/Animations` or another intended asset folder. Non-empty image and sound entries store complete `/Game/Assets/...` paths. Preview timing before relying on an animation's total or visual duration.

![Animation editor showing frame timing and preview controls](../../_images/editor/animation.png)

*Preview animation frames, timing and events before using the asset in gameplay.*

### Exporting MP4 locally

Save the animation before exporting. From the repository root on Windows, run
`tools\animation_to_mp4.bat` to export all current `Game/Data/Animations` JSON
files to `Game/EditorCache/AnimationMp4`. Use `sh tools/animation_to_mp4.sh` on macOS.
The tool requires rebuilt ScriptTools with Pillow and a separate FFmpeg executable
with `libx264` and AAC; see [tool setup and options](../../../tools/README.md#animation-mp4-export).

```bat
tools\animation_to_mp4.bat Game --input Game/Data/Animations/attack.json --output Game/EditorCache/attack.mp4
```

Exports retain frame rate, track order, position/rotation/scale interpolation,
horizontal flips and sound timing/trimming. Each video plays once through the
last image or sound segment, rounded up to whole frames. After visual segments
end, only the background remains. The canvas automatically fits all sampled
frames around the animation origin; `--size 512x512` fixes an even-sized canvas
and crops overflowing content without rescaling. MP4 uses an opaque background:
black by default, or `--background "#202020"`. `--mute` removes audio without
shortening the timeline, and `--overwrite` replaces existing output after a
successful export. Directory inputs are recursive and retain their subdirectories.
Time tags are not encoded as video events. Inputs are saved source JSON and loose
assets, not compressed animation caches or `.ldpak` packages.

## Curves

**Game → New Curve** creates a curve beneath `Data/Curves`. A curve has a name, a default value, pre/post infinity behaviour and ordered keys. Each key contains time, value, interpolation and arrive/leave tangents.

Use the curve editor to add, move and remove keys. Keep key times ordered. Avoid duplicate times unless the intended interpolation explicitly supports the discontinuity.

![Curve editor showing ordered keys and interpolation](../../_images/editor/curve.png)

*Inspect curve keys and interpolation before referencing the curve in gameplay.*

## Referencing data

Metadata-driven selectors can reference animation and curve keys from Blueprints or General Data. Renaming the JSON file changes the logical key derived from its path, so inspect the reference tree first.

## Testing

Test zero-key and one-key curves, animation completion, frame events and transitions at the target frame rate. Check curves used for fades or movement at low and high frame rates as well.
