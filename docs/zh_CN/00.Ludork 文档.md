# Ludork 文档

Ludork 是用于制作地图驱动型 2D 游戏的开发环境，将可视化编辑器、Blueprint 图、Lua 脚本与可扩展的 C++20 运行时统一到同一工作流中。编辑器覆盖项目设置、地图、Actor、数据、动画、用户界面、测试与打包。

![已打开 Sample 地图的 Ludork 编辑器工作区](../_images/overview/editor-workspace.png)

*主工作区将地图画布、编辑模式、项目数据和运行工具组合在一起。*

## 支持的平台

| 产品或输出 | 最低支持系统 | 说明 |
|---|---|---|
| Windows 版 Ludork 编辑器 | Windows 10 或更高版本，x64 | 使用 Windows 发行包。 |
| macOS 版 Ludork 编辑器 | Apple Silicon macOS 13.3 或更高版本 | 使用 macOS arm64 发行包。 |
| 桌面游戏 | Windows 10 或更高版本，x64；或 Apple Silicon macOS 13.3 或更高版本 | 为当前主机平台打包。 |
| iOS 游戏 | iOS 15.0 或更高版本，arm64 | 打包需要 Apple Silicon macOS 上的 C++ Source 项目、完整 Xcode 与 Apple 开发签名。 |
| HarmonyOS 游戏 | HarmonyOS 6.0.1 / API 21 或更高版本，arm64-v8a | Mobile HAP 打包需要 Apple Silicon macOS 上的 C++ Source 项目与 DevEco Studio。 |
| Android 游戏 | Android 7.0 / API 24 或更高版本，arm64-v8a | APK 打包需要 Apple Silicon macOS 上的 C++ Source 项目、Android Studio、SDK Platform 36、Build Tools 36.0.0、NDK r27 或更高版本，以及本机 CMake 3.28 或更高版本。默认输出未签名 APK，也可使用已有 JKS 或 PKCS12 keystore 进行可选签名。 |

其他 CMake 平台尚未经正式发行验证。Standalone 项目使用编辑器所在主机的预构建运行时；需要修改原生代码或输出 iOS/HarmonyOS/Android 版本时，请选择 C++ Source。

## 文档约定

- 除非页面另有说明，路径均相对于项目根目录。
- 菜单命令和字段标签按当前中文编辑器界面书写。
- 底层平台区分大小写时，代码、文件名与 API 标识符也区分大小写。
- “注意”补充背景；“警告”表示可能阻止操作、损坏数据或暴露数据的条件。
- 任务页会在有必要时明确列出目标、前置条件、步骤、预期结果与验证方法。

选择 **帮助 → Ludork Documentation** 或按 F1 可在编辑器内打开文档。可在帮助菜单中切换文档语言，并按提示重启。文档中的本地链接在帮助窗口内跳转，HTTPS 链接会交给系统浏览器。

## 软件与内容许可

Ludork 软件许可、第三方声明与 Sample 资产条款彼此独立。重新分发编辑器包或使用 Sample 内容发布游戏前，必须分别阅读三者。安装插件也会以编辑器进程权限执行可信代码；导入前请检查来源与源码。
