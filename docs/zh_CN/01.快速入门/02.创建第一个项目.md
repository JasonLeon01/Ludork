# 创建第一个项目

## 目标

创建 Standalone 项目，打开初始地图并运行游戏。

## 步骤

### 创建项目

1. 在启动页选择 **New Project**。已打开项目时，可使用 **File → New Project** 或 Ctrl/Command+N。
2. 选择 **Standalone**。
3. 除非游戏必须播放视频，否则保持 **FFmpeg** 关闭。
4. 选择已存在的目标目录，并输入新项目名。
5. 检查最终路径，然后选择 **Create**。Ludork 会复制选定的模板并打开 `Main.proj`。

![已选择 Standalone 模板的新建项目窗口](../../_images/getting-started/new-project.png)

*Standalone 附带可直接运行的原生运行时，是首个项目的推荐模板。*

### 保存与运行

1. 在地图列表中选择一张地图。
2. 按 Ctrl/Command+S。如果出现校验消息，请先解决。
3. 选择工具栏的 Play 操作。根据 **Edit → Development Tools → Individual Window** 设置，游戏会在内嵌面板或独立窗口中运行。
4. 在 Console 中查看插件 Hook、构建与运行时输出。
5. 修改模板或打包设置前，先停止游戏。

## 重要项目文件

| 路径 | 用途 |
|---|---|
| `Main.proj` | C++ 源码、FFmpeg 和运行窗口等项目能力。 |
| `Main.ini` | 入口脚本、语言、音频与显示值等运行时设置。 |
| `Scripts/Entry.lua` | Lua 入口。 |
| `Data/` | 地图、Blueprint、General Data、动画、曲线、Text Config 与 UI 资产。 |
| `Assets/` | 纹理、音频、字体、Shader 和其他文件资源。 |

## 验证

- 保存后，项目的已修改标记消失。
- Console 进入运行时启动阶段，且没有插件 Hook 失败或构建错误。
- **File → Pack Project** 为当前主机打开打包选项。
