# Lua 基础语法

Ludork 使用 Lua 5.5。本页面向第一次接触 Lua 的读者，只介绍语言本身；Ludork 的原生扩展见 [Ludork Lua进阶](<04.Ludork Lua进阶.md>)。

## 文件、注释与局部变量

Lua 文件使用 `.lua` 扩展名。`--` 是单行注释，`--[[ ... ]]` 是块注释。工作变量应使用 `local` 声明；未初始化的变量值为 `nil`。

```lua
-- 单行注释
local playerName = "Hero"
local level = 1
local alive = true
local target = nil
```

Lua 值包括 `nil`、boolean、number、string、function、table、userdata 和 thread。`type(value)` 返回这些内建类别之一；由 table 或 userdata 表示的应用对象仍保留其底层类别。

## 运算符

常用运算符如下：

| 类别 | 运算符 |
|---|---|
| 算术 | `+`、`-`、`*`、`/`、`//`、`%`、`^` |
| 比较 | `==`、`~=`、`<`、`<=`、`>`、`>=` |
| 逻辑 | `and`、`or`、`not` |
| 字符串 | `..` 拼接 |
| 长度 | `#value` |

Lua 只把 `nil` 和 `false` 视为假；`0`、空字符串与空 table 在条件中都为真。

## 条件分支

```lua
if health <= 0 then
    state = "defeated"
elseif health < maxHealth then
    state = "hurt"
else
    state = "healthy"
end
```

只有在“缺失”必须与 `false`、`0` 或空值区分时，才使用显式 nil 比较。

## Table

table 可作为数组、字典或 record；数组索引从 1 开始。

```lua
local items = { "Key", "Potion" }
local player = {
    name = "Hero",
    hp = 100,
}

items[#items + 1] = "Gem"
player.hp = player.hp - 10
```

给普通 table key 赋 `nil` 会删除该项。数组中应避免 nil 空洞，因为 `#`、`ipairs` 与数组 helper 会在首个缺失槽停止。

## 循环

```lua
for index, item in ipairs(items) do
    useItem(index, item)
end

for key, value in pairs(player) do
    inspectValue(key, value)
end

local count = 3
while count > 0 do
    count = count - 1
end
```

稠密数组使用 `ipairs`，字典使用 `pairs`。数值 `for` 会包含首尾值，除非步长跳过末值。

## 函数与方法

函数也是值，并可返回多个结果。实例方法使用冒号语法，它会把接收者作为 `self` 传入。

```lua
local function clampHealth(value, maximum)
    return math.max(0, math.min(value, maximum))
end

local Character = {}

function Character:setHealth(value)
    self.health = clampHealth(value, self.maxHealth)
end

local value, found = findItem("Key")
```

`object:method(value)` 等价于 `object.method(object, value)`。实例方法的声明与调用应统一使用冒号形式。

## 模块

模块是返回公开值的 Lua 文件。`require` 路径相对于 `Scripts`，使用点分隔且不带扩展名。

```lua
-- Scripts/Source/Score.lua
local Score = {}

function Score.Add(current, amount)
    return current + amount
end

return Score
```

```lua
local Score = require("Source.Score")

local total = Score.Add(10, 5)
```

先完成同一作用域的直接 `require`，再声明成员别名。不要创建目录级 `init.lua` 聚合模块。

## 错误

必需条件使用 `assert(condition, message)`，显式失败使用 `error(message)`。必需项目数据应在错误源头失败，不应静默生成不完整状态。
