# Lua 基础语法

Ludork 内置 Lua 5.5。本页写给初次接触 Lua 的读者，只介绍语言本身；Ludork 提供的原生扩展见 [Ludork Lua进阶](<04.Ludork Lua进阶.md>)。

## 文件、注释与局部变量

Lua 脚本使用 `.lua` 扩展名。`--` 表示单行注释，`--[[ ... ]]` 括起来的是块注释。用到的变量都要通过 `local` 声明；未初始化的变量值为 `nil`。

```lua
-- 单行注释
local playerName = "Hero"
local level = 1
local alive = true
local target = nil
```

Lua 的值包括 `nil`、boolean、number、string、function、table、userdata 与 thread。`type(value)` 返回这些内建类别之一；由 table 或 userdata 表示的应用对象，也一样属于其底层的类别。

## 运算符

常用运算符如下：

| 类别 | 运算符 |
|---|---|
| 算术 | `+`、`-`、`*`、`/`、`//`、`%`、`^` |
| 比较 | `==`、`~=`、`<`、`<=`、`>`、`>=` |
| 逻辑 | `and`、`or`、`not` |
| 字符串 | `..` 拼接 |
| 长度 | `#value` |

Lua 中只有 `nil` 与 `false` 为假；`0`、空字符串和空 table 在条件判断中都算真。

## 条件分支

```lua
if health <= 0 then
    state = "defeated"
elseif health < maxHealth then
    state = "hurt"
else
    state = "healthy"
end
```

只有当“缺失”这一状态需要与 `false`、`0` 或空值区分开时，才显式比较 nil。

## 表（table）

table 既可以充当数组，也可以充当字典或记录（record）；数组的索引从 1 开始。

```lua
local items = { "Key", "Potion" }
local player = {
    name = "Hero",
    hp = 100,
}

items[#items + 1] = "Gem"
player.hp = player.hp - 10
```

给普通 table 的某个 key 赋 `nil`，就等于删除该键。数组里应避免出现 nil 空洞，因为 `#`、`ipairs` 和数组辅助函数都会在第一个空洞处停下。

## 循环

```lua
for index, item in ipairs(items) do
    useItem(index, item)
end

for key, value in pairs(player) do
    inspectValue(key, value)
end

local count = 3
while count > 0 do
    count = count - 1
end
```

稠密数组用 `ipairs` 遍历，字典用 `pairs` 遍历。数值型 `for` 循环默认包含起点与终点两个值，除非步长恰好越过了终点。

## 函数与方法

函数本身也是一种值，可以一次返回多个结果。实例方法使用冒号语法：调用时，调用对象会自动作为 `self` 传入方法。

```lua
local function clampHealth(value, maximum)
    return math.max(0, math.min(value, maximum))
end

local Character = {}

function Character:setHealth(value)
    self.health = clampHealth(value, self.maxHealth)
end

local value, found = findItem("Key")
```

`object:method(value)` 与 `object.method(object, value)` 等价。定义和调用实例方法时，都应统一使用冒号形式。

## 模块

模块就是把要公开的内容作为返回值导出的 Lua 文件。`require` 的路径以 `Scripts` 为根，用点号分隔目录层级，且不带扩展名。

```lua
-- Scripts/Source/Score.lua
local Score = {}

function Score.Add(current, amount)
    return current + amount
end

return Score
```

```lua
local Score = require("Source.Score")

local total = Score.Add(10, 5)
```

同一作用域内，应先把直接 `require` 写完，再声明成员别名；也不要创建目录级的 `init.lua` 聚合模块。

## 错误

对必须成立的条件用 `assert(condition, message)` 检查；需要主动报错时用 `error(message)`。项目必需的数据应在出错源头直接失败，而不是悄悄留下不完整的状态。
