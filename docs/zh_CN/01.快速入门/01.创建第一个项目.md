# 创建第一个项目

## 目标

创建一个 Standalone 项目，打开初始地图并运行它。

## 步骤

### 创建项目

1. 在启动页点击 **新建项目**；若当前已打开项目，也可通过 **文件 → 新建项目** 或 Ctrl/Command+N 新建。

![Ludork 启动页：最近项目与创建新项目的入口](../../_images/getting-started/start-page.png)

*启动页用于创建新项目，或重新打开已有项目。*

2. 选择 **Standalone** 模板。
3. 除非游戏需要播放视频，否则不要勾选 **启用视频播放（FFmpeg）**。
4. 选择已存在的目录作为目标位置，并输入新的项目名称。
5. 确认 **完整路径** 无误后，点击 **创建**。Ludork 会复制所选模板并打开 `Main.proj`。

![新建项目窗口：已选中 Standalone 模板](../../_images/getting-started/new-project.png)

*Standalone 自带可直接运行的原生运行时，是首个项目的推荐模板。*

### 保存与运行

1. 在 **地图列表** 中选择一张地图。
2. 按 Ctrl/Command+S 保存。若出现校验消息，请先处理完再继续。
3. 点击工具栏上的 **测试游戏**（Play）按钮运行游戏。若在 **编辑 → 开发工具与设置** 中开启了 **独立窗口**，游戏会运行在独立窗口中，否则运行在编辑器内嵌的面板里。
4. 在 **控制台** 中查看插件 Hook、构建过程与运行时输出。
5. 先停止游戏，再修改模板或打包设置。

## 重要项目文件

| 路径 | 用途 |
|---|---|
| `Main.proj` | 定义项目能力，如是否包含 C++ 源码与 FFmpeg，以及运行窗口偏好。 |
| `Main.ini` | 运行时设置，包括入口脚本、语言以及音频与显示相关值。 |
| `Scripts/Entry.lua` | Lua 入口脚本。 |
| `Data/` | 地图、Blueprint、General Data、动画、曲线、Text Config 与 UI 资产。 |
| `Assets/` | 纹理、音频、字体、Shader 等文件资源。 |
