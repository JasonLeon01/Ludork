# 创建第一个项目

## 目标

创建一个 Standalone 项目，打开它的初始地图并运行。

## 步骤

### 创建项目

1. 在启动页选择 **新建项目**。

![Ludork 启动页：最近项目与创建新项目的入口](../../_images/getting-started/start-page.png)

*启动页是创建新项目或重新打开已有项目的入口。*

2. 选择 **Standalone**。
3. 除非游戏需要播放视频，否则保持 **启用视频播放（FFmpeg）** 关闭。
4. 选择一个已存在的目标目录，并输入新的项目名称。
5. 确认最终路径后选择 **创建**。Ludork 会复制所选模板并打开 `Main.proj`。

![新建项目窗口：已选中 Standalone 模板](../../_images/getting-started/new-project.png)

*Standalone 自带可直接运行的原生运行时，因此是第一个项目的推荐模板。*

### 保存与运行

1. 在 **地图列表** 中选择一张地图。
2. 按 Ctrl/Command+S。若出现校验提示，先全部处理完再继续。
3. 点击工具栏上的 **测试游戏**。游戏运行在内嵌面板还是独立窗口，由 **编辑 → 开发工具与设置 → 独立窗口** 决定。该设置只在 Windows 上可用，其他平台上游戏始终在独立窗口中打开。
4. 在 **控制台** 中查看 Hook、构建与运行时输出。
5. 修改模板或打包设置之前，先停止游戏。

## 重要项目文件

下表列出可正常工作的项目中存在的文件。

| 路径 | 用途 |
|---|---|
| `Main.proj` | 项目能力，例如 C++ 源码、FFmpeg 与运行窗口偏好。 |
| `Main.ini` | 运行时设置，包括入口脚本、语言、音频与显示相关数值。 |
| `Scripts/Entry.lua` | Lua 入口脚本。 |
| `Data/` | 地图、蓝图、通用数据、动画、曲线、文本配置与 UI 资产。 |
| `Assets/` | 纹理、音频、字体、Shader 与其他文件资源。 |

新建项目中没有 `Main.ini`，运行时会在首次运行时创建它。
