# 快速入门

本节从正式发行包开始，引导你创建一个可保存、可运行且已准备好打包的项目。这些步骤不要求了解编辑器源码。

## 学习目标

完成本节后，你将能够：

- 安装或更新编辑器，且不混用不同发行版的文件；
- 根据需求选择项目模板；
- 创建、保存并运行第一个项目；
- 识别项目与运行时配置文件；
- 选择合适的打包目标。

## 建议顺序

1. [安装与更新](<01.安装与更新.md>)
2. [创建第一个项目](<02.创建第一个项目.md>)
3. [项目模板](<03.项目模板.md>)

初次创建项目时，建议选择不含 FFmpeg 的 **Standalone**。它的外部要求最少，创建后即可运行。只有项目明确需要原生开发、iOS 输出、HarmonyOS 输出或 Android 输出时，才选择 C++ Source。

## 完成检查

当编辑器可以打开项目、无校验错误地保存、启动游戏并打开打包选项窗口时，即可认为已完成本节。
