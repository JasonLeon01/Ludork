# 安装与更新

## 目标

为受支持的桌面主机安装完整的 Ludork 1.0 发行版。

## 前置条件

- Windows 10 或更高版本（x64），或 macOS 13.3 或更高版本（Apple Silicon）。
- 具备在目标目录解压并运行应用的权限，或在 macOS 上将应用安装到 `/Applications` 的权限。
- Windows 上的编辑器目录必须可写，因为插件注册表、源码和数据均保存在可执行文件旁。
- 更新已有工作环境前，已经完成可验证的备份。

## 最低支持系统

- Windows 编辑器与游戏：Windows 10 或更高版本，x64。
- macOS 编辑器与游戏：macOS 13.3 或更高版本，Apple Silicon。
- iOS 游戏：iOS 15.0 或更高版本，arm64。
- HarmonyOS 游戏：HarmonyOS 6.0.1 / API 21 或更高版本，arm64-v8a。

## 步骤

### 从发行包安装

1. 打开 `JasonLeon01/Ludork` 的 **Releases** 页，下载 Windows x64 发行包，或适用于 Apple Silicon macOS 的 `Ludork-<版本>-macos-arm64.dmg`。
2. 在 Windows 上，将整个发行包解压到新目录，不要在压缩包内直接运行编辑器。发行包的 `Plugins` 中包含三个已注册官方插件，并在该目录同级包含自动生成的 `plugins.json`。
3. 在 macOS 上打开 DMG，将 `Ludork.app` 拖到卷内的 `Applications` 链接。应用未经签名和公证；如 Gatekeeper 要求确认来源，请在系统隐私与安全设置中批准该应用。
4. 保持 Ludork 关闭，然后双击 DMG 中的 **Install Official Plugins**；Finder 会隐藏安装器的 `.command` 扩展名。阅读整体替换警告，再选择 **Replace and Install**，将三个官方插件安装到 `~/Ludork`。
5. 启动 Ludork。启动页会列出最近项目，并提供新建和打开项目操作。

macOS 安装器使用 DMG 中的隐藏插件载荷，不要把插件文件拖到 Applications。确认后，安装器会以事务方式把 `~/Ludork/Plugins` 与 `~/Ludork/plugins.json` 作为一组整体替换；普通失败会回滚到原安装，如果连回滚也无法完成，则应按安装器显示的恢复信息处理。成功后不会合并，也不会留下备份，并会删除已有第三方插件源码、登记以及 `Plugins/.data` 中的全部数据。如需保留任何内容，必须在确认前自行备份。

![包含最近项目与项目创建操作的 Ludork 启动页](../../_images/getting-started/start-page.png)

*启动页是创建或重新打开项目的入口。*

### 更新安装

1. 关闭编辑器和正在运行的游戏。
2. 备份活动项目与需要保留的插件数据。Windows 插件数据位于当前编辑器目录的 `Plugins/.data`，macOS 插件数据位于 `~/Ludork/Plugins/.data`。
3. 将新的 Windows 发行包安装到独立目录；macOS 则按上面的步骤替换应用并运行 **Install Official Plugins**。
4. 启动新编辑器，先打开重要项目的副本。
5. 在 **Help → About** 中确认版本为 `1.0.0`，并在停用旧安装前运行、打包该项目。

不要用新二进制文件直接覆盖仍在使用的安装。发行包中的编辑器资源、项目模板、原生预览组件、文档与法律声明必须版本匹配。

## 预期结果

Ludork 打开启动页，报告版本 `1.0.0`，并能从同一发行包加载模板、文档、法律声明与三个已注册官方插件。

## 限制

构建编辑器是贡献者工作流，并非安装要求。在源码工作区中，`tools/init.bat` 或 `tools/init.sh` 准备依赖和编辑器自有工具；`tools/run_editor.bat` 或 `tools/run_editor.sh` 启动编辑器。普通项目制作应使用发行包。

Windows 的 per-user MSI 会安装到可写的 `%LocalAppData%\Ludork`。放在只读目录或只读介质中的 Windows 便携发行包可以启动，但不支持插件引入、卸载、注册表更新或插件可写数据。

## 验证

- 启动页可以打开，且没有缺失资源错误。
- **Help → About** 显示 `1.0.0`。
- 启动后，**Plugins → Manage Plugins** 中的 Official Blueprint AI、Official Locale Tools 与 Official Random Map 均显示为 **Loaded**。
- F1 能打开本地文档并显示本页图片。
