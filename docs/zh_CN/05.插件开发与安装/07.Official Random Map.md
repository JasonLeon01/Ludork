# Official Random Map

## 目标

以官方 Random Map 插件为参考，理解地图项命令如何读取不可变编辑器快照、打开自带 Avalonia 工作流，并在 revision 保护下替换单个图层。

## 前置条件

- 安装编辑器发行版；macOS 还需运行 DMG 中的 **Install Official Plugins**。重启 Ludork，并确认 Official Random Map 为 **Loaded**。`Plugins/OfficialRandomMap` 是它在仓库 checkout 中的源码目录。
- 打开至少包含一张地图、一个图层和有效 tileset 的项目。
- 保存目标地图，或明确保留其未保存改动；插件成功写入时会直接保存该地图。

## 注册契约

`OfficialRandomMapPlugin` 只注册一个 `PluginMapContextMenuCommand`。它不注册普通菜单命令、文本提示 provider、before-Run hook 或 before-Pack hook。只有右键实际地图项时才显示该命令。

Handler 接收 `PluginMapContextMenuContext`，检查 `IAvaloniaPluginUserInterface`，再以宿主真实 owner 打开插件拥有的 `RandomMapWindow`。窗口只使用 `IMapEditorHost`，不会获得编辑器 ViewModel、控件或可变 JSON 对象。

## 步骤

1. 右键地图项，选择 Random Map 命令。
2. 选择目标地图与图层。插件读取 `PluginMapSnapshot` 和 `PluginTilesetSnapshot`。
3. 选择有效墙面 tile、生成模式，并添加或清除所需 marker。
4. 生成并检查 preview。生成器只操作插件拥有的矩阵，preview 期间不会修改编辑器。
5. 确认结果。插件发送 `PluginMapLayerWriteRequest`，其中包含原始 `BaseRevision`、`ExpectedTilesetKey`，以及完整 `Height × Width` Tile/AutoTile 矩阵。

## 预期结果

`ReplaceLayerAndSaveAsync` 只替换所选图层，记录一次 Undo 快照，推进地图 revision，刷新目标地图/图层，并以原子方式只保存 `Data/Maps/<mapKey>.json`。

同一地图中此前已有的未保存改动会包含在这次直接保存中。其他地图与项目数据不会被保存，也不会被标记为 clean。Undo 恢复写入前的内存状态，并把地图标记为待保存；它不会自动保存。

## 验证

- 确认右键地图列表空白处没有命令，右键实际地图项时存在命令。
- 使用相同 seed 与输入生成两次，并比较 preview。
- 打开插件后修改地图或 tileset；确认操作必须报告 revision 或 tileset conflict，不能覆盖新状态。
- 成功写入后使用 Undo，再按普通流程保存。
- 运行地图并检查通行、Actor 可达性与视觉连续性。

## 限制

公开 bridge 只能列出地图、读取地图/tileset 快照并替换一个已有图层。它不能创建地图、改变尺寸、编辑 Actor、注入编辑器 UI 或绕过 revision 检查。Random Map 不承担打包职责，也不得通过 Pack hook 生成地图。
