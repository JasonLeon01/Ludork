# 插件开发与安装

Ludork 编辑器插件是由宿主在进程内编译并加载的 C# 13 源码目录。插件可以通过边界明确的公开契约增加命令、文本提示与操作前 hook。插件是完全信任代码，不是 sandbox 内容。

## 信任与所有权

只引入已经检查并信任的源码。插件加载后拥有编辑器进程的文件、网络与操作系统权限。API 会限制插件访问编辑器拥有的对象，但不会限制普通 .NET 能力。

插件拥有自己的源码、窗口、标签、设置、保留数据与第三方声明。宿主负责注册、生命周期、命令 context、受限地图/Blueprint bridge 与操作顺序。

## 支持的公开接口

五个 registrar 方法分别覆盖普通菜单命令、地图项右键命令、文本提示 provider、before-Run hook 与 before-Pack hook。当前没有用于停靠 panel、toolbar、任意宿主控件、数据类型或通用编辑器事件的公开注册点。

本章是公开文档的最后一个顶级板块。Runtime 扩展应通过 [C++ 原生开发](<../04.C++ 原生开发/00.概述.md>)完成，而不是编辑器插件。
