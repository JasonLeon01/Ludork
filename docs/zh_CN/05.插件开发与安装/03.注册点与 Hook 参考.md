# 注册点与 Hook 参考

注册只能在 `IEditorPlugin.Register` 中进行。API 提供五个注册方法。

## 菜单命令

`RegisterMenuCommand(PluginMenuCommand)` 把命令插入 `File`、`Edit`、`Game`、`Database`、`Help` 或 `Plugins`。ID 必须非空且全局唯一，`Order` 在同一位置内排序。

handler 会收到：可选的项目路径、编辑器语言、只读的插件程序目录、可写的插件数据目录、消息 UI、文本提示失效接口、按插件隔离的密钥存储、可选的 Blueprint assistant 宿主桥，以及取消信号（cancellation）。引用 `Ludork.Plugin.Avalonia` 的 Avalonia 源码插件可以把消息 UI 转换为 `IAvaloniaPluginUserInterface`，从而取得插件自带窗口的真正所有者窗口（owner）。成功时返回 `PluginResult.Completed()`；已处理的失败返回 `PluginResult.Failed(error)`。

| `PluginMenuCommand` 字段 | 含义 |
|---|---|
| `Id` | 非空全局命令 ID |
| `Location` | 六个菜单位置之一 |
| `Order` | 数值排序 key |
| `Label` | 显示文本 |
| `Handler` | 异步 `PluginMenuHandler` |

## 地图项右键命令

`RegisterMapContextMenuCommand(PluginMapContextMenuCommand)` 在实际地图项的右键菜单中，把插件命令放在内置命令之后。用户右键地图列表空白处时不会显示这些命令。命令 ID 必须非空，并且在普通菜单命令和地图右键命令之间保持全局唯一。`Order` 用于排列插件命令，`Label` 是已经完成本地化的显示文本。

| `PluginMapContextMenuCommand` 字段 | 含义 |
|---|---|
| `Id` | 非空全局命令 ID |
| `Order` | 数值排序 key |
| `Label` | 显示文本 |
| `Handler` | 异步 `PluginMapContextMenuHandler` |

handler 会收到 `PluginMapContextMenuContext`：`MapKey` 是被右键点击的地图；其余字段提供项目路径、编辑器语言、插件目录、消息 UI、文本提示失效接口、密钥存储、取消信号与 `MapEditorHost`。handler 与普通菜单命令一样返回 `PluginResult`。

`IMapEditorHost` 是一个受限的契约边界。插件不会获得 `GameDataService`、编辑器 ViewModel、`MapPanel`、宿主控件或可变 JSON。

| `IMapEditorHost` 成员 | 含义 |
|---|---|
| `ProjectPath` | 已打开项目根目录 |
| `SuggestedMapKey` | 打开插件的地图 key（如果有） |
| `ListMaps()` | 按顺序返回含 key 与显示名的地图摘要 |
| `ReadMap(mapKey)` | 读取当前内存地图的不可变快照 |
| `ReadTileset(tilesetKey)` | 读取不可变 tileset 快照 |
| `ResolveAssetFile(assetPath)` | 在编辑器最终文件 I/O 前解析逻辑路径；不可用时返回空字符串 |
| `ReplaceLayerAndSaveAsync(request, cancellationToken)` | 带 revision 检查的图层替换与单地图直接保存 |

`PluginMapSnapshot` 包含身份、尺寸、不透明的 `Revision`，以及带矩形 `Tiles`/`AutoTiles` 的有序图层。tileset 与 actor 的 `AssetPath` 保持大小写精确的 `/Game/Assets/...`；仅在最终原生文件 I/O 前调用 `ResolveAssetFile`，snapshot 与中间缓存不得保存物理路径。tileset snapshot 还包含 tile 尺寸、数量与可通行性；revision 只能原样用于写入请求。

`PluginMapLayerWriteRequest` 指定地图和图层，回传 `BaseRevision` 与 `ExpectedTilesetKey`，并提供严格符合快照 `Height × Width` 尺寸的两份矩阵。`PluginMapWriteResult` 区分成功、revision 或 tileset 冲突、带错误信息的失败，并返回当前 revision。校验或写盘失败不会改变编辑器内存、Undo 状态或界面。

成功时，宿主只替换当前内存地图中的目标图层，以原子方式仅保存 `Data/Maps/<mapKey>.json`，记录一次 Undo 快照，推进已保存的 revision，并刷新目标地图与图层。同一地图此前已有的未保存修改会包含在这次直接保存中；其他地图和项目数据不会被保存，它们的脏（Dirty）状态也不会被清除。Undo 会恢复写入前的内存状态并把地图标记为待保存，但不会自动再次写盘。

## 文本提示

`RegisterTextHintProvider(ITextHintProvider)` 注册同步文本解析。`TextHintContext` 包含项目路径、编辑器语言和当前文本。provider 按插件顺序执行，第一个非空结果生效；异常会记录为插件诊断。

## Before Run 与 Before Pack

`RegisterBeforeRunHook` 和 `RegisterBeforePackHook` 接受 `IProjectOperationHook`。hook 在目标操作前顺序执行。context 提供项目路径、语言、操作类型、输出、文本提示失效与 cancellation。

失败结果或异常会停止后续 hook 并阻止 Run/Pack。插件应遵从取消请求，并通过 `IPluginOutput` 输出进度。

| 操作 context 字段 | 含义 |
|---|---|
| `ProjectPath` | 已打开项目根目录 |
| `EditorLanguage` | 当前编辑器语言 key |
| `Operation` | `Run` 或 `Pack` |
| `Packaging` | 仅 before-Pack hook 中非空；before-Run 中为 null |
| `Output` | 只追加的操作输出 |
| `TextHints` | 请求刷新文本提示 |
| `CancellationToken` | 当前操作的取消信号 |

`Packaging` 可用时，只暴露以下打包决策：

| `IProjectPackaging` 成员 | 含义 |
|---|---|
| `UseLuac` | Pack 是否编译受支持的 Lua 源码 |
| `UseLdPak` | Pack 是否归档 `Assets`、`Data` 的每个一级分组，以及裁剪后的完整 `Scripts` 树 |
| `CompileLuaDirectory(relativePath)` | 把项目相对 Lua 目录加入 Pack 编译集合 |
| `ExcludeFile(relativePath)` | 从发行包排除项目相对文件 |

Official Locale Tools 在 Pack 时调用 `ExcludeFile("Data/Locale/Locale.xlsx")`，防止创作用的本地化工作簿被分发。Run 时 `Packaging` 为 null，因此不会调用该方法。

## 蓝图 Assistant

Blueprint assistant 通过普通 `PluginMenuCommand` 注册入口，并由插件自己携带 UI、设置和会话历史。宿主不提供 assistant 窗口或控件，`IAvaloniaPluginUserInterface` 只为插件自带窗口提供可选 owner。项目窗口中可选的 `PluginMenuContext.BlueprintAssistantHost` 提供项目路径、当前建议蓝图、可用蓝图 key 以及 `CreateSession`。

`IBlueprintAssistantSession` 固定绑定一个已有蓝图，暴露其基础 revision 和 `IBlueprintAssistantWorkspace`。workspace 只能列出和读取蓝图、查询 API catalog、搜索或读取 allowlist 内的项目源码、验证候选并生成提案，不能 Apply，也不能访问任意编辑器服务。插件 UI 保留 session，在用户确认后显式调用 session 的 Apply 或 Discard。Apply 会重新检查基础 revision 与候选有效性，记录一个编辑器 Undo 快照、标记项目数据为 Dirty、刷新已打开的蓝图编辑器，并且不会直接保存到磁盘。

API key 必须使用 `PluginMenuContext.SecretStore`。密钥按插件 ID 隔离并写入操作系统凭据存储，不会降级成明文文件。

## 不支持的扩展点

不存在用于宿主停靠面板（panel）、工具栏（toolbar）、任意右键菜单（context menu）、数据类型或编辑器事件的公开 hook。上文的地图项命令是唯一的右键菜单扩展点。插件可以随命令携带并打开自己的 Avalonia 窗口，但不能把任意控件注入编辑器拥有的视图（view）。
