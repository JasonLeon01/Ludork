# 官方 Blueprint AI

## 目标

使用随 Ludork 发行的官方源码插件，安全配置 provider，并通过编辑器审查边界应用一个经过校验的单 Blueprint 提案。

插件 ID 为 `Ludork.OfficialBlueprintAI`，仓库源码固定位于 `Plugins/OfficialBlueprintAI`。重启后，编辑器会从已安装源码重新编译加载，并通过 **游戏 → Blueprint AI** 打开。

## 工作流

1. 按你的环境安装插件，参见下面的“目录与职责”。
2. 打开项目，选择 **游戏 → Blueprint AI**。
3. 在 **Settings** 中配置 provider、模型、endpoint 与密钥。
4. 为一个现有 Blueprint 新建会话，检查 staged 提案与生成差异。
5. 仅在校验成功后选择 **Apply**；准备写入磁盘时再执行普通项目 Save。

## 目录与职责

| 环境 | 程序或源码位置 | 可写数据位置 |
|---|---|---|
| 仓库 checkout | `./Plugins/OfficialBlueprintAI` 源码；导入目录按所选名称直接复制到 `./Plugins` 下 | `./Plugins/.data/Ludork.OfficialBlueprintAI` |
| Windows 发布版 | `<编辑器目录>/Plugins/OfficialBlueprintAI` | `<编辑器目录>/Plugins/.data/Ludork.OfficialBlueprintAI` |
| macOS 发布版 | 由 DMG 隐藏载荷安装到 `~/Ludork/Plugins/OfficialBlueprintAI` | `~/Ludork/Plugins/.data/Ludork.OfficialBlueprintAI` |

macOS DMG 安装器会以事务方式把现有 `~/Ludork/Plugins` 与 `~/Ludork/plugins.json` 作为一组整体替换。普通失败会回滚到原安装；成功后会删除现有第三方插件源码、登记以及 `Plugins/.data` 下的全部数据，而且不会合并或留下备份。确认前请自行保留需要的文件。

菜单命令、Avalonia 窗口、设置界面、本地化、provider client 与会话历史都由插件自己携带，编辑器主程序不包含 Blueprint AI 窗口。宿主只为插件窗口提供可选的 `IAvaloniaPluginUserInterface` owner；打开项目时还提供受限的 `IBlueprintAssistantHost` 桥。该桥为一个已有 Blueprint 创建固定 session，并只暴露本流程需要的读取、提案、验证、Apply 与 Discard 能力。

移除插件程序目录不会删除 `Plugins/.data/Ludork.OfficialBlueprintAI`。删除设置或历史必须是另一个明确操作。

## 范围与权限

每个会话固定绑定一个项目和一个已有 Blueprint。助手可以读取其他 Blueprint、Lua metadata 以及白名单内的 Lua/C/C++ 源码，以理解可用 API；不能创建、改名或删除 Blueprint，不能一次修改多个 Blueprint，不能写源码、运行 shell 或启动进程。

模型只能生成待审 Blueprint 提案。编辑器会验证候选内容并生成差异；用户点击 **Apply** 前不会修改任何 Blueprint。Apply 前会重新读取编辑器工作副本，并与提案的基础 revision 比较。成功 Apply 只产生一个普通 Undo 步骤，项目保持 Dirty，并立即刷新所有已打开的目标 Blueprint 编辑器。只有普通项目 Save 才会把修改写入磁盘。

插件仍是可信的同进程代码，不是操作系统 sandbox。上述限制由官方助手面向模型的能力接口和宿主 session/Apply 边界共同强制保证。

## Provider 设置与凭据

在 Blueprint AI 窗口中打开 **Settings**，选择 provider、模型与 endpoint。OpenAI 使用 Responses API；DeepSeek、Google OpenAI-compatible 与 Custom profile 使用 OpenAI-compatible Chat endpoint。模型和 endpoint 可以手动编辑，不需要为每个新模型版本更新插件。

endpoint 必须是绝对 HTTPS URL；只有本地开发使用的 loopback 地址允许 HTTP。endpoint URL 不允许内嵌凭据、query 或 fragment。

API key 不会写入 `settings.json`。Windows 使用 Credential Manager，macOS 使用 Keychain；其他平台只读取插件专用环境变量，不持久化密钥。设置界面用“前三位 + 固定星号 + 后三位”显示已保存 key；短 key 完全隐藏。只有明确输入新值或勾选删除时才会改变凭据。provider 可用性不由 Ludork 控制。

## 本地历史与 provider 状态

插件数据目录中的本地索引和 append-only JSONL 是会话历史的权威数据，保存消息、模型快照、精简工具活动及提案决定，不保存 API key 或完整源码读取结果。

OpenAI Responses 请求使用 `store:false`，插件不依赖 provider 端保存会话。长会话的下一次请求只携带滚动摘要和最近消息；这种请求上下文压缩不会删除或替换完整本地历史。

未完成的请求会被标记为 interrupted。已完成的本地记录在重启后仍然存在，但进行中的网络请求不会自动续传。

## 安全读取代码

工程搜索和文件读取只接受工程内运行时/API 源码目录下的相对路径与受支持文本扩展名。build 输出、日志、版本控制数据、INI、插件数据、凭据以及工程外路径都会被拒绝。文件内容始终被视为数据，不能作为扩大助手权限的指令。

## 故障排查

- **游戏菜单中没有 Blueprint AI：** 确认 Windows 预置插件存在，或 macOS DMG 安装器已经完成，重启编辑器，再在 **Plugins → Manage Plugins** 检查等待重启、manifest、依赖或初始化诊断。未安装插件时不显示该菜单项是正常行为。
- **没有项目或可选 Blueprint：** 先打开项目；项目窗口以外不会提供宿主桥。项目内还必须至少存在一个 Blueprint。打开插件不会自动选择目标；点击“新会话”后才显示选择器。
- **目标被改名或删除：** 旧会话仍可查看，但目标不能静默切换。请为现有 Blueprint 新建会话。
- **缺少 API key 或服务端返回 401：** 在 Settings 中替换 key，确认它属于当前 provider/profile，并检查 endpoint 以及 OpenAI organization/project。界面只显示脱敏值，不会显示完整 key。
- **网络或 endpoint 错误：** 使用不含内嵌凭据、query 或 fragment 的绝对 HTTPS 基础地址，并检查 DNS、代理、防火墙与 TLS。普通 HTTP 只允许 loopback 开发地址。
- **Apply 报告 revision conflict：** 生成提案后 Blueprint 已变化，编辑器会拒绝覆盖。放弃旧提案，核对当前 Blueprint，再新建会话或基于当前内容重新请求。
- **历史显示 interrupted：** 编辑器、窗口或请求在完成前被停止。本地历史仍是权威数据；准备好后发送新请求，不要等待上一次网络流自动恢复。

## 验证

确认插件重启后正常加载；`settings.json` 与历史中没有密钥；revision conflict 后无法 Apply；Discard 不改变项目；成功 Apply 在普通 Save 前仍未写入磁盘。
