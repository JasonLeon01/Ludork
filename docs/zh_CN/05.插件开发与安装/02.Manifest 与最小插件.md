# Manifest 与最小插件

## 目标

创建一个 C# 13 源码插件，为帮助菜单增加一个命令，并能由 Ludork 1.0.0 引入。

## 前置条件

- 用于 IDE 诊断和本地编译的 .NET 9 SDK。
- 可以从当前仓库或编辑器开发包引用 `Ludork.Plugin.Abstractions`。
- 唯一插件 ID 与 CLR namespace。

## 源码目录

```text
MyPlugin/
├── plugin.json
├── MyPlugin.cs
└── MyPlugin.csproj
```

插件只有一种源码目录形式。源码按相对路径顺序使用 C# 13、nullable、允许 unsafe 和 Release 优化动态编译。宿主不会还原 NuGet 包，也不会加载预构建入口程序集。

## 步骤

### 1. 编写 `plugin.json`

```json
{
  "schemaVersion": 1,
  "id": "Example.MyPlugin",
  "name": "My Plugin",
  "version": "1.0.0",
  "minimumEditorVersion": "1.0.0",
  "entryType": "Example.MyPlugin.Plugin"
}
```

| 字段 | 契约 |
|---|---|
| `schemaVersion` | Manifest schema；必须等于 `1` |
| `id` | 只能包含字母、数字、点、连字符或下划线的标识 |
| `name` | 非空显示名 |
| `version` | 可解析为 .NET `Version` 的插件版本 |
| `minimumEditorVersion` | 按 .NET `Version` 解析的最低编辑器版本 |
| `entryType` | 区分大小写、包含 namespace 的 CLR 类型名 |

JSON 属性名区分大小写。

### 2. 添加入口类型

```csharp
using Ludork.Plugin.Abstractions;
using System;
using System.Threading.Tasks;

namespace Example.MyPlugin;

public sealed class Plugin : IEditorPlugin
{
    public void Register(IPluginRegistrar registrar)
    {
        ArgumentNullException.ThrowIfNull(registrar);
        PluginMenuCommand command = new(
            "Example.MyPlugin.About",
            PluginMenuLocation.Help,
            500,
            "My Plug-in",
            ShowMessageAsync);
        registrar.RegisterMenuCommand(command);
    }

    private static async Task<PluginResult> ShowMessageAsync(
        PluginMenuContext context)
    {
        await context.UserInterface.ShowMessageAsync(
            "My Plug-in",
            "The plug-in is loaded.",
            PluginMessageKind.Information,
            context.CancellationToken);
        return PluginResult.Completed();
    }
}
```

入口类型必须公开、非抽象、实现 `IEditorPlugin`，并具有公开无参构造函数。Command ID 必须全局唯一。

### 3. 添加可选 IDE 工程

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net9.0</TargetFramework>
    <LangVersion>13.0</LangVersion>
    <Nullable>enable</Nullable>
    <ImplicitUsings>disable</ImplicitUsings>
  </PropertyGroup>
  <ItemGroup>
    <ProjectReference Include="..\..\Ludork.Plugin.Abstractions\Ludork.Plugin.Abstractions.csproj">
      <Private>false</Private>
    </ProjectReference>
  </ItemGroup>
</Project>
```

根据源码布局调整引用路径。该工程只用于 IDE 分析；runtime 需要的所有源码必须保留在引入目录内，并使用宿主提供的依赖。

### 4. 引入并重启

选择 **Plugins → Import Plugin**，选择 `MyPlugin`，接受完全信任确认，然后重启 Ludork。
