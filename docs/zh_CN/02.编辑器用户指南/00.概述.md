# 编辑器用户指南

## 制作顺序

1. 熟悉[启动页、工作区与快捷键](<01.启动页、工作区与快捷键.md>)。
2. 检查[项目设置与资产布局](<02.项目设置与资产布局.md>)。
3. 通过[图块集、自动图块与地图](<03.图块集、自动图块与地图.md>)构建世界。
4. 通过[蓝图、Common Function 与 Actor](<04.蓝图、Common Function 与 Actor.md>)添加行为。
5. 编辑 [General Data、游戏变量与 Text Config](<05.General Data 与 Text Config.md>)、[动画与曲线](<06.动画与曲线.md>)和 [UI 资产](<07.UI 资产编辑器.md>)。
6. 使用[运行、调试与打包](<08.运行、调试与打包.md>)验证可分发构建。

[General Data 参考](<09.General Data 参考/00.概述.md>)列出 Sample 项目在 General Data 编辑器中显示的数据族。

## 安全编辑原则

- Run 或 Pack 前先保存，并从错误来源处解决校验问题。
- 通过编辑器创建、重命名、复制和移动数据感知资产，以保留稳定标识与已跟踪路径。
- 引用树是检查工具，不会改写或保护引用。
- 文件资源放在 `Assets`，编辑数据放在 `Data`，运行时代码放在 `Scripts`。
- 操作调用插件 Hook、原生构建或游戏进程时，应检查 Console。
