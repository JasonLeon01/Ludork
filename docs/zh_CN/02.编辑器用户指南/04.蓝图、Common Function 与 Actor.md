# Blueprint 与 Actor

Blueprint 是放在 `Data/Blueprints` 下的 JSON 类定义：它选择一个原生或 Lua 父类，保存可编辑属性，图模式下还包含事件图。地图上放置的 Actor 实例引用这些类。

## 目标

创建一个图模式的 Blueprint：设置类默认值、添加有效的事件图并放置实例，同时不要把图模式与 Script Mixin 的继承方式混用。

## 前置条件

- 要使用的全部字段与节点，都已有对应的最新 metadata（已生成或已加载）。

## 创建 Blueprint

使用 **游戏 → 新建蓝图**，或文件浏览器里的相应命令。选择一个最终继承自 `BPBase` 的父类，再选择 `Data/Blueprints` 下的保存路径。编辑器打开类时，会解析父类默认值与所支持的事件。

## 类值与实例值

类属性为所有实例提供默认值；地图上的 Actor 可以覆盖其中单个字段。组件由 metadata 声明，以结构化字段的形式显示；被 `InvalidVars` 隐藏的字段则不能作为普通属性编辑。

当 Blueprint 的 `ID` 选择了 General Data 类型时，编辑器会显示所选成员（member）的只读 `attributes` 预览。该预览不会写入 Blueprint JSON；运行时通过 `Source.Configs.GeneralDataTypes.Create` 构造生成的 Attribute Set，所以这些值应在 General Data 中编辑。

## Actor 库与 Inspector

Actor 库列出全部 Actor Blueprint，可按文本、顶层文件夹类别和范围进行筛选。**全部**显示完整目录，**收藏**显示加星条目，**最近使用**保留最近选择或放置的 20 个条目。收藏存放在 `Main.proj` 的 `editor.actorFavorites` 中；文件浏览器里移动或重命名 Blueprint 时收藏会同步更新，Blueprint 已不存在时会被自动清理。右键点击条目可以打开或定位其 Blueprint、切换收藏状态，或把它从最近使用中移除。动态预览只为库视口当前可见的行运行。

选中地图上的 Actor 后，Inspector 会显示它的 Blueprint 引用以及 **打开**、**定位** 操作，同时显示网格位置 X/Y、标签与公开类字段。持续聚焦编辑位置或文本时，会合并为一个撤销步骤。覆盖字段旁边的重置按钮用于删除该实例的覆盖值；**全部重置** 会删除该实例的全部类字段覆盖，重新显示继承自 Blueprint 的默认值。当 Actor 所在的图层被隐藏时，Inspector 仍可查看，也能打开、定位其 Blueprint，但标签、位置、重置操作与类字段都变为只读。

## 图模式

每个事件都拥有自己的节点列表与连线。通过选择器添加节点，连接执行 pin 与类型兼容的数据 pin，并为未连接的输入设置字面默认值。Pure 节点只有数据 pin；执行节点必须能从事件起点到达。

新建节点、粘贴节点与重复选区都使用鼠标在 graph 中的当前位置。操作开始时，编辑器会根据当前的平移与缩放，把这个屏幕位置换算成 graph 坐标；鼠标不在 graph 内时则使用视口中心。重复选区会保留原有的相对布局和内部连线，并把选区左上边界放到目标位置。

Windows 的主修饰键是 Ctrl，macOS 的主修饰键是 Command。

| 快捷键 | 操作 |
|---|---|
| Ctrl/Command+N | 在鼠标位置打开节点选择器 |
| Ctrl/Command+A | 选中当前 graph 中全部可编辑的节点 |
| Ctrl/Command+C | 复制选中节点及其内部连线 |
| Ctrl/Command+V | 在鼠标位置粘贴 |
| Ctrl/Command+D | 在鼠标位置重复选区 |
| 方向键 | 把选中的可编辑节点移动 1 个 graph 单位 |
| Delete | 删除选中的可编辑节点 |

继承节点与事件参数节点属于虚拟节点，不参与全选、移动、重复或删除。当参数编辑器或其他输入控件获得焦点时，graph 快捷键不会覆盖它们的键盘输入；只读的 graph 会禁用一切会产生修改的快捷键。

Common Functions 提供可复用的图。多个 Blueprint 需要相同的节点序列时，应优先使用 Common Function，而不是把图复制多份。

General Data 的成员图（member graph）是彼此独立、同步执行的 Ability。纯 graph 编辑器读取类型（type）的事件列表，不显示 class attribute，也排除 latent node；运行时通过 `Source.Gameplay.GeneralDataGraphAbility` 显式激活，并以该 `GameplayEventData` 作为 graph parent。

## 继承

子 Blueprint 会继承字段与行为。请勿随意改动已保存的父类路径：继承的字段、事件与兼容的组件数据都可能随之改变。同一条 Blueprint 继承链必须自始至终使用图模式或 Script Mixin 模式，参见 [Script Mixin](<../03.Lua 与蓝图脚本/03.脚本 Mixin/01.编写工作流.md>)。

## 校验

校验会检查父类解析、循环继承、graph 结构、事件起点、节点函数、link、pin 与已保存的默认值。空的可选事件是有效的；格式错误或越界的连接无效。修完所有报错后再保存，并运行一张有代表性的地图加以验证。

## 限制

校验无法修复对已重命名的运行时成员的引用，也无法证明每个可达的玩法状态都正确。
