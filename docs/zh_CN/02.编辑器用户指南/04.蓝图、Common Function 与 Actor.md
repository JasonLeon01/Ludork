# Blueprint 与 Actor

Blueprint 是位于 `Data/Blueprints` 下的 JSON 类定义。它选择一个原生或 Lua 父类，保存可编辑属性，并在图模式下包含事件图。地图中的 Actor 实例引用这些类。

## 目标

创建图模式 Blueprint，设置类默认值，添加有效事件图并放置实例，同时不混用图模式与 Script Mixin 继承模式。

## 前置条件

- 已生成或加载将使用的所有字段与节点的当前 metadata。

## 创建 Blueprint

使用 **游戏 → 新建蓝图**或文件浏览器命令。选择最终继承 `BPBase` 的父类，再选择 `Data/Blueprints` 下的保存路径。编辑器打开类时会解析父类默认值和支持的事件。

## 类值与实例值

类属性为所有实例提供默认值。地图 Actor 可以覆盖单独字段。组件由 metadata 声明，并显示为结构化字段。`InvalidVars` 隐藏的字段不会作为普通属性编辑。

当 Blueprint 的 `ID` 选择一种 General Data 类型时，与该 General Data schema 同名的类字段和组件直接字段在 Blueprint 编辑器中只读，并显示所选 member 的值。修改 `ID` 会刷新这些预览，但不会把值复制到 Blueprint JSON。初始化会用选中的 General Data member 替换这些类默认值。地图 Actor 的实例覆盖在类构造之后应用，因此仍可编辑。

## Actor 库与 Inspector

Actor 库列出全部 Actor Blueprint，并支持按文本、顶层文件夹分类和范围筛选。**全部**显示完整 catalogue，**收藏**显示加星条目，**最近使用**保留最近选择或放置的 20 个条目。收藏存储在 `Main.proj` 的 `editor.actorFavorites` 中；通过文件浏览器移动或重命名 Blueprint 时会同步更新，Blueprint 不存在时会自动清理。右键条目可打开或定位 Blueprint、切换收藏状态，或从最近使用中移除。动态预览只会为库视口中当前可见的行运行。

选中地图 Actor 后，Inspector 会显示其 Blueprint 引用及**打开**、**定位**操作，还会显示网格位置 X/Y、标签与公开类字段。连续聚焦编辑位置或文本时会合并为一个撤销步骤。覆盖字段旁的重置按钮会删除该实例覆盖值；**全部重置**会删除该实例全部类字段覆盖，再次显示继承的 Blueprint 默认值。当 Actor 所在图层被隐藏时，Inspector 仍可查看并可打开、定位 Blueprint，但标签、位置、重置操作和类字段均为只读。

## 图模式

每个事件拥有节点列表和连接。通过选择器添加节点，连接执行 pin 与类型兼容的数据 pin，并为未连接输入设置字面默认值。Pure 节点只有数据 pin；执行节点必须从事件起点可达。

新建节点、粘贴节点和重复选区使用 graph 中当前鼠标位置。操作开始时，编辑器会依据当前平移与缩放把该视觉位置换算为 graph 坐标；鼠标不在 graph 内时使用视口中心。重复选区会保留相对布局和内部连线，并将选区左上边界放到目标位置。

Windows 的主修饰键是 Ctrl，macOS 的主修饰键是 Command。

| 快捷键 | 操作 |
|---|---|
| Ctrl/Command+N | 在鼠标位置打开节点选择器 |
| Ctrl/Command+A | 选中当前 graph 的全部可编辑节点 |
| Ctrl/Command+C | 复制选中节点及其内部连线 |
| Ctrl/Command+V | 在鼠标位置粘贴 |
| Ctrl/Command+D | 在鼠标位置重复选区 |
| 方向键 | 将选中的可编辑节点移动 1 个 graph 单位 |
| Delete | 删除选中的可编辑节点 |

继承节点和事件参数节点属于虚拟节点，不参与全选、移动、重复或删除。参数编辑器或其他输入控件获得焦点时，graph 快捷键不会取代其键盘输入；只读 graph 会禁用会产生修改的快捷键。

Common Functions 提供可复用图。多个 Blueprint 需要相同节点序列时，应优先使用 Common Function，而不是复制图。

## 继承

子 Blueprint 继承字段与行为。不要随意修改已保存的父类路径，因为继承字段、事件和兼容组件数据可能改变。同一 Blueprint 继承链必须统一使用图模式或 Script Mixin 模式；参见 [Script Mixin](<../03.Lua 与蓝图脚本/03.脚本 Mixin/01.编写工作流.md>)。

## 校验

校验会检查父类解析、循环继承、graph 结构、事件起点、节点函数、link、pin 和已保存默认值。空的可选事件有效；错误或越界的连接无效。修复所有报告后保存，并运行代表性地图验证。

## 验证

- 重新打开 Blueprint，确认父类、字段、事件与 graph link。
- 每次结构性修改 graph 后重新校验。
- 放置两个实例，确认修改一个实例覆盖不会改变类或另一个实例。
- 保持 Console 可见并运行事件路径。

## 限制

校验不能修复已重命名 runtime 成员的引用，也不能证明每个可达玩法状态都正确。
