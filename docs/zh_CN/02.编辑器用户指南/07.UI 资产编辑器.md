# UI 资产编辑器

## 目标

在不编写运行时 Controller 的前提下，创建并排布一个声明式 UI 资产。

## 前置条件

- 已规划资产所有权：完整 UI、owner 专用 part 或 shared part。

## 打开或创建资产

选择 **游戏 → 新建 UI 资产**，或从项目文件浏览器创建、打开 `Data/UI/Assets` 下的 JSON 资产。资产所有权（`Parts/<Owner>` 与 `Shared`）见[声明式 UI 编写工作流](<../03.Lua 与蓝图脚本/05.声明式 UI/01.编写工作流.md>)。

![显示 Palette、Hierarchy、Designer 和 Inspector 的 UI 资产编辑器](../../_images/editor/ui-asset-editor.png)

*UI 资产编辑器将可用控件、树结构、可视化布局与选中节点属性分开显示。*

## 步骤

1. 设置资产的设计宽度与高度。
2. 添加根控件。新屏幕通常以 `Engine.Canvas` 开始。
3. 将系统控件或已暴露的项目资产从 Palette 拖入 Hierarchy。
4. 逐个选择节点，并在 Inspector 中编辑控件属性。
5. 配置子节点 Slot。Canvas 子项使用锚点、偏移、对齐、自动尺寸与 z-order；List 子项使用 List 自有排布。
6. 为每个节点设置在当前资产内唯一的有意义名称。运行时 Controller 使用名称查找节点。
7. 只有资产是完整、可复用且应出现在 Project Palette 中时，才启用 **Exposed**。
8. 保存并检查校验结果。

## 资产路径与节点名称

资产以相对 `Data/UI/Assets`、大小写精确、使用正斜杠且不含扩展名的路径标识。移动或重命名资产会改写受管 JSON 嵌套引用；匹配的 `Ui.Define`、`require` 与 LuaDoc 路径仍需手工更新。完整 key 契约见[资产 Schema](<../03.Lua 与蓝图脚本/05.声明式 UI/04.资产 Schema 与 Control Registry.md>)。

## 预览行为

匹配的 `UiPreviewHost` 与 adapter fingerprint 可用时，Designer 使用原生预览；否则报告原因并使用受支持的 fallback。预览只创建资产树，不执行 Lua Controller，因此顶层资产须包含全部可见窗格和代表性占位内容。`previewText` 与 `editor` 数据只用于设计；Controller 在显示前替换占位内容。
