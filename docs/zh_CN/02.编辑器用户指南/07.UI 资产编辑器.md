# UI 资产编辑器

## 目标

在不编写运行时 Controller 的前提下，创建并排布一个声明式 UI 资产。

## 前置条件

- 已规划好资产归属：完整 UI、某个 owner 专用的 part，或共享 part。

## 打开或创建资产

选择 **游戏 → 新建 UI 资产**，或从项目文件浏览器创建、打开 `Data/UI/Assets` 下的 JSON 资产。资产归属（`Parts/<Owner>` 与 `Shared`）见 [声明式 UI 编写工作流](<../03.Lua 与蓝图脚本/04.声明式 UI/01.编写工作流.md>)。

![显示 Palette、Hierarchy、Designer 和 Inspector 的 UI 资产编辑器](../../_images/editor/ui-asset-editor.png)

*UI 资产编辑器将可用控件、树结构、可视化布局与选中节点属性分开显示。*

## 步骤

1. 设置资产的设计宽度与高度。
2. 添加根控件。新屏幕通常以 `Engine.Canvas` 开头。
3. 把系统控件或已暴露的项目资产从 Palette 拖入 Hierarchy。
4. 逐个选中节点，在检查器中编辑控件属性。
5. 配置子节点的 Slot。Canvas 子项使用锚点、偏移、对齐、自动尺寸与 z-order，List 子项则由 List 自身决定摆放。
6. 给每个节点起一个有意义的名称，并在当前资产内保持唯一。生成的 View 会保留这些名称，作为类型化控件或子 View 的 key。
7. 只有当资产本身完整、可复用，并且应当出现在 Project Palette 中时，才启用 **Exposed**。
8. 保存并查看校验结果，再使用主窗口的 **导出** 操作生成 Lua View 与声明。

将 Palette 控件拖到 Hierarchy 容器行的中间可添加子节点，拖到行顶部或底部的四分之一区域可插入同级节点；拖到层级空白处则追加到根节点。双击 Palette 控件仍按当前选择添加。

添加、复制和移动节点都遵循目标控件的子节点规则。移入 Canvas 时保留视觉位置和固定尺寸，并保留 Canvas 的锚点、对齐、自动尺寸与 z-order；拉伸轴随新父节点的可用尺寸变化。自动尺寸控件和 List 排布遵循原生布局；作者设置的旋转与缩放保持不变，因此父节点变换不同仍可能影响朝向或文本的固有尺寸。同一父节点内重新排序保留完整 Slot。更换父节点与调整 Slot 合并为一次撤销，缩进和取消缩进也遵循这一规则。嵌套的项目资产保持黑盒。校验检查当前资产及其可达的嵌套循环，包括依赖内部形成的循环。

选中 `Engine.Button` 后，检查器提供 `gamepadButton` 与 `gamepadLongPress`。无绑定保存为空字符串。运行时行为见 [Engine：运行时值与功能控件](<../03.Lua 与蓝图脚本/08.全局与 Core 模块/02.Core Modules/01.Engine/09.运行时值与功能控件.md#button>)。

Image 与 FunctionalImage 的 **Draw As** 使用枚举下拉框：**Image** 拉伸图片，**Tile** 则重复纹理区域以填满布局范围。WrapBox 提供 `size`、`count` 与 `spacing`，最多允许一个子模板。Designer 显示全部重复项；选中并编辑任一重复项都会修改同一模板，保存时只保留这一个作者子节点。缩放与运行时访问见 [Engine：布局与图像控件](<../03.Lua 与蓝图脚本/08.全局与 Core 模块/02.Core Modules/01.Engine/10.布局与图像控件.md>)。

## Timeline

Timeline 在左侧列出动画，初始时没有选中项，详情区为空，界面显示编辑器产出的外观。右键可以新建或删除本地动画；选中某个动画后，可以编辑它的名称、target、duration、pivot、轨道与 key。单击列表空白处会清除选择。颜色 key 使用整数 RGBA 分量。

播放、暂停、停止和拖动预览都使用游戏动画运行时。预览采样不会把 presentation transform 写回 Slot。

嵌套的项目节点会列出从它所属资产继承来的 Global 动画。用 **覆盖动画** 操作为当前实例创建同名动画，再在本地编辑；继承来的定义本身仍然是只读的。

## 资产路径与节点名称

资产的身份是相对于 `Data/UI/Assets` 的大小写精确路径，使用正斜杠，不带扩展名。移动或重命名资产会改写受管 JSON 中的嵌套引用。下次导出会重新生成它的 View 与声明，所以导出前要一并更新手写的 `require` 路径和指向已改名节点的引用。完整的 key 契约见 [UI 资产 Schema 与 Control Registry](<../03.Lua 与蓝图脚本/04.声明式 UI/04.资产 Schema 与 Control Registry.md>)。

## 预览行为

Designer 使用项目编译出的预览运行时。改动 C++ UI 之后，点击 **编译** 重新构建：构建期间预览不可用，只有配套产物就绪后才会刷新。设置与校验要求见[声明式 UI 校验与打包](<../03.Lua 与蓝图脚本/04.声明式 UI/05.校验与打包.md>)。

每个编辑窗口各自持有一个预览会话。连续快速的字段编辑会合并成一次刷新；**刷新预览** 会提交待处理的字段编辑并请求最新状态。在画布上拖动或调整控件大小时会持续渲染，一帧渲染期间的指针移动会合并，每次拖动仍只占一步撤销。松开或取消拖动后立即请求最终状态。动画播放的采样会随渲染完成持续推进。来自更早的编辑、已结束的拖动、动画选择、缩放或运行时构建的结果，都无法替换当前预览。关闭窗口会停止播放并释放它的预览连接。

保存的 JSON 保留可直接阅读的中文；引号、反斜杠等特殊字符继续使用 JSON 转义。

预览会实例化资产树，但不运行它的 Lua Controller，因此顶层资产包含全部可见窗格和有代表性的占位内容。`previewText` 与 `editor` 数据仅供设计使用；业务代码在显示之前填充运行时内容。
