# UI 资产编辑器

## 目标

在不编写运行时 Controller 的前提下，创建并排布一个声明式 UI 资产。

## 前置条件

- 已规划资产所有权：完整 UI、owner 专用 part 或 shared part。

## 打开或创建资产

选择 **游戏 → 新建 UI 资产**，或从项目文件浏览器创建、打开 `Data/UI/Assets` 下的 JSON 资产。资产所有权归属（`Parts/<Owner>` 与 `Shared`）见 [声明式 UI 编写工作流](<../03.Lua 与蓝图脚本/05.声明式 UI/01.编写工作流.md>)。

![显示 Palette、Hierarchy、Designer 和 Inspector 的 UI 资产编辑器](../../_images/editor/ui-asset-editor.png)

*UI 资产编辑器将可用控件、树结构、可视化布局与选中节点属性分开显示。*

## 步骤

1. 先设置资产的设计宽度与高度。
2. 添加根控件。新屏幕通常以 `Engine.Canvas` 开始。
3. 将系统控件或已暴露的项目资产从 Palette 拖入 Hierarchy。
4. 逐个选择节点，并在 Inspector 中编辑控件属性。
5. 配置子节点的 Slot：Canvas 子项使用锚点、偏移、对齐、自动尺寸与 z-order；List 子项则遵循 List 自己的排布规则。
6. 给每个节点起一个有意义的名称，并保证它在当前资产内唯一；运行时 Controller 依赖这些名称查找节点。
7. 只有当资产完整、可复用，并且应出现在 Project Palette 中时，才启用 **Exposed**。
8. 保存并检查校验结果。

## Timeline

Timeline 在左侧列出动画。初始状态下没有选中项，详情区为空，界面显示资产的原始（authored）外观。右键可以新建或删除本地动画；选中某个动画后，可以编辑它的名称、target、duration、pivot、轨道与关键帧。点击列表空白处会取消选择。Colour 关键帧使用 RGBA 整数分量。

播放、暂停、停止与 scrub（拖动预览）都使用游戏动画运行时；预览采样不会把 presentation transform 写回 Slot。

嵌套的项目节点会列出从子资产继承的 Global 动画。通过 override 操作创建指向当前实例的同名动画后，就能在父资产里编辑它；继承来的定义本身仍是只读的。

## 资产路径与节点名称

资产的身份是相对于 `Data/UI/Assets` 的路径：区分大小写、使用正斜杠、不带扩展名。移动或重命名资产时，编辑器会改写受管 JSON 中的嵌套引用；对应的 `Ui.Define`、`require` 与 LuaDoc 路径仍需手工更新。完整的 key 契约见 [资产 Schema](<../03.Lua 与蓝图脚本/05.声明式 UI/04.资产 Schema 与 Control Registry.md>)。

## 预览行为

Designer 要求 `UiPreviewHost` 与 adapter fingerprint 兼容。预览只实例化资产树，不会创建 Lua Controller，因此顶层资产需要包含所有可见 pane 以及有代表性的占位项。`previewText` 与 `editor` 数据只用于设计阶段；显示前，Controller 会替换其中的占位内容。
