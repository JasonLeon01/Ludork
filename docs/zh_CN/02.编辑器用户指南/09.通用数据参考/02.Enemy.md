## Schema

| 字段 | 类型 | 默认值 | 描述 | 引用 |
|---|---|---|---|---|
| `name` | `string` | `"NEW ENEMY"` | 该敌人的显示名称。 | `—` |
| `desc` | `string` | `"NEW ENEMY DESC"` | 该敌人的显示说明。 | `—` |
| `MAXHP` | `int` | `0` | 敌人的最大 HP。 | `—` |
| `ATK` | `int` | `0` | 敌人的攻击力。 | `—` |
| `DEF` | `int` | `0` | 敌人的防御力。 | `—` |
| `EXP` | `int` | `0` | 击败该敌人时给予的经验值。 | `—` |
| `GOLD` | `int` | `0` | 击败该敌人时给予的金币。 | `—` |
| `drops` | `Dict[string, sf.Vector2i]` | `{}` | Item 蓝图类路径到地图格偏移的映射，偏移以敌人被击败的位置为基准。 | `—` |
| `special` | `Dict[string, any]` | `{}` | Special 成员 ID 到其带类型参数的映射。 | `general:Special` |
| `ANIMATION_KEY` | `string` | `""` | 敌人攻击时播放的动画。 | `animation` |

## 编辑说明

Enemy schema 不声明成员事件，击败行为由 Gameplay Ability 处理。

在 `special` 中，只要存在对应的 key，`Compete`、`Hard`、`Magic`、`First`、`Flank` 和 `Blockade` 就会启用，它们的取值都是 `""`。`Vampire` 取有限的非负数，`Reborn` 取非空的蓝图类路径。`FixDmg` 既可以取有限的非负数，也可以取非空表达式字符串。只有字符串形式会在 `Engine.Eval` 之前，把玩家与敌人的当前值代入 `{m<attribute>}` 和 `{e<attribute>}`。其他 special 取值一律不求值。

`drops` 的每个 key 都必须是蓝图类路径，其生成的 Actor 需继承 `Source.Item`。对应的 `sf.Vector2i` 值会加到敌人被击败时所处的地图坐标上。生成 Actor 的 tag 由蓝图路径与绝对目标坐标推导得出。若同名 tag 已存在，则跳过这次掉落并写入一条 warning，而不是生成带后缀的重复对象。
