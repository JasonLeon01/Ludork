# Player

来源：`Data/General/Player.json`

| 属性 | 值 |
|---|---|
| 成员事件 | — |

## Schema

| 字段 | 类型 | 默认值 | 描述 | 引用 |
|---|---|---|---|---|
| `name` | `string` | `""` | 该玩家预设的显示名称。 | `—` |
| `desc` | `string` | `""` | 该玩家预设的显示说明。 | `—` |
| `CLASS` | `string` | `""` | 定义玩家装备槽位与初始装备的 `Class` 成员 ID。 | `general:Class` |
| `MAXHP` | `int` | `1000` | 玩家的初始最大 HP。 | `—` |
| `HP` | `int` | `1000` | 玩家的初始当前 HP。 | `—` |
| `ATK` | `int` | `10` | 玩家的初始攻击力。 | `—` |
| `DEF` | `int` | `10` | 玩家的初始防御力。 | `—` |
| `EXP` | `int` | `0` | 玩家的初始经验值。 | `—` |
| `GOLD` | `int` | `0` | 玩家的初始金币。 | `—` |
| `LEVEL` | `int` | `1` | 玩家的初始等级。 | `—` |
| `ANIMATION_KEY` | `string` | `""` | 玩家攻击时播放的动画。 | `animation` |

## 编辑说明

Sample 的 `Bravor` 成员定义了 `MAXHP = 2000` 和 `HP = 1000`。运行时把选中的成员复制到 `PlayerAttributeSet`。`BP_Actor_Braver.json` 蓝图只保存该成员的 `ID`。
