# 动画与曲线

## 目标

创建动画与曲线资产，预览其时序，并从数据或脚本引用稳定项目 key。

## 前置条件

- 已保存项目，以及位于 `Assets` 下的必要源图片。
- 已规划动画帧时序或曲线 key 值。
- 支持所选资产类型的 runtime consumer。

## 步骤

1. 使用 F4 或 Animation Overview（F8）创建或打开动画，编辑 frame 并预览时间。
2. 使用 F5 创建曲线，添加有序 key 并选择 interpolation。
3. 保存资产，通过受支持 selector 设置引用，再运行实际读取它的玩法路径。

## 动画

使用 **Database → Animation Overview**（F8）浏览动画数据。**Game → New Animation**（F4）会在 `Data/Animations` 下创建 JSON。编辑器可编辑动画格式中的帧、时间、视觉资源和事件数据。

源图片应放在 `Assets/Animations` 或其他约定资源目录。玩法依赖动画时长前，应先预览时间。运行时辅助 API 会在适用时区分总时长与视觉时长。

![显示帧时序与预览控件的动画编辑器](../../_images/editor/animation.png)

*在玩法中使用动画资产前，先预览动画帧、时序与事件。*

## 曲线

**Game → New Curve**（F5）在 `Data/Curves` 下创建曲线。曲线包含名称、默认值、前后延伸行为和有序 key；每个 key 包含 time、value、interpolation、arrive tangent 和 leave tangent。

使用曲线编辑器添加、移动和删除 key。应保持时间顺序；除非插值明确支持跳变，否则不要使用重复时间。

![显示有序 key 与插值设置的曲线编辑器](../../_images/editor/curve.png)

*在玩法中引用曲线前，先检查曲线 key 与插值。*

## 数据引用

由 metadata 驱动的选择器可从 Blueprint 或 General Data 引用 animation/curve key。重命名 JSON 文件会改变由路径推导的逻辑 key，因此应先查看引用树。

## 测试

应测试零 key、单 key 曲线、动画结束、帧事件以及目标帧率下的切换。用于淡入淡出或移动的曲线还应在低帧率和高帧率下检查。

## 预期结果

动画在预期时间结束并触发已配置事件；曲线在 key 之前、之间与之后均能稳定求值。

## 验证

- 重新打开每个已保存资产，检查时间与 key 顺序。
- 在目标、低与高帧率下测试 runtime consumer。
- 重命名资产路径后检查每个引用。

## 限制

编辑器不能从时间数据推断玩法意图。重复 key time 与路径变化都需要作者明确复核。
