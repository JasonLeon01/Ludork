# 动画与曲线

## 目标

创建动画与曲线资产，预览它们的时序，并从数据或脚本中引用稳定的项目 key。

## 动画

用 **数据库 → 动画总览**（F5）浏览动画数据；**游戏 → 新建动画** 会在 `Data/Animations` 下创建 JSON。编辑器提供对动画格式中帧、时间、视觉资源与事件数据的编辑能力。

源图片放在 `Assets/Animations` 或其它按约定组织的资产目录。在玩法逻辑依赖动画时长之前，先预览一下时间；运行时辅助 API 会在合适的地方区分总时长与视觉时长。

![显示帧时序与预览控件的动画编辑器](../../_images/editor/animation.png)

*在玩法中使用动画资产前，先预览动画帧、时序与事件。*

## 曲线

**游戏 → 新建曲线** 会在 `Data/Curves` 下创建曲线。曲线由名称、默认值、首尾两端向无穷延伸的行为，以及有序的 key 组成；每个 key 包含 time、value、interpolation、arrive tangent 与 leave tangent。

用曲线编辑器添加、移动或删除 key。key 的时间应保持有序；除非所用的插值明确支持跳变，否则不要出现重复时间。

![显示有序 key 与插值设置的曲线编辑器](../../_images/editor/curve.png)

*在玩法中引用曲线前，先检查曲线 key 与插值。*

## 数据引用

metadata 驱动的选择器可以从 Blueprint 或 General Data 引用 animation/curve 的 key。重命名 JSON 文件会改变由路径推导出的逻辑 key，所以动手前应先查看引用树。

## 测试

测试应覆盖零 key 与单 key 曲线、动画结束、帧事件，以及目标帧率下的切换。用于淡入淡出或移动的曲线，还要在低帧率与高帧率下检查。
