# 动画与曲线

## 目标

创建动画与曲线资产，预览它们的时序，并在数据或脚本中引用它们稳定的项目 key。

## 动画

打开 **数据库 → 动画总览**（`F5`）浏览动画数据。**游戏 → 新建动画** 在 `Data/Animations` 下创建 JSON 资产。编辑器开放动画格式中的帧、时序、视觉资源与事件数据。

源图片放在 `Assets/Animations` 或其他打算使用的资产目录。非空的图片和声音条目保存完整的 `/Game/Assets/...` 路径。依赖动画的总时长或视觉时长之前，先预览时序。

![显示帧时序与预览控件的动画编辑器](../../_images/editor/animation.png)

*在玩法中使用动画资产前，先预览动画帧、时序与事件。*

### 本地导出 MP4

导出前先保存动画。在 Windows 仓库根目录运行 `tools\animation_to_mp4.bat`，
即可将当前 `Game/Data/Animations` 下的全部 JSON 导出到 `Game/EditorCache/AnimationMp4`。
macOS 使用 `sh tools/animation_to_mp4.sh`。需要重新构建包含 Pillow 的 ScriptTools，
并另行准备支持 `libx264` 和 AAC 的 FFmpeg 可执行文件；详见
[工具准备与参数](../../../tools/README.md#animation-mp4-export)。

```bat
tools\animation_to_mp4.bat Game --input Game/Data/Animations/attack.json --output Game/EditorCache/attack.mp4
```

导出保留原始帧率、轨道顺序、位置/旋转/缩放插值、水平翻转及音效时序和裁剪。
视频播放一次，直到最后一个图片或声音片段结束，时长向上取整到完整帧。
视觉片段结束后只显示背景。画布以动画原点为中心，自动容纳所有采样帧；
`--size 512x512` 指定宽高为偶数的固定画布，不缩放内容，超出部分会被裁剪。
MP4 使用不透明背景，默认为黑色，可用 `--background "#202020"` 指定。
`--mute` 移除音轨但不缩短时间轴；`--overwrite` 在导出成功后覆盖已有文件。
目录输入会递归处理，并保留子目录结构。时间标签不会编码为视频事件。
输入必须是已保存的源 JSON 和散装资源，不支持压缩动画缓存或 `.ldpak` 包。

## 曲线

**游戏 → 新建曲线** 在 `Data/Curves` 下创建曲线。曲线包含名称、默认值、首尾两端的无穷延伸行为，以及有序的 key。每个 key 包含 time、value、interpolation 和 arrive/leave tangent。

用曲线编辑器添加、移动和删除 key。key 的时间要保持有序；除非所用的插值明确支持跳变，否则避免出现重复时间。

![显示有序 key 与插值设置的曲线编辑器](../../_images/editor/curve.png)

*在玩法中引用曲线前，先检查曲线 key 与插值。*

## 数据引用

由 metadata 驱动的选择器可以从蓝图或通用数据中引用动画与曲线的 key。重命名 JSON 文件会改变由路径推导出的逻辑 key，因此先查看引用树。

## 测试

在目标帧率下测试零 key 与单 key 曲线、动画结束、帧事件和切换。用于淡入淡出或移动的曲线，还要在低帧率与高帧率下分别检查。
