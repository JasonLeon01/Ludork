# 启动页、工作区与快捷键

## 目标

打开项目，识别主要工作区，使用当前全局快捷键，并在编辑项目数据前找到诊断入口。

## 安全编辑

- Run 或 Pack 前先保存，并从错误来源处解决校验问题。
- 通过编辑器创建、重命名、复制和移动数据感知资产，以保留稳定标识与已跟踪路径。
- 引用树是检查工具，不会改写或保护引用。
- 文件资源放在 `Assets`，编辑数据放在 `Data`，运行时代码放在 `Scripts`。
- 操作调用插件 Hook、原生构建或游戏进程时，应检查 Console。

## 启动页

启动页列出最近打开的三个项目，并提供 **New Project** 与 **Open Project**。通过校验的 `.proj` 文件在打开后会移到列表顶部；启动页加载时会移除不可用的记录。打开 `Main.proj` 时，只有未保存内容检查通过后才会替换当前项目。

## 主工作区

主窗口包含地图列表、地图画布、编辑模式属性面板、Actor Outliner、项目文件浏览器与 Console。工具栏用于切换 Tile、Light 与 Actor 模式，并控制游戏进程。

工作区窗口以及地图列表、Actor 库、右侧属性区和下方面板均可调整尺寸，编辑器会保存调整后的尺寸。

Animation Overview、Tilesets、General Data、Common Functions、Blueprint 与 UI Asset 窗口会先显示 Loading，并以 UI 后台优先级初始化。General Data 页面、Tileset 页签和 Animation 内容只在首次选中时创建。

*当前编辑模式决定可见属性面板与画布交互。*

## 全局快捷键

Windows 使用 Ctrl 作为主修饰键，macOS 使用 Command。

| 快捷键 | 操作 |
|---|---|
| Ctrl/Command+N | New Project |
| Ctrl/Command+O | Open Project |
| Ctrl/Command+S | Save |
| Ctrl/Command+Z | Undo |
| Ctrl/Command+Y | Redo |
| Ctrl/Command+W | 退出或关闭项目窗口 |
| Ctrl/Command+1 | Tile 模式 |
| Ctrl/Command+2 | Light 模式 |
| Ctrl/Command+3 | Actor 模式 |
| F1 | Ludork Documentation |
| F3 | Game Config |
| F4 | System Config |
| F5 | Animation Overview |
| F6 | Tilesets Data |
| F7 | Common Functions |
| F8 | Game Variables |
| F9 | General Data |

部分文档窗口另有上下文快捷键。例如，当 Blueprint 图或 Common Function 窗口提供相应操作时，F2 用于重命名当前选中项。

单按钮 Hint 与错误弹窗可通过 Enter、Return、Space 或 Escape 关闭。确认弹窗中，Enter、Return 与 Space 执行确认，Escape 执行取消。

## 编辑与保存

修改在保存前留在编辑器模型中。Undo 与 Redo 覆盖受支持的数据变更。关闭或替换已修改项目时，编辑器会在丢弃内容前提示。普通保存会校验已修改 Blueprint；只有刻意保留未完成图时才使用强制保存。

Undo 与 Redo 保留最近 100 个项目数据步骤。同一输入框获得焦点期间的连续文本或数字编辑会合并为一步；移动到其他控件会结束该步骤。保存、Undo 和 Redo 会切分当前焦点编辑，之后继续输入可独立撤销。按钮、复选框和选择操作仍分别形成一步。

## 文件浏览器与引用树

文件浏览器支持在项目根目录内新建、重命名、复制、移动、剪切和删除。数据感知右键命令可创建 Blueprint、Animation、Curve、Text Config 与 UI Asset。引用树显示传入和传出引用，但不会改写引用或阻止删除。

## Console 与 Performance Monitor

Console 收集插件、构建与运行时输出。只有兼容的运行时连接就绪时才能发送输入。**Edit → Development Tools → Performance Monitor** 在游戏运行期间显示最近的帧、逻辑与内存样本。

![Sample 运行结束后的 Console 输出](../../_images/editor/console-output.png)

*Console 记录启动进度、运行时诊断和进程结束结果。*

![等待运行时遥测的 Performance Monitor](../../_images/editor/console-performance.png)

*没有兼容的运行时会话时，监视器保持等待状态属于正常现象；连接遥测后，时间线才会开始填充。*

## 验证

- F1 打开当前语言的文档。
- Ctrl/Command+S 保存受支持改动，并清除修改标记。

## 限制

上下文窗口可以定义额外快捷键，但不会改变全局 F3–F9 映射。
