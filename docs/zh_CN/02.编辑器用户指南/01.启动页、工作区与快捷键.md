# 启动页、工作区与快捷键

## 目标

打开项目，识别主要工作区，使用当前全局快捷键，并在编辑项目数据前找到诊断入口。

## 安全编辑

- 在 Run 或 Pack 之前先保存，并到出错根源处解决校验问题。
- 数据感知（data-aware）资产要通过编辑器来创建、重命名、复制和移动，以保持稳定标识与已跟踪路径有效。
- 使用引用树检查已索引的引用；地图操作只保护可识别的结构化引用，不处理任意字符串。
- 文件类资源放在 `Assets`，编辑器产出的项目数据放在 `Data`，运行时代码放在 `Scripts`。
- 只要操作会调用插件 Hook、原生构建或游戏进程，就应查看 **控制台**。

## 启动页

启动页列出最近打开过的三个项目，并提供 **新建项目** 与 **打开项目**。通过校验的 `.proj` 文件一经打开就会移到列表顶部；启动页加载时会清除其中不可用的记录。只有未保存内容的检查通过后，打开 `Main.proj` 才会替换当前项目。

也可以将已有的 `.proj` 文件拖到启动页任意位置打开。一次拖入多个文件时，使用其中第一个存在的 `.proj` 文件，忽略其他文件。

## 主工作区

主窗口包含地图列表、地图画布、编辑模式属性面板、Actor Outliner、项目文件浏览器与控制台。工具栏用于切换 Tile、Light 与 Actor 模式，并控制游戏进程。

工作区窗口本身，以及地图列表、Actor 库、右侧属性区和下方面板都可以调整大小，编辑器会记住调整后的尺寸。

动画总览、图块集数据、通用数据、公共函数、Blueprint 与 UI 资产等窗口会先显示 Loading（加载中）视图，并以 UI 后台优先级完成初始化。通用数据页面、图块集数据页签与动画内容，都只在首次选中时才创建。

## 全局快捷键

Windows 使用 Ctrl 作为主修饰键，macOS 使用 Command。

| 快捷键 | 操作 |
|---|---|
| Ctrl/Command+N | 新建项目 |
| Ctrl/Command+O | 打开项目 |
| Ctrl/Command+S | 保存 |
| Ctrl/Command+Z | 撤销 |
| Ctrl/Command+Y | 重做 |
| Ctrl/Command+W | 退出或关闭项目窗口 |
| Ctrl/Command+1 | Tile 模式 |
| Ctrl/Command+2 | Light 模式 |
| Ctrl/Command+3 | Actor 模式 |
| F1 | Ludork Documentation |
| F3 | 游戏配置 |
| F4 | 系统配置 |
| F5 | 动画总览 |
| F6 | 图块集数据 |
| F7 | 公共函数 |
| F8 | 游戏变量 |
| F9 | 通用数据 |

部分文档窗口还提供各自的上下文快捷键。例如，在 Blueprint 图或公共函数窗口中，只要该窗口支持此操作，F2 就用于重命名当前选中项。

只有单个按钮的提示（Hint）与错误弹窗，按 Enter、Return、Space 或 Escape 即可关闭。在确认弹窗中，Enter、Return 与 Space 表示确认，Escape 表示取消。

## 编辑与保存

界面上显示的字段默认值，只有在编辑后才会保存。

受管资源的修改在保存前只存在于内存中。所有保存按钮与 Ctrl/Command+S 都保存全部已修改文档，包括未打开的资源；运行和打包使用同一流程。普通保存校验改动过的 Blueprint，强制保存可保留未完成的图。[游戏配置](<02.项目设置与资产布局.md#mainini>)在确认时立即写入。

Undo/Redo 只作用于当前文件，每个文件保留最近 100 条记录。同文件的窗口共享数据与历史，关闭后重新打开仍保留。同一字段中的连续文本或数字输入合并为一步；切换控件或编辑窗口、自动更新、保存、撤销和重做会结束该步。按钮、复选框和选择操作各自成一步。

自动引用更新会在每个改变的目标文件中形成带标记的撤销屏障，包括未打开的文件。之后的编辑仍可撤销，但不能越过屏障，尝试时会提示来源。撤销或重做源文件改名会按目标当前内容同步引用并加入新屏障，保留无关编辑。保存保留历史与屏障，之后撤销可使文件再次变为已修改。

已修改文件在文件浏览器和编辑窗口标题中显示 `*`，资源选择器也会标记未保存项。关闭或替换项目时列出未保存文件，提供保存全部、放弃并继续、取消。保存失败会保留修改标记并阻止关闭；仅关闭资源窗口会保留未保存数据，直到项目退出。

## 文件浏览器与引用树

文件浏览器管理项目文件，并可创建 Blueprint、Animation、Curve、Text Config 与 UI Asset 等资产。引用树显示传入与传出引用。地图操作会以原子方式更新或保护可识别的已索引引用；任意字符串不受管理。

新建或复制的受管资源处于未保存状态，初始创建不计入撤销步骤。改名立即显示在编辑器中，全局保存时才将新路径与引用更新一起写入磁盘。删除前须先移除并保存所有可识别引用；确认删除立即生效且不可撤销。

右上角的打开菜单始终提供系统文件管理器，只在安装了对应程序时才列出 VS Code 或 Cursor。C++ Source 工程还会列出已安装的 CLion；Windows 上还提供 Visual Studio 2022。首次用 CLion 或 Visual Studio 打开工程时，如果本机还没有 `.idea` 或 `.vs` 配置，编辑器会先询问是否运行项目自带的环境生成脚本；取消不会改动工程。Visual Studio 打开的是生成的 `Main.sln`。

## 控制台与性能监视器

控制台收集插件、构建与运行时的输出；只有兼容的运行时连接就绪后，才能向它发送输入。游戏运行期间，**编辑 → 开发工具与设置 → 性能监视器** 会显示最近的帧、逻辑与内存样本。

### 大地图流送样本

对组合式大地图进行性能采样时，性能监视器会附带一个可选的 `worldStreaming` 快照；普通地图与未采样的 tick 不会有该字段。

| 字段 | 含义 |
|---|---|
| `queueDepth` | 排队等待流送的子地图区域数量。 |
| `reading` | 当前处于 `Reading` 状态的区域数量。 |
| `prepared` | 已加载并处于 `Prepared` 状态的区域数量。 |
| `active` | 处于 `Active` 状态的区域数量。 |
| `dormant` | 已加载并处于 `Dormant` 状态的区域数量。 |
| `cacheBytes` | 非 Active 区域缓存占用量的保守估算；它不是进程、Lua、native 或 GPU 内存的精确值。 |
| `publishMilliseconds` | 本次逻辑 tick 中用于转换与发布区域的时间。 |
| `visibleTileChunks` | 最近一次绘制中，可见子地图图层提交的不重复 32×32 格 TileLayer chunk 数量。 |
| `activeActors` | 当前位于大地图 Active 更新/绘制批次中的 Actor 数量。 |
