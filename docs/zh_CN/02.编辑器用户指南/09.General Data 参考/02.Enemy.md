## 编辑说明

Enemy 没有 member event；击败行为由 gameplay ability 处理。

`Reborn` 是非空的 Blueprint 类路径 string。special value 是 JSON literal，不会作为 Lua 表达式执行。

`drops` 的每个 key 都是必需的 Blueprint 类路径，生成的 Actor 必须继承 `Source.Item`；对应的 `sf.Vector2i` value 会加到被击败敌人的地图坐标上。生成 Actor 的 tag 由 Blueprint 路径和绝对目标坐标组成；已有相同 tag 时会跳过该掉落并记录 warning，不会生成带数字后缀的重复对象。
