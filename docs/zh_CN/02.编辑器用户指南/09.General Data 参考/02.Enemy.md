## 编辑说明

Enemy 没有成员事件；击败行为由 Gameplay Ability 处理。

`Compete`、`Hard`、`Magic`、`First`、`Flank` 与 `Blockade` 都使用 `""`，是否启用由 key 是否存在决定。`Vampire` 是有限非负数；`Reborn` 是非空 Blueprint 类路径。`FixDmg` 可以接受上述 number，也可以接受非空表达式 string；只有 string 形式会在 `Engine.Eval` 之前替换玩家/敌人的当前 `{m<属性>}` / `{e<属性>}`。其它 special 值一律不会执行。

`drops` 的每个 key 都必须是 Blueprint 类路径，生成的 Actor 需要继承 `Source.Item`；对应的 `sf.Vector2i` 值会加到被击败敌人的地图坐标上。生成 Actor 的 tag 由 Blueprint 路径与绝对目标坐标组合而成；若已存在相同 tag，则跳过该次掉落并记录一条 warning，而不会生成带数字后缀的重复对象。
