## 编辑说明

应先添加字段，再大量创建成员。reference 控制选择器，但保存值仍使用声明的 JSON 形状。类型列出 events 时，每个成员可以在 `_graph` 下保存 graph；缺少 start node 表示该可选事件未实现。

Special 记录只定义展示信息；参数保存在 `Enemy.special`。无参数 special 使用 `""`，说明可含一个 `{value}` 占位符。怪物手册会先本地化 `FixDmg` 表达式 token，再填入其值。
