## Schema

| Field | Type | Default | Description | Reference |
|---|---|---|---|---|
| `name` | `string` | `""` | The display name of this special. | `—` |
| `desc` | `string` | `""` | The display description of this special. | `—` |
| `icon` | `file` | `"Icons"` | The icon asset path relative to Assets. | `—` |

## 编辑说明

先添加好字段，再批量创建成员。reference 只控制选择器，保存的值仍遵循声明的 JSON 形状。类型列出 events 时，每个成员可以在 `_graph` 下保存对应的图；缺少起始节点（start node）表示该可选事件没有实现。

Special 记录只定义展示信息，参数保存在 `Enemy.special` 里。无参数的 special 使用 `""`，其说明可以包含一个 `{value}` 占位符。怪物手册会先本地化 `FixDmg` 表达式中的 token，再填入实际值。
