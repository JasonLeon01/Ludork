# Class

根据当前 Sample 的 `Data/General` schema 生成：schema 字段、关联运行时类型和成员事件。具体值属于项目数据，不是引擎固定枚举。

每个类型使用 `params` 定义字段，使用 `members` 保存记录。`reference` 用于限定编辑器选择器；`linkedType` 把成员 graph 连接到运行时 metadata。花括号显示字符串遵循[游戏本地化工作流](<../../05.插件开发与安装/06.游戏本地化工作流.md>)。

来源：`Data/General/Class.json`

## Schema

| Field | Type | Default | Description | Reference |
|---|---|---|---|---|
| `name` | `string` | `""` | The display name of this class. | `—` |
| `desc` | `string` | `""` | The display description of this class. | `—` |
| `slot` | `Dict[string, string]` | `{}` | Equipment slot names mapped to the equipment initially equipped in each slot; use an empty value for an unequipped slot. | `—` |

## 编辑说明

应先添加字段，再大量创建成员。reference 控制选择器，但保存值仍使用声明的 JSON 形状。类型列出 events 时，每个成员可以在 `_graph` 下保存 graph；缺少 start node 表示该可选事件未实现。
