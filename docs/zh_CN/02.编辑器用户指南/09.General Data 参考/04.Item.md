# Item

来源：`Data/General/Item.json`

| 属性 | 值 |
|---|---|
| 关联运行时类型 | `ItemInfo` |
| 成员事件 | `onDrop`, `onUse` |

## Schema

| Field | Type | Default | Description | Reference |
|---|---|---|---|---|
| `name` | `string` | `""` | The display name of this item. | `—` |
| `desc` | `string` | `""` | The display description of this item. | `—` |
| `usable` | `bool` | `false` | Whether the item can be activated from the inventory and trigger onUse. | `—` |
| `price` | `int` | `0` | The gold price used when buying or selling the item in shops. | `—` |
| `icon` | `file` | `"Icons"` | The icon asset path relative to Assets. | `—` |
| `cost` | `bool` | `true` | Whether the inventory displays this item's stack count. | `—` |

## 编辑说明

应先添加字段，再大量创建成员。reference 控制选择器，但保存值仍使用声明的 JSON 形状。类型列出 events 时，每个成员可以在 `_graph` 下保存 graph；缺少 start node 表示该可选事件未实现。

`onUse` 由背包物品窗口触发。Enemy 掉落生成该 Item Actor 时会执行一次 `onDrop`；Item 不存在 `onGet` 事件。
