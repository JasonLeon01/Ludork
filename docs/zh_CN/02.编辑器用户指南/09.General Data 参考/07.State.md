# State

来源：`Data/General/State.json`

| 属性 | 值 |
|---|---|
| 成员事件 | `onWalk`, `onHookTriggered` |

## Schema

| Field | Type | Default | Description | Reference |
|---|---|---|---|---|
| `name` | `string` | `""` | The display name of this state. | `—` |
| `desc` | `string` | `""` | The display description of this state. | `—` |
| `icon` | `file` | `""` | 完整图标逻辑路径；选择根：`/Game/Assets/Icons`。 | `—` |
| `stackable` | `bool` | `false` | Whether adding this state again increases the existing state's stack count. | `—` |

## 编辑说明

应用 State 会创建 Infinite Gameplay Effect，并授予对应的事件 Ability（event ability）。`onWalk` 监听 `Event.Movement.Step`；`onHookTriggered` 需要通过 `Event.State.Trigger.<stateID>` 显式触发，或在 gameplay graph 中调用 `NodeFunctions.Gameplay.SendEvent`。添加或叠加 State 不会发出这个 hook；缺少 graph 起点时返回 `NoGraph`。
