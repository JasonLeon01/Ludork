# State

来源：`Data/General/State.json`

| 属性 | 值 |
|---|---|
| 成员事件 | `onWalk`, `onHookTriggered` |

## Schema

| Field | Type | Default | Description | Reference |
|---|---|---|---|---|
| `name` | `string` | `""` | The display name of this state. | `—` |
| `desc` | `string` | `""` | The display description of this state. | `—` |
| `icon` | `file` | `"Icons"` | The icon asset path relative to Assets. | `—` |
| `stackable` | `bool` | `false` | Whether adding this state again increases the existing state's stack count. | `—` |

## 编辑说明

应用 State 会创建 Infinite Gameplay Effect 并授予其 event ability。`onWalk` 监听 `Event.Movement.Step`；使用 `Event.State.Trigger.<stateID>` 显式触发 `onHookTriggered`，在 gameplay graph 内可调用 `NodeFunctions.Gameplay.SendEvent`。添加或叠加不会发出该 hook；缺少 graph start 时返回 `NoGraph`。
