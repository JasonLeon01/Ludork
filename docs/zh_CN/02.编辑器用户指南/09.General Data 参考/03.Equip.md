# Equip

来源：`Data/General/Equip.json`

| 属性 | 值 |
|---|---|
| 关联运行时类型 | `EquipInfo` |
| 成员事件 | `onEquip`, `onUnequip` |

## Schema

| Field | Type | Default | Description | Reference |
|---|---|---|---|---|
| `name` | `string` | `""` | The display name of this equipment. | `—` |
| `desc` | `string` | `""` | The display description of this equipment. | `—` |
| `icon` | `file` | `"Icons"` | The icon asset path relative to Assets. | `—` |
| `slot` | `string` | `""` | The Class slot key occupied by this equipment. | `—` |
| `attrPlus` | `Dict[string, int]` | `{}` | Attribute names mapped to integer modifiers applied while this equipment is equipped. | `—` |

## 编辑说明

应先添加字段，再大量创建成员。reference 控制选择器，但保存值仍使用声明的 JSON 形状。类型列出 events 时，每个成员可以在 `_graph` 下保存 graph；缺少 start node 表示该可选事件未实现。
