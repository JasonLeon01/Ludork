# Tileset、Autotile 与地图

## 目标

使用已验证 tileset、顺序正确的图层、灯光和已放置 Actor 实例创建地图，然后在没有无效引用的情况下保存并运行。

## Tileset 与 Autotile

使用 **数据库 → 图块集数据**（F6）定义 tileset 图片及其图块属性。Autotile 数据描述由 autotile 源图组合出的动画或连接图块。图片应放在 `Assets/Tilesets` 或 `Assets/Autotiles`，JSON 定义保存在对应的 `Data` 目录。

窗口通过 **Tilesets Data** 与 **AutoTiles** 两个页签分别管理普通定义和 Autotile。先在左侧列表选择定义，再修改名称，并使用 **File Name** 旁的浏览按钮从对应资源目录选择源图片。

主地图调色板中的 tileset 页签显示各定义的 `name`，JSON 文件名仍作为内部 key。重命名已被地图图层占用的 key 时，编辑器会列出受影响的地图文件，并询问是否在同一步 Undo 中更新这些地图的 `layerTileset` 引用；确认后会同时修改 key 与全部所列地图，取消则两者都不改变。

![显示逐图块通行属性的 Tilesets Data 页签](../../_images/editor/tilesets-data.png)

*在 Passable 模式中，圆圈表示可以通行，叉号表示不可通行。*

![显示整套通行属性的 AutoTiles 页签](../../_images/editor/auto-tile.png)

*Autotile 属性作用于完整源图，而不是显示出的每个源单元格。*

绘制前先确认图块尺寸和源区域。地图制作完成后再改变 tileset 定义，可能改变现有图块索引的含义。大幅修改地图尺寸、图层顺序或 tileset 后应立即测试。

地图 JSON 要求以 `layerOrder` 字符串数组作为权威绘制与 Actor 处理顺序；`layers` 和 `actors` 仍是以这些名称为键的字典，编辑器会保持数组同步。Runtime 加载拒绝缺失、重复或未列入顺序的图层，也不会从 JSON 对象键推断顺序。

普通 Tileset 提供 **Passable**、**Material** 与 **Dir4** 模式。鼠标左键单击会切换单个图块的通行属性、打开其材质编辑器，或切换距离点击位置最近的边所对应的方向。Shift+鼠标左键拖动会把按下位置的源图块属性复制到经过的所有单元格。当前模式决定复制内容：Passable 复制布尔值，Material 深拷贝完整材质，Dir4 复制全部四个方向。稀疏鼠标事件之间会自动补齐，一次拖动只形成一步 Undo。Autotile 只提供作用于整套资源的 **Passable** 和 **Material**，不提供该批量刷。

![地图编辑器中的图块面板与图层列表](../../_images/editor/tile-layers.png)

*图块面板与当前图层配合使用；所有绘制操作都会写入当前图层。*

## 地图列表与组合式大地图

地图列表包含普通地图和大地图。大地图行显示 `_world.json` 中的 `worldName`；展开后，直接子地图按可编辑的 `mapName` 显示，`_world.json` 保持隐藏。“大地图属性”修改大地图显示名称，“重命名大地图”则修改文件夹和 runtime 路径。子地图保留普通的“地图名称”字段，确保其文件仍可独立使用。选择大地图会打开拼合面板。右键菜单可创建各类资产。复制子地图会分配新的 Actor MapTag，但不自动摆放副本。

把未摆放子地图拖到大地图画布即可摆放；拖动可移动，Delete/Backspace 或右键菜单可移除。每次 placement 编辑形成一步 Undo/Redo，并拒绝重叠、越界或图层顺序冲突。

通过滚动或中键平移画布；Windows/Linux 使用 Ctrl+滚轮缩放，macOS 使用 Command+滚轮或捏合手势缩放。只读预览显示 Tile、Autotile 第一帧和时间零点的静态 Actor 图像，不播放 Actor 动画，也不绘制灯光、雾或地图图层 shader。

校验覆盖大地图清单、扁平目录结构、直接 JSON 地图、placement、图层顺序和全局 Actor MapTag 唯一性；非 JSON 普通文件会被忽略。会使 placement 失效的缩放直接被拒绝，不会自动移动或裁切；删除子地图会移除 placement。

重命名会在同一步 Undo 中更新[项目设置与资产布局](<02.项目设置与资产布局.md>)所述的可识别引用；仍有外部引用时禁止删除。File Explorer 保持 `Data/Maps` 层级：根地图、大地图目录和子地图不能跨层级或大地图移动。创建和删除应通过地图列表完成。

![地图属性窗口](../../_images/editor/map-properties.png)

*制作图层前，请先核对地图尺寸和所选 tileset。*

## 图层与绘制

图块模式支持图层新建、重命名、排序、复制、粘贴和删除；图层可指定 shader。选择 tileset 页签会立即修改活动图层的 tileset，图层中已有的图块索引随后按该 tileset 解释。在调色板选择普通图块或 autotile，在活动图层绘制，并使用擦除工具删除。缩放和平移不会修改地图数据。

每个图层标签左侧显示名称，右侧提供显隐按钮。显隐状态属于地图数据；隐藏图层不会渲染，并且为只读状态。

地图只使用一种图块画笔：鼠标左键拖动连续绘制所选图块或 autotile，Shift+鼠标左键拖动绘制实心矩形，鼠标右键点击取样目标单元格。一次画笔笔画或矩形只形成一次地图编辑与一步 Undo。隐藏图层会拒绝所有编辑入口，并显示只读提示。

## Light 与 Actor

切换到 Light 模式放置和编辑灯光，包括位置、颜色和半径。切换到 Actor 模式放置 Blueprint 实例、移动实例并编辑公开属性。实例可以覆盖类默认值，而不会修改 Blueprint 本身。

![灯光编辑模式](../../_images/editor/light-mode.png)

*Light 模式在地图上显示所选发光体及其半径范围。*

![Actor 编辑模式](../../_images/editor/actor-mode.png)

*Actor 模式修改已放置的 Blueprint 实例，不改变类默认值。*

Actor 灯光的 `LightComponent.lightOffset` 以 Actor 本地包围盒中心为基准，并应用完整的 Actor transform，因此发光点会跟随旋转和缩放。配置墙面火把时，应把 offset 放在房间一侧可见火焰的实际位置；渲染器不会把发光点自动移动到附近的可通行格。

`Material.lightBlock` 表示穿过一个 `CellSize` 厚度时的遮光率，合法范围为 `[0, 1]`。`0` 完全透光，`1` 完全阻断直射光，中间值会按实际穿透长度复合。例如 `0.5` 穿过半格、一格和两格时，透射率分别约为 `0.707`、`0.5` 和 `0.25`。

发光 Actor 只会从自身灯光的动态遮挡体中排除；它仍会遮挡其他灯光，同位置的 Tile 和其他 Actor 也不会被豁免。墙体和火把发光体不得合并为同一个 Actor，应分别使用墙体遮挡 Actor 与火把 Actor，否则排除发光体时也会一并排除墙体。

### 大地图中的 MapTag

在大地图子地图中新建或粘贴 Actor 时，默认 tag 会加上子地图文件名 stem 前缀，编辑器会在整个大地图内检查唯一性。子地图或大地图重命名不会改写已有或自定义 tag。复制子地图时，副本 tag 会改为 `<新子地图 stem>.<原 tag 主体>`，并同步更新匹配的 `BPClassVarChanged` key。

## 地图目标

`startMap` 文件字段和 Blueprint Transfer 选择器使用同一棵地图树。选择大地图时保存 `<大地图文件夹>/_world.json`，position 使用大地图格坐标；选择已摆放子地图时保存 `<大地图文件夹>/<子地图文件>.json`，position 使用该子地图的局部坐标，并由运行时换算为大地图坐标。未摆放子地图仍会显示在树中，但不能选作运行时目标。

## 限制

任意 string、自定义协议和动态拼接路径不会被改写；移动 tileset 同样不会修复玩法字符串。
