# 图块集、自动图块与地图

## 目标

使用通过校验的图块集、顺序正确的图层、灯光与已放置的 Actor 实例创建地图，保存时不得留下无效引用，并运行验证。

## 图块集与自动图块

使用 **数据库 → 图块集数据**（F6）定义图块集图片及其图块属性。自动图块数据描述由自动图块源图组合出的动画图块或连接图块。图片放在 `Assets/Tilesets` 或 `Assets/Autotiles`，JSON 定义则保存在对应的 `Data` 目录下。

窗口用 **Tilesets Data** 与 **AutoTiles** 两个页签分别管理普通图块集和自动图块。先在左侧列表选中一个定义，再修改其名称；需要更换源图时，用 **File Name** 旁边的浏览按钮，从对应的资产目录选择图片。

地图主调色板上的图块集页签显示各定义的 `name`，而 JSON 文件名仍然是它的内部 key。重命名已被地图图层使用的 key 时，编辑器会列出受影响的地图文件，询问是否在同一步 Undo 里更新这些地图的 `layerTileset` 引用：确认后 key 与所有列出的地图一起修改；取消则二者都不变。

![显示逐图块通行属性的 Tilesets Data 页签](../../_images/editor/tilesets-data.png)

*在 Passable 模式中，圆圈表示可以通行，叉号表示不可通行。*

![显示整套通行属性的 AutoTiles 页签](../../_images/editor/auto-tile.png)

*自动图块属性作用于完整的源图，而不是逐格显示出来的每个源单元格。*

动手绘制前，先确认图块尺寸与源区域。地图已经做好之后再改动图块集定义，可能改变现有图块索引的含义。大幅调整地图尺寸、图层顺序或图块集后，应立即进行测试。

地图 JSON 要求用 `layerOrder` 字符串数组作为绘制与 Actor 处理的权威顺序；`layers` 和 `actors` 仍是以这些名称作为键的字典，编辑器会保持数组与之一致。运行时加载会拒绝缺失、重复或未列入顺序的图层，也绝不会从 JSON 对象键去推断顺序。

普通图块集提供 **Passable**、**Material** 与 **Dir4** 三种模式。鼠标左键单击可切换单个图块的通行属性、打开它的材质编辑器，或切换点击位置最近的那条边所对应的方向。按住 Shift 拖动鼠标左键，会把按下起点处源图块的属性复制到拖过的所有单元格。复制的内容由当前模式决定：Passable 复制布尔值，Material 深拷贝整个材质，Dir4 复制全部四个方向。拖动期间指针移动稀疏的地方会自动补齐，一次拖动只形成一步 Undo。自动图块只有作用于整个资产的 **Passable** 与 **Material**，不支持这种批量刷。

![地图编辑器中的图块面板与图层列表](../../_images/editor/tile-layers.png)

*图块面板与当前图层配合使用；所有绘制操作都会写入当前图层。*

## 地图列表与组合式大地图

地图列表包含普通地图与大地图。大地图行显示 `_world.json` 中的 `worldName`；展开后，直接子地图按各自可编辑的 `mapName` 显示，`_world.json` 保持隐藏。“大地图属性”修改大地图的显示名称，“重命名大地图”则修改文件夹与运行时路径。子地图保留普通的“地图名称”字段，使它的文件仍能作为独立地图使用。选中大地图会打开拼合面板；右键菜单可以创建各类资产。复制子地图会为副本分配新的 Actor MapTag，但不会自动摆放副本。

把尚未摆放的子地图拖到大地图画布上即可完成摆放；拖动可以移动位置，按 Delete/Backspace 或使用右键菜单可以移除。每次摆放编辑都是一步 Undo/Redo，发生重叠、越界或图层顺序冲突时会被拒绝。

滚动或按住鼠标中键拖动即可平移画布；Windows/Linux 用 Ctrl+滚轮缩放，macOS 用 Command+滚轮或捏合手势缩放。只读预览会显示图块、自动图块的第一帧，以及时间零点处的静态 Actor 图像；它不播放 Actor 动画，也不绘制灯光、雾或地图图层 shader。

校验覆盖大地图清单、扁平的目录结构、直接 JSON 地图、摆放、图层顺序以及全局 Actor MapTag 唯一性；非 JSON 的普通文件会被忽略。会让摆放失效的缩放会直接被拒绝，不会自动去移动或裁切摆放；删除子地图会同时移除对应的摆放。

重命名会在同一步 Undo 中更新 [项目设置与资产布局](<02.项目设置与资产布局.md>) 所述的可识别引用；只要仍存在外部引用，就禁止删除。文件浏览器保持 `Data/Maps` 的层级：根地图、大地图目录与子地图不能跨层级或跨大地图移动；创建和删除都应通过地图列表完成。

![地图属性窗口](../../_images/editor/map-properties.png)

*开始制作图层前，先核对地图尺寸与所选图块集。*

## 图层与绘制

图块模式支持新建、重命名、排序、复制、粘贴和删除图层；图层还可以指定 shader。选中图块集页签会立即改变活动图层的图块集，图层中已有的图块索引将按新图块集解释。在调色板里选择普通图块或自动图块，在活动图层上绘制，需要擦除时使用擦除工具。缩放与平移不会修改地图数据。

每个图层页签左侧显示图层名，右侧是显隐按钮。显隐状态属于地图数据：隐藏的图层不会被渲染，而且处于只读状态。

地图只有一种图块画笔：按住鼠标左键拖动可连续绘制所选图块或自动图块；Shift+左键拖动绘制实心矩形；右键点击可取样目标单元格。一次笔画或一个矩形只算一次地图编辑，对应一步 Undo。隐藏的图层会拒绝所有编辑入口，并给出只读提示。

## 灯光与 Actor

切换到 Light 模式可放置并编辑灯光（位置、颜色与半径）；切换到 Actor 模式可放置 Blueprint 实例、移动实例并编辑其公开属性。实例可以覆盖类默认值，而不会改动 Blueprint 本身。

![灯光编辑模式](../../_images/editor/light-mode.png)

*Light 模式在地图上显示所选发光体及其半径范围。*

![Actor 编辑模式](../../_images/editor/actor-mode.png)

*Actor 模式修改已放置的 Blueprint 实例，不改变类默认值。*

Actor 灯光的 `LightComponent.lightOffset` 以 Actor 本地包围盒的中心为基准，并且会应用完整的 Actor transform，所以发光点会随旋转与缩放移动。配置墙面火把时，应把 offset 设在房间内侧、火焰可见的实际位置；渲染器不会自动把发光点挪到附近可通行的格子上。

`Material.lightBlock` 表示光穿过一个 `CellSize` 厚度时的遮光率，合法范围是 `[0, 1]`：`0` 完全透光，`1` 完全阻断直射光，中间值按实际穿过的路径长度复合。例如取 `0.5` 时，光穿过半格、一格、两格后的透射率分别约为 `0.707`、`0.5` 与 `0.25`。

发光 Actor 只会从它自己灯光的动态遮挡体里被排除；它仍然会遮挡其他灯光，同一位置上的 Tile 与其他 Actor 也不会因此豁免。墙体与其火把发光体不能合并成同一个 Actor：应分别使用一个墙体遮挡 Actor 和一个火把 Actor，否则排除发光体时会把墙体一起排除掉。

### 大地图中的 MapTag

在大地图的子地图里新建或粘贴 Actor 时，默认 tag 会加上子地图文件名的 stem 前缀，编辑器还会在整个大地图范围内检查唯一性。子地图或大地图重命名不会改写已有或自定义的 tag。复制子地图时，副本的 tag 会改成 `<新子地图 stem>.<原 tag 主体>`，并同步更新与之匹配的 `BPClassVarChanged` key。

## 地图目标

`startMap` 文件字段与 Blueprint Transfer 选择器使用同一棵地图树。选中大地图时保存 `<大地图文件夹>/_world.json`，position 使用大地图格子坐标；选中已摆放的子地图时保存 `<大地图文件夹>/<子地图文件>.json`，position 使用该子地图的局部坐标，由运行时再换算成大地图坐标。未摆放的子地图仍会出现在树中，但不能选作运行时目标。

## 限制

任意字符串、自定义协议和动态拼接的路径不会被改写；移动图块集同样不会修复玩法里的字符串。
