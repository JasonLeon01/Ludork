# 项目设置与资源布局

## 范围

本页定义编辑器用户在移动、检查或打包项目内容时必须保留的项目根设置与目录所有权。

```text
MyGame/
├── Main.proj
├── Main.ini
├── Assets/
├── Data/
│   ├── Animations/
│   ├── AutoTiles/
│   ├── Blueprints/
│   ├── CommonFunctions/
│   ├── Configs/
│   ├── Curves/
│   ├── General/
│   ├── Locale/
│   ├── Maps/
│   └── Tilesets/
├── Scripts/
│   ├── Entry.lua
│   ├── Mixins/
│   ├── Source/
│   │   └── Locale/
│   └── stub/
│       ├── Mixins/**/*.d.lua
│       └── Source/**/*.d.lua
└── Core/
```

## Main.proj

`Main.proj` 描述编辑器与打包能力。Sample 启用了 C++ runtime 和 FFmpeg，并保存首选运行窗口模式：

```json
{
  "Cpp": true,
  "ffmpeg": true,
  "IndividualWindow": true,
  "lastFileExplorerPath": "Data/Blueprints/Actors"
}
```

未知键可能属于编辑器状态，应予以保留。FFmpeg 模板必须与 `ffmpeg` 设置保持一致。

## Main.ini

`Main.ini` 保存面向游戏的设置，包括 `script`、`language`、缩放、帧率、垂直同步和音频开关/音量。Game Config 提供全屏（`scale = 0`）、`1`、`1.25`、`1.5`、`1.75` 和 `2`，缩放修改会立即生效。使用 Game Config 修改受支持字段。编辑器模式读取项目内的文件；打包游戏会在平台用户数据目录保存可变设置。

## Assets

资源路径相对于 `Assets`。建议使用约定目录，以便选择器和 metadata 提示正确过滤：`Tilesets`、`Autotiles`、`Characters`、`Animations`、`Icons`、`Fonts`、`Musics`、`Sounds`、`Voices`、`Shaders`、`Fogs`、`Transitions`、`System` 和 `Videos`。

移动资源不会自动修复所有已保存引用。移动或删除前先打开引用树，再手工更新受影响的数据。

## Data 与 Scripts

`Data` 保存编辑器生成的 JSON；`Data/Locale/Locale.xlsx` 是 Official Locale Tools 的本地化工作簿。`Scripts` 保存运行时 Lua、生成的 Core metadata 与 LuaLS 声明；插件生成的语言模块位于 `Scripts/Source/Locale`。普通 `.lua` 承载运行时逻辑，镜像的 `stub/**/*.d.lua` 承载公开文档和类型，运行时脚本旁的 `_meta.lua` 只声明编辑器纯数据。`_meta.lua` 与 `.d.lua` 都不是玩法模块。

手写声明应与对应运行时模块一同纳入版本控制。不得手改 `Engine_meta.lua`、`GlobalCore_meta.lua`、`GlobalFunctions_meta.lua` 或生成的 Core/LuaSF 声明。模板保留声明目录；打包会删除 `Scripts/stub` 并拒绝其他位置的 `.d.lua`。

## 验证

- 每次外部移动后打开项目，在继续保存其他改动前解决缺失引用。
- 确认 `Main.proj` capability 与所选模板一致。
- 改变 `Main.ini`、资产位置或入口脚本后，至少运行并打包一次。

## 限制

文件浏览器不能保证改写每个基于字符串的 runtime 引用。生成的 Core metadata 与声明属于 build 输出，手写 `.d.lua` 镜像运行时路径；玩法脚本旁的 `_meta.lua` 则只用于编辑器声明。
