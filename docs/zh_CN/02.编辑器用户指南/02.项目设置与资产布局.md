# 项目设置与资源布局

```text
MyGame/
├── Main.proj
├── Main.ini
├── Assets/
├── Data/
│ ├── Animations/
│ ├── AutoTiles/
│ ├── Blueprints/
│ ├── CommonFunctions/
│ ├── Configs/
│ ├── Curves/
│ ├── General/
│ ├── Locale/
│ ├── Maps/
│ └── Tilesets/
├── Scripts/
│ ├── Entry.lua
│ ├── Mixins/
│ ├── Source/
│ │ ├── Configs/
│ │ │ ├── GameVariables.lua
│ │ │ └── GameVariables_meta.lua
│ │ └── Locale/
│ └── stub/
│ ├── Mixins/**/*.d.lua
│ └── Source/**/*.d.lua
└── Core/
```

## Main.proj

`Main.proj` 描述编辑器与打包能力。Sample 启用了 C++ runtime 和 FFmpeg，并保存首选运行窗口模式：

```json
{
 "Cpp": true,
 "ffmpeg": true,
 "IndividualWindow": true,
 "lastFileExplorerPath": "Data/Blueprints/Actors"
}
```

未知键可能属于编辑器状态，应予以保留。FFmpeg 模板必须与 `ffmpeg` 设置保持一致。

## Main.ini

`Main.ini` 保存面向游戏的设置，包括 `script`、语言、缩放、帧率、抗锯齿等级、垂直同步和音频开关/音量（音效、语音、音乐）。抗锯齿默认使用 SFML 自身的上下文默认值，并在下次初始化显示时生效。缩放默认为 `1.0`；桌面 Config 提供全屏（`0`），并按显示器工作区过滤正数预设值，移动端则不显示缩放选项。使用 Game Config 修改受支持字段。编辑器模式读取项目内的文件；打包游戏会在平台用户数据目录保存可变设置。

## Assets

资源路径相对于 `Assets`。建议使用约定目录，以便选择器和 metadata 提示正确过滤：`Tilesets`、`Autotiles`、`Characters`、`Animations`、`Icons`、`Fonts`、`Musics`、`Sounds`、`Voices`、`Shaders`、`Fogs`、`Transitions`、`System` 和 `Videos`。

移动资源不会自动修复所有已保存引用。移动或删除前先打开引用树，再手工更新受影响的数据。

## Data 与 Scripts

`Data` 保存编辑器生成的 JSON；`Data/Locale/Locale.xlsx` 是 Official Locale Tools 的本地化工作簿。`Scripts` 保存运行时 Lua、生成的 Core metadata 与 LuaLS 声明；生成的语言模块位于 `Scripts/Source/Locale`。文件分层（`.lua`、`stub/**/*.d.lua`、`_meta.lua`）见 [Lua 运行时与模块](<../03.Lua 与蓝图脚本/01.Lua 运行时与模块.md>)。

Game Variable Manager 管理 `Scripts/Source/Configs/GameVariables.lua` 与 `GameVariables_meta.lua`；General Data 保存流程管理 `Scripts/Source/Configs/GeneralEnum.lua` 与 `Scripts/stub/Source/Configs/GeneralEnum.d.lua`。四者都是生成文件，不得手工修改。重新生成规则见 [General Data 与 Text Config](<05.General Data 与 Text Config.md>)。

不得手改 `Engine_meta.lua`、`GlobalCore_meta.lua`、`GlobalFunctions_meta.lua` 或生成的 Core/LuaSF 声明。打包会删除 `Scripts/stub` 并拒绝其他位置的 `.d.lua`。

## 验证

- 每次外部移动后打开项目，在继续保存其他改动前解决缺失引用。
- 确认 `Main.proj` capability 与所选模板一致。
- 分别修改一个游戏变量和一个 General Data 成员，并确认每对生成文件包含相同的有序名称。
- 改变 `Main.ini`、资产位置或入口脚本后，至少运行并打包一次。

## 限制

文件浏览器不能保证改写每个基于字符串的 runtime 引用。
