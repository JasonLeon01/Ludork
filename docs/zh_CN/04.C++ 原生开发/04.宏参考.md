# 宏参考

为受支持的绑定或原生 UI adapter 选择声明标记。详细选项语法见任务页与高级模式页。

| 宏 | 用途 |
|---|---|
| `BIND_CLASS` | 声明绑定类及唯一的模块根名称；`callbacks = true` 选择该类的非 static 虚绑定方法用于 C++ 到 Lua 派发 |
| `BIND_ENUM` | 把 C++ scoped enum 公开为一个模块根 Lua table 与 LuaLS 类型 |
| `BIND_FUNCTION` | 绑定自由函数；`outpins(...)` 与 `latent(...)` 为内联选项 |
| `BIND_FUNCTION_GROUP` | 把头文件中的绑定自由函数放入同一 table |
| `BIND_METHOD` | 绑定方法或 getter 属性；方法默认进入 metadata，除非 `metadata = false`；`callback = false` 会把虚方法排除在所属类的自动 callback 选择之外 |
| `BIND_PROPERTY` | 绑定实例数据属性 |
| `BIND_INIT` | 绑定构造函数 |
| `BIND_REGISTER_EVENT` | 注册蓝图事件入口 |
| `BIND_INJECT` | 在支持位置注入声明式绑定代码 |
| `BIND_MODULE_PROPERTY` | 公开模块级属性 |
| `BIND_CLASS_PROPERTY` | 公开类级属性 |
| `BIND_LUA_REVERSE` | 描述反向 Lua/C++ 适配 |
| `BIND_LUA_HELPER` | 声明可复用 Lua 绑定 helper |
| `BIND_MODULE_INIT` | 添加模块初始化行为 |

无需公开的声明不写绑定标记。类的转换选项见[绑定类](<02.绑定类.md#值转换契约>)。`invalid_vars(...)`、`rect_range_vars(...)` 等类装饰器写在 `BIND_CLASS` 内；循环协议使用内联 `loop_node(...)`，`BIND_REGISTER_EVENT()` 则单独声明。

可变参数 `BIND_*` 标记在 C++ 编译时展开为空。Bindgen 读取 `outpins(...)`、`latent(...)`、`nil`、`function` 等原始 token，这些 token 不能为了通过 C++ 解析而加引号。协议值一律使用小写 `nil`、`true` 与 `false`；`defaults` 与 `parameter_types` 使用花括号列表，结构化 `meta(...)` 与属性 `default` 使用可嵌套的花括号，而不是带引号的 JSON。

`BIND_CLASS` 会推断已声明的基类。`cast_bases = {"BaseA", "BaseB"}` 提供有序的额外祖先，不能写成逗号分隔的字符串。

`BIND_ENUM` 把 `enum class` 绑定为一个模块根 table。LuaLS 保留枚举类型，Lua 值与蓝图 Metadata 签名使用整数；`name` 可替换 table 标识符。

绑定类、未分组函数与模块属性只占用一条模块根路径，分组函数使用各自的 group table。`BIND_INJECT(global = ...)` 中的 `global` 是注入来源标识符。`variadic = true` 仅用于匹配的 vector 输入/输出 `std::function` 注入，它把尾部 vector 直接映射为 Lua 栈参数与返回值。

## 原生转换声明

在类的 public 区域，查询根类型声明 `LUDORK_CAST_ROOT(Type)`，派生类型声明 `LUDORK_CAST_DERIVED(Type, Bases...)` 并列出参与查询的直接基类。每个动态转换目标和每个多态绑定类都必须声明自身的宏；继承祖先的声明不会登记新类型。非多态值类型无需声明转换协议。生成的 Lua adapter 自动声明该协议，其公开宿主类仍须自行声明。

这些宏生成查询子对象地址的虚方法，以及 `std::string_view ludorkDynamicTypeKey() const noexcept`，不改变 Lua 名称或绑定基类。头文件要求与指针语义见[原生指针转换](<01.构建与模块布局.md#原生指针转换>)；Lua 包装遵循[原生对象包装](<09.运行时值边界.md#原生对象包装>)。

## 限制

表格只说明受支持的标记，不列出所有允许的选项组合。`Pure`、执行协议与属性声明仍受对应专页的校验规则约束。
