# 宏参考

为受支持的绑定或原生 UI adapter 选择声明标记。详细选项语法见任务页与高级模式页。

| 宏 | 用途 |
|---|---|
| `BIND_CLASS` | 声明绑定类及唯一的模块根名称；`callbacks = true` 选择该类的非 static 虚绑定方法用于 C++ 到 Lua 派发 |
| `BIND_ENUM` | 把 C++ scoped enum 公开为一个模块根 Lua table 与 LuaLS 类型 |
| `BIND_FUNCTION` | 绑定自由函数；`outpins(...)` 与 `latent(...)` 为内联选项 |
| `BIND_FUNCTION_GROUP` | 把头文件中的绑定自由函数放入同一 table |
| `BIND_METHOD` | 绑定方法或 getter 属性；方法默认进入 metadata，除非 `metadata = false`；`callback = false` 会把虚方法排除在所属类的自动 callback 选择之外 |
| `BIND_PROPERTY` | 绑定实例数据属性 |
| `BIND_INIT` | 绑定构造函数 |
| `BIND_REGISTER_EVENT` | 注册 Blueprint 事件入口 |
| `BIND_INJECT` | 在支持位置注入声明式绑定代码 |
| `BIND_MODULE_PROPERTY` | 公开模块级属性 |
| `BIND_CLASS_PROPERTY` | 公开类级属性 |
| `BIND_LUA_REVERSE` | 描述反向 Lua/C++ 适配 |
| `BIND_LUA_HELPER` | 声明可复用 Lua 绑定 helper |
| `BIND_MODULE_INIT` | 添加模块初始化行为 |

无需公开的声明不写 marker。`BIND_CLASS(dynamic_value = true)` 与 `BIND_CLASS(opaque_identity = true)` 选择生成的转换 trait。`invalid_vars(...)`、`rect_range_vars(...)` 等类 decorator 写在 `BIND_CLASS` 内；循环协议使用内联 `loop_node(...)`，`BIND_REGISTER_EVENT()` 则保持独立。

可变参数 `BIND_*` marker 在 C++ 编译时展开为空；bindgen 直接读取 `outpins(...)`、`latent(...)`、`nil`、`function` 等 token，不得仅为通过 C++ 解析而加引号。协议值使用小写 `nil`、`true`、`false`；`defaults` 与 `parameter_types` 使用花括号列表，结构化 `meta(...)` 和属性 `default` 使用可嵌套花括号而非带引号 JSON。通用转换支持放在 `LudorkRuntimeBinding/` 下；bindgen 不得按业务名添加特殊分支。

`BIND_CLASS` 会识别已声明基类；`cast_bases = {"BaseA", "BaseB"}` 提供有序的额外祖先，不能写成逗号分隔字符串。

`BIND_ENUM` 把 `enum class` 绑定为一个模块根 table。LuaLS 保留枚举类型，Lua 值与 Blueprint metadata 签名使用整数；`name` 可替换 table 标识符。

绑定类、未分组函数和模块属性只使用模块根路径，分组函数使用其 group table。
`BIND_INJECT(global = ...)` 中的 `global` 是注入来源标识符。`variadic = true` 仅用于匹配的 vector 输入/输出 `std::function` 注入，把尾部 vector 直接映射为 Lua 栈参数和返回值。

## 限制

表格只说明受支持标记，不列出所有允许的选项组合。`Pure`、执行协议与属性声明仍受对应专页的校验规则约束。
