# 宏参考

## 范围

通过本页为受支持的绑定或原生 UI adapter 选择声明标记。详细选项语法见任务页与高级模式页。

| 宏 | 用途 |
|---|---|
| `BIND_CLASS` | 声明绑定类及唯一的模块根名称 |
| `BIND_FUNCTION` | 绑定自由函数；`outpins(...)` 和 `latent(...)` 使用内联选项 |
| `BIND_FUNCTION_GROUP` | 把头文件中的绑定自由函数放入同一 table |
| `BIND_METHOD` | 绑定方法或 getter 属性；方法默认进入 metadata，除非 `metadata = false` |
| `BIND_PROPERTY` | 绑定实例数据属性 |
| `BIND_INIT` | 绑定构造函数 |
| `BIND_IGNORE` | 排除声明 |
| `BIND_REGISTER_EVENT` | 注册 Blueprint 事件入口 |
| `BIND_INVALID_VARS` | 隐藏无效/不适用于编辑器的字段 |
| `BIND_RECT_RANGE_VARS` | 为矩形字段增加纹理/范围语义 |
| `BIND_LOOP_NODE` | 描述循环节点协议 |
| `BIND_INJECT` | 在支持位置注入声明式绑定代码 |
| `BIND_MODULE_PROPERTY` | 公开模块级属性 |
| `BIND_CLASS_PROPERTY` | 公开类级属性 |
| `BIND_LUA_REVERSE` | 描述反向 Lua/C++ 适配 |
| `BIND_LUA_HELPER` | 声明可复用 Lua 绑定 helper |
| `BIND_MODULE_INIT` | 添加模块初始化行为 |
| `BIND_DYNAMIC_VALUE_TYPE` | 标记由动态值转换处理的类型 |
| `BIND_OPAQUE_IDENTITY_TYPE` | 标记必须保持不透明身份的类型 |
| `BIND_UI_CONTROL` | 声明一个原生声明式 UI 控件 adapter 及其目录属性 |

`BIND_METHOD(...)` 及其他可变参数绑定标记会在 C++ 编译器中展开为空。Bindgen 直接读取其中的 token，因此 `outpins(...)`、`nil`、`function`、`{nil, false}` 等注解专用 token 不需要具有 C++ 表达式或类型语义，也不得仅为通过 C++ 解析而加引号。命名执行分支使用 `outpins(...)`，latent 状态使用 `latent(...)`，协议值使用小写 `nil`、`true`、`false`。方法与自由函数的有序 `defaults`、`parameter_types` 使用花括号 token list，构造函数的 `defaults` 也使用同样形式。`meta(...)` 的结构化数据和单数属性 `default` 同样使用花括号：位置项组成数组，例如 `default = {0.0, 0.0}`；命名项组成对象，例如 `meta(Rely = {source = "autoSound", op = "!=", value = ""})`，并且可以嵌套。不得把完整数组或对象编码为带引号的 JSON。应沿用相邻声明已经建立的注解形式。额外转换能力必须放在通用 `LudorkCoreBinding` trait、递归 adapter 或声明中，不能在 bindgen 内按业务名写特殊分支。

绑定类、未分组函数和模块属性都只有一条模块根路径。原 `scope`/`scopes`、
`alias`/`aliases`、函数 `global`/`globals` 导出选项及直接 Lua 值别名注解均已
废弃，bindgen 会把它们报告为注解错误。`BIND_INJECT(global = ...)` 仍然有效，
因为这里的 `global` 指定注入来源，而不是额外导出。

## 验证

添加标记后重新构建，确认声明出现在所有适用的生成消费者中，且没有注解诊断。

## 限制

表格只说明受支持标记，不列出所有允许的选项组合。`Pure`、执行协议与属性声明仍受对应专页的校验规则约束。
