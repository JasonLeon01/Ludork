# 函数、事件与执行语义

## 目标

从同一声明源暴露方法、分组自由函数、事件与 Blueprint 执行协议。

## 前置条件

- 所属模块中已有绑定类或公开自由函数头文件。
- 已定义节点的 Pure、分支输出、Latent 状态或循环行为契约。

## 步骤

### 1. 绑定方法与自由函数

`BIND_METHOD` 向原生 Lua 与 LuaLS 公开类方法，逻辑公开的方法还会默认进入 Blueprint metadata。`BIND_FUNCTION` 公开自由函数，但不改变既有的 metadata 选择规则。只有 Blueprint 节点没有执行输入输出时才声明 `Pure = true`；非 void 返回不代表 pure。

```cpp
BIND_FUNCTION(name = "clampValue", Pure = true)
float clampValue(float value, float minimum, float maximum);
```

未分组自由函数只公开在模块根，例如 `Engine.clampValue`；`name` 用于选择该根字段的
Lua 标识符。当 group table 是函数的规范 owner 时，使用 `BIND_FUNCTION_GROUP`。

非 void 函数生成一个名为 `return` 的 metadata 输出；void 函数生成空 return table。

### 2. 指定函数组

只包含自由函数的头文件可以开头声明：

```cpp
BIND_FUNCTION_GROUP(name = "Manager")

BIND_FUNCTION(name = "playSE")
void playSE(const std::string &path);
```

该头中的所有绑定函数只注册到分组 table。C++ 注册、LuaLS stub 与 metadata 使用相同分组；未分组函数保留在模块根。

### 3. 声明执行行为

非 pure 方法默认使用普通执行流，不需要显式执行注解：

```cpp
BIND_METHOD()
void refresh();
```

返回结果需要选择命名执行分支时，把各分支写入内联 `outpins(...)`；bindgen 保留声明顺序：

```cpp
BIND_METHOD(outpins(default = nil))
void setCollisionEnabled(bool enabled);

BIND_METHOD(outpins(success = true, fail = false))
bool tryMove();
```

latent 工作把恢复状态写入 `latent(...)`：

```cpp
BIND_METHOD(latent(TimeUp = true),
            defaults = {nil, nil, {}, false},
            parameter_types = {float, function, any[], bool})
TimerHandle addTimer(float interval,
                     RuntimeIdentityPtr task = {},
                     RuntimeValue::Array params = {},
                     bool blocking = false);
```

`defaults` 描述参数默认值，与 `outpins(default = nil)` 无关；构造函数和自由函数的 `defaults` 同样使用该列表形式。小写 token 与花括号选项列表见[宏参考](<04.宏参考.md>)。

`Pure = true` 不能与执行协议组合。getter 属性也不能携带执行协议，其顶层单数 `default` 仍表示属性默认值。内联 `loop_node(ForEach)` 声明循环，独立的 `BIND_REGISTER_EVENT()` 创建事件入口；没有显式输出的事件使用默认分支值 `nil`。

显示、编辑器和执行信息写在 `BIND_METHOD(...)` 或对应函数/属性注解中。不支持独立的 metadata、pure、执行分支与 latent 标记。

## 限制

注解只描述执行协议，不实现 runtime 行为。C++ 函数体与 runtime 调度器必须实际产生每个已声明分支、Latent 状态或循环转换。
