# 原生 UI Adapter

## 目标

把原生控件加入 Ludork 声明式 UI 契约，使 runtime、preview host 与编辑器实时 Control Registry 对同一控件保持一致描述。

## 前置条件

- 一个 C++ Source 项目。
- 原生控件类型，以及用于创建、设置属性、测量、布局和挂载子控件的通用 adapter 操作。
- 已了解[声明式 UI 运行时契约](<../03.Lua 与蓝图脚本/05.声明式 UI/02.运行时契约.md>)。

## Descriptor 契约

`BIND_UI_CONTROL` 声明于 `Core/include/BindAnnotations.hpp`，由 `Core/Engine/include/UI/UiControlAdapterDescriptors.hpp` 消费。其逻辑签名为：

```cpp
BIND_UI_CONTROL(TAG, CONTROL_ID, ADAPTER, DISPLAY_NAME, CATEGORY,
                CHILD_POLICY, SLOT_TYPE, ...PROPERTIES)
```

| 参数 | 含义 |
|---|---|
| `TAG` | 用于特化 `UiControlAdapterTraits` 的唯一 C++ tag |
| `CONTROL_ID` | UI 资产序列化使用的稳定系统控件标识符；使用原生类的规范模块根路径 |
| `ADAPTER` | runtime adapter 标识符；使用同一条规范模块根路径 |
| `DISPLAY_NAME` | palette 显示名称 |
| `CATEGORY` | palette 分类 |
| `CHILD_POLICY` | `UiChildPolicy::None`、`Single` 或 `Multiple` |
| `SLOT_TYPE` | `UiControlSlotType::None`、`Canvas` 或 `List` |
| `...PROPERTIES` | 一个或多个属性 descriptor |

属性使用三类 descriptor 宏之一。`UI_CONTROL_COMMON_PROPERTY` 适用于所有控件；`UI_CONTROL_PROPERTY` 会写入资产并由 runtime adapter 消费；`UI_CONTROL_EDITOR_PROPERTY` 仅用于编辑器或 preview。每项声明包含 ID、schema 类型、required 标记和 JSON 默认值。

系统控件的两个路径字段必须完全一致。Engine 中绑定的 `Canvas` 同时以
`Engine.Canvas` 作为 `CONTROL_ID` 与 `ADAPTER`；嵌套或缩写路径无效。

## 步骤

1. 实现原生控件，并保持转换逻辑通用。不得在 bindgen 中增加按业务类型名或成员名分支的逻辑。
2. 在 `LUDORK_UI_CONTROL_DEFINITIONS` 中增加一项 `BIND_UI_CONTROL`。选择稳定的 control ID，并准确声明 child policy 与 Slot type。
3. 只声明实际支持的属性。复用现有递归 runtime-value 转换与资源处理；确需新类型时，扩展通用机制。
4. 在 `UiControlAdapterRegistry` 中注册 tag，提供 descriptor 所需的 factory、setter、arranger 与 child 函数。Registry 会从 descriptor 收集 adapter property ID。
5. 若控件需要编辑器侧 adapter，应通过现有共享契约更新对应 descriptor。不得另建一套 Registry，也不得硬编码 fingerprint。
6. 校验 descriptor 与 UI 资产：

   ```sh
   ScriptTools ui-adapter-check .
   ScriptTools ui-assets validate Sample
   ```

7. 构建项目，并在 UI Asset Editor 与 preview host 中打开代表性资产。

## 验证

- `ui-adapter-check` 报告各 descriptor 来源具有同一个 fingerprint。
- `ui-assets validate` 报告所有路径型 UI 资产有效。
- CMake 能构建 `Engine` target；其 `UiAssetValidate` 依赖也会执行以上两项检查。
- 资产会拒绝不受支持的属性和不合法的子控件数量。
- 只有 descriptor 声明对应 Slot type 时，runtime layout 才接受 `Canvas` 或 `List` Slot 数据。

## 限制

`BIND_UI_CONTROL` 用于描述原生 runtime 控件，不是编辑器插件扩展点。编辑器插件不能向宿主拥有的 UI Asset Editor palette 添加控件。`UiChildPolicy::None` 控件不能包含子控件，`Single` 最多接受一个子控件。
