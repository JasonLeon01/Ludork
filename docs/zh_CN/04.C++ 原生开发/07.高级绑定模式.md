# 高级绑定模式

本页面向无法用普通 class、property、method 与自由函数工作流表达的引擎基础设施。

## 类 Metadata decorator

类 decorator 嵌套在所属类注解中：

```cpp
BIND_CLASS(callbacks = true,
           invalid_vars(defaultRect, internalState),
           rect_range_vars(defaultRect = texturePath))
class Character : public Actor {
public:
  BIND_METHOD(metadata = false)
  virtual void _applyDirection(float x, float y);
};
```

`invalid_vars(...)` 隐藏字段，`rect_range_vars(...)` 关联矩形与资源/范围字段。两者只能在 `BIND_CLASS` 内接受有序标识符；属性自己的矩形语义仍在 `BIND_PROPERTY` 中写作 `meta(RectRangeVars = "texturePath")`。`metadata = false` 不会禁用 callback，应使用 `callback = false`。见[绑定类](<02.绑定类.md>)。

成员级编辑器 decorator 写在其所属注解内。结构化值使用花括号数据，而不是完整 JSON 字符串：

```cpp
BIND_PROPERTY(
    meta(Rely = {source = "autoSound", op = "!=", value = ""}))
float autoSoundInterval = 0.0f;

BIND_METHOD(defaults = {{}},
            meta(MoveRouteVars = {"route"}),
            outpins(default = nil))
void setRoute(
    const std::optional<std::vector<sf::Vector2i>>& route = {});
```

第一个值包含命名项，因此是对象；第二个值只包含位置项，因此是数组。完整花括号语法与带引号 JSON 的拒绝规则见[宏参考](<04.宏参考.md>)。

## 事件、Latent 与循环

```cpp
BIND_REGISTER_EVENT()
BIND_METHOD()
virtual void onCreate();

BIND_METHOD(latent(TimeUp = true),
            defaults = {nil, nil, {}, false},
            parameter_types = {float, function, any[], bool})
TimerHandle addTimer(float interval,
                     RuntimeIdentityPtr task = {},
                     RuntimeValue::Array params = {},
                     bool blocking = false);

BIND_METHOD(loop_node(ForEach))
void forEach(const RuntimeValue::Array &values);
```

Event、内联 latent 和 loop 注解会生成执行 metadata；C++/Lua 实现仍必须兑现所承诺的运行时协议（见[函数、事件与执行](<03.函数、事件与执行.md>)）。

## 值、反向表与 Helper

```cpp
BIND_MODULE_PROPERTY()
extern std::string LANGUAGE;

class FocusTransition {
public:
  BIND_CLASS_PROPERTY(readonly = true)
  static const std::string DIRECTIONAL;
};

BIND_LUA_REVERSE(path = "Input.KeyName", source = "sf.Keyboard.Key")
BIND_LUA_HELPER(kind = "cast", path = "Cast")
```

模块属性公开在模块根，类属性公开在所属类上。Bindgen 不会把已有 Lua 值重复
挂载到另一条运行时路径。reverse 声明在自身规范路径创建新的反向名称查找；
helper 使用通用 native 支持。`eval` helper 只求值调用方传入的表达式，可选 locals
优先于运行时全局变量。缺失或空表达式返回 `nil`；非空表达式的求值是同步的；从可 yield（可挂起）
协程中调用会立即报错。

## 初始化、注入与值 Trait

```cpp
BIND_MODULE_INIT()
void initialiseRuntimeServices(lua_State *state);

BIND_INJECT(global = "_LUDORK_BLUEPRINT_EVENT_VALIDATOR")
void setBlueprintEventValidator(BlueprintEventValidator validator);

BIND_CLASS(opaque_identity = true)
class RuntimeIdentity {};

BIND_CLASS(dynamic_value = true)
class RuntimeValue {};
```

`BIND_MODULE_INIT` 在打开模块时运行。`BIND_INJECT` 把 Lua 全局 callback 连接到 C++ setter，且只在该 Lua state 有效期间可用。启用 `variadic = true` 时，setter 必须接收 `std::function<std::vector<T>(Fixed..., const std::vector<T>&)>`；零返回值与中间或末尾的 `nil` 保持可区分，不使用封装 table。上面两个 `BIND_CLASS` flag 选择转换/身份 trait，不能与不兼容的 table-value 模式组合。引擎子系统使用强类型 runtime façade 与固定 provider 槽位，不得引入通用字符串 operation dispatcher。

## 限制

Bindgen 必须保持声明驱动。不得按玩法模块、类或成员名新增生成器分支，也不得用基础设施标记绕过不受支持的转换。
