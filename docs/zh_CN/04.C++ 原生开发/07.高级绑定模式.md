# 高级绑定模式

仅当引擎基础设施无法用普通 class、property、method 与自由函数工作流表达时，才使用这些模式。

## 类 Metadata decorator

紧邻类或成员的 decorator 会合并到同一个生成 metadata 条目：

```cpp
BIND_INVALID_VARS(vars = "defaultRect,internalState")
BIND_RECT_RANGE_VARS(defaultRect = texturePath)
BIND_CLASS(callbacks = true)
class Character : public Actor {
public:
 BIND_METHOD(metadata = false)
 virtual void _applyDirection(float x, float y);
};
```

`BIND_INVALID_VARS` 隐藏字段，`BIND_RECT_RANGE_VARS` 关联矩形与资源/范围字段。`metadata = false` 不会禁用 callback，应使用 `callback = false`。见[绑定类](<02.绑定类.md>)。

成员级编辑器 decorator 写在其所属注解内。结构化值使用花括号数据，而不是完整 JSON 字符串：

```cpp
BIND_PROPERTY(
 meta(Rely = {source = "autoSound", op = "!=", value = ""}))
float autoSoundInterval = 0.0f;

BIND_METHOD(defaults = {{}},
 meta(MoveRouteVars = {"route"}),
 outpins(default = nil))
void setRoute(
 const std::optional<std::vector<sf::Vector2i>>& route = {});
```

第一个值包含命名项，因此是对象；第二个值只包含位置项，因此是数组。完整花括号语法与带引号 JSON 的拒绝规则见[宏参考](<04.宏参考.md>)。

## 事件、Latent 与循环

```cpp
BIND_REGISTER_EVENT()
BIND_METHOD()
virtual void onCreate();

BIND_METHOD(latent(TimeUp = true),
 defaults = {nil, nil, {}, false},
 parameter_types = {float, function, any[], bool})
TimerHandle addTimer(float interval,
 RuntimeIdentityPtr task = {},
 RuntimeValue::Array params = {},
 bool blocking = false);

BIND_LOOP_NODE(ForEach)
BIND_METHOD()
void forEach(const RuntimeValue::Array &values);
```

Event、内联 latent 和 loop 注解会生成执行 metadata；C++/Lua 实现仍必须真正实现所承诺的 runtime 协议（见[函数、事件与执行](<03.函数、事件与执行.md>)）。

## 值、反向表与 Helper

```cpp
BIND_MODULE_PROPERTY()
extern std::string LANGUAGE;

class FocusTransition {
public:
 BIND_CLASS_PROPERTY(readonly = true)
 static const std::string DIRECTIONAL;
};

BIND_LUA_REVERSE(path = "Input.KeyName", source = "sf.Keyboard.Key")
BIND_LUA_HELPER(kind = "cast", path = "Cast")
```

模块属性公开在模块根，类属性公开在所属类上。Bindgen 不会把已有 Lua 值重复
挂载到另一条 runtime 路径。reverse 声明在自身规范路径创建新的反向名称查找；
helper 使用通用 native 支持。`eval` helper 只求值调用方传入的表达式，可选 locals
优先于 runtime 全局值。缺失或空表达式返回 `nil`；非空求值是同步边界，从可 yield
协程调用会立即报错。

## 初始化、注入与值 Trait

```cpp
BIND_MODULE_INIT()
void initialiseRuntimeServices(lua_State *state);

BIND_INJECT(global = "_LUDORK_RUNTIME_RESOLVER", variadic = true)
void setRuntimeResolver(RuntimeResolver resolver);

class RuntimeIdentity {
public:
 BIND_OPAQUE_IDENTITY_TYPE();
};

class RuntimeValue {
public:
 BIND_DYNAMIC_VALUE_TYPE();
};
```

`BIND_MODULE_INIT` 在打开模块时调用声明的初始化函数。`BIND_INJECT` 把受支持 Lua 全局回调连接到 C++ setter。启用 `variadic = true` 时，setter 参数必须是 `std::function<std::vector<T>(Fixed..., const std::vector<T>&)>`：bindgen 依次压入固定参数和 vector 中的每个值，并把全部 Lua 返回值收集到结果 vector。Lua 栈会保留零返回值以及中间或末尾的 `nil`，因此该形式不得再创建参数或结果包络 table。dynamic-value 与 opaque-identity trait 选择通用转换/身份规则；它们不是普通 usertype，也不能与不兼容的 table-value 模式组合。

runtime resolver 具有明确的会话生命周期。只有 Lua state 与必需服务准备完成后才能安装非空 callback，并应在该 state 失效前清除。没有安装 resolver、会话正在停止、服务未注册或 operation 不受支持时，调用都会立即抛错。零返回值与单个 `nil` 仍是不同结果；固定结果的 C++ helper 会强制恰好一个返回值并校验其声明类型，void operation 则强制恰好零个返回值。

## 限制

Bindgen 必须保持声明驱动。不得按玩法模块、类或成员名新增生成器分支，也不得用基础设施标记绕过不受支持的转换。
