# 运行时值边界

根据 API 接受的值及其所有权要求选择类型。

| 需求 | 类型 |
|---|---|
| 字段固定，或可选项是一组具名常量 | 结构体、枚举或具体的 C++/SFML 类型 |
| 值只可能属于几种类型 | `std::variant<T...>` |
| 值可能缺失 | `std::optional<T>`；nil 是 variant 分支时使用 `std::monostate` |
| 不依赖 VM 的递归 JSON 兼容数据 | `RuntimeData` |
| 持有已知类型的原生对象 | 对应类型的指针，按需要选择共享指针或弱指针 |
| 接受任意脚本值，包括原生对象和引用 | `RuntimeValue` |
| 保留 Lua 对象身份，用于相等比较、订阅或后续调用 | 绑定到单个会话的 `RuntimeHandle` 或 `RuntimeIdentityPtr` |

事件载荷、蓝图引脚和共享玩法上下文等需要接受任意脚本值的接口，可使用 `RuntimeValue`。进入类型要求明确的算法前，再转换为具体类型。缺失值、零和空容器应有各自明确的含义。

## Lua 值转换

Lua 直接调用时，传入 `std::variant` 某个分支所需的实际值，无需额外封装。Lua 整数优先匹配整数分支，浮点数优先匹配浮点分支，不会把小数截断为整数。字符串和布尔值必须与声明类型一致；不同的原生 SFML 类型即使数据形状相同，也不会混为一类。

`RuntimeData` 和 `BIND_CLASS(pure_data = true)` 使用纯数据转换：接受 nil、已注册的 JSON null 标记值、布尔值、有限数值、字符串、无环数组和字符串键字典；拒绝函数、原生对象、循环结构、非法键和未识别的元表。

空 Lua 表 `{}` 表示字典，`{ n = 0 }` 表示空数组。非负整数 `n` 用于保留数组长度和 nil 空位，转换输出的数组也会包含 `n`。已注册的 JSON 数组元表同样受支持。字典中的 null 值需使用已注册的 JSON null 标记值，才能保留对应的键。

## 容器与视图

`RuntimeData` 持有不依赖 VM 的数据，副本在修改时分离。`RuntimeValue` 还可以持有不依赖 VM 的原生对象或绑定到会话的 Lua 句柄。其 `Array` 为 `std::vector<RuntimeValue>`，`Map` 为 `std::unordered_map<std::string, RuntimeValue>`。从 `RuntimeData` 构造时共享容器，从 Array/Map 构造时接收容器所有权。

通过 `value.view().array()` 或 `.map()` 读取容器，返回值是可选的借用视图。数组索引和遍历得到 `RuntimeValueView`；Map 的 `find` 可区分键不存在和键对应的值为 nil。使用视图或借用字符串期间，源值必须始终存活且未被修改，也不能从临时值获取此类视图。需要持有数据时，使用 `toValue()`、`toArray()` 或 `toMap()`。

`getMutableIf<Array/Map>()` 按需将待修改的容器转换为可写形式，或将其与共享数据分离。`toData()` 共享已有的 Data 分支，或递归转换桥接容器；遇到原生对象或句柄时会报错。

## Lua 引用与会话生命周期

普通参数和返回值直接传递 `RuntimeValue`。需要显式转换或操作 Lua 引用时，使用 `<Runtime/RuntimeReference.hpp>`：

| 操作 | 行为 |
|---|---|
| `intern` | 获取 `get`、`set`、`invoke` 所需的句柄；复用已有句柄，或将持有数据的容器转换为新的 Lua 表 |
| `retain` | 保留标量和已有的非标量句柄，将持有数据的容器转换为新的 Lua 表 |
| `snapshot` | 复制普通的无环数组或字符串键字典，并保留其中的函数和对象引用；其他表及 opaque-identity 绑定保留原始身份 |
| `data` | 转换为纯数据；原生对象和无法转换的引用会报错 |

快照转换通过 `n` 保留数组长度，字典中值为 nil 的字段会被省略。快照与类、实例默认值的复制是不同的操作。

调用保留所有返回值，包括中间和末尾的 nil，并向调用方传播错误。句柄不能跨 VM 使用，所属会话关闭后即失效。用空句柄或空身份指针构造 `RuntimeValue` 时，结果为 nil。
