# 运行时值边界

依据 API 接受的值与所有权要求选择类型。

| 需求 | 类型 |
|---|---|
| 字段固定，或取值限于一组具名选项 | 结构体、枚举或具体的 C++/SFML 类型 |
| 值只可能属于有限几种类型 | `std::variant<T...>` |
| 值可能缺失 | `std::optional<T>`；nil 是 variant 分支时使用 `std::monostate` |
| 不依赖 VM 的递归 JSON 兼容数据 | `RuntimeData` |
| 持有已知类型的原生对象 | 对应类型的指针，按需要选择共享所有权或弱所有权 |
| 接受任意脚本值，包括原生对象和引用 | `RuntimeValue` |
| 保留 Lua 对象身份，用于相等比较、订阅或后续调用 | 绑定到单个会话的 `RuntimeHandle` 或 `RuntimeIdentityPtr` |

事件载荷、蓝图引脚、共享玩法上下文这类开放的脚本边界使用 `RuntimeValue`。进入契约固定的算法之前，先转换为具体类型。缺失值要与零和空容器区分开来。

## 原生编译契约

`<Runtime/TypeSchema.hpp>` 定义递归的原生类型描述。`TypedDataService::compileType` 解析脚本描述，`resolveTypedDataValue` 与 `resolveRuntimeTypedValue` 的确定类型重载复用解析结果。编译后的 `NodeDefinition` 按顺序保存参数描述，由 DataNode、模板与实例共享。每个参数在首次需要校验时编译 schema。接收可变类型表的公开调用仍在每次调用时解析传入的描述。

蓝图事件描述、生成类初始化计划与组件字段映射使用原生记录。原生图服务传递 `std::shared_ptr<Graph>`。固定 Actor 事件在分发需要脚本值之前保留确定类型的参数。开放图引脚、默认值、多返回值、共享局部上下文与用户字段继续保持动态值语义。

复制原生组件时，按声明类型重建记录值后再校验；调用方写入组件字段时仍执行严格校验。

`RuntimeNumber` 是原生 `std::variant<std::int64_t, double>` 数值类型，`GameplayNumber` 也使用它。AttributeSet 数值访问在 Lua 字段边界转换，AbilitySystem 快照与通知在内部保留该数值类型。Current 值仍存储在 Lua 字段中，包括直接写入与 monitor 通知。

组件与事件描述缓存保留 Lua 弱键索引。私有 userdata 持有原生记录，关联 Lua 值存放在 userdata 的 uservalue 中，让 GC 与热重载能够跟踪。C++ 弱指针不等于 Lua 弱引用。会话所属的类记录保留明确引用，并在关闭时清理。`ClassDict:getData` 继续返回原始共享定义表，修改该表不会改变已编译的默认值或图模板。

## Lua 值转换

Lua 直接调用时，`std::variant` 的某个分支按其实际值传入，不带任何包装。Lua 整数优先匹配整数分支，浮点数优先匹配浮点分支。小数绝不会被截断成整数。字符串与布尔值必须是对应的 Lua 类型。原生 SFML 类型即使取值形状相同，也始终保持彼此独立。

`RuntimeData` 与 `BIND_CLASS(pure_data = true)` 使用纯数据转换：接受 nil、已注册的 JSON null 标记值、布尔值、有限数值、字符串、无环数组与字符串键映射。它拒绝函数、原生对象、循环结构、非法键以及未识别的元表。

空的 Lua 表 `{}` 是映射，`{ n = 0 }` 是空数组。非负整数 `n` 保留数组长度与 nil 空洞，输出的数组也会带上它。已注册的 JSON 数组元表同样接受。映射中的 null 项使用已注册的 JSON null 标记值，以保留对应的键。

## 原生对象包装

返回共享原生对象时，先复用已有的 Lua owner。原包装被回收后，提供[原生 Cast 协议](<04.宏参考.md#原生转换声明>)的来源通过 `ludorkDynamicTypeKey()` 选择已注册的 writer。writer 接收来源的静态类型键，以及指向其子对象的别名共享指针。生成的转换基类集合支持经过编译期检查的静态指针回转，包括多重继承中的非零地址偏移，同时保留原控制块。

缺少 writer 或来源类型不受支持时，使用普通的静态类型包装。`sf::Drawable` 等外部基类未提供 Cast 协议且没有现存 Lua owner 时，也遵循该规则。非多态值类型使用声明的静态类型，不登记动态 writer。

包装登记公开类型及所有转换基类的子对象地址，以保持重复返回时的 Lua 对象身份。Lua 回调 adapter 通过 Cast 协议释放捕获的引用。不透明 Lua 引用保留原值，并遵循[会话生命周期规则](<#lua-引用与会话生命周期>)。

## 容器与视图

`RuntimeData` 持有与 VM 无关的数据，副本在修改时分离。`RuntimeValue` 还可以持有与 VM 无关的原生对象，或持有绑定到会话的 Lua 句柄。它的 `Array` 是 `std::vector<RuntimeValue>`，`Map` 是 `std::unordered_map<std::string, RuntimeValue>`。从 `RuntimeData` 构造时共享其容器，而 Array 与 Map 构造函数取得所有权。

通过 `value.view().array()` 或 `.map()` 读取容器，得到的是可选的借用视图。数组索引与遍历产生 `RuntimeValueView`，Map 的 `find` 能区分键不存在与键对应的值为 nil。视图或借用字符串在使用期间，源值必须保持存活且未被修改。视图不能取自临时的持有型值。需要所有权时，改用 `toValue()`、`toArray()` 或 `toMap()`。

`getMutableIf<Array/Map>()` 会物化待修改的容器，或把它从共享数据中分离。`toData()` 共享已有的 Data 分支，或递归转换桥接容器；遇到原生对象与句柄时会拒绝。

## Lua 引用与会话生命周期

普通参数与结果传递直接保留 `RuntimeValue`。需要显式转换与 Lua 引用操作时，使用 `<Runtime/RuntimeReference.hpp>`：

| 操作 | 行为 |
|---|---|
| `intern` | 获取 `get`、`set`、`invoke` 所需的句柄；复用已有句柄，或将持有数据的容器转换为新的 Lua 表 |
| `retain` | 保留标量和已有的非标量句柄，将持有数据的容器转换为新的 Lua 表 |
| `snapshot` | 复制普通的无环数组或字符串键映射，并保留其中的函数与对象引用；其他表及 opaque-identity 绑定保留原始身份 |
| `data` | 转换为纯数据；原生对象和无法转换的引用会被拒绝 |

快照转换通过 `n` 保留数组长度，映射中值为 nil 的字段会被省略。快照与类、实例默认值的复制是不同的操作。

调用保留所有返回值，包括中间和末尾的 nil，并向调用方传播错误。句柄不能跨 VM 使用，所属会话关闭后即失效。用空句柄或空身份指针构造 `RuntimeValue` 时，结果为 nil。
