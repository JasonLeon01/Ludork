# C++ 原生开发

当 Lua 与 Blueprint API 不足、需要新的原生 UI adapter，或需要生成 iOS/HarmonyOS/Android 构建时，使用 C++ Source 项目。运行时使用 C++20、CMake 与声明驱动绑定。

## 开发顺序

1. [构建与模块布局](<01.构建与模块布局.md>)
2. [绑定类](<02.绑定类.md>)
3. [函数、事件与执行](<03.函数、事件与执行.md>)
4. [宏参考](<04.宏参考.md>)
5. [生成 Metadata 与 Stub](<05.生成 Metadata 与 Stub.md>)
6. [故障排除](<06.故障排除.md>)与[高级绑定模式](<07.高级绑定模式.md>)
7. [原生 UI Adapter](<08.原生 UI Adapter.md>)

一份公开声明必须同时驱动 C++ 注册、LuaLS stub 与编辑器 metadata。不得修改生成输出，也不得在生成器内新增以玩法模块、类型或成员名为条件的分支。
