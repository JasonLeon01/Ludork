# 生成 Metadata 与 Stub

生成文件属于构建产物，不得手工修改。

一份声明生成四类输出：

1. 稳定的 `<Module>.<NativeClass>.auto.cpp` 注册单元，以及原生 Lua 模块使用的唯一 `<Module>.stub.auto.cpp`；
2. Lua 语言工具使用的 `Scripts/stub/<Module>.d.lua`；
3. 编辑器使用的 `Scripts/<Module>_meta.lua`，包括生成的 Engine、GlobalCore 与 GlobalFunctions 目录。
4. `<Module>.traits.auto.hpp`，由所属原生模块私有强制包含，聚合声明与 type registry 中的 dynamic-value 和 opaque-identity trait。

这些输出必须在规范模块路径、类名、函数分组与参数顺序上保持一致。Metadata 还携带 Blueprint 执行信息与编辑器信息。

类文件名由完整限定 C++ 类型名决定，不受 Lua `name` 选项影响。`<Module>.stub.auto.cpp` 负责模块注册、按绑定顺序调用类单元，并提供 LuaLS stub 写入函数。

所有逻辑公开的 `BIND_METHOD` 都会进入 metadata。`metadata = false` 只用于内部 helper 和次要适配重载，不影响原生注册或 LuaLS stub。Bindgen 会拒绝同一类型中重复公开的 metadata 方法名，而不是静默覆盖条目。

生成的 stub 在模块根声明类、未分组函数和模块属性，例如 `Engine.ListView`。分组函数位于 `BIND_FUNCTION_GROUP` 声明的 table 中。嵌套 C++ 类型的命名规则见[绑定类](<02.绑定类.md#5-绑定宿主专用的嵌套类型>)。

每个 `BIND_ENUM` 只拥有一个模块根 table；LuaLS 保留其名义类型，运行时值与 Blueprint metadata 签名使用底层整数。

Core bindgen 会完整保留多行 `///` 文档的全部内容（含空段落与 Doxygen 命令起始行），对普通成员与 `Pure = true` 成员均不丢弃。生成 `.d.lua` 时，`\brief`、`\param`、`\return`、`\see`、`\code`/`\endcode`、警告与行内格式等已识别 Doxygen 命令会转成对应 `@` 形式；路径等普通反斜杠保持不变。LuaSF 生成 `Scripts/stub/LuaSF.d.lua` 时使用相同规则。

## 默认值与类型

Bindgen 只能从安全的布尔、数值、字符串或空 table 成员初始化器推导默认值；显式复杂默认值使用注解语法本身支持的花括号纯数据；带引号的 JSON 数组与对象会被拒绝。Core 对象引用使用完整模块/类型二元组，数组在类型项后添加 `[]`。

LuaSF 会通过 CMake 导出绝对路径 `LUASF_CALLBACK_CODECS_FILE`。对于 Lua 调用约定不同于规范 `std::function` 类型的 callback alias，Core bindgen 会读取这份带 schema 版本的 manifest。选择发生在规范展开之前，并使用声明处的语义 alias；另一个具有相同 C++ 签名的无关 alias 不会继承该 codec。Manifest 提供 codec、具名 Lua 类型与精确 Lua 签名，因此 Core binding 代码和 ScriptTools 都不再保存 SFML callback 签名表。Codec-aware 转换会递归组合 `vector`、`array`、`optional`、`variant`、`pair`、`map` 与 `tuple` 参数和返回值，并在每个 callback 叶节点保留对应 policy。Manifest 或相邻的 `sfml_api.json` 缺失、schema 不受支持、selector 重复、方向不匹配或不允许的 `nil` 都会立即终止生成；生成的 codec 使用点还会同时依据 manifest 与 LuaSF API 断言 alias 的规范类型，因此陈旧的规范类型会在 binding 可用之前终止编译。

## 重新生成

运行普通 CMake 构建即可新增、更新或删除生成类单元和模块输出。Bindgen 只写入变化内容，未变化文件保留原名与时间戳。输出似乎过期时，确认注解头文件属于该模块配置的公开头集合，检查生成器诊断并重新构建。

即使生成内容未变化，修改被包含的头文件仍可能重新编译依赖它的类单元。

“Blueprint API 参考”页面记录 metadata 目录，完整脚本 API 请查阅 LuaLS stub。
