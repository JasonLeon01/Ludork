# 生成 Metadata 与 Stub

生成文件属于构建产物，不得手工修改。

一份声明供三个消费者使用：

1. 原生 Lua 模块使用的生成 sol2 注册；
2. Lua 语言工具使用的 `Scripts/stub/<Module>.d.lua`；
3. 编辑器使用的 `Scripts/<Module>_meta.lua`，包括生成的 Engine、GlobalCore、GlobalFunctions catalogue（CoreSystem metadata catalogue 为空）。

三者必须在唯一规范模块路径、类名、函数分组与参数顺序上保持一致。Metadata 还携带 Blueprint 执行语义和编辑器信息。

所有逻辑公开的 `BIND_METHOD` 都会进入 metadata。`metadata = false` 只用于内部 helper 和次要适配重载，不影响原生注册或 LuaLS stub。Bindgen 会拒绝同一类型中重复公开的 metadata 方法名，而不是静默覆盖条目。

生成的 stub 只在模块根声明每个绑定类、未分组函数和模块属性。例如
`ListView` 只公开为 `Engine.ListView`，不生成嵌套字段、重复值赋值或 runtime 路径类型别名。
文件级 `BIND_FUNCTION_GROUP` 声明拥有 group table，分组函数只出现在该 table 中。不得手写重复路径。

Core bindgen 会完整保留多行 `///` 文档的空段与命令行，并且不会丢弃 `Pure = true` 成员的文档。生成 `.d.lua` 时，`\brief`、`\param`、`\return`、`\see`、`\code`/`\endcode`、警告与行内格式等已识别 Doxygen 命令会转成对应 `@` 形式；路径等普通反斜杠保持不变。LuaSF 生成 `Scripts/stub/LuaSF.d.lua` 时使用相同规则。

## 默认值与类型

Bindgen 只能从安全的布尔、数值、字符串或空 table 成员初始化器推导默认值；显式复杂默认值使用注解原生的花括号纯数据，带引号的 JSON 数组和对象会被拒绝。Core 对象引用使用完整模块/类型二元组，数组在类型项后添加 `[]`。

LuaSF 会通过 CMake 导出绝对路径 `LUASF_CALLBACK_CODECS_FILE`。对于 Lua 调用约定不同于规范 `std::function` 类型的 callback alias，Core bindgen 会读取这份带 schema 版本的 manifest。选择发生在 canonical 展开之前，并使用声明处的语义 alias；另一个具有相同 C++ 签名的无关 alias 不会继承该 codec。Manifest 提供 codec、具名 Lua 类型与精确 Lua 签名，因此 Core binding 代码和 ScriptTools 都不再保存 SFML callback 签名表。Codec-aware 转换会递归组合 `vector`、`array`、`optional`、`variant`、`pair`、`map` 与 `tuple` 参数和返回值，并在每个 callback 叶节点保留对应 policy。Manifest 或相邻的 `sfml_api.json` 缺失、schema 不受支持、selector 重复、方向不匹配或不允许的 `nil` 都会立即终止生成；生成的 codec 使用点还会同时依据 manifest 与 LuaSF API 断言 alias 的 canonical 类型，因此陈旧 canonical 类型会在 binding 可用前终止编译。

## 重新生成

运行普通 CMake 构建。输出似乎过期时，确认注解头文件属于该模块配置的公开头集合，检查生成器诊断，并从项目 build 目录重新构建。不要修补生成文件，因为下次构建会覆盖。

“Blueprint API 参考”页面是 metadata 清单，不替代 LuaLS stub。显式标记为 `metadata = false` 的成员仍可供脚本使用，但不会进入节点目录。

## 验证

针对每个变化的公开成员，对比 runtime 路径、LuaLS 声明与 metadata 条目。对于 manifest 选择的 callback，还要对比 C++ 使用点的 alias、生成的 codec 调用与 `LuaSF.d.lua` 中的具名类型，不能接受内联 `fun(...: any): any` 代替。确认多行文档完整，已识别 Doxygen 命令没有残留反斜杠前缀。运行模块 bindgen 校验，再执行一次无源码变更构建。

## 限制

Blueprint metadata 会按设计省略 `metadata = false` 成员，这不属于生成漂移。生成参考说明声明，不证明其实现的 runtime 正确性。
