# Script Mixin Metadata

与脚本同名的 `_meta.lua` 文件必须返回 `_METADATA`，且其中只能有一个名称与脚本文件名一致的类型。它只为单个挂载行为暴露可编辑字段，不声明运行时方法、Blueprint 节点入口或继承层级。

```lua
local _METADATA = {
    KeyDoor = {
        attrs = {
            "needKeyID",
            "needKeyCount",
        },
        needKeyID = {
            type = "string",
            default = "",
            Meta = {
                GeneralDataVars = "Item",
            },
        },
        needKeyCount = {
            type = "int",
            default = 1,
        },
    },
}

return _METADATA
```

## 规则

- `attrs` 是不含空洞、有序且值唯一的非空字段名数组。
- 每个列出字段都是带有效 `type` 的 table。
- `default` 如果存在，必须是有限、无循环且可转为 JSON 的纯数据。
- `bases` 应缺省或为空 table。基类由 Blueprint 继承提供。
- 根对象不得包含第二个类型、函数、userdata、协程或外部状态访问。
- `Meta.GeneralDataVars`、`Meta.PathVars` 和 `Meta.ConfigVars` 等 Decorator 用于细化编辑器控件，不改变运行时值。`Meta.InstVar` 选择已声明的游戏变量名，可选用 `types` 过滤；`Meta.InstVarValue` 指名同级的一个字段，由该字段的已选声明控制值编辑器。

## 限制

既不在已保存的 attribute 中、也没有 `default` 的字段，只表示 schema（无默认值）。
