# Script Mixin 运行时契约

运行时把选定脚本作为 `Mixins.<点分路径>` 模块加载，并要求它返回一个不带 metatable 的 table。本契约约束生成 Blueprint 类成员、实例默认值、保留名称与父方法分派。

## Table 规则

- 每个键必须是字符串。
- 函数会成为生成 Blueprint 类的方法。
- 非函数值会深复制到类默认值与实例默认值。
- 继承成员不能从字段变成函数，也不能从函数变成字段。
- 已保存的 Blueprint 属性不能替换 Mixin 方法。

以下名称保留：

```text
__* init new scriptMixin scriptPath
_GENERATED_CLASS _graph _hasImplementationOwner
```

由于 `init` 是保留名，Direct Script Mixin 不声明构造函数。私有实例状态应在所属类型提供的生命周期回调（如 `onCreate`）中初始化，并在对应拆卸回调中释放订阅或资源。

## 调用父方法

在 Mixin 方法内使用 `super()` 继续 Blueprint/原生继承链：

```lua
local Door = {}

function Door:onCollision(other)
 if self.opening then
 return
 end
 super().onCollision(other)
 self:openDoor()
 self.opening = true
end

return Door
```

父类必须实际提供 Mixin 使用的每个原生属性或方法。编辑器校验 schema 与路径规则；缺失运行时成员时，会在真实调用处报错。

## 验证

至少构造两个实例，分别修改各自复制默认值，并使用声明的父类执行每个 Mixin 方法。确认 `super()` 到达预期的下一个实现。
