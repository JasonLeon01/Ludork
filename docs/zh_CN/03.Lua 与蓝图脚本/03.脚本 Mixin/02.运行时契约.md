# Script Mixin 运行时契约

运行时将所选脚本作为 `Mixins.<点分路径>` 模块加载，要求返回一个不带元表的 Lua 表。本页说明生成蓝图类的成员、实例默认值、保留名称和父类方法调用规则。

## 返回表的规则

- 每个键必须是字符串。
- 函数会成为生成 Blueprint 类的方法。
- 非函数值会深复制到类默认值与实例默认值。
- 继承成员不能从字段变成函数，也不能从函数变成字段。
- 已保存的 Blueprint 属性不能替换 Mixin 方法。

以下名称保留：

```text
__*  init  new  scriptMixin  scriptPath
_GENERATED_CLASS  _graph  _hasImplementationOwner
```

由于 `init` 是保留名称，直接挂载的 Script Mixin 不声明构造函数。私有实例状态应在所属类型的生命周期回调（如 `onCreate`）中初始化，订阅和资源则在对应的清理回调中释放。

## 调用父方法

在 Mixin 方法内使用 `super()` 继续 Blueprint/原生继承链：

```lua
local Door = {}

function Door:onCollision(other)
    if self.opening then
        return
    end
    super().onCollision(other)
    self:openDoor()
    self.opening = true
end

return Door
```

父类必须提供 Mixin 使用的每个原生属性和方法。编辑器只校验结构和路径，运行时成员缺失会在实际调用时报错。

## 热更新

控制台的 `$r` 命令会更新已使用的 Script Mixin 中已有的方法，不会重新执行 `onCreate` 或清理回调。Mixin 默认值与实例状态保持不变，结构变更需要重启。兼容性与错误处理规则见 [Lua 热更新](<../01.Lua 运行时与模块.md#lua-热更新>)。
