# Script Mixin 校验与打包

## 目标

保存前校验挂载脚本及其 metadata，并证明打包游戏能够加载每个被引用 Mixin。

## 前置条件

- 已配置为 Script Mixin 模式的 Blueprint 继承链。
- `Scripts/Mixins` 下的运行时/metadata 文件对。
- 包含每个受影响 Blueprint 的代表性地图。

## 步骤

1. 校验相对脚本路径与同名 metadata 文件。
2. 按报告顺序解决保存时 Blueprint 与字段诊断。
3. 在编辑器模式中运行所有生命周期/事件路径。
4. 按预期的 Lua 编译设置打包，并重复运行时检查。

## 路径校验

`scriptPath` 必须是 `Scripts/Mixins` 下非空、相对的 `.lua` 路径。路径使用正斜杠，不得包含空段、`.`、`..`、驱动器前缀、绝对根或 `_meta.lua` 后缀。

继承链中第一个 Script Mixin Blueprint 必须设置 `scriptPath`。子类可以继承该值或提供另一个有效路径。本地路径指向缺失文件时，校验失败。

## 保存时校验

保存前，编辑器检查父类与模式继承链、脚本路径与同名 metadata 文件，以及 [Script Mixin Metadata](<04.Metadata.md>) 中的 metadata 规则。应先解决第一个路径或 metadata 错误，再检查后续字段错误。

## 打包

Pack 会把项目的 `Scripts` 树复制到暂存区（staging）。**Use luac** 只编译暂存区中的 Lua 文件，不会改写项目源文件。发布前，对每个被引用的 Script Mixin Blueprint 至少执行一次打包运行，并确认 Console 中没有模块解析错误。

## 限制

编辑器 metadata 校验不能证明所有父方法存在。打包会保留有效的源码路径，但无法修复已过期的 Blueprint attribute。
