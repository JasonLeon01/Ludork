# 声明式 UI 校验与打包

## 目标

校验基于路径的 UI 声明，对比原生 Preview 与运行时，并在不包含编辑器 preview 数据的情况下打包资产。

## 外部修改后校验

UI JSON 在编辑器外发生变更时运行：

```text
ScriptTools ui-assets validate <project-root>
ScriptTools ui-adapter-check <repo-root>
```

两项检查都只读，不生成索引文件。原生构建会执行相同的资产与 adapter 检查，并在 schema、路径或 descriptor 无效时停止。

## 校验层

保存、原生预览、Run 与 Pack 都执行[资产 Schema](<04.资产 Schema 与 Control Registry.md>)，并拒绝未知字段、资产内重复节点名和别名路径。

## 原生预览与打包

Preview 需要匹配的协议和系统 adapter fingerprint。Render 请求发送根资产 key 与以逻辑 key 索引的 dependency snapshot，不发送或读取 Catalog。

Packaging 校验 staging 副本、移除 `editor` 数据，并按配置编译、加密或归档，不改动源工程。JSON、`.ldc` 与 packed Data 保持相同的无扩展名 UI key；packed Controller 保持原逻辑模块路径。
