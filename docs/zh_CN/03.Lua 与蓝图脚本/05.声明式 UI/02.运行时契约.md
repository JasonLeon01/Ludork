# 声明式 UI 运行时契约

本页说明声明式 UI 控制器的类定义、准备、挂载、命名空间查找、刷新和释放。

## 类定义

`Ui.Define(assetKey, definition, baseClass)` 设置资产标识和更新事件名称，再通过 `class(definition, baseClass or UiController)` 完成类定义。加载模块后，传入模型即可创建实例：

```lua
local InventoryUI = require("Source.UI.Inventory")

local inventoryUI = InventoryUI.new(inventoryModel)
```

未提供资产实例时，`UiController:init` 会按资产的逻辑标识创建实例。

## 准备与挂载

`prepare(logicalSize)` 按以下顺序执行：

1. 调用一次 `bind`；
2. 订阅已声明刷新事件，并注册 UI 更新通道；
3. 调用 `refresh`；
4. 使用当前逻辑尺寸对 View 重新布局；
5. 返回根控件。

`mount(uiManager, logicalSize)` 先准备，再调用一次 `UIManager:loadUI`；`attachTo` 把已准备根节点添加到上级。`deferView = true` 的窗口通过 `attachWindowView` 安装完整根。`attachNestedWindowView` 把输入宿主绑定到已加载的顶层资产内的窗格，不会重新挂接（reparent），并保留焦点、选择、滚动与返回按钮行为。`WindowBase:setVisible` 同时作用于宿主与窗格根。程序式窗口与纯覆盖（overlay-only）窗口沿用普通的基础 View 路径。

`bind` 必须可安全重复调用，控制器只在 `_bound` 变为 true 前执行它。刷新和重新布局可以多次执行。

同一资产的控制器共享更新通道，首次绑定时才创建通道。仅加载模块不会订阅事件。

Controller 负责控件、布局和显示缓存，通过公开查询读取模型，通过操作方法修改模型。

## 查找边界

`requireControl(name)` 与 `getNodeByName(name)` 查找当前资产命名空间。`requireAsset(name)` 获取嵌套资产实例。上级不能通过子节点名穿透嵌套资产；应用该嵌套实例构造子 Controller。

## 属性值

`AssetInstance:setProperty(name, propertyId, value)` 和 `UiController:setProperty` 要求传入符合属性声明类型的运行时值。各属性的类型及可选值清除方式见 [AssetInstance API](<../07.API 参考/04.Core 模块/02.Engine/13.交互与声明式 UI 控件.md#assetinstance>)。

## 动画播放

`AssetInstance:hasAnimation(name, target?)`、`playAnimation(name, target?, onFinished?)` 与 `stopAnimation(name, target?)` 操作 Global 或资产内节点动画，`UiController` 也提供这些方法。播放采用线性插值并立即应用 0 秒采样。自然完成会保持末帧并调用一次完成回调。

不同 target 独立运行。同 target 替换动画会清除旧效果和回调，并从零开始。`stopAnimation` 只清除名称匹配的动画效果及待执行回调，也可清除已完成动画保持的末帧。隐藏 root 和释放实例会清除所有动画效果及待执行回调。

动画缺失时会输出一条包含 asset、target 与 name 的警告，返回 false，并同步调用完成回调。嵌套资产只在边界及其子树导出 Global 动画；父资产在该节点上的同名动画只覆盖当前实例。父 Global 动画不会启动 override，子节点动画也不会导出。

## 释放

`dispose()` 是终止操作，至多执行一次，包括之后的垃圾回收。它会卸载根、注销资产更新通道，并取消通过 `subscribe` 注册的每个事件。调用继承释放前，Controller 必须清除仍持有 Lua 闭包的原生控件回调。

`UIManager` 销毁时会清除注册到其生命周期的回调，包括已脱离的控件。`removeUI` 会保留回调供之后 `loadUI`；加载或重新挂接子树会转移回调所有权。Controller 仍须调用 `dispose()` 取消订阅并释放自身资源。

## 限制

已释放的控制器不能再次准备或挂载，父级也不能修改嵌套资产实例的内部结构。

[Lua 热更新](<../01.Lua 运行时与模块.md#lua-热更新>)可以更新兼容的控制器方法，并保留界面状态与事件订阅；不会重新调用 `bind`、挂载控件或重建 JSON 视图。
