# 声明式 UI

Ludork 声明式 UI 将 JSON View 与 Lua Controller 分离。资产拥有控件树、静态属性与上级所有布局；Controller 拥有运行时数据、输入、本地化文本、刷新与生命周期。

## 所有权边界

| 层 | 拥有内容 |
|---|---|
| JSON View | Hierarchy、稳定身份、静态控件属性、Slot 与纯设计预览数据 |
| Lua Controller | Model 访问、回调、本地化/格式化文本、状态刷新与动态组合 |
| 原生控件 | 渲染、测量、命中测试、焦点与原子交互状态 |
| UIManager | 挂载和移除已准备根控件 |

不要在 UI 资产中存储 Controller 函数、表达式、事件处理器或 `LOC(...)` 调用。
