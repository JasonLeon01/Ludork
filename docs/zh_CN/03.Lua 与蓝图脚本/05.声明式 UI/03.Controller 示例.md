# 声明式 UI Controller 示例

窗口模块包含一个私有业务 Controller，并导出 UI 类。框架创建和绑定生成 View，开发者按需添加行为。

## 从原始模板开始

已有 `Inventory.json` 时，在 `Scripts/Source/Windows/WindowInventory.lua` 中写入：

```lua
local Ui = require("Source.UIBase.Ui")
local InventoryView = require("Source.UI.Inventory")

local Controller = {}

return Ui.DefineWindow(InventoryView, Controller)
```

Scene 创建并注册窗口：

```lua
local WindowInventory = require("Source.Windows.WindowInventory")

local window = WindowInventory.new():mount(uiManager)
```

窗口使用模板内容与尺寸。将窗口保存在拥有者上，不再使用时调用 `window:dispose()`。

## 替换内容并响应字段变化

假设 `Inventory.json` 包含 `WindowFrame`、`Content`，以及名为 `Title`、`Count` 的 `Engine.PlainText` 节点。在同一窗口模块中添加业务行为：

```lua
local LocaleCore = require("Source.Locale.Core")
local Ui = require("Source.UIBase.Ui")
local InventoryView = require("Source.UI.Inventory")
local WindowBase = require("Source.Windows.Base.WindowBase")

---@class Source.Windows.WindowInventory.Controller
local Controller = {}

Controller.windowOptions = { centered = true, returnButton = true }

function Controller:init(inventory)
    self.model = inventory
    self.view:setText("Title", LocaleCore.ApplyStringLocaleFormat("INVENTORY_TITLE"))
    self:watch(inventory, "count", Controller.updateCount)
end

function Controller:updateCount(count)
    self.ui.controls.Count:setString(tostring(count or 0))
end

function Controller:onReturn()
    self.host:hideImmediate()
end

return Ui.DefineWindow(InventoryView, Controller, WindowBase)
```

`watch` 立即显示当前数量，并在字段变化时更新：

```lua
local WindowInventory = require("Source.Windows.WindowInventory")

local inventoryModel = { count = 3 }
local window = WindowInventory.new(inventoryModel):mount(uiManager)
inventoryModel.count = 4
```

显示值会变成 `4`，无需调用 `refresh`。若标题也需响应语言变化，将标题更新移入 `refresh`，并在 `refreshEvents` 中订阅语言事件。

### 业务成员只声明一次

手写 `Scripts/stub/Source/Windows/WindowInventory.d.lua` 只包含 Controller 及其业务类型：

```lua
---@meta

---@class InventoryModel
---@field count integer

---@class Source.Windows.WindowInventory.Controller: Source.UIBase.UiController
---@field host Source.Windows.WindowInventory
---@field ui Source.UI.Inventory
---@field model InventoryModel
local Controller = {}

---@param inventory InventoryModel
function Controller:init(inventory) end

---@param count integer | nil
function Controller:updateCount(count) end

function Controller:onReturn() end
```

运行 `ScriptTools ui-assets generate <project-root>` 派生公开窗口声明。require 路径为 `Source.Windows.WindowInventory`；`Source.Windows.WindowInventory.Controller` 是私有类型，不是模块。

## 绑定原生回调

独立行 Controller 保留 `Ui.Define(RowView, RowController)` 与 `RowController.new(model, ui?)`。设置行可绑定已有 DropBox：

```lua
function SettingRowController:bind()
    self.ui.controls.DropBox:setItems(self.model.items)
    self.ui.controls.DropBox:setOnSelectedIndexChanged(self:bindCallback(SettingRowController.onSelectedIndexChanged))
end

function SettingRowController:onSelectedIndexChanged(index)
    self.model:setSelectedIndex(index)
end
```

向 `bindCallback` 传入未绑定的类方法；它会提供 `self`，并在 Controller 释放后失效。详见[回调契约](<02.运行时契约.md#观察模型字段与绑定回调>)。

## 为已有子 View 添加行为

父 JSON 包含 `DetailsAsset` 时，在父 Controller 中创建它的业务窗口：

```lua
local WindowDetails = require("Source.Windows.WindowDetails")

function Controller:init(inventory)
    self.details = self:createChild("DetailsAsset", WindowDetails, inventory)
end
```

`createChild` 复用 `self.ui.assets.DetailsAsset` 及其原始布局，子窗口由父 View 管理生命周期。

独立固定行继续使用原有 Controller 路径：

```lua
local ItemRowController = require("Source.Windows.WindowInventory.ItemRow.Controller")

local row = ItemRowController.new(itemModel, self.ui.assets.ItemRow)
row:prepare()
```

## 填充模型决定的行

根据 `self.model.items` 填充 `ItemList`：

```lua
function Controller:bind()
    self.rows = self:createCollection(self.ui.controls.ItemList, ItemRowController)
end

function Controller:refresh()
    self.rows:clear()
    for _, item in ipairs(self.model.items) do
        self.rows:add(item)
    end
    self.rows:layout()
end
```

将 `ItemRowController` 与其他依赖一同 require。集合替换预览子项并管理行的生命周期，详见[动态集合](<02.运行时契约.md#动态集合>)。

## 发布更新

`WindowInventory.Publish(payload)` 通过资产的 EventBus 通道更新所有存活且已准备的 Controller。重写 `onViewUpdate(payload)`，可在刷新和布局前保存状态；需要时通过 `refreshEvents` 添加语言变更等事件。独立行与 Scene Controller 通过 `Ui.Define` 提供 `Publish`，没有 Controller 的 View 不订阅这些事件。
