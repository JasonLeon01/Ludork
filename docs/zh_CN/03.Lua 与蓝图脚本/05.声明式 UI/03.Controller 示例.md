# 声明式 UI Controller 示例

## 目标

实现可重复的 Model-to-View refresh、原生 callback、嵌套 part 所有权与更新发布，同时不泄漏 Lua closure。

## 前置条件

- 已保存 UI 资产，包含稳定节点名和匹配的 `Ui.define` key。
- 控制 Controller 构造与释放的 Model 和 owner。
- Runtime 使用前已生成所需本地化 key。

## 步骤

1. 在 `bind` 中只获取一次控件并安装 callback。
2. 在可重复调用的 `refresh` 中从 Model 推导可见状态。
3. 为每个嵌套资产提供独立 Controller。
4. 只发布应由所有活动实例接收的更新。
5. 调用继承 `dispose` 前清除原生 callback。

## 本地化与 Model 派生文本

```lua
local Ui = require("Source.UI.Ui")

local InventoryUI = {}

function InventoryUI:refresh()
    self:setText("Title", LOC("INVENTORY_TITLE"))
    self:setText("Count", tostring(self.model.itemCount))
end

return Ui.define("Inventory", InventoryUI)
```

这类内容的 `properties.text` 保持为空。`editor.previewText` 可以为 Designer 提供仅用于预览的文字；运行时不读取预览数据。

## 绑定原生控件

```lua
function SettingRowUI:bind()
    self._dropBox = self:requireControl("DropBox")
    self._dropBox:setItems(self._items)
    self._dropBox:setOnSelectedIndexChanged(function(index)
        self:_onSelectedIndexChanged(index)
    end)
end

function SettingRowUI:dispose()
    self._dropBox:setOnSelectedIndexChanged(nil)
    super().dispose()
end
```

程序赋值 API 不播放交互音效。对 `DropBox` 而言，`open()` 表示用户发起的打开；`setExpanded(...)` 静默更改状态。

## 拥有嵌套部件

```lua
local ItemRowUI = require("Source.UI.Parts.Inventory.ItemRow")

local rowInstance = self:requireAsset("ItemRow")
local rowUI = ItemRowUI.new(itemModel, rowInstance)
rowUI:prepare(self._viewLogicalSize)
```

每个嵌套实例拥有独立控件树。上级只能控制嵌套实例自身的名称与上级 Slot，不能改写内部属性或子项。

## 发布更新

`InventoryUI.publish(payload)` 通过资产 EventBus 通道更新每个活动、已准备实例。覆写 `onViewUpdate(payload)` 以保存新状态；Controller 随后执行标准 refresh 与 reflow 流程。只有当 UI 实际需要时，才把语言切换等横切事件加入 `refreshEvents`。

## 预期结果

已准备实例显示当前 Model 数据，每次原生交互只响应一次，保持嵌套所有权边界，并在 dispose 时释放所有订阅。

## 验证

- 使用不变与已改变 Model 重复调用 `refresh`。
- 多次打开和关闭所属 Scene/窗口，检查是否出现重复 callback。
- 创建两个嵌套实例，确认控件树互相独立。
- 切换语言，确认只有已订阅 UI 刷新。

## 限制

`publish` 只面向一个资产类中活动且已准备的实例，不是通用项目 message bus。Preview text 从不作为 runtime fallback。
