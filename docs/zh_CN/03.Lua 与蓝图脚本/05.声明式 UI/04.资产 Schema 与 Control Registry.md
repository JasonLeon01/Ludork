# UI 资产 Schema 与 Control Registry

## 资产 key 与结构

UI 资产使用 `type = "uiAsset"` 并遵循下述字段契约，不保存 schema 版本字段。资产唯一身份是相对 `Data/UI/Assets`、大小写精确、使用正斜杠且不含扩展名的路径。`Title.json` 的 key 为 `Title`；`Parts/Shared/WindowBase.json` 的 key 为 `Parts/Shared/WindowBase`。

Key 不得是绝对路径，不得包含反斜杠、空段、`.`、`..`、扩展名或 `Assets/`、`UI/Assets/` 等重复前缀。资产对象包含 `designSize`、`palette` 与一个 `root` 节点；资产和节点均不包含 UUID 字段。

每个节点包含：

| 字段 | 契约 |
|---|---|
| `name` | 资产内节点身份与 Controller 查找名，在资产内唯一；完整身份为 `(assetKey, name)`。 |
| `controlId` | 系统控件的规范模块根原生类路径，或 `Project:<相对路径>`。 |
| `properties` | 控件 schema 拥有的值。 |
| `slot` | 上级拥有的布局；根节点没有该字段。 |
| `editor` | `previewText` 等纯设计数据。 |
| `children` | 有序子节点；当 z-order 相同时，顺序是稳定 tie-breaker。 |

嵌套项目资产是黑盒。节点声明项目 `controlId`、`name` 与上级 Slot，不包含内部覆盖或子节点。目标资产必须 exposed，直接或间接嵌套循环无效。

系统 ID 使用绑定类唯一的 runtime 路径，例如 `Engine.Canvas` 或
`Engine.FunctionalPlainText`。不匹配其绑定类唯一 runtime 路径的系统 ID 属于未知控件。

## Slot 与资源 key

Canvas 上级提供锚点、偏移、对齐、自动尺寸与 z-order。List 上级提供 List 排布，不接受 Canvas Slot 字段。上级 adapter 声明决定子项策略与 Slot 类型。

`Engine.ScrollBox` 是使用 List Slot 的多子控件 Layout，序列化 `size` 与 `windowSkin`。滚动、方向提示和裁剪由原生控件负责。

- 文件资源使用大小写精确、以 `Assets/` 开头、带扩展名的项目相对路径，并使用正斜杠。
- `textConfig` 相对于 `Data/TextConfigs`，不含目录前缀或扩展名。
- `opacityCurve` 相对于 `Data/Curves`，不含目录前缀或扩展名，并解析为标量曲线。
- 绝对路径、反斜杠、越界与别名前缀均无效。

普通文本控件将字体、字号、样式、间距、对齐、描边、辉光和渐变直接保存在 UI 节点上。共享或特殊文本仍可选用 `textConfig`；其非空时，编辑器禁用这些内联样式项，运行时使用 TextConfig。RichText 可用 TextConfig 定义具名标签样式。

## 实时控件 Registry

编辑器从原生系统 descriptor 与项目 UI 资产实时构建内存 Registry。只有 `palette.exposed = true` 的资产会作为项目控件出现。Runtime 不生成、保存或读取任何 Registry/Catalog 文件。

`Engine.TabView` 是不包含子节点、也不提供自身 Slot 的 Input 控件。它与普通文本共用内联文本样式或可选 `textConfig`，并提供 `size`、`windowSkin` 与仅构造期生效且非空的 `items: string[]`。资产通常写入 `#TAB 1...`，使原生预览直接显示每个 Tab。Controller 必须在首个可见帧前，以相同 item 数量、本地化标签和选择 callback 调用 `setItems`。`selectedIndex` 与按键提示表只属于运行时；不再接受 `tabCount`。

`Engine.CharacterView` 是无子节点 Visual，属性为 `size`、`texture`、可选 `textureRect`、`characterScale`、`animatable`、`switchInterval`、`shader`、`hue` 与 `colour`。`shader` 为空或相对 `Assets/Shaders`。控件负责裁帧、动画、Actor 缩放适配、Shader/Hue 合成和固定边界，不参与输入。

Adapter fingerprint 只由系统 descriptor 推导，编辑器与 PreviewHost 用它拒绝不匹配的原生 adapter。Runtime 与 Preview 都按规范相对 key 直接解析项目资产。
