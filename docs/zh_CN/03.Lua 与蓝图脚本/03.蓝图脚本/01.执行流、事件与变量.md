# 事件、公共函数与蓝图流程

蓝图把类默认值与可视化图保存在 `Data/Blueprints` 下，公共函数保存可复用的图。编辑器按当前项目的 metadata 目录校验两者。

用 **游戏 → 新建蓝图** 创建蓝图：选择有效的父类，添加受支持的事件入口。连接执行引脚与数据引脚，然后校验并保存。多个图需要同一种操作时，按 F8 打开公共函数。Script Mixin 蓝图遵循独立的 [Script Mixin 编写工作流](<../02.脚本 Mixin/01.编写工作流.md>) 契约，不执行自己的图。

![带有事件图与已连接节点的蓝图编辑器](../../../_images/editor/blueprint-editor.png)

*图通过执行引脚表达执行顺序，通过有类型的数据引脚传递值。*

![给出可操作诊断的蓝图校验窗口](../../../_images/editor/blueprint-validation.png)

*校验会指出普通保存前必须修正的类、图、节点、连线或引脚。*

## 目标

构建一张通过校验的事件图：执行流明确、数据引脚有类型、公共函数可复用、默认值切合意图。

## 前置条件

- 使用当前 metadata 的图模式蓝图。
- 一个受支持的事件入口，以及工作流所需的节点 API。
- 公共函数与被引用的项目数据都有稳定名称。

## 步骤

1. 添加一个受支持的事件入口。
2. 添加节点，先连执行引脚再连数据引脚，并为每个必需但尚未连接的输入设置取值。
3. 把重复逻辑抽到用 F8 打开的公共函数中。
4. 校验并保存，然后让控制台保持可见，运行事件。

## 事件

事件是用 `type = "event"` 声明的入口，提供有序的数据引脚与执行输出。没有显式声明 `ExecSplit` 的事件会得到默认执行输出。

通用数据的成员图是同步 ability，不参与继承，也不是隐式的蓝图事件。`Source.Gameplay.GeneralDataGraphAbility` 以 `GameplayEventData` 作为 parent 激活选定的图。start 为 `null` 时返回 `NoGraph`。latent 节点无效，错误向调用方传播。

## 公共函数

打开 **数据库 → 公共函数**（F8）。一个公共函数拥有一张可复用的图，可以新建、重命名、复制、删除、整理与校验。调用时使用对应的节点，不要复制图里的片段。

## 执行语义

- `Pure = true` 会移除执行输入引脚与执行输出引脚。有返回值并不代表节点是 pure。
- `ExecSplit` 把具名执行输出映射到结果值。
- `Latent` 节点会挂起图，之后通过已声明的状态恢复。
- 只要当前执行还有未完成的 latent 节点，蓝图事件就会丢弃同一个图实例、同一个事件键的重复触发。该次执行的全部 latent 工作结束后，才接受新的触发。不同的图实例与事件键彼此独立。
- `LoopNode` 描述循环体与完成时的行为。
- 数据连线连接类型兼容的引脚，执行连线连接流程引脚。

运行时的事件查询与执行使用原生 `Engine.Graph` userdata。原始 GraphData 用于定义阶段的事件检查。本地执行上下文保存调用状态，本身不是可执行的图。

## 连线的类型规则

只要联合类型中至少有一个分支接受该值的类型，这个值就能连到该联合类型。联合类型的输出要连出去，则必须让目标接受所有可能分支。列表、字典与元组按同样的规则递归判断。派生类型可以连到已声明的基类。`int` 可以连到 `float`，但 `float` 连到 `int`、以及不同 SFML 向量类型之间的转换都会被拒绝。`any` 允许动态连线，实际值在运行时检查。

加载或粘贴图之后，类型不兼容的连线仍会保留并显示为红色，悬停提示会说明原因。修正后才能正常保存。

## 默认值与引用

新输入采用已声明的默认值，或该类型的一个有效字面量。对象与函数输入两者都没有时保持未设置。已保存的字面量必须符合声明类型，即使该输入已经连线。无效值会保留显示并阻止正常保存，连线传入的值在运行时检查。默认值与返回值的 metadata 写法见[函数与事件](<02.Metadata 结构与 Decorator.md#函数与事件>)。

## 类定义与会话生命周期

同一个 Lua VM 中的 ClassDict 实例共享已解析的类、定义表与已编译的图模板。改动 JSON 类定义或图模板后需要重启。[Lua 热更新](<../01.Lua 运行时与模块.md#lua-热更新>)只更新兼容的脚本函数。

`ClassDict:getData(path)`（Game 项目中也以 `Data.GetClassData(path)` 暴露）先用与 `get` 相同的加载路径解析，然后返回 resolver 持有的 JSON 定义表。未知路径会抛错，没有 JSON 定义的模块类返回 nil。同一个 VM 内重复读取会得到同一张 table；需要独立的 table 时用 `copy` 或 `deepcopy`。

改动这张 table 会影响后续的定义读取，但不会更新已生成的类、实例默认值记录或已编译模板。新实例与可执行事件查询继续使用已生成的结果。

## 调试

从事件起点入手，沿执行连线往下查，再看数据来源与未连接的默认值。移动或重命名节点函数后要重新校验。

## 限制

图校验检查结构与 metadata 契约，既不证明玩法正确，也不会执行 latent 工作。
