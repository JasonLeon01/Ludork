# Lua 与蓝图脚本

## 选择脚本模型

| 模型 | 适用内容 | 主要源文件 |
|---|---|---|
| Blueprint 图 | 可视化事件与执行流 | `Data/Blueprints/*.json` |
| Lua 类 | 可复用系统与玩法类型 | `Scripts/**/*.lua` |
| Script Mixin | 直接挂载到 Blueprint 类的 Lua 行为 | `Scripts/Mixins/**/*.lua` 与同名 `_meta.lua` |
| 声明式 UI | JSON View 与 Lua Controller | `Data/UI/Assets/**/*.json` 和 `Scripts/Source/UI/**/*.lua` |

同一条 Blueprint 继承链只能使用图模式或 Script Mixin 模式之一，不能在链内切换。
