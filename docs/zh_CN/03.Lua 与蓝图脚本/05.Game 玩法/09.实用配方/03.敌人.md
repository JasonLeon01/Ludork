# 敌人

## 目标

创建一个物理蓝图与通用数据战斗定义可分别复用的敌人。

## 前置条件

- 有效的 Enemy 通用数据文件，以及兼容 Actor 的敌人父类。
- 新记录所引用的 Item 蓝图路径、特殊效果标识符与动画标识符都已存在。

## 步骤

在通用数据中定义敌人，在蓝图中搭建敌人实体。

1. 添加 Enemy 成员，设置战斗数值、奖励、掉落、特殊效果与动画 key。
2. 创建或派生 Enemy 蓝图，并让它指向该数据成员。
3. 配置移动、碰撞与表现默认值。
4. 自定义的击败演出放在 Enemy Actor 的 `onDefeat` hook 中，或放在子类授予的 Gameplay Ability 中。Enemy 通用数据没有事件，固定结算仍会等待 `onDefeat`。
5. 放置蓝图，测试战斗、奖励、掉落、存读档与地图重置。

共用的战斗算法放在 Gameplay Ability、Gameplay Effect 或 Lua 模块中。

## Game 演练

`BP_Enemy_Slime.json` 继承 `Source.Enemy`，并设置 `ID = "Slime"`。该 ID 解析 `Data/General/Enemy.json` 中的 `Slime` 成员。纹理、源矩形、material speed 等物理与表现默认值由蓝图持有，`MAXHP`、`ATK`、`DEF`、`EXP`、`GOLD`、`drops`、`special` 与 `ANIMATION_KEY` 则由通用数据成员持有。

内置的击败粉碎特效由项目级的 `Enemy.DefeatShatterEffectEnabled` 选择，默认值为 `true`。它是全局类设置，不是蓝图字段。开启后，运行时立即记录并销毁敌人，玩法上即刻移除。随后，一张不参与碰撞、也不遮挡光线的快照会化作世界空间逻辑像素碎片，在约 0.65 秒内从中心径向散开。把该类设置改为 `false`，或在不支持 Shader 的环境中运行，都会保留立即消失的表现。

每个 `drops` key 都是 `Source.Item` 蓝图路径，而不是通用数据 ID。它的 `sf.Vector2i` value 表示格偏移。掉落生成在敌人所在图层并持久化，同时激活自身的 `onDrop` `GeneralDataGraphAbility`。持久化 tag 重复时，该掉落会被跳过。

`GhostSoldier` 演示了 `special.Reborn = "Data.Blueprints.Enemies.BP_Enemy_Skeleton_01"`。击败结算期间，运行时会先记录并销毁原敌人。目标蓝图随后以新的地图放置 tag 在同一格、同一图层生成，并被记录为 added Actor。不要复用被击败 Actor 的 tag：地图重建时，destroyed 记录会把替代者一并移除。

要制作变体，先复制一个已有的敌人蓝图，再创建或选择匹配的 Enemy 成员，并更新蓝图的 `ID`。表现部分单独修改。

## 限制

未知 ID 与缺失的引用记录都是错误。运行时不会合成替代的战斗定义。
