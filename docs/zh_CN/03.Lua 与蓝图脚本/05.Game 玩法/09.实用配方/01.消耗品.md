# 消耗品

## 目标

用 Script Mixin 创建由碰撞触发的回复或属性拾取物。

## 前置条件

- 已保存、继承自 Actor 且启用碰撞的蓝图。
- 生成的 Player 属性集中存在匹配的数值字段，并且 Audio 配置中有有效的回退值。

## 步骤

物品行为适合直接写成 Actor 碰撞方法时，就使用 Script Mixin。

1. 创建继承 `ConditionalActor` 的蓝图，并启用 Script Mixin。
2. 挂载 `Consumables/Bottle.lua` 或 `Consumables/Gem.lua`。
3. 回复药水设置 `HP_plus`，宝石设置 `ATTR_key` 与 `plus`。
4. 选择音效，或留空以使用 Audio 配置的回退值。
5. 把蓝图放到地图上，分别在有玩家和无玩家时测试碰撞。

Bottle 脚本对 `HP` 施加 Instant Add Effect。Gem 脚本对 `ATTR_key` 选定的 `int` 或 `float` Player 属性施加同样的效果。两者共用的拾取流程先找到 Player，把拾取物记录为已销毁，然后销毁它。

每个配方都要测试成功路径、条件未满足路径与重复触发。

## Game 演练

- `BP_Bottle_200.json` 直接继承 `Source.MapActors.ConditionalActor.ConditionalActor`，启用 `scriptMixin`，选择 `Consumables/Bottle.lua`，设置 `HP_plus = 200`，开启碰撞并选择药水纹理。
- `BP_Gem_1_1.json` 选择 `Consumables/Gem.lua`，设置 `ATTR_key = "ATK"` 与 `plus = 1`，并选择宝石纹理。
- 两条记录都保留 `getSE` 的 metadata 默认值，因此脚本会解析 `Audio.getSE`。

## 限制

Game 脚本依赖自身声明的父类能力、metadata 字段，以及通用数据或配置里的 key。它们并不是通用的背包组件。
