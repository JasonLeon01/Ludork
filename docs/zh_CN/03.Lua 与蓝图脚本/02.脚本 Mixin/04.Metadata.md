# Script Mixin Metadata

同名的 `_meta.lua` 文件必须返回 `_METADATA`，且其中只能有一个类型，其名称与脚本文件名一致。它为一个挂载的行为暴露可编辑字段，不声明运行时方法、蓝图节点入口或继承层级。

```lua
local _METADATA = {
    KeyDoor = {
        attrs = {
            "needKeyID",
            "needKeyCount",
        },
        needKeyID = {
            type = "string",
            default = "",
            Meta = {
                GeneralDataVars = "Item",
            },
        },
        needKeyCount = {
            type = "int",
            default = 1,
        },
    },
}

return _METADATA
```

## 规则

- `attrs` 是稠密、有序的数组，其中的字段名互不重复且非空。
- 列出的每个字段都是一张带有效 `type` 的 table。
- `default` 如果存在，必须是有限、无环、可转换为 JSON 的纯数据。
- `bases` 缺省，或为空 table。基类由蓝图继承提供。
- 根 table 中不得出现第二个类型、函数、userdata、协程或外部状态访问。
- `Meta.GeneralDataVars`、`Meta.PathVars`、`Meta.ConfigVars` 等 decorator 只细化编辑器控件，不改变运行时值。`Meta.InstVar` 选择一个已声明的游戏变量名，可用 `types` 过滤。`Meta.InstVarValue` 指名同级字段，由该字段选中的声明决定值编辑器。

## 限制

既没有出现在已保存 attribute 中、又没有 `default` 的字段，只存在于 schema 中。
