# Source.MapActors.Player

Metadata 来源：`Scripts/Source/MapActors/Player_meta.lua`

`Player` 声明可操控 Actor 的 Character 属性，以及背包、装备与属性命令。

直接 metadata 基类：`{ "Engine", "Character" }`、`{ "Source.Battler", "Battler" }`

Meta：`{ GeneralDataVars = { { "ID", "Player" } } }`

编辑器会显示生成的 `PlayerAttributeSet` 只读预览。该预览不会序列化到 Blueprint JSON 中。

## 属性

| 名称 | 类型 | 默认值 | Metadata |
|---|---|---|---|
| `ID` | `string` | `"FILL_IT_BY_YOURSELF"` | GeneralDataVars = `Player` |
| `tickable` | `bool` | `true` | — |
| `collisionEnabled` | `bool` | `true` | — |
| `animatable` | `bool` | `true` | — |
| `speed` | `float` | `96` | — |

`attributes` 是生成的 Player Attribute Set。背包、装备、移动与 Ability System 属于运行时状态。

## Lua 运行时 API

| 成员 | 签名 | 行为 |
|---|---|---|
| `ValidateName` | `(name) -> string, "empty"/"tooLong"/nil` | 返回去除首尾空白后的候选名与校验错误；合法时错误为 `nil` |
| `init` | `(texture?, tag?)` | 构造 Attribute Set、Ability System，以及空的背包与装备状态 |
| `InitPlayer` | `(playerPath, applyInitialEquipment? = true) -> Player` | 根据 Blueprint class path 构造 Player，并可选应用 Class 的初始装备 |
| `FromDict` | `(data) -> Player` | 恢复 Base、背包 ability、装备 Effect 与 State Effect。不应用 Class 的初始装备，也不执行成员图 |
| `asDict` | `() -> SaveData` | 序列化稳定状态，不含运行时 Effect handle |
| `activateItem` | `(itemID) -> GameplayAbilityResult` | 激活 `GeneralData.Item.<id>.onUse` |
| `consumeMovementSpecialPath` | `() -> sf.Vector2i[]` | 取出并清空已到达的地图格 |
| `getClassPath` / `setClassPath` | `() -> string` / `(path)` | 访问可用于重建的 Blueprint path |
| `getItems` / `getEquips` | `() -> table<string, integer>` | 返回各自独立的数量快照。修改 Player 时改用背包与装备命令 |
| `restoreFromData` | `(data)` | 将存档状态恢复到同一 Blueprint 类的 Player 中，不重放成员图 |
| `MeetPlayer` | `(actors, player) -> Player?` | 仅当 Actor 数组中出现指定 player 时，才返回该 Player |

`InitPlayer` 会应用 Class 的初始装备。`FromDict` 重建存档中的装备，但不重放 `onEquip`。运行时的装备与卸下先修改 Infinite Effect，再运行对应的图。移动完成时会发送 `Event.Movement.Step`。

HP Current 限制在 `0..MAXHP` 范围内。永久 MAXHP 与 LEVEL 的成长通过 Base 增量实现。Effect 与 Constraint 的变化不会改动成长用的 Base。

`setName` 会去除 Unicode 首尾空白，并接受 1–32 个字素簇。输入非法时，名字保持不变。`getDisplayName` 返回自定义名字原文，或通用数据的本地化默认名。
