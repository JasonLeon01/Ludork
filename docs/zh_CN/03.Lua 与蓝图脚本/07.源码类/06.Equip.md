# Source.Equip

Metadata 来源：`Scripts/Source/Equip_meta.lua`

`Equip` 声明装备 Actor 的通用数据标识与音效。

直接 metadata 基类：`{ "Source.ConditionalActor", "ConditionalActor" }`

继承的可见性条件见 [Source.ConditionalActor](<12.ConditionalActor.md>)。

编辑器会按 `ID` 显示生成的 `EquipAttributeSet` 预览。`attributes` 字段只读，不会序列化到 Blueprint JSON 中。

## 属性

| 名称 | 类型 | 默认值 | Metadata |
|---|---|---|---|
| `ID` | `string` | `"FILL_IT_BY_YOURSELF"` | GeneralDataVars = `Equip` |
| `getSE` | `string` | `""` | `Sounds` 路径；回退到 `Audio.getSE` |

## 运行时 API

| 成员 | 签名 | 行为 |
|---|---|---|
| `init` | `(texture?, rect?, tag?)` | 根据 `ID` 构造生成的 Equip Attribute Set |
| `onCollision` | `(other)` | 通过共享的拾取流程，将 Equip 加入 Player 的背包 |

`Player:equip` 将 `attributes.attrPlus` 作为 Infinite Effect 应用，并显式运行通用数据的 `onEquip` 或 `onUnequip` ability。
