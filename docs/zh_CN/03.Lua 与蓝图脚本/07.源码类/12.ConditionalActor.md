# Source.ConditionalActor

Metadata 来源：`Scripts/Source/ConditionalActor_meta.lua`

直接 metadata 基类：`{ "Engine", "Actor" }`

`ConditionalActor` 声明控制 Actor 可见性的条件变量、运算符与比较值。

## 属性

| 名称 | 类型 | 默认值 | Metadata |
|---|---|---|---|
| `conditionVariable` | `string` | `""` | `InstVar` 仅限 `int`、`float`、`bool` 与 `string` |
| `conditionOperator` | `string` | `"=="` | 下拉选择：`==`、`~=`、`>`、`>=`、`<`、`<=` |
| `conditionValue` | `any` | `0` | `InstVarValue = "conditionVariable"`；运行时接受 number、boolean 或 string |

变量名为空时，配置的 `visible` 值保持不变。否则，当前变量与比较值的标量类型必须一致。数值支持全部六种运算符。布尔与字符串只支持相等和不等。变量缺失、运算符不受支持、类型不匹配或类型不受支持时都会报错，且不做隐式转换。

条件会持续控制 `setVisible(result, false)`：结果为 false 时，Actor 再次隐藏。子 Actor 保留各自的可见性设置，并跟随祖先的有效可见性。隐藏的 Actor 保留实例与订阅，Tick 仍受 `tickable` 与大地图流送控制。

## 生命周期

`onCreate()` 订阅 `GameInstance:getVariables()`，并立即判断条件。订阅以当前地图路径与非空的 `getMapTag()` 为标识。多个 Actor 可以各自监听同一字段。初始判断失败时，会先释放订阅，再向上传播错误。

`onDestroy()` 与 `onWorldSleep()` 会退订。`onWorldWake(elapsedSeconds)` 重新订阅，并按当前变量重新判断。Lua 或 Script Mixin 中的覆盖必须调用 `super()`；Blueprint 生命周期图必须继续执行父事件。Game 项目中的空生命周期图会自动继承这一行为。

`releaseConditionMonitor()` 可重复清理订阅，不改动可见性，也不改动持久销毁记录。`ConditionalActor.ReleaseMapMonitors(gameMap)` 释放属于离开地图的全部条件订阅。`SceneMap` 在替换地图和销毁之前调用它，并在移除被抑制的大地图 Actor 身份之前释放其子树。Scene 被临时覆盖时会保留订阅，便于重新进入。

订阅与由此推导出的可见性状态都不会进入存档。变量在存档快照中保留当前逻辑值。地图恢复会在 `onCreate` 之前移除已销毁的摆放项，因此已拾取的物品不会重新出现。

## 继承

Enemy、Item、Equip、DoorBase 与 Teleporter 都继承此类。Bottle、Gem 以及 Game 项目中其他直接的地图 Actor Blueprint 以 `Source.ConditionalActor.ConditionalActor` 为父类。`EnemyDamageText` 保留原有的父类与提示逻辑。
