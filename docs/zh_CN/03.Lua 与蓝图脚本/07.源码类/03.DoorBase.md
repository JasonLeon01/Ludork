# Source.DoorBase

Metadata 来源：`Scripts/Source/DoorBase_meta.lua`

`DoorBase` 声明门的碰撞、开启间隔、开门音效与门状态属性，以及开门和关门节点。

它的两阶段 latent 条件与移动节点共享 `Source.Configs.MovementLatentOutputs.STARTED`（`0`）和 `FINISHED`（`1`）；这些值表示执行输出索引。
