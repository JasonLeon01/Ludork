# Lua 与 native 边界基准

从 Sample 目录运行 Release 构建，无需修改游戏入口脚本即可测量图形、光照和文本布局工作负载：

```powershell
cd Sample
./bin/Release/Main.exe ../tools/benchmark_lua_native_boundaries.lua pixel
./bin/Release/Main.exe ../tools/benchmark_lua_native_boundaries.lua lighting
./bin/Release/Main.exe ../tools/benchmark_lua_native_boundaries.lua text
```

脚本报告 `os.clock` CPU 时间；只比较同一机器、同一构建配置的结果。像素网格计时前，脚本会逐项比较 native 与 Lua 参考实现生成的顶点位置、纹理坐标和颜色。
