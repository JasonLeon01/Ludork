# 资源、音频、视频与效果

## 资源路径

使用 `Assets/System/Icon.png` 这类不带前导 `./` 的项目相对资源路径和 metadata 驱动的选择器。C++ manager 会缓存 texture、shader 和 audio 资源；Lua 中不要自行拼接操作系统路径分隔符。Android 会把最终化资源作为 APK assets 保存，并在原生启动前镜像到内部 runtime 目录，因此 SFML 与普通文件系统调用都使用同一个 `Assets/...` key。只有行为确实因平台而异时才读取 `PLATFORM`。

## 音频

音乐、音效和语音在 `Main.ini` 中拥有独立开关与音量。GlobalFunctions 的 Manager 分组提供玩法侧辅助函数。缺失的可选音效路径应显式处理；用不同拼写重复加载同一资源会破坏缓存效果。

玩法 Manager 与 Blueprint 节点使用的音频 Effect 是定义在 `Source.AudioEffects` 中的 Lua DSP processor。Sample 提供大小写敏感的 `Echo`、`Distortion`、`Underwater` 和 `BehindWall` 四个 preset。默认参数仍分别为 0.3 秒/0.5 衰减的 Echo、2.0 drive/0.7 threshold 的 Distortion、0.7 depth/0.3 bubble intensity 的 Underwater，以及 900 Hz/0.35 transmission 的 BehindWall。

`NodeFunctions.System.SetEffect(audioType, effect)` 通过 `AudioEffects.Get` 解析名称，并分别为 `Sound`、`Voice` 或 `Music` 类别保存返回的 attacher；metadata 会把两个参数都显示为下拉框。选择操作不会创建 processor，也不会修改已经开始播放的声源。之后创建的每个声源都会调用 attacher，由它创建隔离的音频 Lua state 和全新的 processor。选择字面量字符串 `nil` 可清除后续播放使用的 preset；其他未知名称会立即报错。`Source.AudioEffects` 是唯一的 preset registry；新增或删除 key 时，还需手动同步 `SetEffect` metadata 下拉框以及对应文档和测试。Effect 选择不属于 `SoundFilter` 或 `MusicFilter`。

使用非空 preset 时，创建声源会在播放前锁定当前播放设备采样率。设备 reroute 后，活动声源继续使用创建时的系数；如需使用新设备采样率，应通过 Manager 发起一次新播放。attacher 必须恰好安装一个非空 processor，因此已选择的 preset 不会以 dry 模式播放。SFML 的每个声源只保存一个 processor，preset 不会串联或混合。

`Echo` 会在自然结束时排空已缓存尾音。通过 Manager 停止、跳过对话或 shutdown 会丢弃剩余尾音。直接使用 `sf.SoundSource:setEffectProcessor` 属于另一套低层 API，不具备 Manager 的隔离、EOS 或取消协议。

`NodeFunctions.Scene.ShowVoiceMessageByTag` 和 `ShowVoiceMessage` 会在对话生命周期内捕获并持有本次调用实际启动的 Voice handle。对话结束时，它们的 latent condition 会先停止该 handle，再通过 `FinishedDialogue` 恢复后续 Blueprint 执行。紧随其后的 `SetEffect` 会配置下一段 Voice。离开或销毁地图场景时也会停止当前全局 Voice。普通消息节点不会改变 Voice 播放。

## Shader、雾与转场

图层 shader 与屏幕效果是可选 runtime 能力；使用 `sf.Shader.isAvailable()` 或 `sf.Shader.isGeometryAvailable()` 检查，并保留可玩的 fallback。进入大地图时，每个大地图或 Active 图层 shader 预热一次；重建的 shader 对象会重新预热。HarmonyOS OpenGL ES 把无版本 shader 视为 ESSL 1.00，并保留公开的 `setUniform("texture", ...)` 名称；显式版本必须匹配后端。

Actor fragment shader 会按精确的 shader 路径缓存到本次 Engine runtime 结束。使用同一路径的 Actor 因此会从 `Actor:getShader()` 获取同一个 `sf.Shader`。每次绘制 Actor 地图图像或预览图像前，runtime 都会重新绑定标准的 `texture`、`time`、`textureSize` 和 `textureRect` uniform。其他 uniform 仍是 shader 的共享可变状态，不得将其当作 Actor 私有的持久值。shader 加载失败时不会进入缓存；受影响的 Actor 会通过 `Actor:hasShaderError()` 报告错误，并继续使用现有 fallback 绘制路径。

雾贴图遵循普通 RGBA 语义：RGB 提供雾颜色，Alpha 提供逐像素密度，地图的 `fogPower` 缩放最终不透明度。Shader 路径和 Sprite fallback 使用相同的颜色与 Alpha 解释。

地图雾效数据采用严格的可选字段协议。`fog` 是字符串；缺失、为 `nil` 或为空白时禁用雾效。`fogPower`、`fogOx`、`fogOy` 与 `fogDistort` 必须是 float 范围内的有限数值，并且仅在缺失或为 `nil` 时默认为 `0`。小于等于 `0` 的 `fogPower` 同样禁用雾效。强度与扭曲度会向下取整并 clamp 到 `0..100`，两个 offset 字段控制滚动。不接受数值字符串或其他标量 coercion。

### 组合式大地图环境

大地图清单可以定义全局雾，但不能定义 BGM、BGS、音频 filter 或环境光。全局雾覆盖 Camera；子地图雾裁剪到 placement 并按大地图坐标采样。淘汰子地图时会移除其区域雾，重新加载后恢复。

BGM、BGS 和环境光由玩家所在子地图决定。音频切换使用 0.5 秒淡变；淡出期间返回会恢复原声源。后续环境光变化同样在 0.5 秒内插值，空洞使用白色；大地图全局雾仍保留。

Sample 的高级敌人击败特效由全局类设置 `Enemy.DefeatShatterEffectEnabled` 控制；该设置默认为 `true`，且不是 Blueprint 字段。它的 Shader 会把视觉快照绘制为世界空间逻辑像素碎片，并在约 0.65 秒内从中心径向向外消散。此时敌人已经被记录并销毁，所以快照不影响可通行性，也不参与碰撞或遮光。当该设置为 `false`，或 `sf.Shader.isAvailable()` 返回 false 时，敌人会改为立即消失。

## 视频

视频播放需要启用 FFmpeg 的项目或模板。视频放在 `Assets/Videos`，并打包正确 runtime 变体。Windows 与 macOS 的 FFmpeg 构建使用共享库或动态库；iOS、HarmonyOS 与 Android 视频需要 C++ Source + FFmpeg，并使用 `Sample/cmake/FFmpeg` 构建的静态 `.a` 库。下游发行必须满足 `Licenses/FFmpeg/README.md` 所述的适用 LGPL 重链接材料要求。Android 裁剪构建保留 file protocol、MOV demuxer、H.264/AAC decoder 与 parser、swscale 和 swresample，不启用 network、JNI、MediaCodec 或硬件加速。资源存在并不表示非 FFmpeg 模板能够播放。

## 限制

Shader 可用性由运行时图形环境决定；编辑器预览成功不代表目标硬件具备同等支持。

大地图灯光使用大地图坐标，因此 Active Actor 灯光与子地图静态灯光可以跨子地图边界照明和投影。Tile mask 仍裁剪到 placement；空洞不贡献 surface 或 blocker。编辑器拼合预览不显示雾和灯光。
