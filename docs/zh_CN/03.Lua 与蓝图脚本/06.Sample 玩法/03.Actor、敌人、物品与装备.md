# Actor、敌人、物品与装备

## 适用范围

本页说明 Sample 如何组合脚本类、Blueprint 与 General Data，以定义世界 Actor、敌人、物品和装备。这里界定各数据层的职责，不重复列出每个 schema 字段。

## Actor 与 Character

`Actor` 提供地图所有权、位置、生命周期和碰撞相关行为。Character 类增加移动和朝向。公开类默认值必须写在 Lua 类表上；`init` 只用于构造参数和私有运行时状态。

## 敌人

Enemy Blueprint 把类默认值与 Enemy General Data 成员组合。运行时数据提供战斗数值、奖励、掉落、动画和特殊效果配置。`onDefeat` graph 可选，只在存在时执行。

## 物品

Item 记录定义显示、可用性、价格、图标和使用后是否消耗。成员 graph 实现 `onUse` 与 `onGet`。可复用算法应放入 Lua 或 Common Function，不要在多个成员中复制大型图。

## 装备

Equip 记录定义槽位和属性增量。`onEquip` 与 `onUnequip` graph 在普通数值变化前后实现特殊行为。槽位名必须与选择的 Class 数据一致。

## 运行时引用

General Data 标识符应作为稳定 key。显示名称和说明可以使用花括号本地化标识符；查找表由“插件开发与安装”专题管理。重命名标识符时必须更新所有引用。

Sample 的精确 schema 与成员列表见“General Data 参考”；Bottle、Gem、门和敌人范例见“用法范例”。

## 验证

分别创建相关类型的 Actor 并运行地图，确认其 Blueprint 默认值、引用的 General Data 记录和成员 graph。装备必须分别测试装备与卸下路径；消耗品必须分别测试使用效果与库存扣除。

## 限制

General Data 标识符属于项目契约，重命名时不会自动修复全部引用。Sample 中的战斗和库存规则仅为示例，不是引擎强制行为。
