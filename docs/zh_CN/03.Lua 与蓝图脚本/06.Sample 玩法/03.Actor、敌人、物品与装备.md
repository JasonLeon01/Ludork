# Actor、敌人、物品与装备

## 适用范围

本页说明 Sample 如何组合脚本类、Blueprint 与 General Data，以定义世界 Actor、敌人、物品和装备。这里界定各数据层的职责，不重复列出每个 schema 字段。

## Actor 与 Character

`Actor` 提供地图所有权、位置、生命周期和碰撞相关行为。Character 类增加移动和朝向。公开类默认值必须写在 Lua 类表上；`init` 只用于构造参数和私有运行时状态。

## 移动、寻路与动画

`GameMap` 会缓存地块可通行性和动态 Actor 占用。Actor 列表或地形变化时会重建相应缓存，普通移动只更新单个 Actor 的占用；执行 A* 前，寻路会核对并更新占用格发生变化的 Actor。点击移动对普通目标与单格阻挡目标会复用直接 A* 结果；若移动 Actor 的完整占用范围使该直接结果不可用，则回退为搜索目标的相邻格。碰撞目标仍作为最后一次尝试移动，以继续触发其碰撞交互。普通无碰撞 `onOverlap` Actor 仍会令移动停在邻格；显式点击 Teleporter 时则会进入所选占用格，以触发 overlap 传送。

`PathRouteState` 持有路线副本，并公开随路线变化的 revision。预览渲染器只在 revision 变化后刷新缓存路线，复用矩形图形，并在玩家进入另一个地图格时裁剪可见路线。若 texture rectangle 尺寸不变，仅修改图集帧源位置不会刷新 Actor 边界；帧尺寸变化时仍会刷新缓存边界与占用格。

实时地图还会缓存移动特殊效果的危险格。领域以严格小于配置范围的曼哈顿距离判定，夹击要求两名对应敌人处于玩家两侧，阻击则在敌人相邻格生效；同格的正伤害贡献会累加。玩家取得怪物手册后，`EnemyDamageText.EnemyDamageHintLevel` 决定预计伤害提示：`EnemyDamageText.DamageHintLevel.NONE`（`0`）同时隐藏敌人的预计战斗伤害读数和危险格预计总伤害，`BATTLE`（`1`，默认值）只显示每个敌人的读数，`MAP`（`2`）还会在每个受影响格中央显示预计总伤害。怪物手册是所有可见等级的共同前提。危险格提示复用敌人读数的文字样式与伤害颜色，不绘制彩色背景或边框。该预览不会执行 Blueprint、`onOverlap`、`onWalk`、阻击后退、攻击动画或伤害结算。提示等级只影响提示，不改变生命结算，也不隐藏命中后的真实伤害飘字。即使尚未取得怪物手册，普通点击寻路也始终会把正伤害格作为禁止进入的 Actor anchor 交给 A*；直接点击危险格时仅放行明确目标格。点击领域或阻击敌人占用的任一格时，会从所有候选格移除该目标敌人自身的伤害贡献；若它还参与夹击，也只移除它的一侧，其他来源的伤害仍保持禁行。玩家实际不会进入的碰撞或 overlap 目标也不会因目标格自身危险而被拒绝。自动移动期间若危险 revision 变化，玩家会回到最后一个完整进入的地图格再重新规划，而不会向前四舍五入到下一格；没有安全路线时不再移动。

## 敌人

Enemy Blueprint 把类默认值与 Enemy General Data 成员组合。运行时数据提供战斗数值、奖励、掉落、动画和特殊效果配置。`onDefeat` graph 可选，只在存在时执行。

伤害预览只计算攻击者打出致命一击之前发生的反击。防守方最大生命为 `H`、每轮受到的正伤害为 `D` 时，反击次数为 `max(ceil(H / D) - 1, 0)`。

累计的领域、夹击、阻击伤害导致玩家战败时，Sample 会立即结算该伤害，但只在同时开始的攻击动画中最长者播放完毕后进入 Game Over 场景，与普通敌人战斗的时序一致。

## 物品

Item 记录定义显示、可用性、价格、图标和使用后是否消耗。成员 graph 实现 `onUse` 与 `onGet`。可复用算法应放入 Lua 或 Common Function，不要在多个成员中复制大型图。

## 装备

Equip 记录定义槽位和属性增量。`onEquip` 与 `onUnequip` graph 在普通数值变化前后实现特殊行为。槽位名必须与选择的 Class 数据一致。

## 运行时引用

General Data 标识符应作为稳定 key。显示名称和说明可以使用花括号本地化标识符；查找表由“插件开发与安装”专题管理。重命名标识符时必须更新所有引用。

Sample 的精确 schema 与成员列表见“General Data 参考”；Bottle、Gem、门和敌人范例见“用法范例”。

## 验证

分别创建相关类型的 Actor 并运行地图，确认其 Blueprint 默认值、引用的 General Data 记录和成员 graph。依次点击空闲格、碰撞目标、无碰撞 `onOverlap` 目标，以及单格和多格 Teleporter 的每个占用格，再在移动或生成阻挡 Actor 后重复测试；确认 Teleporter 会传送玩家，且玩家尚未取得怪物手册时，自动路线仍会绕开领域、夹击和阻击的正伤害格。取得怪物手册后，依次测试三个伤害提示等级：`NONE` 隐藏敌人和危险格提示，`BATTLE` 只显示敌人战斗读数，`MAP` 再增加受影响格中央的预计总伤害；提示等级不得改变寻路或实际伤害。路线预览必须按地图格推进，相关敌人的移动或数值变化必须触发无预览副作用的安全重规划。分别用领域、夹击和阻击造成致命伤害，并配置不同时长的动画，确认 Game Over 会等待所有唯一攻击者中最长的动画；非致命和零时长动画应保持正常时序。同时确认使用不同尺寸帧的动画仍具有正确的碰撞边界。装备必须分别测试装备与卸下路径；消耗品必须分别测试使用效果与库存扣除。

## 限制

General Data 标识符属于项目契约，重命名时不会自动修复全部引用。Sample 中的战斗和库存规则仅为示例，不是引擎强制行为。
