# 消耗品

## 目标

使用 Script Mixin 创建由碰撞触发的回复或属性拾取物。

每个配方都应测试成功路径、条件不满足路径与重复触发。

## 前置条件

- 已保存且启用碰撞的 Actor 派生 Blueprint。
- 生成 Player Attribute Set 中匹配的数值字段，以及有效的 Audio 配置回退（fallback）。

## 步骤

物品行为适合表示为 Actor 碰撞方法时，可使用 Script Mixin。

1. 创建继承 Actor 的 Blueprint 并启用 Script Mixin。
2. 挂载 `Consumables/Bottle.lua` 或 `Consumables/Gem.lua`。
3. 回复瓶设置 `HP_plus`；宝石设置 `ATTR_key` 与 `plus`。
4. 选择音效，或留空，使用 Audio 配置中的回退（fallback）。
5. 放置到地图，分别测试与玩家和非玩家碰撞。

Bottle 对 `HP` 应用 Instant Add Effect；Gem 对 `ATTR_key` 选择的 `int` 或 `float` Player attribute 执行同类操作。共享的拾取流程负责找到 Player：先把拾取物记录为已销毁，再销毁它。

## Sample 演练

- `Bottle_200.json` 直接继承 `Engine.Actor`，启用 `scriptMixin`，选择 `Consumables/Bottle.lua`，设置 `HP_plus = 200`，开启碰撞并选择药水纹理。
- `Gem_1_1.json` 选择 `Consumables/Gem.lua`，设置 `ATTR_key = "ATK"` 与 `plus = 1`，并选择宝石纹理。
- 两者都保留 metadata 的 `getSE` 默认值，因此脚本会解析 `Audio.getSE`。

## 限制

Sample 脚本依赖其声明的父类能力、metadata 字段与 General Data/配置 key，不是通用背包组件。
