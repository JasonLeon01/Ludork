# 游戏设置参考

Game Config 修改 `Main.ini` 的 `[Main]` 字段。

## 支持的字段

| 键 | 类型 | 含义 |
|---|---|---|
| `script` | 路径 | Lua 入口，通常是 `Scripts/Entry.lua` |
| `language` | 字符串 | 游戏语言表 key；见“游戏本地化工作流” |
| `scale` | 浮点 | 显示缩放偏好；桌面端与 HarmonyOS 2in1 默认 `1.0`，启用自由多窗模式的 HarmonyOS Mobile 平板在字段缺失时以内存值 `0` 为默认 |
| `maxrenderscale` | 浮点 | 最大内部渲染缩放，默认 `2.0`；不限（`0`）表示不设上限 |
| `lightingrenderscale` | 离散浮点 | 直接光照渲染倍率：`0.5`、`0.75` 或 `1.0`；缺失或无效值使用 `1.0` |
| `framerate` | 整数 | 目标帧率，默认 `30` |
| `antialiasinglevel` | 非负整数 | 请求的 SFML 抗锯齿等级；默认使用 `sf::ContextSettings` 自身的默认值 |
| `verticalsync` | 布尔 | 垂直同步 |
| `musicon`、`soundon`、`voiceon` | 布尔 | 音频通道开关 |
| `musicvolume`、`soundvolume`、`voicevolume` | 浮点 | 通道音量，限制到 0–100 |

编辑器保留未知 section/key。受支持字段值无效时，对应读取器会使用安全默认值；应修复源值，而不是依赖 fallback。

`Main.proj` 保存项目/工具标志，而不是可变游戏偏好。`Cpp` 选择原生项目行为，`ffmpeg` 选择视频打包能力，`IndividualWindow` 保存编辑器首选运行模式。

项目打开期间修改的设置参与统一 dirty 状态，并由普通 Save 写入。已有文件保留其已保存帧率；把默认值改为 `30` 不会覆盖旧值。

`System.isDisplayScaleConfigurable()` 为 true 时，缩放立即生效。桌面端（包括 HarmonyOS 2in1）使用正数值调整窗口，`0` 表示无边框全屏；手动调整不保存，不匹配的宽高比使用黑边。在 HarmonyOS Mobile API 22 或更高版本的平板上，仅自由多窗模式提供“缩放”：正数请求自由窗口，`0` 请求最大化/全屏。此时新建配置会写入 `scale = 0`；字段缺失时只在内存中按 `0` 处理。模式变化时 Config 会更新该行，并在保存前重新检查。其他移动端不显示该项。负数或非有限值按 `1` 处理。宿主映射见[场景与系统](<../07.API 参考/04.Core 模块/03.GlobalCore/06.场景与系统.md>)。

`maxrenderscale` 在界面中显示为“渲染上限”，用于限制 System 内部 canvas 及其依赖 render target，而不改变窗口、逻辑游戏尺寸或已配置缩放。它在全平台立即生效。Config 提供 `0.5`、`0.75`、`1`、`1.5`、`2`、`3`、`4` 与不限（`0`），保留其他有限非负值，并把负数或非有限值按 `2` 处理。

光照渲染倍率立即生效，且不重建 System canvas。动态直接光照目标使用当前逻辑相机 View，静态目标始终使用完整地图逻辑 View；每个目标轴为 `floor(逻辑像素数 * lightingrenderscale)`，且最小为一个像素。Surface Mask 以及静态/动态 Transmission 和 Occupancy 目标继续保持全分辨率。低于 `1.0` 的值使用平滑上采样，`1.0` 保持全分辨率采样路径。倍率变化会重建两个直接光照目标并使静态光缓存失效，从下一次地图帧开始生效。其他数值、非有限值与缺失字段均按 `1.0` 处理。

Config 依次列出“低 / 中 / 高 / 超高 / 原画 / 自定义”，并根据（`maxrenderscale`、`framerate`、`antialiasinglevel`、`lightingrenderscale`）反推当前档位：

| 档位 | 数值 |
|---|---|
| 低 | （`0.75`、`30`、`0`、`0.5`） |
| 中 | （`1`、`60`、`2`、`0.75`） |
| 高 | （`2`、`60`、`8`、`1`） |
| 超高 | （`3`、`90`、`8`、`1`） |
| 原画 | （不限（`0`）、`120`、`8`、`1`） |

其他组合显示位于末尾、仅用于显示的“自定义”；选择它不会应用数值。配置中不保存档位字段，`scale` 与 `verticalsync` 不参与判定。

抗锯齿等级是请求的多重采样等级，SFML 可能创建平台所支持的最接近上下文。`0` 是 SFML 默认值，表示关闭抗锯齿。该值属于上下文创建参数，因此修改时会保存偏好，但只有再次初始化显示（通常是下次启动游戏）后才影响渲染。负数或超出范围的值按 SFML 默认值处理。

桌面独立运行（包括 HarmonyOS 2in1）启动时，会按主显示器工作区过滤正数缩放预设 `1`、`1.25`、`1.5`、`1.75`、`2`、`3`、`4`；打开 Config 时重新检查窗口当前所在显示器。HarmonyOS Mobile 自由多窗模式使用显示器可用区域与 Stage 最大尺寸中的较小者。全屏（`0`）和能放下的非预设值仍可选。超限值改为最高可用预设，无正数预设时改为全屏；移到更大显示器后不会自动升档。尺寸查询失败则保持选项和配置值。

## 限制

受支持字段由当前 Sample 读取器解释。增加项目专用字段时必须实现对应运行时处理；仅在 `Main.ini` 中写入字段不会自动产生行为。

可配置的 HarmonyOS Mobile 宿主会在初始化原生宿主以及每次启用自由多窗模式时采样最大窗口尺寸。若运行期间把窗口移到其他显示器或显示器可用区域发生变化，且自由多窗模式没有发生切换，则仍需重建宿主或重启，缩放选项才会采用新的容量。HarmonyOS 2in1 则使用普通桌面窗口与显示器查询。
