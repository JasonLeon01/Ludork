# 游戏设置参考

Game Config 修改 `Main.ini` 的 `[Main]` 字段。

## 支持的字段

| 键 | 类型 | 含义 |
|---|---|---|
| `script` | 路径 | Lua 入口，通常是 `Scripts/Entry.lua` |
| `language` | 字符串 | 游戏语言表 key；见“游戏本地化工作流” |
| `scale` | 浮点 | 桌面端画布到窗口的首选缩放，默认 `1.0`；`0` 表示桌面尺寸的无边框全屏 |
| `framerate` | 整数 | 目标帧率 |
| `verticalsync` | 布尔 | 垂直同步 |
| `musicon`、`soundon`、`voiceon` | 布尔 | 音频通道开关 |
| `musicvolume`、`soundvolume`、`voicevolume` | 浮点 | 通道音量，限制到 0–100 |

编辑器保留未知 section/key。受支持字段值无效时，对应读取器会使用安全默认值；应修复源值，而不是依赖 fallback。

`Main.proj` 保存项目/工具标志，而不是可变游戏偏好。`Cpp` 选择原生项目行为，`ffmpeg` 选择视频打包能力，`IndividualWindow` 保存编辑器首选运行模式。

项目打开期间修改的设置参与统一 dirty 状态，并由普通 Save 写入。运行中的 Sample 会在桌面端立即应用缩放。正数缩放会设置可调整大小的桌面窗口；手动调整窗口仅影响当前运行，不覆盖 `Main.ini`。手动选择与游戏不同的宽高比时会以黑边居中，而不会拉伸画面。移动端仍保留该配置值，但系统窗口始终全屏，因此 Game Config 不提供缩放选项。无效的负数或非有限缩放值按 `1` 处理。

桌面独立运行启动时，会按主显示器工作区过滤正数预设值 `1`、`1.25`、`1.5`、`1.75`、`2`；打开 Config 时则重新检查窗口当前所在显示器。全屏（`0`）和能放下的当前非预设值会保留。超限值会保存为能放下的最高预设值；若没有正数预设值可用，则保存为全屏。移到更大的显示器后不会自动升档。工作区查询失败时，选项和配置值保持不变。

## 验证

每次只修改一个受支持值，保存、关闭并重新打开项目，再运行游戏确认生效值。检查 `Main.ini`，确认不相关 section 和 key 未丢失。对于缩放，验证跨显示器过滤、持久化降档以及不会自动升档。

## 限制

受支持字段由当前 Sample 读取器解释。增加项目专用字段时必须实现对应运行时处理；仅在 `Main.ini` 中写入字段不会自动产生行为。
