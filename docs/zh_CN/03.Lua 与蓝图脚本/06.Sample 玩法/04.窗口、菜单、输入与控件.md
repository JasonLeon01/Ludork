# 窗口、菜单、输入与控件

默认 Lua UI 由运行时窗口与控件类构建。场景创建窗口，控件接收焦点和输入，UI manager 管理层叠与所有权。

## 窗口与菜单

在所属窗口中创建控件，按可预测顺序添加，并在窗口关闭时释放回调。菜单应把稳定命令标识符与显示文本分离。长说明应使用现有换行和格式化辅助函数。

游戏内菜单包含物品道具、装备、存档、设置与回到标题。选择设置会在菜单之上打开共享的 Config 窗口并停用命令列表；关闭 Config 窗口后焦点回到菜单。

每个窗口模块只返回一个公开类。调用方 require 其具体路径，不存在聚合导出表或旧路径别名。

标题界面打开 Config 或 Save/Load 后，底层 command window 不会收到同一触摸手势的任何阶段。

`WindowBase` 在 `Content` 外的左上边框提供可选的 16 × 16 返回按钮。可取消窗口通过 `setHasReturnBtn(true)` 启用它，并覆盖默认无操作的 `onReturn()`，执行与其他 Cancel 输入相同的状态返回步骤。该共享返回步骤只播放一次系统 CancelSE，不要从第二条 Cancel 路径再播一次。多面板窗口只在当前活动的交互面板显示按钮；隐藏、停用或被抑制的窗口不显示该按钮。

静态命令行保存 `localeKey`，动态命令行保存字面量 `text`，同一行不得同时定义两者。命令行在刷新时解析 `localeKey`，因此语言切换可以原位更新已有控件，而不替换 callback 或游标状态。运行时语言变化后，标题命令、游戏内菜单、存读档命令、商店命令和当前可见的地图区域标题都会立即更新。

`SceneMap` 为长生命周期地图窗口统一持有一个 `LocaleChanged` 订阅。活动对话会保留原始说话者、消息或选项、显式 `localeArgs`，以及节点局部变量和实例变量快照；刷新时依次重新解析模板、解析 `localeArgs` 中的 string、应用这些参数，再应用两份变量快照，最后原位更新现有 `WindowMessage` 控件。物品和装备详情、属性商店、怪物手册、`WindowEnemyEncyclopedia` 与地图传送器（`WindowFloorTeleporter`）也会原位刷新本地化文本，并保持当前选择、焦点和预览状态。隐藏窗口下次打开时按当前语言解析；Config、存档槽与玩家 HUD controller 保留各自订阅。玩家 HUD 还会轮询轻量的地图、战斗 revision、成长、钥匙与有序状态签名，并只在某个签名变化时刷新受影响的控件。

## 输入

运行时输入来自 C++ input service。应使用文档中的键盘、鼠标、控制器和注入输入 API，不要读取编辑器状态。Windows 嵌入模式通过 runtime 协议转发兼容输入；独立游戏直接使用原生窗口。

在 Android 与 HarmonyOS 上，宿主把系统返回键或返回手势转换为一次 Cancel/Escape 脉冲，而不关闭应用或使其退到后台。该路径与 HarmonyOS 外接键盘转发保持独立；后者把 SFML 映射的常规键转发为带修饰状态的 scancode 边沿，并在可解析时同时产生 logical key 边沿。双指触摸仍是独立的鼠标右键取消手势；系统返回与双指触摸都会调用焦点窗口的 `onReturn()`，但只有后者产生鼠标右键输入。

物理 Enter 与 Space 使用 Confirm action，Escape 使用 Cancel。键盘按下与释放是边沿事件；见[输入与服务](<../07.API 参考/04.Core 模块/02.Engine/07.输入与服务.md>)。

`WindowSelectable` 统一负责默认 Cancel 键和鼠标右键关闭行为；派生窗口把未处理输入交回基类，使每个输入边沿只播放一次 Cancel 音效并执行一次关闭切换。

## 焦点与导航

键盘/控制器导航需要明确焦点顺序。禁用或隐藏控件不应继续作为活动焦点。指针激活与键盘/控制器激活应分别测试。

## 设置控件

默认 Config 窗口在独立边框的设置窗口上方显示完整的 Tab 命令窗口。它提供“画质 / 音量 / 语言”三个 Tab，默认位于画质页。左右方向即时预览页面，Confirm 或指针点击进入该页设置。每页在本次运行中保留游标与滚动位置，切换语言会原位刷新可见文本而不丢失焦点。

Cancel 与返回按钮会依次收起展开的 DropBox、离开设置列表、关闭 Config。画质页包含画质档位、可选的缩放、渲染上限、帧率、抗锯齿、垂直同步与光照分辨率；音量页包含三个音频通道的开关与音量；语言页包含语言。各项选项、档位、平台可用性、生效时机与持久化规则集中在[游戏设置参考](<07.游戏设置参考.md>)。

移动端的 Slider 点击会在释放时设置数值。超过拖动阈值后，横向移动归 Slider，纵向或等量斜向移动归 Config 列表。手势归属在释放前保持不变，列表仅在内容超出可视区域时滚动。

展开的 Config DropBox 会覆盖设置行并独占输入，直至折叠或关闭 Config；两种操作都会恢复父列表输入。高度受限的 popup 在内部滚动，移动端触摸采用预览后确认。见[交互与声明式 UI 控件](<../07.API 参考/04.Core 模块/02.Engine/13.交互与声明式 UI 控件.md>)。

精确 UI 与输入 API 见 [Blueprint API 参考](<../07.API 参考/01.节点函数/01.Container.md>)。游戏本地化标签遵循[游戏本地化工作流](<../../05.插件开发与安装/06.游戏本地化工作流.md>)；本节不介绍编辑器语言切换。

## 限制

嵌入式输入转发仅适用于受支持的 Windows 编辑器运行模式。最终输入、焦点和控制器测试仍应以原生独立窗口为准。
