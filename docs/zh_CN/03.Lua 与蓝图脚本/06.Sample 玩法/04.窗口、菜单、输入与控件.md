# 窗口、菜单、输入与控件

默认 Lua UI 由运行时窗口与控件类构建。场景创建窗口，控件接收焦点和输入，UI manager 管理层叠与所有权。

## 窗口与菜单

在所属窗口中创建控件，按可预测顺序添加，并在窗口关闭时释放回调。菜单应把稳定命令标识符与显示文本分离。长说明应使用现有换行和格式化辅助函数。

游戏内菜单包含物品道具、装备、存档、设置与回到标题。选择设置会在菜单之上打开共享的 Config 窗口并停用命令列表；关闭 Config 窗口后焦点回到菜单。

每个可见默认界面都有一个顶层资产：Init、Title、Game Over、Region Title、HUD、Menu、Config、Message、Item、Equip、Shop、Save/Load、属性商店、怪物手册、百科和楼层传送器。多窗格界面把各窗格嵌套在同一根下；同级输入宿主复用其中的列表与滚动区。

资产包含代表性的 `#TAB`/`#ITEM` 子项和 Sample 视觉资源，Controller 在显示前替换它们，并在不改变数量的情况下本地化 TabView items。Enemy Book 与 Encyclopedia 使用 `CharacterView`；运行时传入真实 Actor 快照，原生控件负责裁帧、动画、缩放和 Shader/Hue 特效。

每个窗口模块只返回一个公开类。调用方 require 其具体路径，不存在聚合导出表或旧路径别名。

标题界面打开 Config 或 Save/Load 后，底层 command window 不会收到同一触摸手势的任何阶段。

`WindowBase` 在 `Content` 外的左上边框提供可选的 16 × 16 返回按钮。可取消窗口通过 `setHasReturnBtn(true)` 启用它，并覆盖默认无操作的 `onReturn()`，执行与其他 Cancel 输入相同的状态返回步骤。该共享返回步骤只播放一次系统 CancelSE，不要从第二条 Cancel 路径再播一次。多面板窗口只在当前活动的交互面板显示按钮；隐藏、停用或被抑制的窗口不显示该按钮。

静态命令行保存 `localeKey`，动态命令行保存字面量 `text`，同一行不得同时定义两者。命令行在刷新时解析 `localeKey`，因此语言切换可以原位更新已有控件，而不替换 callback 或游标状态。运行时语言变化后，标题命令、游戏内菜单、存读档 Tab、商店 Tab 与详情，以及当前可见的地图区域标题都会立即更新。

可复用选择窗口开始新的打开会话时，选择器从零索引开始并滚动到顶部；空选择器使用 `nil`。该规则适用于游戏内菜单、物品与装备窗口、商店、Config、怪物手册和地图传送器。同一会话中的焦点变化和原位刷新保留选择。

商店的两列物品列表保持焦点，Q/E、LB/RB、鼠标或触摸切换买卖。切换 Tab 会重置游标和滚动；交易刷新保留仍有效的选择。购买格显示图标，出售格另显示持有数量；详情显示本地化名称、说明和右对齐价格。出售获得 `floor(price / 2)` GOLD，零售价结果不进入列表。仅购买商店隐藏 Tab 并居中其余窗格；Cancel 直接关闭。

溢出列表使用 `Engine.ScrollBox`。它裁剪绘制与命中，只滚动溢出轴，并保证键盘/控制器当前选择可见。原生边缘提示显示剩余内容；详见[布局与图像控件](<../07.API 参考/04.Core 模块/02.Engine/10.布局与图像控件.md>)。

消息窗口使用全屏 Canvas 和透明 `FunctionalImage`，为普通消息消费一次点击或触摸确认。选项模式禁用该层，点击空白不会选择选项。最多四个选项直接放在面板内，不使用 ScrollBox；`SceneMap` 只在对话期间阻断地图输入。

`SceneMap` 为长生命周期地图窗口统一持有一个 `LocaleChanged` 订阅。活动对话会保留原始说话者、消息或选项、显式 `localeArgs`，以及节点局部变量和实例变量快照；刷新时依次重新解析模板、解析 `localeArgs` 中的 string、应用这些参数，再应用两份变量快照，最后原位更新现有 `WindowMessage` 控件。物品和装备详情、商店 Tab 与详情、属性商店、怪物手册、`WindowEnemyEncyclopedia` 与地图传送器（`WindowFloorTeleporter`）也会原位刷新本地化文本，并保持当前选择、模式、焦点和预览状态。隐藏窗口下次打开时按当前语言解析；Config、存档槽与玩家 HUD controller 保留各自订阅。玩家 HUD 还会轮询轻量的地图、战斗 revision、成长、钥匙与有序状态签名，并只在某个签名变化时刷新受影响的控件。

地图传送器左侧槽位在楼层与传送点列表之间切换；取消传送点选择会恢复楼层列表。传送点列表滚动时不移动右侧预览。组合式清单仍是一个楼层身份：相交子地图按世界偏移合成，传送点名称来自其所在子地图。

## 输入

运行时输入来自 C++ input service。应使用文档中的键盘、鼠标、控制器和注入输入 API，不要读取编辑器状态。Windows 嵌入模式通过 runtime 协议转发兼容输入；独立游戏直接使用原生窗口。

在 Android 与 HarmonyOS 上，宿主把系统返回键或返回手势转换为一次 Cancel/Escape 脉冲，而不关闭应用或使其退到后台。该路径与 HarmonyOS 外接键盘转发保持独立；后者把 SFML 映射的常规键转发为带修饰状态的 scancode 边沿，并在可解析时同时产生 logical key 边沿。双指触摸仍是独立的鼠标右键取消手势；系统返回与双指触摸都会调用焦点窗口的 `onReturn()`，但只有后者产生鼠标右键输入。

物理 Enter 与 Space 使用 Confirm action，Escape 使用 Cancel。键盘按下与释放是边沿事件；见[输入与服务](<../07.API 参考/04.Core 模块/02.Engine/07.输入与服务.md>)。

手柄按钮通过按平台解析的 `Engine.JoystickButton.getA()` 至 `getShare()` getter 选择，API 不再提供固定数字字段。Android 与 HarmonyOS 使用已有 SFML 手柄后端；当前 SFML iOS joystick 后端无法报告连接、按键或轴输入，逻辑 getter 配置仅为未来后端支持预留。

默认移动和菜单方向只使用左摇杆 `X`/`Y` 与十字键 `PovX`/`PovY`。`|X| >= |Y|` 时选择水平方向，否则选择垂直方向；精确 45 度输入归入水平方向。触发式导航与持续移动共用该扇区规则，右摇杆和扳机轴不会抢占方向。

`WindowSelectable` 统一负责默认 Cancel 键和鼠标右键关闭行为；派生窗口把未处理输入交回基类，使每个输入边沿只播放一次 Cancel 音效并执行一次关闭切换。

## 焦点与导航

键盘/控制器导航需要明确焦点顺序。禁用或隐藏控件不应继续作为活动焦点。指针激活与键盘/控制器激活应分别测试。

## 设置控件

Config 打开后位于画质页并聚焦第一行。Q/E、LB/RB、鼠标悬停与触摸点击会切换 Tab 并播放 CursorSE。本次打开期间各页保留游标与滚动；重新打开会全部重置，语言刷新则保留状态。

切换 Tab 会静默收起已展开的 DropBox。Cancel 与返回按钮也会先收起它，下一次输入再关闭 Config。具体设置见[游戏设置参考](<07.游戏设置参考.md>)。

移动端的 Slider 点击会在释放时设置数值。超过拖动阈值后，横向移动归 Slider，纵向或等量斜向移动归 Config 列表。手势归属在释放前保持不变，列表仅在内容超出可视区域时滚动。

展开的 Config DropBox 会覆盖设置行并独占输入，直至折叠或关闭 Config；两种操作都会恢复父列表输入。高度受限的 popup 在内部滚动，移动端触摸采用预览后确认。见[交互与声明式 UI 控件](<../07.API 参考/04.Core 模块/02.Engine/13.交互与声明式 UI 控件.md>)。

存读档共用一套槽位列表。切换 Load/Save Tab 时保留游标、滚动与详情；重新打开时选择 Load 和最新已有存档，没有存档时选择 0 号槽。Cancel 关闭窗口；标题界面的仅加载模式不显示 Tab。

精确 UI 与输入 API 见 [Blueprint API 参考](<../07.API 参考/01.节点函数/01.Container.md>)。游戏本地化标签遵循[游戏本地化工作流](<../../05.插件开发与安装/06.游戏本地化工作流.md>)；本节不介绍编辑器语言切换。

## 限制

嵌入式输入转发仅适用于受支持的 Windows 编辑器运行模式。最终输入、焦点和控制器测试仍应以原生独立窗口为准。
