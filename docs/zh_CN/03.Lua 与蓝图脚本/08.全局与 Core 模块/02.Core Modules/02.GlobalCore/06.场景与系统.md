# GlobalCore：场景与系统

## SceneBase

直接 metadata 基类：—

### 显示缩放语义

`getConfiguredScale()` 返回配置的显示偏好，取值可以是 `0`。`getScale()` 返回应用最大渲染缩放之后，渲染与输入当前使用的正数有效缩放。配置偏好的默认值为 `1.0`。`setScale` 应用该值并保存。`applyScale` 只应用，`saveScale` 只保存。非有限值或负数一律归一为 `1`。桌面端用 `0` 选择无边框全屏，且不改变显示模式。正数值设置桌面独立窗口的固定尺寸，用户不能拖拽窗口边框改变大小，需通过缩放设置调整。渲染保持宽高比，并在需要时以黑边居中。macOS 上显示缩放以 Cocoa 客户区 point 计量，与 Retina backing scale 无关。

`isDisplayScaleConfigurable()` 对独立桌面窗口（包括 HarmonyOS 2in1）返回 true，对嵌入式显示和普通移动端显示返回 false。在 API 22 或更高版本的 HarmonyOS Mobile 构建中，只有启用自由多窗模式的平板返回 true。ArkTS 宿主监听 `freeWindowModeChange`，并据此更新原生状态。启用自由多窗模式时，或应用回到前台且仍处于该模式时，运行时会重新应用当前配置的缩放值。此时正数值请求 `round(gameSize * scale)` 像素的可绘制客户区，宿主另加窗口装饰尺寸后设置 Stage 外框大小。`0` 请求最大化或全屏窗口。宿主禁止用户拖拽改变窗口大小，窗口尺寸与全屏由缩放设置控制。渲染使用最终获得的 surface；若系统尺寸限制使客户区无法达到请求大小，仍保持宽高比并在需要时以黑边居中。HarmonyOS 2in1 遵循桌面缩放协议（默认 `1.0`）。

`getMaximumWindowedScale(gameSize)` 返回可用窗口尺寸所能容纳的最大缩放。桌面端（包括 HarmonyOS 2in1）使用当前窗口的装饰工作区；没有窗口时改用主显示器。可配置的 Mobile 宿主自行提供上限，并在 HarmonyOS 启用自由多窗模式时，或应用回到前台且仍处于该模式时刷新。嵌入式宿主、不可配置的移动端宿主、逻辑尺寸为零以及可用尺寸未知时，结果均为 `nil`。

### 最大渲染缩放语义

`getMaximumRenderScale()` 返回有效缩放的上限。`0` 表示不限，默认值为 `1`，无效值变为 `2`。`setMaximumRenderScale` 应用该值并在帧间保存，不调整窗口尺寸。`saveMaximumRenderScale` 只保存。

### 光照渲染倍率语义

`getLightingRenderScale()` 返回 `0.5`、`0.75` 或 `1`。默认值为 `0.75`，无效值变为 `1`。`setLightingRenderScale` 应用该值并保存，同时重建直接光照目标、使静态缓存失效。`saveLightingRenderScale` 只保存。Surface Mask、Transmission 与 Occupancy 保持全分辨率。

### 抗锯齿语义

抗锯齿默认值为 `2`，无效值使用 SFML 默认值。`setAntiAliasingLevel` 只保存该值，不重建当前上下文，因此该等级在下次初始化显示时生效。SFML 可能协商为其他受支持的等级。

### 帧率语义

`getFrameRate()` 返回配置的目标帧率，默认值为 `60`。`0` 表示不限，会关闭主动帧率限制。垂直同步保持独立，仍可能限制画面呈现。`setFrameRate` 应用该值并保存，`saveFrameRate` 只保存。不限时，固定更新步长为 `1/60` 秒；目标帧率为正数时，步长为 `1/framerate` 秒。

### iOS 图形上下文

在 iOS 上，启动需要 OpenGL ES 3.0 或更高版本的上下文。
