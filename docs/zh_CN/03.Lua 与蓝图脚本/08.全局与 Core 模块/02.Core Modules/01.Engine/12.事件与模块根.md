## EditorLiveDebug

`Engine.EditorLiveDebug` 是内置的编辑器服务。该类及两个静态方法都使用 `metadata = false`：Lua 和生成声明可以访问，但不会产生蓝图节点。

| 方法 | 参数 | 结果 |
|---|---|---|
| `install` | handler: function | 安装或替换当前 VM 的请求 handler。 |
| `uninstall` | — | 释放该 handler，重复调用无副作用。 |

handler 接收一个请求 table，必须恰好返回一个可 JSON 序列化的 table。原生分发不解释编辑动作。未安装 handler、Lua 错误、返回数量不正确或编码失败时，返回包含 `success = false` 与字符串 `error` 的响应。默认 Game 模块负责注册，普通玩法脚本不应在正常运行中替换该 handler。不存在编辑器桥接时，安装操作不生效。

注册归属于 Lua VM，并在关闭时释放。编辑器功能见 [实时调试](<../../../../02.编辑器用户指南/08.运行、调试与打包.md#实时调试>)。线协议分帧与调用时机见[编辑器桥接边界](<../../../../04.C++ 原生开发/01.构建与模块布局.md#编辑器桥接边界>)。

## 原生网页

`Engine.OpenWebView(url)` 在游戏最前方的独立原生层中打开 HTTP 或 HTTPS 网页。返回值表示请求是否被接受，不表示网络加载是否成功。无效地址或宿主不可用时返回 `false`。蓝图节点具有普通执行引脚与布尔返回值，不等待网页关闭。

该层提供关闭按钮、加载或错误状态以及可交互网页。JavaScript、链接、滚动与文字输入由系统 WebView 处理。打开新窗口的链接与重复调用都在当前层导航。不暴露下载、额外设备权限或 JavaScript 到游戏的桥接。输入截留见 [输入与服务](<07.输入与服务.md#webview-输入截留>)。替换游戏窗口或退出应用时关闭网页。

macOS 与 iOS 使用 WKWebView，Android 使用系统 WebView，HarmonyOS 使用 ArkWeb，Windows 使用已安装的 Evergreen WebView2 Runtime。Windows 缺少该 Runtime 时显示安装入口；游戏不会安装它，也不随包携带浏览器引擎。

## 类型化数据值

`resolveTypedDataValue(value, type, environment?, declaringModule?, evaluateAnyExpressions?)` 依据 [蓝图 Metadata](<../../../03.蓝图脚本/02.Metadata 结构与 Decorator.md>) 的 schema 还原并校验存储值，同时处理 `Union` 分支标签。`evaluateAnyExpressions` 默认为 `true`；传入 `false` 时，各层嵌套的 `any` 字符串都保留为字面值。

`resolveRuntimeTypedValue(value, type, declaringModule?)` 校验已有的运行时值并原样返回，不对字符串求值，也不重建原生对象。

`setRuntimeTypedAttribute(owner, name, value)` 依据所属对象的 metadata 校验并写入属性。在普通脚本字段上，显式 nil 会覆盖继承来的默认值。

## SavePreviewReader

`Engine.SavePreviewReader.new()` 创建异步存档预览读取器。所有公开调用与轮询都在游戏线程执行；此 API 仅供 Lua 使用，不生成蓝图节点。

| 方法 | 契约 |
|---|---|
| `requestScan(paths)` / `pollScan()` | 后台扫描不超过 10,000 个路径；每个完成结果仅返回一次 true。 |
| `getLatestSlot()` / `getScanError()` | 获取已完成扫描的最新槽位（从 1 开始；不存在时为 0）和错误，成功时错误字符串为空。 |
| `requestPreview(path, width, height)` / `pollPreview()` | 请求文件信息及原生缩略图，宽高各为 1–1024；轮询发布完成结果，按实际路径读取现有 JSON/LDC 文件。 |
| `getState()` | `idle`、`loading`、`empty`、`ready` 或 `failed`；无截图的有效存档为 ready，图片为空。 |
| `getModificationTime()` / `getImage()` / `getError()` | 获取已发布的 Unix 修改时间、`sf.Image` 或 nil，以及错误文字。仅在游戏线程创建纹理。 |
| `cancelPreview()` / `cancel()` | 取消预览或同时取消扫描及预览，不等待后台线程；新请求同样使旧的同类请求失效。 |
| `SavePreviewReader.invalidate(path)` | 文件保存成功后立即使其预览缓存失效。 |

原生服务按路径、修改时间和大小保留最多 8 张缩略图，请求尺寸也参与匹配。窗口关闭时应取消读取器；析构会自动取消。引擎关停先丢弃排队任务并等待线程结束，再释放资源存储。
