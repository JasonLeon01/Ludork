## Emitter

本节 Lua API 签名省略冒号调用的接收者。对应的蓝图实例方法节点保留可见的 `self: Engine.Emitter` 输入，默认使用图 owner。

`Engine.Emitter` 管理 [通用粒子](<../../../../02.编辑器用户指南/10.通用粒子.md>) 资源的 GPU 播放，独立于已有 `ParticleSystem`。Actor 组件和 UI 控件各自持有实例；只构造对象不会把它挂到 Scene。

| Lua API | 契约 |
|---|---|
| `Engine.Emitter.new(resourceKey = "")` | 可选的 `Data/Particles` 相对键，不带扩展名。非空键会加载并开始播放资源。 |
| `load(resourceKey)` | 校验并替换资源，清除此前 GPU 状态后重播。 |
| `setConfiguration(configuration)` | 接收 `Engine.EmitterConfiguration`，校验所有轨道与曲线、烘焙曲线采样，替换配置并重播。仅 Lua/原生可用，不进入蓝图 metadata。 |
| `getConfiguration()` | 返回独立配置快照：C++ 为 `EmitterConfiguration` 值副本，Lua 为符合 `Engine.EmitterConfiguration` 声明的字段表。修改后须显式调用 `setConfiguration` 应用；读取或编辑副本不会改变播放实例。仅 Lua/原生可用。 |
| `play()` | 停止或暂停时从头开始；已经播放时保持运行。 |
| `pause()`、`resume()` | 暂停保留粒子；恢复继续已有时间轴，并重置宿主移动历史。 |
| `restart()` | 清除播放状态并从零开始，重复配置的预热。 |
| `stop(clear = true)` | 默认清空并停止。传 `false` 禁止后续发射/循环；播放仍在推进时，已有粒子继续完成寿命。 |
| `emit(trackName, count)` | 为指定发射轨道排入非负手动数量并启用播放。名称不存在或轨道为 resident 时出错；待发数量受轨道容量限制。 |
| `setSpeed(speed)`、`getSpeed()` | `[0,100]` 内的有限播放倍率，零值冻结时间轴推进。 |
| `setColour(colour)` | 将渲染 RGBA 乘以给定的 `sf.Color`。`EmitterView` 绘制时会提供 UI presentation 颜色。 |
| `getTime()`、`isPlaying()` | 模拟秒数与播放标志；宿主隐藏时 Scene 调度冻结，标志仍可能为 `true`。 |
| `getCapacity()` | 已启用轨道的容量总和，不是存活粒子数。 |
| `setProfiling(enabled)`、`getStatistics()` | 启用异步 GPU 计时，并读取 `Engine.EmitterStatistics` 快照。统计仅 Lua/原生可用；没有结果的可选值为 `nil`，不代表零。 |

配置具有固定声明的字段。原生签名为 `setConfiguration(const EmitterConfiguration&)` 与 `EmitterConfiguration getConfiguration() const`，Lua getter 返回独立字段表。已有发射器的标量配置可以这样修改并应用：

```lua
local configuration = emitter:getConfiguration()
configuration.seed = 42
emitter:setConfiguration(configuration)
```

原生宿主 API 为 `tick(float deltaTime)`、`draw(sf::RenderTarget&, sf::RenderStates = {})`、`setHostTransform(const sf::Transform&)`、`resetHostMotion()`、`shutdown() noexcept` 和静态 `collectGarbage() noexcept`。Delta time 必须有限且非负。`EmitterScheduler` 每个 Scene 帧依次执行 `beginFrame()`、为活动宿主调用 `registerEmitter(shared_ptr<Emitter>, transform)`，再执行一次 `advance(deltaTime)`。登记采用弱引用并去重，重新进入活动集合时重置距离历史。`shutdown()` 停止已知实例，并在有效上下文中回收待释放图形资源。运行时脚本应使用所属组件或控件，避免再对同一实例额外 Tick。

## EmitterConfiguration

`Engine.EmitterConfiguration` 描述可复制的配置记录，不进入蓝图 metadata。C++ 使用结构体，Lua getter 生成符合该声明形状的普通字段表。`setConfiguration` 可以接收已构造的原生值，或按声明属性初始化的 Lua table。

| 属性 | 类型 | 默认值与契约 |
|---|---|---|
| `name` | `string` | `""`；编写时指定的配置名称。 |
| `simulationRate` | `int` | `60`；1–240 的整数。 |
| `seed` | `int` | `1`；0–16,777,215 的整数。 |
| `tracks` | `Engine.EmitterTrack[]` | 空数组；有序轨道，名称唯一。 |

该结构没有 `type` 属性；`"type": "particle"` 是资源 JSON 边界的标记。加载资源时会把曲线引用解析成值，返回的配置不保留未解析的曲线资源键。

## EmitterTrack

`Engine.EmitterTrack` 继承 `Engine.EmitterTrackParameters`，另有 `curves: Engine.EmitterCurves`。C++ 参数基类为 `ludork::runtime::graphics::EmitterTrackParameters`。时序、力、纹理序列与变换沿用[通用粒子](<../../../../02.编辑器用户指南/10.通用粒子.md#资源标识与-schema>)中的名称、单位和限制，表示形式存在以下区别：

| 资源 JSON | 结构化属性 |
|---|---|
| `mode: "emission"` / `"resident"` | `resident: false` / `true` |
| `space: "local"` / `"world"` | `world: false` / `true` |
| `blend: "alpha"` / `"add"` | `additive: false` / `true` |
| `shape: "point"`、`"line"`、`"rectangle"`、`"disk"`、`"ring"` | `shape: 0`、`1`、`2`、`3`、`4` |
| `scaleMode: "hierarchy"`、`"local"`、`"shape"` | `scaleMode: 0`、`1`、`2` |
| `colourMin`、`colourMax`：四个 `[0,255]` RGBA 分量 | 四个 `[0,1]` float，各 JSON 分量除以 255；两者默认均为 `{1,1,1,1}`。 |
| 二维向量和最小/最大值范围 | `sf.Vector2f`；范围的 `x` 为最小值，`y` 为最大值。 |
| `textureRect: [x,y,width,height]` | 由 `position` 与 `size` 组成的 `sf.IntRect`。 |
| `bursts` 数组 | `Engine.EmitterBurst[]` |
| 内联曲线或曲线资源键 | 已解析的 `Engine.EmitterCurves`，包含八个 `Engine.CurveData` 值。 |

结构化默认值为 `resident = world = additive = false`、`shape = scaleMode = 0`、`count = 32`。将 `capacity` 降到 32 以下时，需要显式设置合法的 `count`。JSON 加载器则单独把省略的 `count` 默认为 `min(32, capacity)`。应用完整配置时统一校验：数值范围必须有限且有序，颜色必须归一化，枚举整数必须位于支持范围内。

## EmitterCurves

`Engine.EmitterCurves` 有八个具名属性：`speed`、`sizeX`、`sizeY`、`rotation`、`red`、`green`、`blue`、`alpha`。每个属性均为 `Engine.CurveData`（C++ 为 `Curve::CurveData`）。七个乘数通道默认常数 1；旋转默认常数 0，按角度追加。曲线键时间使用归一化生命周期 `[0,1]`。`setConfiguration` 在重播前校验曲线并烘焙 GPU 查找采样；后端接收采样值，不接收 Core 曲线对象或字典。

## EmitterBurst

`Engine.EmitterBurst` 是固定值记录，字段为 `time: float = 0`、`count: int = 0`、`cycles: int = 1`、`interval: float = 0`。时间与间隔单位为秒。首次时间位于 `[0, duration)`，数量为 0–1,000,000，重复次数为 1–10,000，多次重复时要求间隔为正数。

## EmitterStatistics

`getStatistics()` 返回符合 `Engine.EmitterStatistics` 声明的快照。C++ 按值返回 `ludork::runtime::graphics::EmitterStatistics`，Lua 取得包含声明字段的普通 table。

| 属性 | C++ 类型 / Lua 值 | 含义 |
|---|---|---|
| `capacity` | `int` / integer | 必有；已启用轨道的总容量，不是存活数。 |
| `time` | `double` / number | 必有；播放时间，单位为秒。 |
| `renderer` | `std::optional<std::string>` / string 或 `nil` | 可用时的渲染器标识。 |
| `aliveCount` | `std::optional<std::int64_t>` / integer 或 `nil` | `sampledTime` 时刻的延迟 GPU 存活数。 |
| `sampledTime` | `std::optional<double>` / number 或 `nil` | 存活数采样对应的模拟时间。 |
| `gpuSimulationMs`、`gpuDrawMs` | `std::optional<double>` / number 或 `nil` | 最近可用的异步 GPU 耗时，单位为毫秒。 |
| `simulationSample`、`drawSample` | `std::optional<std::int64_t>` / integer 或 `nil` | 计时采样标识；各通道单独去重，求模拟与绘制总耗时时按相同标识配对。 |

不可用的渲染器、存活数或计时结果保持 `nil`，不会补成空字符串或零。重复轮询可能取得同一次已完成采样。编辑器 JSON 消息边界会省略不可用的可选值，继续沿用已有协议。

## EmitterComponent

蓝图实例方法节点显式提供 `self: Engine.EmitterComponent`，未设置时使用图 owner。

`Engine.EmitterComponent` 继承 `Component`，配置在 `Actor.emitterComp`。它沿用已有 Component 附着协议，只接受 Actor 宿主。`getEmitter()` 延迟返回其 `Engine.Emitter`；替换或清空 `resource` 会释放此前实例。运行时粒子状态不序列化。

替换 `actor.emitterComp` 或赋 `nil` 会立即清除旧组件的播放，即使 Actor 已休眠且外部仍持有旧组件或发射器。正常地图生成会通过 Component 协议调用 `onAttach(actor)`；生成后安装的新组件也需要通过该协议附着，才能参与 Scene 播放。

| 属性 | 默认值 | 含义 |
|---|---|---|
| `resource` | `""` | `PARTICLE` 资源选择器，保存 `Data/Particles` 下不带扩展名的键；空值关闭效果。 |
| `anchor` | `[0.5,0.5]` | Actor 局部边界内的归一化位置。 |
| `offset` | `[0,0]` | 附加局部偏移，单位为逻辑像素。 |
| `rotation` | `0` | 局部旋转，单位为度。 |
| `scale` | `[1,1]` | 局部缩放。 |
| `beforeActor` | `false` | 为 true 时紧接宿主之前绘制，为 false 时紧接宿主之后绘制。 |

地图渲染保留既有 Actor 列表与层顺序。不可见和休眠 Actor 冻结其效果，不修改暂停标志。销毁、区域逐出、地图替换和 Scene 退出会清空并释放效果。组件对 Actor 使用弱引用，只拥有自身播放实例。

## EmitterView

蓝图实例方法节点显式提供 `self: Engine.EmitterView`，未设置时使用图 owner。

`Engine.EmitterView` 继承 `ControlBase`，作为无子节点的可视化 UI 控件放在 Canvas 或 List 容器下。它独立于 Actor 持有一个 `Emitter`，遵循已有 Slot 布局、父级排序和裁剪。

| Lua API | 契约 |
|---|---|
| `Engine.EmitterView.new(particle = "", size = sf.Vector2f.new(100, 100), anchor = sf.Vector2f.new(0.5, 0.5), autoPlay = true)` | 创建粒子控件，`size` 是 UI 逻辑像素布局边界，`anchor` 指定边界内的发射位置。 |
| `getEmitter()` | 返回共享的 `Emitter` 播放对象。 |
| `getParticle()`、`setParticle(key)` | 读取/更改粒子资源键，更改时清空此前效果。 |
| `getSize()`、`setSize(size)` | 读取/更改布局边界。 |
| `getAnchor()`、`setAnchor(anchor)` | 读取/更改归一化发射锚点。 |
| `getAutoPlay()`、`setAutoPlay(value)` | 读取/更改资源加载或切换 Canvas 时使用的自动播放策略；setter 本身不启动或暂停播放。 |
| `dispose()` | 幂等释放播放实例并停止后续参与。 |

其 `world` 粒子坐标域是所属 Canvas 的逻辑空间，与地图 View 分离。UI 合成只应用一次全局缩放。转移到不同 Canvas 时效果重置；隐藏或解除挂载时冻结并保留粒子，恢复控件仍保留用户手动暂停。生成的 UI View 通过正常的强类型引用暴露该节点，取得粒子节点后可调用 `getEmitter():pause()`。
