# Engine：玩法类型

## Actor

直接 metadata 基类：—

`collectTree()`（`metadata = false`）返回根节点在前的广度优先快照，保留子节点顺序和归属关系。出现重复项或环时报错。

`setGraph` 保存一个 `Engine.Graph` 实例，`getGraph` 会返回它。传入 nil 即清除图，此后 `getGraph` 返回 nil。

`visible` 是可编辑的布尔字段，默认值为 `true`，`getVisible()` 返回它的当前值。`isVisibleInHierarchy()` 还会检查全部祖先。Actor 不可见时仍保留实例、生命周期和已配置的 Tick 行为，但不产生绘制，不贡献附属光源与遮光，也不参与碰撞、Overlap 与寻路阻挡。渲染、交互和玩法缓存都会依据当前可见性判断。`setVisible(value, applyToChildren = true)` 默认也会设置子孙自身的标记。传入 `false` 可以保留这些标记，但父级的可见性仍然约束整棵层级。直接赋值只改变 Actor 自身的标记。
