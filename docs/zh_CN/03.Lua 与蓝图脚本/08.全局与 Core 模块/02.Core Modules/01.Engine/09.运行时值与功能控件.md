## Button

直接 metadata 基类：`{ "Engine", "Image" }`、`{ "Engine", "FunctionalBase" }`

声明式 Button 的 `texture` 为空时，使用当前窗口皮肤中的选择 Rect 图片。连接手柄后隐藏这层默认背景，按钮的尺寸、global bounds、点击范围和独立文本控件均不改变。自定义图片继续显示，断开手柄后恢复默认背景。

`gamepadButton` 与 `gamepadLongPress` 用于添加手柄绑定。JSON 保存 `"X"` 等逻辑名称，`""` 表示未绑定，长按默认为 `false`。Lua 使用 `button:setGamepadButton(Engine.JoystickButton.getX())` 与 `button:setGamepadLongPress(true)` 配置，传入 `nil` 可清除按键绑定。

连接手柄后，绑定按键以 16 逻辑像素圆形显示在按钮内部最右侧并垂直居中，不随背景纹理拉伸。它与 [`GamepadHintBar`](<13.交互与声明式 UI 控件.md#gamepadhintbar>) 共用白色按键图案及绿色顺时针长按进度。短按通过 `onConfirm` / `addConfirmCallback` 触发一次；长按在达到一秒时触发一次，松开后才能再次触发。按钮无需取得焦点，但按钮及所属窗口必须可见、可交互。禁用或隐藏任一方、窗口失活或手柄断开都会清空进度；禁用按钮上仍可见的提示显示为灰色。

### 属性

声明式属性包含 `gamepadButton`（默认为空）和 `gamepadLongPress`（默认为 `false`），以及既有的纹理和颜色设置。

## FunctionalBase

直接 metadata 基类：`{ "Engine", "FocusableMixin" }`

### 输入事件数据

输入方法和回调都接收 `Engine.UiInputEventArguments`。指针事件提供 `position: sf.Vector2f`。鼠标按键事件还提供 `button: sf.Mouse.Button`，滚轮事件还提供 `delta: number`。所有字段都是可选的，键盘事件中不出现任何字段。在代码中触发确认或取消时，使用 `Engine.UiInputEventArguments.new({})`。

### 交互资格

`FunctionalBase` 只在自身与每一个 `FunctionalBase` 祖先都处于激活状态，且自身与每一个 `ControlBase` 祖先都可见时接收焦点和输入。`getActive` 与 `getVisible` 仍然只查询控件自身的状态。失去这些资格时，整个子树都会清除指针与触摸捕获，被取消的手势在释放之前一直保持已消耗状态，帧更新与渲染则继续进行。

### 触摸捕获

`setTouchHitBounds` 在控件的局部逻辑坐标中设置一个仅用于触摸的可选命中矩形。矩形必须有有限的坐标和非负的尺寸，传入 `nil` 则恢复默认矩形。`getAbsoluteTouchHitBounds` 返回应用运行时显示缩放和控件层级变换之后的屏幕轴对齐矩形。`FunctionalBase` 与 `ControlBase` 组合时默认采用控件的绝对边界；单独使用时没有控件坐标空间，因此该 getter 返回 `nil`。

实际处于启用状态的功能控件会捕获起点落在其绝对触摸命中范围内的主触点。捕获之后，即使指针移出该范围，控件仍会收到移动事件和最终的释放事件。在范围外释放会清除按下状态，但不触发点击或确认；属于该次捕获的 tap 仍会被消耗，因此不会激活下层控件。多点触摸取消同样会释放捕获。触摸命中范围不影响鼠标命中测试。

### 指针点击

鼠标按下只开始指针捕获，并不触发 `onClick`。只有当按下的按键在指针仍悬停于同一控件上时释放，点击才会触发；若指针已移出控件后再释放，则只清除按下状态而不触发点击。点击参数会带上释放的 `button`，因此只处理左键的回调可据此过滤。触摸 tap 遵循上面的触摸捕获规则，且在存在确认回调时优先触发 `onConfirm`。
