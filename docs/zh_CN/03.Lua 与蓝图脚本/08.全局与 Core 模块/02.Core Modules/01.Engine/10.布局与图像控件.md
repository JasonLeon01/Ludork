## CharacterView

直接 metadata 基类：`{ "Engine", "FunctionalImage" }`

`CharacterView` 在固定的 `size` 边界内渲染角色与敌人的逐帧图集动画。`textureRect` 选择初始帧，`characterScale` 先于帧的居中和不放大的适配应用。`animatable` 为 true 时，正的 `switchInterval` 会推进等宽的横向帧序列；取值为零或负数时暂停动画。

`shader` 为空，或者是完整的 `/Game/Assets/Shaders/...` 逻辑路径。控件使用 Actor uniform `texture`、`time`、`textureSize` 和 `textureRect`，并叠加世界 Actor 的 Hue pass。Shader 失败时显示洋红色。`setFrameRect` 修改复位帧，修改声明式 `texture` 会把复位帧重置为完整纹理。资产属性（`size`、`texture`、可选 `textureRect`、`characterScale`、`animatable`、`switchInterval`、`shader`、`hue`、`colour`）只是预览数据，运行时会以真实快照调用 `setCharacter`。

## ScrollBox

直接 metadata 基类：`{ "Engine", "Canvas" }`

`ScrollBox` 是带裁剪的多子控件布局视口。声明式资产设置 `size` 与 `windowSkin`，`windowSkin` 为空时加载当前系统窗口皮肤。它继承 Canvas 的标准子控件接口，自身方法如下：

| 名称 | 种类 | 参数 | 返回 | 执行语义与 metadata |
|---|---|---|---|---|
| `getSize` | `function` | self: { "Engine", "ScrollBox" } = "self" | return: sf.Vector2f | Pure |
| `resize` | `function` | self: { "Engine", "ScrollBox" } = "self"; size: sf.Vector2f | — | — |
| `setWindowSkin` | `function` | self: { "Engine", "ScrollBox" } = "self"; windowSkin: sf.Image | — | — |
| `getScrollOffset` | `function` | self: { "Engine", "ScrollBox" } = "self" | return: sf.Vector2f | Pure |
| `setScrollOffset` | `function` | self: { "Engine", "ScrollBox" } = "self"; offset: sf.Vector2f | — | — |
| `getMaxScrollOffset` | `function` | self: { "Engine", "ScrollBox" } = "self" | return: sf.Vector2f | Pure |
| `getScrollingEnabled` | `function` | self: { "Engine", "ScrollBox" } = "self" | return: bool | Pure |
| `setScrollingEnabled` | `function` | self: { "Engine", "ScrollBox" } = "self"; enabled: bool | — | — |
| `scrollDescendantIntoView` | `function` | self: { "Engine", "ScrollBox" } = "self"; descendant: { "Engine", "ControlBase" } | — | — |

每个轴都依据可见直接子控件的内容边界判断，只有超出视口时才启用；否则偏移量和最大偏移都为零。写入、resize 与内容缩小之后都会钳制偏移量。绘制和后代命中都会裁剪，`scrollDescendantIntoView` 会拒绝不属于该 ScrollBox 的控件。

普通滚轮输入使用 32 逻辑像素的步长，精确 delta 直接作用于对应的轴。触摸拖动在超过输入阈值后才开始，并且没有惯性。选择列表点击、Config Slider 方向归属和 DropBox popup 输入的语义保持不变。

### 窗口皮肤溢出提示

系统窗口皮肤必须包含 `(144, 16)` 处完整的标准 32 × 32 提示图集；皮肤更小即为错误。ScrollBox 从不采样中央的 `(156, 28, 8, 8)` 和四个角，只按最近邻截取以下区域：

| 方向 | 源矩形 | Viewport 位置 | 显示条件 |
|---|---|---|---|
| 上 | `(156, 16, 8, 12)` | 顶边水平居中 | `offset.y > 0` |
| 下 | `(156, 36, 8, 12)` | 底边水平居中 | `offset.y < maximum.y` |
| 左 | `(144, 28, 12, 8)` | 左边垂直居中 | `offset.x > 0` |
| 右 | `(164, 28, 12, 8)` | 右边垂直居中 | `offset.x < maximum.x` |

提示随全局 UI 的 `Scale` 缩放并使用最近邻采样，绘制在内容之上，也不影响滚动、边界或命中。`setWindowSkin` 会立即重建这些提示。
