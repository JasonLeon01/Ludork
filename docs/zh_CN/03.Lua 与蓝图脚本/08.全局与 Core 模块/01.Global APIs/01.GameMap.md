# Global.GameMap

Metadata 来源：`Scripts/Global/GameMap_meta.lua`

## GameMap

直接 metadata 基类：`{ "GlobalCore", "GameMapBase" }`

`getGameMap` 的输出可以连接到声明为 `GlobalCore.GameMapBase` 的参数，例如 `Camera.setMap`。下列方法使用显式的 GameMap 接收者。`setTerrainTile` 与 `setTerrainTiles` 会修改地形，因此带有执行输入与执行输出；结果引脚用于返回改动情况。

### 组合式大地图门面（facade）

面对大地图清单时，`WorldGameMap` 对外提供大地图坐标。原生稀疏区域索引为已摆放的子地图提供通行性、Dir4、材质与地形。空洞可以通行，查询也不会加载远处的子地图。

`getTilemap()` 返回稀疏的底层存储，而不是扁平化的大地图。`getActorByTag` 不执行 I/O，只在 Active 或曾经激活的驻留 root 中查找。

`getGameplayCellRect()` 返回一份格子矩形副本，不触发区域加载。普通地图的结果是完整边界；大地图的结果是 Active 边界，Active 区域尚未建立时退回可见边界。

`prepareViewportAt` 同步准备并绘制所需的 Camera 邻域，外围摆放仍保持异步。必需子地图、Actor 或发布环节失败时，错误会向外传播。

### Actor 可见性

`getAllActors` 与 tag 查询会保留隐藏实例。位置查询、范围查询、碰撞、Overlap 与寻路都会排除被自身或祖先的 `visible` 标记隐藏的 Actor。绘制同样排除它们附带的光源与遮光。Game 会把这类 Actor 从敌人列表和移动危险中过滤掉。可见性变化后，下一次查询之前就会刷新危险缓存，不必等待 Tick。
