# 类、默认值与生命周期

## 目标

定义公开默认值可发现、可继承的 Ludork 类，同时保持每个实例的可变 runtime 状态互相独立。

## 前置条件

- 已按文档顺序加载所需根模块。
- 每个基类已经完成为 Ludork 类或已注册原生类型。

## 步骤

1. 创建普通定义 table，把公开默认值与方法放在其中。
2. `init` 只处理构造输入与实例状态。
3. 调用必要原生基类初始化，并对可变默认值使用 `copy` 或 `deepcopy`。
4. 按预期 C3 顺序传入基类，并返回 `class(definition, ...)`。
5. 构造多个实例，验证继承与状态隔离。

## 定义类

先创建普通定义 table，把类默认值与方法放在其中，然后使用 `class(definition, ...)` 完成类定义：

```lua
local Engine = require("Engine")

local Actor = Engine.Actor

local Pickup = {}

Pickup.count = 1
Pickup.sound = ""

function Pickup:init(texture, tag)
    Actor.init(self, texture, tag)
    self._collected = false
end

return class(Pickup, Actor)
```

定义必须是不带 metatable 且尚未完成类化的普通 table。后续每个参数必须是已完成的 Ludork 类或已注册原生类型。重复基类会被拒绝。运行时使用 C3 方法解析顺序，因此基类声明顺序具有语义。

## 类默认值与实例状态

可编辑、可继承的值构成 Class Default Object，必须在类完成前写在定义 table 上。这包括 metadata 字段、组件默认值、spawn 使用的 `default*` 值，以及需要被子类或 Blueprint 覆盖的标识。

`init` 用于构造参数与必须归属于单个实例的状态。可变私有 table 和生命周期标志应在此逐实例初始化。实例需要某个可变类默认值的独立副本时，使用 `copy` 或 `deepcopy`。

```lua
local RouteFollower = {}

RouteFollower.speed = 96.0
RouteFollower.defaultRoute = {}

function RouteFollower:init()
    self._route = deepcopy(self.defaultRoute)
    self._routeIndex = 1
end

return class(RouteFollower)
```

不得把公开默认值移入 `init`；子类与 Blueprint 发现必须能从类上读取它。

## 构造与生命周期

调用 `Type.new(...)` 创建实例。已完成的类也可直接调用，但项目代码应与相邻模块保持风格一致。`init` 以新实例作为 `self`。没有 `init` 的类不接受参数，除非它唯一的原生根类提供构造契约。

存在原生基类时，应在 `init` 中显式调用必需的基类初始化。只有所属运行时契约会调用时，才实现 `onCreate`、`onTick`、`onDestroy` 或 `dispose` 等生命周期回调。

## 继承与 super 调用

在方法内使用 `super()` 时，会从定义该方法的类开始解析下一个实现。回调或间接调用使 owner 不明确时，使用 `super(ClassName, self)`。构造和刻意组合仍可使用 `Actor.init(self, ...)` 这样的显式基类调用。

运行时支持多继承。Sample 的 `Player` 将定义与原生 `Character`、脚本 `PlayerInfo` 和 `Battler` 基类组合。基类顺序决定方法解析，不应随意变更。

## Class 工具

| API | 用途 |
|---|---|
| `Class.isInstance(value, targetClass)` | 根据完整 MRO 检查实例。 |
| `Class.isSubclass(value, targetClass)` | 根据完整 MRO 检查类。 |
| `Class.type(value)` | 返回 Ludork 类或原生类型 fallback。 |
| `Class.hasOwnField(value, key)` | 检查字段是否直接存储。 |
| `Class.getMro(value)` | 返回独立 MRO 数组。 |
| `Class.constructNamed(type, arguments)` | 把命名值匹配到 `init` 参数并构造。 |
| `Class.monitor` / `Class.unmonitor` | 监视字段并移除监视。 |

## 验证

- 所有公开默认值在构造前都可从类 table 读取。
- 所有私有可变状态都按实例独立初始化。
- 基类调用按预期 C3 顺序执行。
- `Class.isInstance` 与 `Class.isSubclass` 对所有已声明基类返回正确结果。

## 预期结果

Blueprint 发现与子类可以从完成后的类读取所有公开默认值；实例修改不会泄漏到其他实例，也不会改变 Class Default Object。

## 限制

重复基类、未完成基类和归属不明确的类会被拒绝。Direct Script Mixin 遵循独立生命周期契约，不能声明 `init`。
