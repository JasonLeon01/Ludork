# GlobalCore Gameplay API

原生 Ability System 由 `require("GlobalCore")` 暴露，包括 `AttributeSet`、`AbilitySystemComponent`、ability/result/event 与 Effect/spec 类型。原 `Global/Gameplay/*.lua` 路径不存在。

## AttributeSet

`AttributeSet` 子类声明有序 `ATTRIBUTE_NAMES` 及 `SCHEMA` 中的 `{ type, default }`。构造会复制传入值或默认值，并在 `ID` 中保留 General Data member key。

| 成员 | 签名 | 行为 |
|---|---|---|
| `init` | `(values?)` | 初始化全部已声明 attribute 与 `ID` |
| `getAttributeNames` | `() -> string[]` | 返回有序名称的副本 |
| `getAttributeSchema` | `(name) -> AttributeSchema?` | 返回该 attribute 的 schema |

只有 `int` 和 `float` 字段具有 Base/Current 与 modifier。值必须有限；`int` 要求 Lua integer，`float` 接受任意有限 number。其他字段是直接类型化数据。

## AbilitySystemComponent

`AbilitySystemComponent.new(owner, attributeSet)` 持有 attribute、ability、active Effect 和带计数的 tag。

### Attribute

| 成员 | 签名 | 行为 |
|---|---|---|
| `getOwner` | `() -> any` | 返回玩法 owner |
| `getAttributeSet` | `() -> AttributeSet` | 返回实时 Attribute Set |
| `getNumericAttribute` | `(name) -> number` | 返回 active modifier 计算后的当前值 |
| `getNumericAttributeBase` | `(name) -> number` | 返回未修饰的 base value |
| `setNumericAttributeBase` | `(name, value)` | 修改一个 Base，并重算全部数值 Current |
| `setNumericAttributeBases` | `(values)` | 修改多个 base value，再重算全部数值 attribute |
| `getNumericAttributeBases` | `() -> table<string, number>` | 返回适合持久化的副本 |
| `addAttributeChangeListener` | `(name, callback, params?)` | 相关 Current 或 Base 改变后调用 `callback(oldValue, newValue, change, ...)` |
| `setNumericAttributeConstraint` | `(name, callback?)` | 安装或移除最终 Current constraint，并立即重算 |
| `getRevision` | `() -> integer` | 返回 attribute、ability 或 effect 改变时递增的 revision |

Base setter 会在提交前校验完整候选 Base/Current 状态；未知 attribute、非有限值或 schema 不匹配会失败，不留下部分修改。直接写入数值字段也视为 Base 写入。

Listener 的 `oldValue` 与 `newValue` 始终是 Current value，第三个参数是 `AttributeChange` context：

| 字段 | 类型 | 含义 |
|---|---|---|
| `source` | `"Base" \| "Effect" \| "Constraint"` | 触发本次解析的操作 |
| `force` | `boolean` | Base 写入可在可见 Current 未改变时仍要求通知 |
| `oldBase` | `number \| Class.MissingValue \| nil` | `Base` source 的旧 Base；其他 source 为 nil |
| `newBase` | `number \| nil` | `Base` source 的新 Base；其他 source 为 nil |

Listener `params` 位于 `change` 之后；批量写入只通知最终状态。Base 写入在 Current 未变时仍通知；Effect/Constraint 只在 Current 改变时通知。

Constraint 在 modifier 聚合后收到 `(value, abilitySystem, resolvedValues)`，必须返回符合 schema 的有限值，且不写 Base。传入 nil 移除。解析按 `ATTRIBUTE_NAMES` 顺序，HP 最后；`resolvedValues` 只包含本轮已解析字段。

### Ability 与事件

| 成员 | 签名 | 行为 |
|---|---|---|
| `giveAbility` | `(ability, sourceKey?) -> GameplayAbilitySpec` | 授予 ability 并记录来源 |
| `removeAbilitiesBySource` | `(sourceKey)` | 删除由完全相同来源授予的全部 ability |
| `tryActivateAbility` | `(abilityID, eventData?) -> GameplayAbilityResult` | 激活该 ID 中优先级最高且通过 gate 的 ability |
| `handleGameplayEvent` | `(eventData) -> GameplayAbilityResult[]` | 执行 trigger tag 与事件匹配的全部 ability |

Ability 按 `priority` 降序、再按授予顺序执行。Tag 层级匹配。直接激活在 ID 不存在时返回 `AbilityNotFound`，全部 gate 失败时返回 `AbilityNotActivated`。

### Effect 与 Tag

| 成员 | 签名 | 行为 |
|---|---|---|
| `applyGameplayEffectSpec` | `(spec) -> integer?` | 应用 Instant effect，或返回 Infinite effect handle |
| `validateGameplayEffectSpec` | `(spec) -> bool` | 校验并 preview spec，不改变 Ability System state |
| `removeActiveGameplayEffect` | `(handle, stacks?) -> bool` | 删除若干 stack 或整个 active effect |
| `getActiveEffectStacks` | `(effectID) -> integer` | 汇总该 ID 的全部 active effect stack |
| `getActiveGameplayEffects` | `() -> ActiveGameplayEffect[]` | 按应用顺序返回 active effect |
| `hasMatchingGameplayTag` | `(tag) -> bool` | 检查完全匹配或子级 owned tag |

Instant modifier 按顺序更新 Base、立即应用各自的 `minimum`，且不返回 handle。Infinite modifier 持续重算 Current：Add 求和，Multiply 相乘，最后的 Override 生效，再由最高 `minimum` 钳制 Current。Aggregate stack 线性放大 Add，并对 Multiply 求幂。`None` 对相同非空 ID/source 去重。

Magnitude、minimum、Base 和 Current 必须有限且符合 schema。Instant Effect 不能授予 tag 或 ability。`None` 要求一层；Aggregate Infinite Effect 要求非空 ID。移除 Infinite Effect 也会移除其 tag 和授予的 ability。

Effect 的应用、叠加和移除都会在修改前 preview 完整结果状态。`validateGameplayEffectSpec` 执行同样的 preview 但不修改状态；正式应用会再次校验。Magnitude function 与 constraint 在 preview 期间不得产生外部副作用；commit 后的 listener 错误不回滚。

## GameplayAbility

`GameplayAbility` 定义激活策略与行为。

| 字段 | 类型 | 默认值 |
|---|---|---|
| `id` | `string` | `""` |
| `priority` | `integer` | `0` |
| `abilityTags` | `string[]` | `{}` |
| `requiredTags` | `string[]` | `{}` |
| `blockedTags` | `string[]` | `{}` |
| `triggerTags` | `string[]` | `{}` |

| 成员 | 签名 | 行为 |
|---|---|---|
| `canActivate` | `(abilitySystem, eventData) -> GameplayAbilityResult` | 检查 required 与 blocked owned tag |
| `calculate` | `(abilitySystem, eventData) -> GameplayAbilityResult` | 默认只计算、不提交结果 |
| `activate` | `(abilitySystem, eventData) -> GameplayAbilityResult` | 委托给 `calculate`；子类可覆盖以提交行为 |

被授予的 ability 要求非空 ID；覆盖方法必须返回 `GameplayAbilityResult`。

## GameplayAbilityResult

`GameplayAbilityResult` 包含 `ok`、稳定的字符串或整数 `code`，以及任意 `data`。

| 静态成员 | 签名 | 行为 |
|---|---|---|
| `Success` | `(code?, data?) -> GameplayAbilityResult` | 创建成功结果；默认 code 为 `Success` |
| `Failure` | `(code, data?) -> GameplayAbilityResult` | 创建失败结果，并要求非空字符串或非零整数 code |

## GameplayEventData

`GameplayEventData.new(instigator?, target?, eventTag?, payload?)` 携带一次激活或 event。

| 字段 | 类型 | 默认值 |
|---|---|---|
| `instigator` | `any` | `nil` |
| `target` | `any` | `nil` |
| `eventTag` | `string` | `""` |
| `payload` | `table<string, any>` | `{}` |

处理器可修改 `payload`。`handleGameplayEvent` 要求非空 tag；直接激活不要求。

## GameplayEffect 与 GameplayEffectSpec

`GameplayEffect` 描述 modifier 与授予内容；`GameplayEffectSpec` 绑定 Effect、event data、stack 与来源。

| GameplayEffect 字段 | 类型 | 取值/默认值 |
|---|---|---|
| `id` | `string` | `""` |
| `durationPolicy` | `string` | `Instant` 或 `Infinite`；默认 `Instant` |
| `stackingPolicy` | `string` | `None` 或 `Aggregate`；默认 `None` |
| `modifiers` | `GameplayModifier[]` | `{}` |
| `grantedTags` | `string[]` | `{}`；仅 Infinite |
| `grantedAbilities` | `GameplayAbility[]` | `{}`；仅 Infinite |
| `data` | `table<string, any>` | `{}` |

| GameplayModifier 字段 | 类型 | 取值/默认值 |
|---|---|---|
| `attribute` | `string` | 目标数值 attribute |
| `operation` | `string` | `Add`、`Multiply` 或 `Override` |
| `magnitude` | `number` 或 `function` | 有限 number，或 `(spec, stacks) -> finite number` |
| `minimum` | `number?` | 可选的有限下限 |

`data` 对 Ability System 不透明。`GameplayEffectSpec.new(effect, eventData?, stacks?, sourceKey?)` 要求正整数 stack。Effect ID 与 Lua 相等的 `sourceKey` 用于 Infinite Effect 去重或叠加；匹配定义一致性由调用方保证，Aggregate 保留首个 active spec。

## Runtime spec

`GameplayAbilitySpec` 存储 `ability`、`sourceKey` 和 `grantOrder`。`ActiveGameplayEffect` 存储 `handle`、`spec`、`stacks`、`applicationOrder` 和已授予 ability spec。

## 范围

支持 Instant/Infinite Effect、Add/Multiply/Override、aggregate stacking、层级 tag 和同步 ability。不支持 timer、periodic Effect、prediction、replication、异步 task 或内建持久化。
