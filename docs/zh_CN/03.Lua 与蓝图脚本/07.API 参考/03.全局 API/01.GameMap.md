### 组合式大地图 facade

大地图清单通过 `WorldGameMap` 公开大地图坐标。已摆放子地图的通行、Dir4、材质与地形来自原生稀疏区域索引；空洞可通行，查询不会加载远处子地图。

`getTilemap()` 只是稀疏 backing storage，不是扁平化大地图。`getActorByTag` 不执行 I/O，只查找 Active 或曾激活的驻留 root。

`prepareViewportAt` 同步准备并绘制必需的 Camera 邻域；外围 placement 保持异步。必需子地图、Actor 或发布错误会传播。
