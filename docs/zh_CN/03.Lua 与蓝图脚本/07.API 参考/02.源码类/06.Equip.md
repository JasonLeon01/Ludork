# Source.Equip

Metadata 来源：`Scripts/Source/Equip_meta.lua`

直接 metadata 基类：`{ "Engine", "Actor" }`

编辑器会按 `ID` 显示生成的 `EquipAttributeSet` 预览；`attributes` 只读，不序列化进 Blueprint JSON。

## 属性

| 名称 | 类型 | 默认值 | Metadata |
|---|---|---|---|
| `ID` | `string` | `"FILL_IT_BY_YOURSELF"` | GeneralDataVars = `Equip` |
| `getSE` | `string` | `""` | Sounds path；fallback 为 `Audio.getSE` |

## 运行时 API

| 成员 | 签名 | 行为 |
|---|---|---|
| `init` | `(texture?, rect?, tag?)` | 根据 `ID` 构造生成的 Equip Attribute Set |
| `onCollision` | `(other)` | 通过共享 pickup 流程把 Equip 加入 Player inventory |

`Player:equip` 将 `attributes.attrPlus` 作为 Infinite Effect 应用，并显式运行 General Data `onEquip` 或 `onUnequip` ability。
