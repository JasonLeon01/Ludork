# Source.ConditionalActor

Metadata 来源：`Scripts/Source/ConditionalActor_meta.lua`

直接 metadata 基类：`{ "Engine", "Actor" }`

## 属性

| 名称 | 类型 | 默认值 | Metadata |
|---|---|---|---|
| `conditionVariable` | `string` | `""` | `InstVar` 仅列出 `int`、`float`、`bool` 与 `string` |
| `conditionOperator` | `string` | `"=="` | 下拉选择 `==`、`~=`、`>`、`>=`、`<`、`<=` |
| `conditionValue` | `any` | `0` | `InstVarValue = "conditionVariable"`；运行时接受 number、boolean 或 string |

变量名为空时保留配置的 `visible` 值。否则，当前变量与比较值必须是相同的标量类型。数值支持六种运算符；布尔和字符串只支持相等与不等。变量缺失、运算符无效、类型不匹配或类型不受支持时明确报错，不作隐式转换。

条件持续控制 `setVisible(result, false)`，结果回落为 false 时再次隐藏。子 Actor 保留自己的可见性配置，并受祖先的有效可见性约束。隐藏 Actor 保留实例与订阅，Tick 仍由 `tickable` 和大地图流送控制。

## 生命周期

`onCreate()` 监听 `GameInstance:getVariables()` 并立即判断。订阅使用当前地图路径和非空 `getMapTag()` 组成标识；多个 Actor 可以独立监听同一字段。初始判断失败时先清理订阅，再向上传播错误。

`onDestroy()` 与 `onWorldSleep()` 退订；`onWorldWake(elapsedSeconds)` 重新订阅并读取当前变量判断。Lua 或 Script Mixin 覆盖这些事件时必须调用 `super()`；Blueprint 生命周期图需继续执行父事件。Sample 的空生命周期图自动继承父事件。

`releaseConditionMonitor()` 可重复清理订阅，不改动可见性或持久销毁记录。`ConditionalActor.ReleaseMapMonitors(gameMap)` 清理离开地图的全部条件订阅；`SceneMap` 在替换地图与销毁前调用，并在移除被抑制的大地图 Actor 身份前清理其子树订阅。Scene 被临时覆盖时保留订阅，返回后继续生效。

订阅和条件推导的可见状态不进入存档。变量快照保存当前逻辑值；地图恢复在 `onCreate` 前排除已销毁放置项，因此已拾取物不会重现。

## 继承

Enemy、Item、Equip、DoorBase 与 Teleporter 继承此类。Bottle、Gem 和 Sample 其他直接地图 Actor Blueprint 的父类为 `Source.ConditionalActor.ConditionalActor`。`EnemyDamageText` 保留原父类与提示逻辑。
