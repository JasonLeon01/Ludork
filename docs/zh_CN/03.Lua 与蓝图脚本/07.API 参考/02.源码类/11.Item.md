# Source.Item

Metadata 来源：`Scripts/Source/Item_meta.lua`

直接 metadata 基类：`{ "Engine", "Actor" }`

编辑器会按 `ID` 显示生成的 `ItemAttributeSet` 预览；`attributes` 只读，不序列化进 Blueprint JSON。

## 属性

| 名称 | 类型 | 默认值 | Metadata |
|---|---|---|---|
| `ID` | `string` | `""` | GeneralDataVars = `Item` |
| `count` | `int` | `1` | — |
| `getSE` | `string` | `""` | Sounds path；fallback 为 `Audio.getSE` |

## Runtime API

| 成员 | 签名 | 行为 |
|---|---|---|
| `init` | `(texture?, rect?, tag?)` | 根据 `ID` 构造生成的 Item Attribute Set |
| `onCollision` | `(other)` | 通过共享 pickup 流程把 `count` 个 Item 加入 Player inventory |

Item 数量为正时，Player 授予 `GeneralData.Item.<ID>.onUse`。Enemy drop 会显式激活 `onDrop`。
