# Source.Enemy

Metadata 来源：`Scripts/Source/Enemy_meta.lua`

直接 metadata 基类：`{ "Engine", "Actor" }`、`{ "Source.Battler", "Battler" }`

Meta：`{ GeneralDataVars = { { "ID", "Enemy" } } }`

Blueprint 编辑器会合成 `Source.Configs.GeneralDataTypes.EnemyAttributeSet` 的只读 `attributes` 预览；它不会序列化进 Blueprint JSON。

## 属性

| 名称 | 类型 | 默认值 | Metadata |
|---|---|---|---|
| `ID` | `string` | `"FILL_IT_BY_YOURSELF"` | GeneralDataVars = `Enemy` |
| `childActorComp` | `Source.Components.ChildActorComponent` | 伤害文本子 Actor | component |
| `collisionEnabled` | `bool` | `true` | — |
| `animatable` | `bool` | `true` | — |
| `animateWithoutMoving` | `bool` | `true` | — |
| `afterBattleVarChanges` | `Dict[string, Tuple[string, any]]` | `{}` | 数值游戏变量选择器与固定运算符（operator）选择器 |

运行时类设置 `DefeatShatterEffectEnabled`，默认值为 `true`；`attributes` 是生成的 Enemy Attribute Set。

Enemy 继承 Actor 默认的 `tickable = false`。

## 函数与事件

| 名称 | 种类 | 参数 | 返回 | 执行语义与 metadata |
|---|---|---|---|---|
| `onCollision` | event | `other: Engine.Actor[]` | — | default execution output |
| `onDefeat` | event | — | — | default execution output |

`init(texture?, rect?, tag?)` 构造 Attribute Set、Ability System、Mota ability，以及按 `special` 配置生成的 Effect。碰撞会在提交反击伤害前，预校验战斗与必需结算；失败时会在动画之后应用已准备好的 Game Over Effect。

胜利动画结束后，先执行 Actor Blueprint 的 `onDefeat` hook，再按固定顺序执行销毁、Reborn/drop、奖励与 State。这些值使用预先准备的快照；`afterBattleVarChanges` 会在 hook 之后求值。Enemy General Data 不定义 `onDefeat` 成员图。
