# Source.Enemy

Metadata 来源：`Scripts/Source/Enemy_meta.lua`

直接 metadata 基类：`{ "Engine", "Actor" }`、`{ "Source.Battler", "Battler" }`

Meta：`{ GeneralDataVars = { { "ID", "Enemy" } } }`

Blueprint 编辑器会合成 `Source.Configs.GeneralDataTypes.EnemyAttributeSet` 的只读 `attributes` 预览；它不会序列化进 Blueprint JSON。

## 属性

| 名称 | 类型 | 默认值 | Metadata |
|---|---|---|---|
| `ID` | `string` | `"FILL_IT_BY_YOURSELF"` | GeneralDataVars = `Enemy` |
| `childActorComp` | `Source.Components.ChildActorComponent` | 伤害文本 child | component |
| `tickable` | `bool` | `true` | — |
| `collisionEnabled` | `bool` | `true` | — |
| `animatable` | `bool` | `true` | — |
| `animateWithoutMoving` | `bool` | `true` | — |
| `afterBattleVarChanges` | `Dict[string, Tuple[string, any]]` | `{}` | 数值游戏变量 selector 与固定 operator selector |

Runtime class 设置 `DefeatShatterEffectEnabled` 默认为 `true`；`attributes` 是生成的 Enemy Attribute Set。

## 函数与事件

| 名称 | 种类 | 参数 | 返回 | 执行语义与 metadata |
|---|---|---|---|---|
| `onCollision` | event | `other: Engine.Actor[]` | — | default execution output |
| `onDefeat` | event | — | — | default execution output |

`init(texture?, rect?, tag?)` 构造 Attribute Set、Ability System、Mota ability 和已配置的 special Effect。碰撞会在提交反击伤害前预校验战斗及必需结算；失败时在动画后应用已准备的 Game Over Effect。

胜利动画后先执行 Actor Blueprint `onDefeat` hook，再强制执行销毁、Reborn/drop、奖励和 State。这些值使用预备 snapshot；`afterBattleVarChanges` 在 hook 之后求值。Enemy General Data 不定义 `onDefeat` 成员 graph。
