# Source.Battler

Metadata 来源：`Scripts/Source/Battler_meta.lua`

`Battler` 是 `Enemy` 与 `Player` 的 Lua gameplay 基类；具体类型从 General Data 构造生成的 Attribute Set。

## Runtime 状态

| 名称 | 类型 | 含义 |
|---|---|---|
| `attributes` | `GlobalCore.AttributeSet` | 实时生成 Attribute Set；具体类型收窄为 Enemy 或 Player |
| `_abilitySystemComponent` | `GlobalCore.AbilitySystemComponent` | 私有 attribute、ability、effect 与 tag owner |

## Runtime API

| 成员 | 签名 | 行为 |
|---|---|---|
| `init` | `(attributes)` | 要求 Attribute Set，并创建对应 Ability System Component |
| `getAbilitySystemComponent` | `() -> AbilitySystemComponent` | 返回实时 Ability System |
| `playAttackAnimationAt` | `(scene, targetPosition) -> number` | 在目标播放 `attributes.ANIMATION_KEY` 并返回视觉时长；空 key 返回 `0` |

数值 Base/Current 通过 Ability System 访问，且必须为有限值并符合生成的 `int` 或 `float` schema；其他数据直接从 `attributes` 读取。
