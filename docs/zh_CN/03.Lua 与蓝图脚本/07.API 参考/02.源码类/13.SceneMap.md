### 组合式大地图行为

`getGameMap` 返回 `GameMap` 或兼容的 `WorldGameMap`。`gotoMapAndPos` 接受“清单 + 大地图坐标”或“已摆放子地图 + 局部坐标”，并把清单保存为当前地图。`blockTransition` 跳过遮罩，但不跳过目标就绪检查。

大地图 Actor 记录使用清单身份，地形使用子地图路径与局部格。`recordActorPosition` 更新已移动根 Actor（moved-root）的归属 owner；`recordDestroyedActorTag` 命中驻留项时销毁它，未命中则只作记录、不产生 I/O；`recordDestroyedActor` 仍只负责记录。
