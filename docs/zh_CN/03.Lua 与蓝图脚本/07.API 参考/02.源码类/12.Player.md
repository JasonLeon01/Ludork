# Source.Player

Metadata 来源：`Scripts/Source/Player_meta.lua`

直接 metadata 基类：`{ "Engine", "Character" }`、`{ "Source.Battler", "Battler" }`

Meta：`{ GeneralDataVars = { { "ID", "Player" } } }`

编辑器会显示生成的 `PlayerAttributeSet` 只读预览；它不序列化进 Blueprint JSON。

## 属性

| 名称 | 类型 | 默认值 | Metadata |
|---|---|---|---|
| `ID` | `string` | `"FILL_IT_BY_YOURSELF"` | GeneralDataVars = `Player` |
| `tickable` | `bool` | `true` | — |
| `collisionEnabled` | `bool` | `true` | — |
| `animatable` | `bool` | `true` | — |
| `speed` | `float` | `96` | — |

`attributes` 是生成的 Player Attribute Set；inventory、装备、移动和 Ability System 是 runtime state。

## Lua runtime API

| 成员 | 签名 | 行为 |
|---|---|---|
| `init` | `(texture?, tag?)` | 构造 Attribute Set、Ability System 和空 inventory/equipment state |
| `InitPlayer` | `(playerPath, applyInitialEquipment? = true) -> Player` | 从 Blueprint class path 构造 Player，并可选应用 Class 初始装备 |
| `FromDict` | `(data) -> Player` | 恢复 Base、inventory ability、装备 Effect 和 State Effect，不应用 Class 初始装备，也不执行 member graph |
| `asDict` | `() -> SaveData` | 序列化稳定状态，不保存 runtime Effect handle |
| `activateItem` | `(itemID) -> GameplayAbilityResult` | 激活 `GeneralData.Item.<id>.onUse` |
| `consumeMovementSpecialPath` | `() -> sf.Vector2i[]` | 取出并清空已到达地图格 |
| `getClassPath` / `setClassPath` | `() -> string` / `(path)` | 访问用于重建的 Blueprint path |

`InitPlayer` 应用 Class 初始装备；`FromDict` 重建存档装备而不重放 `onEquip`。Runtime 装备/卸下会先更改 Infinite Effect，再运行对应 graph。移动结束发送 `Event.Movement.Step`。

HP Current 限制为 `0..MAXHP`。永久 MAXHP 和 LEVEL 成长使用 Base delta；Effect 与 Constraint 变化不修改成长 Base。
