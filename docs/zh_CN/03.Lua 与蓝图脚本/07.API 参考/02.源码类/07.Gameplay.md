# Source Gameplay API

`Source.Gameplay` 包含基于 `GlobalCore` 的 Sample 专用 ability 与 Effect。

## GeneralDataGraphAbility

模块：`Source.Gameplay.GeneralDataGraphAbility`

直接基类：`GlobalCore.GameplayAbility`

| 字段 | 类型 |
|---|---|
| `generalType` | `string` |
| `memberID` | `string` |
| `graphEvent` | `string` |

| 成员 | 签名 | 行为 |
|---|---|---|
| `init` | `(generalType, memberID, graphEvent, triggerTags?)` | 创建 ability ID `GeneralData.<type>.<member>.<event>` |
| `calculate` | `(abilitySystem, eventData) -> GameplayAbilityResult` | 返回包含 graph data 的 `ExecutableGraph`，或成功的 `NoGraph` |
| `activate` | `(abilitySystem, eventData) -> GameplayAbilityResult` | 构建并同步执行所选 event；返回 `GraphExecuted` 或 `NoGraph` |

Graph parent 与 `eventData` 参数是同一个 `GameplayEventData`。其 payload 会写入上述三个字段；State graph 还可获得 `activeEffect`。执行使用 `Engine.BPBase.ExecuteGraph`；General Data graph 没有 Actor 派发或继承，不能 latent，错误直接传播。

## Effects

模块：`Source.Gameplay.Effects`

| 函数 | 签名 | 结果 |
|---|---|---|
| `CreateInstantModifierSpec` | `(effectID, attribute, operation, magnitude, eventData?) -> GameplayEffectSpec` | 创建但不应用单个 Instant modifier spec |
| `ApplyInstantModifier` | `(target, effectID, attribute, operation, magnitude, eventData?)` | 应用单个 Instant modifier |
| `CreateEquipmentEffect` | `(equipID, slot, attrPlus) -> GameplayEffect` | 创建 Infinite 装备 effect 与 `Equipment.Slot.<slot>` tag |
| `CreateStateEffect` | `(stateID) -> GameplayEffect` | 创建 Infinite state effect、tag 与授予 ability |
| `CreateStateSpec` | `(stateID, stacks?, eventData?) -> GameplayEffectSpec` | 创建但不应用一个 stack 数为正数的 State spec |
| `ApplyState` | `(target, stateID, stacks?, eventData?) -> integer` | 应用或叠加 State effect，并返回 handle |
| `RemoveState` | `(target, stateID) -> bool` | 删除整个 State effect |
| `ReduceState` | `(target, stateID, stacks?) -> bool` | 在支持时只删除请求的 stack 数 |
| `ClearStates` | `(target)` | 删除 ID 以 `State.` 开头的全部 effect |
| `GetStateStacks` | `(target) -> table<string, integer>` | 返回 State ID 到 stack 数映射 |
| `GetStateIDs` | `(target) -> string[]` | 按稳定顺序返回 active State ID |
| `FindActiveEffectHandle` | `(abilitySystem, effectID) -> integer?` | 返回首个匹配的 active handle |

装备按稳定 attribute 顺序使用 `attrPlus`。Weak 每层应用 `-1 ATK` 和 `-1 DEF`，minimum 为 `0`；Poisoned 授予伤害 ability。State 可授予 `onWalk` 和 `onHookTriggered` graph ability。

## MotaBattleAbility

模块：`Source.Gameplay.MotaBattleAbility`

直接基类：`GlobalCore.GameplayAbility`

Ability ID：`Ability.Combat.MotaBattle`

| 枚举 | 成员 |
|---|---|
| `BattleResult` | `WIN = 1`、`CANNOT_DAMAGE = 2`、`LETHAL_COUNTER_DAMAGE = 3` |
| `CriticalResult` | `VALUE = 1`、`NOT_NEEDED = 2`、`UNKNOWN = 3` |

| 成员 | 签名 | 行为 |
|---|---|---|
| `calculate` | `(abilitySystem, eventData) -> GameplayAbilityResult` | 无 mutation 地生成 `BattleResult` code 与预校验的伤害/Game Over spec |
| `activate` | `(abilitySystem, eventData) -> GameplayAbilityResult` | 计算，并在 `eventData.payload.commit` 为 true 时提交 |
| `CalculateDamagePerRound` | `(attacker, defender) -> damage, details` | 运行攻击、防御、伤害、hit count 与 incoming damage 事件管线 |
| `CommitResult` | `(result)` | 只应用一次已预校验的反击伤害 Effect |
| `CalculateCriticalValue` | `(enemy, player) -> GameplayAbilityResult` | 返回一个 `CriticalResult` code |

Owner 为 enemy，`eventData.target` 为 player。计算校验但不应用反击伤害或 Game Over Spec。`BattleResult` data 包含单回合伤害、反击次数、Vampire 回复、先攻/固定伤害、双方 Battler、预备 Spec 和 `committed`。`CommitResult` 只提交一次合计伤害；Enemy 在动画后处理 Game Over。临界值计算考虑 Vampire 回复和 First 不变的回合阈值，但忽略 FixDmg 表达式。

## SpecialAbilities

模块：`Source.Gameplay.SpecialAbilities`

| 成员 | 签名/值 | 行为 |
|---|---|---|
| `MOVEMENT_HAZARD_TAG` | `"Gameplay.Movement.Hazard"` | 所有移动危险 special 都授予的共享 owned tag |
| `BATTLE_RULES_EVENT` | `"Event.Combat.ResolveBattleRules"` | 收集顺序无关的 Vampire、First 与 FixDmg 战斗字段 |
| `CreateEffect` | `(specialID, magnitude) -> GameplayEffect` | 创建一个 Infinite `Special.<id>` effect、tag 与 ability |
| `CreatePoisonedAbility` | `() -> GameplayAbility` | 创建 State Poisoned incoming-damage ability |
| `GetMagnitude` | `(abilitySystem, specialID) -> any` | 读取 active special effect 保存的 magnitude |

Compete、Hard、Magic、MultiHit 和 Poisoned 使用各自的战斗解析 event。`BATTLE_RULES_EVENT` 汇集 Vampire 回复、First 伤害与 FixDmg；number 直接使用，string 求值前替换玩家/敌人当前 numeric attribute。Domain、Flank 和 Blockade 处理 `Event.Movement.QueryHazard` 并授予 `Gameplay.Movement.Hazard`。其他 ID 授予可查询 passive tag。

## MovementSpecials 与移动危险

模块：`Source.MovementSpecials`

| 函数 | 签名 | 行为 |
|---|---|---|
| `CreatePreviewContext` | `(enemies, player) -> PreviewContext` | 为一次未变化的玩家/敌人快照缓存与位置无关的战斗伤害 |
| `Preview` | `(enemies, player, playerPosition, ignoredEnemies?, previewContext?) -> GameplayAbilityResult` | 解析移动危险伤害与贡献来源 |
| `Commit` | `(player, pathPositions) -> GameplayAbilityResult` | 对每个经过格复用 `Preview`，应用总伤害并执行 Blockade 后退 |
| `NotifyPlayerMovementFinished` | `(player, pathPositions?) -> GameplayAbilityResult` | 提交已完成移动路径，缺省时提交当前格 |

`Preview` 统一负责移动危险几何：派发 `Event.Movement.QueryHazard`，解析 Flank 与 ignored enemy，并返回有序来源和总伤害。Danger grid 按 `Gameplay.Movement.Hazard` 筛选并按需生成；`PreviewContext` 在未变化的快照内缓存与位置无关的伤害，但不跳过逐格事件。被忽略的 Flank 敌人参与几何，不贡献伤害。Preview handler 不得修改 gameplay state。

## 生成的 GeneralDataTypes

模块：`Source.Configs.GeneralDataTypes`

General Data 生成器拥有该模块及 stub。`Types` 和命名字段导出各生成 `<TypeName>AttributeSet`。

`Create(typeName, memberID, memberData) -> AttributeSet` 深拷贝 schema 字段并设置 `ID`。只有 ID 时使用 `Source.Data.CreateGeneralAttributeSet(typeName, memberID)`。
