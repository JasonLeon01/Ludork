# GlobalFunctions Lua API

## 范围

`GlobalFunctions` 通过 `Components`、`Manager`、`NodeGraph` 与 `UI` 分组 table 暴露原生自由函数。本参考以 `Scripts/stub/GlobalFunctions.d.lua` 及 `Core/GlobalFunctions/include/GlobalFunctions` 下的声明为依据。

`Scripts/GlobalFunctions_meta.lua` 当前为空，因此本页函数属于 Lua API，不会生成 Blueprint 节点。分组函数也不会同时出现在模块根。

## 加载

```lua
local Engine = require("Engine")
local GlobalCore = require("GlobalCore")
local GlobalFunctions = require("GlobalFunctions")

local Components = GlobalFunctions.Components
local Manager = GlobalFunctions.Manager
local NodeGraph = GlobalFunctions.NodeGraph
local UI = GlobalFunctions.UI
```

按显示顺序加载三个玩法根。

## 验证

确认生成 stub 只暴露四个分组 table，通过分组路径调用代表性函数，并确认这些名称都没有根级 alias 或 Blueprint 节点。

## 限制

资源加载器遵循项目/runtime 路径约定并返回原生 SFML 对象；可用性与加载失败遵循底层原生 manager 契约。标记为基础设施的 Component 函数可能随组件 runtime 变化，不应替代已记录的玩法 API。
