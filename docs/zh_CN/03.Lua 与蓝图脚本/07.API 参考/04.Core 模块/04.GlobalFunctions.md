# GlobalFunctions Lua API

`GlobalFunctions` 通过 `Components`、`Manager`、`NodeGraph` 与 `UI` 分组 table 暴露原生自由函数。本参考以 `Scripts/stub/GlobalFunctions.d.lua` 及 `Core/GlobalFunctions/include/GlobalFunctions` 下的声明为依据。

`Scripts/GlobalFunctions_meta.lua` 为空，因此本页函数属于 Lua API，不会生成 Blueprint 节点。分组函数只通过其分组 table 公开。

## 加载

```lua
local Engine = require("Engine")
local GlobalCore = require("GlobalCore")
local GlobalFunctions = require("GlobalFunctions")

local Components = GlobalFunctions.Components
local Manager = GlobalFunctions.Manager
local NodeGraph = GlobalFunctions.NodeGraph
local UI = GlobalFunctions.UI
```

按显示顺序加载三个玩法根模块（Engine、GlobalCore、GlobalFunctions）。

## Components

这些组件工具支持类（class）级 metadata、序列化与挂载。以 `_` 开头的名称，以及声明为 `metadata = false` 的函数，都属于运行时基础设施；项目玩法应优先使用公开的类/组件工作流。

`getComponentFieldValue` 与 `setComponentFieldValue` 要求声明的组件实例已经存在；组件缺失或类型错误时直接报错，不会重建。

| 名称 | 参数 | 返回 |
|---|---|---|
| `_cloneComponentValue` | value: any; valueType: any = nil; declaringModule: any = nil | any |
| `_cloneComponentFieldValue` | componentType: any; fieldName: string; value: any | any |
| `isComponentType` | value: any | bool |
| `getComponentTypes` | classValue: any | table |
| `getComponentFieldDefaults` | componentType: any | table |
| `getComponentFieldMap` | classValue: any | table |
| `componentFromData` | componentType: any; data: any | any |
| `componentToData` | value: any | table |
| `_getComponentFieldTarget` | object: any; fieldName: string | any; any; any |
| `getComponentFieldValue` | object: any; fieldName: string; defaultValue: any = nil | any |
| `setComponentFieldValue` | object: any; fieldName: string; value: any | bool |
| `_isBlankValue` | value: any | bool |
| `_mergeComponentDefaults` | object: any | — |
| `normaliseInstanceComponents` | object: any | — |
| `attachInstanceComponents` | object: any | any[] |

## 限制

类别 helper 只接受类别内相对路径并补 `/Game/Assets/...` 前缀，例如 `loadCharacter("actors/Hero.png")` 与 `playSE("cursor.ogg")`。持久化数据和 `getSoundBuffer(filePath)` 则要求完整逻辑路径。加载失败遵循原生 manager 契约；基础设施 Component 函数不是玩法 API。
