## FunctionalBase

直接 metadata 基类: `{ "Engine", "FocusableMixin" }`

### 交互有效状态

`FunctionalBase` 仅在自身及所有 `FunctionalBase` 祖先均为 active，且自身及所有 `ControlBase` 祖先均为 visible 时接收焦点和输入。`getActive` 与 `getVisible` 仍只返回本地状态。失去资格会清除整个子树的指针和触摸捕获，被取消的手势在释放前保持已消费；tick 与渲染继续。

### 触摸捕获

`setTouchHitBounds` 在控件的本地逻辑坐标中设置仅用于触摸的可选命中矩形。矩形坐标必须为有限值且尺寸不得为负；传入 `nil` 恢复默认值。`getAbsoluteTouchHitBounds` 返回经过运行时显示缩放与控件层级变换后的屏幕轴对齐矩形。混入 `ControlBase` 的 `FunctionalBase` 默认使用控件的 absolute bounds；独立的 `FunctionalBase` 没有控件坐标空间，因此 getter 返回 `nil`。

交互有效的功能控件会捕获起点位于其绝对触摸命中范围内的 primary touch。捕获后，即使指针移出该范围，该控件仍会收到移动和最终释放。范围外释放会清除 pressed 状态，但不会调用 click 或 confirm；属于该捕获的 tap 仍会被消费，避免穿透并激活下层控件。多点触摸取消也会释放捕获；触摸命中范围不影响鼠标命中测试。
