## FunctionalBase

直接 metadata 基类: `{ "Engine", "FocusableMixin" }`

### 输入事件数据

输入方法和回调接收 `Engine.UiInputEventArguments`。指针事件包含 `position: sf.Vector2f`，鼠标按键和滚轮事件还分别包含 `button: sf.Mouse.Button` 和 `delta: number`。这些字段均为可选，键盘事件不包含任何字段。在代码中触发确认或取消时，使用 `Engine.UiInputEventArguments.new({})`。

### 交互有效状态

`FunctionalBase` 仅在自身及所有 `FunctionalBase` 祖先均处于激活状态，且自身及所有 `ControlBase` 祖先均可见时接收焦点和输入。`getActive` 与 `getVisible` 只查询控件自身的状态。条件不再满足时，整个子树会释放指针和触摸捕获；被取消的手势在释放前仍由原控件消耗，帧更新与渲染继续执行。

### 触摸捕获

`setTouchHitBounds` 在控件的局部逻辑坐标中设置触摸命中矩形。坐标必须为有限值，尺寸不得为负；传入 `nil` 恢复默认值。`getAbsoluteTouchHitBounds` 返回经过显示缩放和控件层级变换后的屏幕轴对齐矩形。与 `ControlBase` 组合使用时，`FunctionalBase` 默认采用控件的绝对包围盒；独立使用时没有控件坐标空间，因此返回 `nil`。

可交互的功能控件会捕获起点位于其绝对触摸命中范围内的主触点。捕获后，即使指针移出该范围，控件仍会收到移动和释放事件。在范围外释放会清除按下状态，但不会触发点击或确认；此次触摸也不会穿透并激活下层控件。多点触摸取消同样会释放捕获。触摸命中范围不影响鼠标命中测试。
