## CharacterView

直接 metadata 基类: `{ "Engine", "FunctionalImage" }`

`CharacterView` 在固定 `size` 边界内渲染角色和敌人图集动画。`textureRect` 选择初始帧；`characterScale` 在居中且不放大的适配前应用。`animatable` 为 true 时，正数 `switchInterval` 沿水平方向推进等宽帧，非正数则暂停。

`shader` 为空或相对 `Assets/Shaders`。控件使用 Actor uniform（`texture`、`time`、`textureSize`、`textureRect`）和世界 Actor 的 Hue pass；Shader 失败时显示洋红色。`setFrameRect` 修改复位帧，修改声明式 `texture` 会把它重置为完整纹理。资产属性（`size`、`texture`、可选 `textureRect`、`characterScale`、`animatable`、`switchInterval`、`shader`、`hue`、`colour`）只提供预览；运行时以真实快照调用 `setCharacter`。

## ScrollBox

直接 metadata 基类：`{ "Engine", "Canvas" }`

`ScrollBox` 是裁剪多子控件的布局 viewport。声明式资产设置 `size` 与 `windowSkin`；空 `windowSkin` 加载当前系统窗口皮肤。它继承 Canvas 的标准子控件接口，并提供：

| 名称 | 种类 | 参数 | 返回 | 执行语义与 metadata |
|---|---|---|---|---|
| `getSize` | `function` | — | return: sf.Vector2f | Pure |
| `resize` | `function` | size: sf.Vector2f | — | — |
| `setWindowSkin` | `function` | windowSkin: sf.Image | — | — |
| `getScrollOffset` | `function` | — | return: sf.Vector2f | Pure |
| `setScrollOffset` | `function` | offset: sf.Vector2f | — | — |
| `getMaxScrollOffset` | `function` | — | return: sf.Vector2f | Pure |
| `getScrollingEnabled` | `function` | — | return: bool | Pure |
| `setScrollingEnabled` | `function` | enabled: bool | — | — |
| `scrollDescendantIntoView` | `function` | descendant: { "Engine", "ControlBase" } | — | — |

每个轴使用可见直接子控件的内容边界，只有超出 viewport 时才启用，否则偏移和最大偏移为零。写入、resize 和内容缩小都会 clamp 偏移。绘制与后代命中统一裁剪；`scrollDescendantIntoView` 拒绝不属于此 ScrollBox 的控件。

普通滚轮使用 32 逻辑像素步长，精确 delta 直接作用于对应轴。触摸拖动超过阈值后跟手且无惯性。选择列表点击、Config Slider 方向归属和 DropBox popup 输入语义保持不变。

### 窗口皮肤溢出提示

系统窗口皮肤必须完整包含从 `(144, 16)` 开始的标准 32 × 32 提示区；尺寸不足会直接报错。ScrollBox 不采样中央 `(156, 28, 8, 8)` 与四角，只以最近邻截取：

| 方向 | 源矩形 | Viewport 位置 | 显示条件 |
|---|---|---|---|
| 上 | `(156, 16, 8, 12)` | 顶边水平居中 | `offset.y > 0` |
| 下 | `(156, 36, 8, 12)` | 底边水平居中 | `offset.y < maximum.y` |
| 左 | `(144, 28, 12, 8)` | 左边垂直居中 | `offset.x > 0` |
| 右 | `(164, 28, 12, 8)` | 右边垂直居中 | `offset.x < maximum.x` |

提示随全局 UI `Scale` 以最近邻方式缩放，绘制在内容上方，且不影响滚动、边界或命中。`setWindowSkin` 会立即重建提示纹理。
