# Engine：文本与窗口

## Engine.TextConfig

`Engine.TextConfig` 为 `Source.Data` 和声明式 UI 构建经过校验的纯文本与富文本配置。输入的 Lua 表必须兼容 JSON，不接受函数、原生对象或循环引用。编辑器中的用法见[文本配置](<../../../../02.编辑器用户指南/05.General Data 与 Text Config.md#text-config>)。

| 名称 | 参数 | 返回 |
|---|---|---|
| `buildPlain` | data: table; sourceName: string | `Engine.PlainTextConfig` |
| `buildRich` | data: table; sourceName: string | `Engine.RichTextConfig` |

## Engine.TextLayout

`Engine.TextLayout` 在不修改控件的前提下，对 UTF-8 文本进行测量、截断和换行；`maxWidth` 必须是有限正数。

| 名称 | 参数 | 返回 |
|---|---|---|
| `measurePlainText` | control: `Engine.PlainText`; text: string | number |
| `measureRichText` | textConfigKey: string; text: string | number |
| `fitPlainText` | text: string; maxWidth: number; control: `Engine.PlainText` | string |
| `wrapPlainText` | text: string; maxWidth: number; control: `Engine.PlainText` | string |
| `wrapRichText` | text: string; maxWidth: number; textConfigKey: string | string |

`fitPlainText` 在文本能容纳时返回原文，否则按字素边界截断并追加 `.`，确保结果不超出 `maxWidth`；连 `.` 也放不下时返回空字符串。
