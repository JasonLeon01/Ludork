# Engine：玩法类型

## Actor

直接 metadata 基类: —

`collectTree()`（`metadata = false`）按广度优先顺序返回以根节点开头的快照，保留子节点顺序和对象所有权；出现重复 Actor 或环时报错。

`setGraph` 保存 `Engine.Graph` 实例，`getGraph` 返回同一实例。传入 nil 可清除图，此后 `getGraph` 返回 nil。

## LightComponent

直接 metadata 基类: `{ "Engine", "Component" }`

### 属性

| 名称 | 类型 | 默认值 | Metadata |
|---|---|---|---|
| `lightColour` | `sf.Color` | `{ [1] = 255, [2] = 255, [3] = 255, [4] = 255 }` | — |
| `lightRadius` | `float` | `16` | — |
| `lightOffset` | `sf.Vector2f` | `{ [1] = 0, [2] = 0 }` | — |

`lightOffset` 以 Actor 的局部包围盒中心为基准，并随 Actor 的完整变换变化。墙面光源必须使用独立 Actor，并通过偏移将光源放在房间一侧的火焰位置；渲染器不会自动寻找可通行格。

未声明任何 Blueprint 函数或事件。
