# Engine：交互与声明式 UI 控件

## TextBox

直接元数据基类：`Engine.ControlBase`、`Engine.FunctionalBase`。

TextBox 是默认不编辑的单行 UTF-8 输入框，点击、触摸或确认操作开始编辑，单纯获得焦点不会激活。桌面支持闪烁光标、选区、横向滚动、按字素移动和删除、Home/End 及剪贴板快捷键。

Enter 或 `finishEdit` 保留编辑后的值，Escape 或 `cancelEdit` 恢复激活前的值，两者均不提交外层表单。失焦保留已提交文字并丢弃未完成的组合文本；隐藏、禁用、移除或销毁控件会结束编辑。同一时刻只有一个 TextBox 编辑。

iOS、Android 和 HarmonyOS Mobile 使用系统输入弹层，HarmonyOS 2in1 使用桌面编辑。原生完成更新文本，取消恢复弹层打开前的值；应用进入后台会关闭会话，返回前台时不会自动重开。

| --- | --- | --- |
| `new` | size: sf.Vector2f；windowSkin: sf.Image；textConfig: Engine.PlainTextConfig；text: string = "" | TextBox |
| `getString` / `setString` | 无 / text: string | string / 无 |
| `isEditing` / `beginEdit` | 无 | bool |
| `finishEdit` / `cancelEdit` | 无 | 无 |
| `setInputDialogLabels` | title: string；done: string；cancel: string | 无 |
| `setOnTextChanged` | callback: function(text: string) 或 nil | 无 |
| `setOnEditingChanged` | callback: function(editing: bool) 或 nil | 无 |

`setOnTextChanged` 在已提交值改变时触发，包括 `setString` 和取消回滚；输入法组合文本不改变 `getString()`。换行、制表符转换为空格，其他控制字符移除。表单校验由 Controller 负责。

Windows 嵌入运行与独立窗口均支持字符输入和 IME 组合态。嵌入模式由编辑器持有 IME，并按游戏光标定位候选框。桥接连接断开时结束编辑，已提交文本的保留规则与失焦相同。

## DropBox

直接 metadata 基类：`{ "Engine", "ControlBase" }`、`{ "Engine", "FunctionalBase" }`

### 属性

未声明任何可编辑属性。

### 浮层与尺寸

DropBox 存在 Canvas 祖先时，展开的列表会绘制在最外层 Canvas 的浮层中，位于该 Canvas 的普通内容和动画之上。因此列表不受中间各层 Canvas 的裁剪，也不会改变父布局中其他控件的尺寸或位置。

展开列表的可见高度限制在根 Canvas 内容矩形与游戏屏幕的交集内。下方能容纳完整列表时优先向下展开，否则尝试向上展开；两侧都放不下时，选择空间较大的一侧，并允许在列表内滚动。

`getSize()` 始终返回折叠时的布局尺寸。`getLocalBounds()` 在折叠时返回对应矩形，展开时返回该矩形与可见列表的并集；向上展开时，局部 Y 坐标可能为负。继承的绝对包围盒和默认触摸命中范围也会随可见范围变化。

### 列表滚动与选择

普通鼠标滚轮按行平滑滚动，精确滚轮和移动端触摸拖动则直接应用偏移。这些操作只滚动列表，不改变游标或已确认的选择；松开拖动也不会确认选项。方向键移动游标，并按需将其滚动到可见位置。鼠标悬停预览选项，桌面端点击确认选项，移动端点击采用下述两步确认方式。所有索引均对应完整的 `items` 数组。

### 移动端触摸确认

移动端展开的 DropBox 采用两步确认：点击未高亮的选项时，只移动高亮并播放游标音效，不改变 `selectedIndex`，也不触发选择回调。点击当前高亮项才会确认，包括展开时已高亮的选项。取消会丢弃预览，并保留原来的 `selectedIndex`。

### 选择回调

`setOnSelectedIndexChanged(callback)` 仅在 `setSelectedIndex` 实际改变选择时传入新索引并触发回调；确认操作同时改变索引时，它先于确认回调执行。`setOnSelectionConfirmed(callback)` 在已展开且非空的 DropBox 确认选择时传入当前索引并触发回调，即使索引未变。通过代码选择或替换选项、取消选择、确认空列表均不触发确认回调。向任一设置方法传入 `nil` 可清除对应回调。

## TabView

直接 metadata 基类：`{ "Engine", "ControlBase" }`、`{ "Engine", "FunctionalBase" }`

### 选择与导航

TabView 的选项数量固定且不能为零，索引从零开始，超出范围时取最近的有效索引，选中高亮始终显示。中间区域等分给各标签页，左右各留 16 个逻辑像素作为提示区。控件不获取键盘焦点。声明式资产通过必填且非空的 `items: string[]` 确定选项数量，不提供 `tabCount` 属性。

`setItems(items)` 可替换相同数量的标签，不改变当前选择或回调；数量不符时控件保持原样。`setOnSelectedIndexChanged(callback)` 设置选择回调，传入 `nil` 清除。`setSelectedIndex` 实际改变选择时只调用回调，不播放音效；`selectPrevious`、`selectNext`，以及 Q/E、LB/RB、鼠标移动或触摸点击引起的切换，会先播放一次游标音效，再调用回调。选择未变或已到边界时均不播放音效、不调用回调，首尾不循环。

持有焦点的内容调用 `handleNavigationInput()`。TabView 可见且处于激活状态时，该方法会处理并消耗 Q/E/LB/RB 输入；同方向输入只切换一次，相反方向则互相抵消。鼠标移入中间的标签区域时切换选择；该区域的左键点击会被消耗，但不切换选择。右键、中键以及两侧提示区的输入继续传递。触摸操作只在点击时切换，滑动不切换。

### 按键提示

`setKeyHint(leftHint, rightHint)` 接收两个 `Engine.KeyHint` 值，可选字段只有 `Keyboard` 和 `Joystick`：前者为非 `Unknown` 的 `sf.Keyboard.Key`，后者为 `Engine.JoystickButton` 的取值方法返回的按钮值。不含字段的提示对象可清除对应侧的提示；未配置当前设备的字段时隐藏提示。输入无效时，两侧提示均保持原样。

```lua
tabView:setKeyHint(
    Engine.KeyHint.new({ Keyboard = sf.Keyboard.Key.Q, Joystick = Engine.JoystickButton.getLB() }),
    Engine.KeyHint.new({ Keyboard = sf.Keyboard.Key.E, Joystick = Engine.JoystickButton.getRB() })
)
```

仅在对应方向可以切换时显示提示。连接手柄时使用 `Joystick` 提示；未连接手柄时，桌面端、HarmonyOS 2in1 和 HarmonyOS Mobile 平板使用 `Keyboard` 提示，Android、iOS 和 HarmonyOS 手机则隐藏提示。提示不改变按键绑定或输入是否可用。

## Slider

直接 metadata 基类：`{ "Engine", "ControlBase" }`、`{ "Engine", "FunctionalBase" }`

### 触摸交互

Slider 捕获触摸时，立即根据指针 X 坐标在可见范围内的位置设置数值；此后即使指针移出命中范围，也会持续更新并将数值限制在有效区间内，直到释放。`setTouchHitBounds` 只改变触摸命中范围，不改变显示范围或鼠标命中范围。
