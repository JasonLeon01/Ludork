## DropBox

直接 metadata 基类：`{ "Engine", "ControlBase" }`、`{ "Engine", "FunctionalBase" }`

### 属性

未声明可编辑属性。

### Overlay 与尺寸

DropBox 存在 Canvas 祖先时，展开的 popup 会在最外层祖先 Canvas 的 overlay 层绘制，顺序位于该 Canvas 的普通内容与动画之后。因此 popup 不受中间 Canvas 裁剪，也不会改变父布局中其他控件的尺寸或位置。

Popup 的可见高度会限制在根 Canvas 内容矩形与游戏屏幕的交集内。完整列表能向下容纳时优先向下展开，否则在能完整向上容纳时向上展开；两侧都放不下时选择空间较大的一侧，并在内部滚动选项。

`getSize()` 始终返回折叠布局尺寸。折叠时 `getLocalBounds()` 返回同一矩形，展开时返回它与当前可见 popup 的并集；向上展开会使本地 Y 位置可能为负数。继承的绝对 bounds 与默认触摸命中范围随该视觉范围变化。

### Popup 滚动与选择

普通鼠标滚轮平滑移向按行计算的目标，精确滚轮与移动端触摸拖动则直接应用偏移。这些输入只移动 popup viewport，不改变游标或已提交选择，拖动释放也不会确认选项。方向键移动游标，并在需要时滚动到可见位置。鼠标 hover 会预览可见选项，桌面点击会确认选项，移动端点击使用下述两段式确认。所有索引仍对应完整 `items` 数组。

### 移动端触摸确认

移动端展开的 DropBox 对捕获的触摸输入采用两段式确认。点击游标当前高亮项以外的选项时，只移动高亮并播放已配置的游标音效：不改变 `selectedIndex`、不触发任一选择 callback、不应用该选项、不播放选择音效，也不折叠 DropBox。点击当前高亮项才会确认，包括 DropBox 展开时已经高亮的选项。

预览其他选项后取消会保留已提交的 `selectedIndex`，并丢弃预览。

### 选择 callback

`setOnSelectedIndexChanged(callback)` 仅在 `setSelectedIndex` 解析为不同选项时携带新索引触发；确认同时改变索引时，它先于确认回调触发。`setOnSelectionConfirmed(callback)` 在展开且非空的 DropBox 被确认时携带当前索引触发，即使索引未变。程序化选择或替换 items、取消及确认空列表均不触发它；向任一 setter 传入 `nil` 可清除它。

## TabView

直接 metadata 基类：`{ "Engine", "ControlBase" }`、`{ "Engine", "FunctionalBase" }`

### 选择与导航

TabView 的 items 数量固定且不可为零，索引从零开始并会被夹紧，选中高亮持续显示。中间区域等分为 Tab 槽，左右各保留 16 logical px 作为提示区。控件不获取键盘焦点。声明式资产通过必填且非空的 `items: string[]` 属性构造该固定数量；`tabCount` 不是资产属性。

`setItems(items, callback)` 会原子替换同数量标签与 callback；数量不符时两者均不变，传入 `nil` 清除 callback。`setSelectedIndex` 的真实变化只调用 callback，不播放音效；`selectPrevious`、`selectNext` 以及 Q/E、LB/RB、鼠标移动或触摸点击造成的真实切换会播放一次 CursorSE，再调用 callback。未变化与边界选择均无音效、无 callback，首尾不循环。

持有焦点的内容调用 `handleNavigationInput()`。TabView 可见且 active 时它会消费 Q/E/LB/RB；同方向输入只移动一次，相反方向相消。鼠标移动选择中间槽；槽内左键仅被消费，不负责切换，右键、中键和两侧提示区继续透传。触摸移动不切换，点击才切换。

### 按键提示

`setKeyHint(leftHint, rightHint)` 会原子设置两侧视觉提示。只接受精确键名 `Keyboard` 与 `Joystick`，值分别必须是非 Unknown 的 `sf.Keyboard.Key` 与 `Engine.JoystickButton` getter 返回值。空表清除该侧；缺少当前设备项时隐藏。非法输入会报错且两侧均不改变。

```lua
tabView:setKeyHint(
    { Keyboard = sf.Keyboard.Key.Q, Joystick = Engine.JoystickButton.getLB() },
    { Keyboard = sf.Keyboard.Key.E, Joystick = Engine.JoystickButton.getRB() }
)
```

仅在对应方向可移动时显示提示。手柄连接时使用 `Joystick` 提示；否则桌面、HarmonyOS 2in1 与 HarmonyOS Mobile 平板使用 `Keyboard`，Android、iOS 与 HarmonyOS 手机隐藏提示。提示不会重绑或禁用输入。

## Slider

直接 metadata 基类：`{ "Engine", "ControlBase" }`、`{ "Engine", "FunctionalBase" }`

### 触摸交互

Slider 捕获触摸时立即按指针 X 坐标相对于可视范围的位置设置数值；此后即使移出命中范围，也会持续更新并夹紧到区间，直至释放。`setTouchHitBounds` 只改变触摸目标，不改变显示或鼠标命中范围。
