## Slider

直接 metadata 基类：`{ "Engine", "ControlBase" }`、`{ "Engine", "FunctionalBase" }`

### 触摸交互

Primary touch 在 Slider 的有效触摸命中范围内开始时，Slider 会立即开始调整。起点位置会立刻设置数值，因此首次接触的 tap 会同时选中并调整 Slider。开始、tap 与拖拽都只根据指针 X 坐标相对于 Slider 可视 bounds 计算数值。Y 不影响数值，完成捕获后也不会因 Y 越界而取消调整。

一旦完成捕获，即使指针在任一轴移出触摸命中范围，Slider 仍会根据 X 移动持续调整直到释放。超出左边缘或右边缘的位置分别夹到范围最小值或最大值。释放会结束拖拽，不会把该手势转交给其他控件。可通过继承的 `setTouchHitBounds` API 扩大触摸目标，而不改变 Slider 的渲染尺寸或鼠标命中范围。
