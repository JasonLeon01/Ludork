# Engine：地图与材质

## TileLayer

直接 metadata 基类: `{ "Engine", "TileLayerGraphics" }`

Tile 几何按 32×32 格分块，只绘制与 view 相交的块。`deferred = true` 启用运行时的增量构造。

稀疏大地图流送通过 `isCellBuilt(position)`（`metadata = false`）复用 Tile 图形层的 chunk 就绪规则。

## Material

直接 metadata 基类: —

### 属性

| 名称 | 类型 | 默认值 | Metadata |
|---|---|---|---|
| `lightBlock` | `float` | `0` | — |
| `mirror` | `bool` | `false` | — |
| `reflectionStrength` | `float` | `0.5` | — |
| `opacity` | `float` | `1` | — |
| `speedRate` | `float` | `1` | — |
| `ignoreLighting` | `bool` | `false` | — |

`lightBlock` 的合法范围为 `[0, 1]`，表示穿过一个 `CellSize` 厚度时被阻挡的比例。部分遮挡会按实际穿透长度复合；值为 `0.5` 时，穿过半格、一格和两格的透射率分别约为 `0.707`、`0.5` 和 `0.25`。

## TileLayerData
