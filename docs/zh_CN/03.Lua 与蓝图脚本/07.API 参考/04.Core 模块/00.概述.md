# Core 模块 API

这些页面列出从原生绑定声明生成的 Blueprint 可见 metadata。

- [CoreSystem](<01.CoreSystem.md>) 包含当前底层 metadata 表面。
- [Engine](<02.Engine/00.概述.md>) 包含引擎值、玩法基础、输入、服务与 UI 控件。
- [GlobalCore](<03.GlobalCore/00.概述.md>) 包含项目全局玩法类与管理器。
- [GlobalFunctions](<04.GlobalFunctions.md>) 包含 `Components`、`UI`、`NodeGraph` 与 `Manager` 分组函数。

只存在于 LuaLS 的成员是脚本 API，不是 Blueprint 节点。不得编辑生成 metadata；应修改原生声明并重新构建。
