### 显示缩放语义

`getConfiguredScale()` 返回所选配置值（包括 `0`）；`getScale()` 返回当前用于渲染和输入映射的正数比例。`setScale(value)` 会应用并保存，`applyScale(value)` 只应用而不保存，`saveScale(value)` 只保存而不应用。非有限值和负数会规范化为 `1`；`0` 表示不切换显示模式的桌面无边框全屏。独立运行时，正缩放窗口可以自由调整大小，游戏内容保持比例并居中，空白区域为黑色；手动调整只对当前运行有效。Embedded 模式继续使用宿主尺寸，移动端继续使用平台全屏行为，但仍可保存配置偏好。
