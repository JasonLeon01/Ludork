### 显示缩放语义

`getConfiguredScale()` 返回配置的显示偏好（可为 `0`）；`getScale()` 返回应用最大渲染缩放后，当前真正用于渲染和输入的正数有效缩放。配置偏好默认为 `1.0`。`setScale` 应用并保存，`applyScale` 只应用，`saveScale` 只保存；非有限值或负数归一为 `1`。桌面端的 `0` 表示不切换显示模式的无边框全屏。正数值下，桌面独立窗口可调整大小、保持宽高比并以黑边居中，手动调整不持久化。macOS 以 Cocoa 客户区 point 计量显示缩放，不受 Retina backing scale 叠加。

`isDisplayScaleConfigurable()` 对 embedded 显示返回 false，对桌面独立窗口返回 true；移动端只有显式注册显示缩放请求处理器的原生宿主返回 true，普通移动端宿主返回 false。HarmonyOS 平板宿主把正数值映射为 `round(gameSize * scale)` 的自由多窗 Stage 窗口尺寸请求，把 `0` 映射为平台最大化/全屏状态。渲染采用该操作后实际获得的 surface；平台装饰可能使 surface 小于 Stage 窗口，用户手动调整平台窗口不会改变已保存偏好。

`getMaximumWindowedScale(gameSize)` 返回逻辑尺寸 `gameSize` 在可用窗口尺寸内的最大缩放。桌面端使用当前窗口所在显示器的带装饰工作区；没有窗口时查询主显示器。可配置移动端宿主使用该宿主报告的最大窗口尺寸；embedded 与不可配置移动端宿主返回 `nil`。任一逻辑尺寸为零或可用尺寸未知时同样返回 `nil`。

### 最大渲染缩放语义

`getMaximumRenderScale()` 返回已配置上限。正数值会把内部有效缩放限制为 surface 适配缩放与该上限中的较小值，`0` 表示不设上限。默认值为 `2.0`，负数或非有限值归一为 `2`。`setMaximumRenderScale` 会应用并保存上限，在完整帧之间重建 render target 且不改变原生窗口尺寸；`saveMaximumRenderScale` 只保存而不应用。

### 抗锯齿语义

抗锯齿方法读取或保存请求的非负 SFML 上下文等级，初始默认值来自 `sf::ContextSettings`。`setAntiAliasingLevel` 会保存值，但不会重新创建当前图形上下文；它在下次初始化显示时生效，SFML 也可能协商为平台支持的其他等级。

### iOS 图形上下文

iOS 启动要求 OpenGL ES 上下文版本不低于 3.0。
