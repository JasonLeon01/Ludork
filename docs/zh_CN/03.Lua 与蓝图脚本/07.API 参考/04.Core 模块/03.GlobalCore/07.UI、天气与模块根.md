## WeatherType

`GlobalCore.WeatherType` 定义 `NONE = 0`、`RAIN = 1`、`STORM = 2`、`SNOW = 3`，不存在模块根别名。Lua 签名保留枚举类型，Blueprint metadata 使用 `int`。
