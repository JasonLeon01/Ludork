## WorldStreamingState

`WorldRegionState` 暴露 `Unloaded`、`Reading`、`Prepared`、`Active` 和 `Dormant`；`WorldRegionDemand` 暴露 `None`、`Prepared` 和 `Active`。`WorldStreamingState` 使用 1-based index，原生持有 demand/队列、Camera 排序（Active 优先，再按区域中心平方距离，最后用 region index 稳定打破平局）、last-used/缓存账本、淘汰及统计。其方法均为 `metadata = false`；Blueprint 使用带上下文的世界地图节点。

Lua 调用 `updateCameraCenter`/`updateDemand`，消费 `takeReadBatch`/`takePublishItem`，报告读/发布完成或取消，标记激活/停用/淘汰，并读取 `getEvictionList`/`getStats`；文件、builder 和 payload 仍由 Lua 持有。
