| 名称 | 参数 | 返回 | 执行语义与 metadata |

| `ReducePlayerState` | `stateID: string; stacks: int = 1` | — | default execution output；State selector |
| `SendEvent` | `target: Battler; eventTag: string; payload: any = {}` | `results: any` | default execution output |
| `ApplyEffect` | `target: Battler; effect: any; stacks: int = 1; sourceKey: any` | `handle: int` | default execution output |

上下文读取（context accessor）与上下文绑定的变更（context-bound mutation）节点，要求 General Data 图提供 `GameplayEventData` parent；用在普通 Actor 图中会报错。`RemovePlayerState` 与 `ReducePlayerState` 作用于该 context 的 target，State 不存在时仍保留单一执行输出。

动态 attribute pin 使用 `any`，但 Ability System 仍要求是符合所选 schema 类型的有限数值。`SetNumericAttributeBase` 写入 Base；`ApplyAttributeDelta` 应用 Instant Add modifier。

`SendEvent` 同步保留 instigator，并以传入 Battler 为 target。`ApplyEffect` 接受 `GameplayEffect`；Instant Effect 不返回持久 handle，也不能授予 tag 或 ability。
