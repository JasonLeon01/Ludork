# 节点函数

这些模块根据 `Scripts/Source/NodeFunctions` 与同名 metadata 伴生文件提供项目 Blueprint 节点。

| 族 | 用途 |
|---|---|
| Container、Math、String、Utils | 通用数据变换 |
| GameMap、Movement、Scene | 地图与 Scene 操作 |
| Mota、Player、State | Sample 玩法与战斗状态 |
| Save、System | 持久化与项目系统操作 |

请选择与模块名对应的页面。节点签名、有序参数、返回值与执行 metadata 均来自当前 metadata。
