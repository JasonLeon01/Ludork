# 节点函数

`Scripts/Source/NodeFunctions` 与同名 metadata 伴生文件提供的项目 Blueprint 节点。叶子页根据当前纯数据 metadata 生成；只存在于 LuaLS 的成员不是 Blueprint 节点。

| 族 | 用途 |
|---|---|
| Container、Math、String、Utils | 通用数据变换 |
| GameMap、Movement、Scene | 地图与 Scene 操作 |
| Mota、Player、State | Sample 玩法与战斗状态 |
| Save、System | 持久化与项目系统操作 |
