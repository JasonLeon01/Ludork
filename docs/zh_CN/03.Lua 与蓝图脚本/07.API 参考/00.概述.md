# Blueprint API 参考

当前 Sample 中所有非 Mixin `*_meta.lua` 的编辑器可见属性、函数和事件清单，按 NodeFunctions、Source class、Global API 和生成的 Core 模块分组。

叶子页根据当前纯数据 metadata 生成。只存在于 LuaLS stub、未进入 metadata 的成员不是 Blueprint 节点。签名保留参数和输出顺序。执行修饰与 metadata 以紧凑 Lua 形式原样展示。

Metadata 变化后应重新生成或审计页面。不得手改生成的 Core metadata；应修改 C++ `BIND_*` 声明并重新构建。
