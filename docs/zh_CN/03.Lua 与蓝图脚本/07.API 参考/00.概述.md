# Blueprint API 参考

本参考从当前 Sample 中所有非 Mixin 的 `*_meta.lua` 推导，是编辑器可见属性、函数和事件的完整清单，并按 NodeFunctions、Source class、Global API 和生成的 Core 模块分组。

签名保留参数和输出顺序。执行修饰与 metadata 以紧凑 Lua 形式原样展示。只存在于 `Scripts/stub` 的成员是 Lua 脚本 API，不是 Blueprint 节点。

Metadata 变化后应重新生成或审计页面。不得通过修改生成的 Core metadata 改变本参考；应修改 C++ `BIND_*` 声明并重新构建。
