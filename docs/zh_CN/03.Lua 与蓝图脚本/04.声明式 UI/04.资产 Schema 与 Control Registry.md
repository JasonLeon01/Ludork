# UI 资产 Schema 与 Control Registry

## 资产 key 与结构

UI 资产使用 `type = "uiAsset"`，并遵循下面的字段契约。它不保存 schema 版本字段。资产的唯一身份是相对 `Data/UI/Assets` 的路径：大小写精确、使用正斜杠、不带扩展名。`Title.json` 的 key 是 `Title`，`Parts/Shared/WindowBase.json` 的 key 是 `Parts/Shared/WindowBase`。

key 不得是绝对路径，也不得包含反斜杠、空段、`.`、`..`、扩展名，或 `Assets/`、`UI/Assets/` 这样的重复前缀。每个路径段都必须不含点号，生成的 Lua 模块才有无歧义的 require 路径。空格、连字符与 Unicode 名称仍然受支持。资产对象包含 `designSize`、`palette` 与一个 `root` 节点。资产和节点都不含 UUID 字段。

每个节点包含：

| 字段 | 契约 |
|---|---|
| `name` | 资产内的节点身份、生成引用的 key 与原生查找名，在资产内唯一；完整身份为 `(assetKey, name)`。 |
| `controlId` | 系统控件的规范模块根原生类路径，或 `Project:<relative-key>`。 |
| `properties` | 由控件 Schema 拥有的值。 |
| `slot` | 由父级拥有的布局；根节点没有该字段。 |
| `editor` | `previewText` 等仅用于设计的值。 |
| `children` | 有序子节点；z-order 相同时以顺序作为稳定依据。 |

嵌套的项目资产是黑盒：这类节点只声明项目 `controlId`、`name` 与父级 Slot，内部既无覆盖也不含子节点。目标资产必须启用 **Exposed**，直接或间接的嵌套循环都无效。

系统 ID 使用绑定类唯一的运行时路径，例如 `Engine.Canvas` 或 `Engine.FunctionalPlainText`。与绑定类唯一运行时路径不符的系统 ID 属于未知控件。

## 动画 Timeline

资产可以包含 `animations` 数组。每一项都有非空 `name`、必填的 `target`（Global 动画填 `null`，资产内节点动画填节点名）、正数 `duration`、可选且默认为 `[0.5, 0.5]` 的归一化 `pivot`，以及 `tracks` 对象。同一 target 内名称唯一。target 可以指向直接嵌套的资产节点，但绝不能指向该边界内部的节点。

`tracks` 接受 `translation`、`rotation`、`scale` 与 `colour`。每个存在的轨道都是非空的菱形关键帧数组，关键帧形状为 `{ "time": number, "value": ... }`。时间必须有限、严格递增，并落在 `0..duration` 内。向量值使用两个有限数字，scale 不得为负。colour 值是四个 `0..255` 范围内的 RGBA 整数分量，各分量独立插值。缺少的轨道按恒等值处理，只有一个关键帧的轨道保持常量。超出轨道的关键帧范围时，运行时保持首值或末值。插值方式为线性。

translation 是布局之后的本地加法偏移，rotation 是本地角度增量，scale 与已编写或布局得到的缩放相乘，colour 则与子树原有的 RGBA 分量相乘。presentation transform 围绕 target 的本地 bounds 与 pivot 合成，不改写 position、rotation、scale、origin 或 Slot 数据，因此重新布局不会累积动画偏移。渲染、绝对 bounds 与命中测试共用这个合成变换。Canvas 只在自身的合成边界上应用一次子树 colour。

嵌套资产只导出自己的 Global 动画。父资产中针对该嵌套节点、使用同名动画的条目属于实例 override，兄弟实例之间互不影响。父资产的 Global 动画可以与这个 override 并存，并且不会自动播放它。

重命名节点会改写指向它的动画 target。删除节点会删除所有指向被删子树的动画。复制节点会连带复制这些动画，并把 target 重定向到副本。

## Slot 与资源 key

Canvas 父级提供锚点、偏移、对齐、自动尺寸与 z-order；List 父级提供列表排布，不接受 Canvas 的 Slot 字段。子项策略与 Slot 类型由父级的 adapter 声明决定。

Canvas Slot 根据控件的本地 bounds 定位，并计入 bounds 的非零偏移。文本的 `lineAlignment` 决定文本内部的行位置，Slot 的 `alignment` 则将所得 bounds 放置到父级中。因此，右对齐文本可以同时使用右对齐、自动尺寸的 Slot，文本宽度变化时右边缘保持固定。

`Engine.ScrollBox` 是使用 List Slot 的多子控件 Layout，序列化 `size` 与 `windowSkin`。滚动、提示与裁剪都由原生控件负责。

- 文件资源使用大小写精确、以 `/Game/Assets/` 开头、带扩展名并使用正斜杠的逻辑路径。
- `textConfig` 相对于 `Data/TextConfigs`，不带目录前缀，也不带扩展名。
- `opacityCurve` 相对于 `Data/Curves`，不带目录前缀，也不带扩展名，并解析为标量曲线。
- 原生绝对路径、`Assets/...`、类别相对路径、反斜杠、路径穿越与别名前缀都无效。

普通文本控件把字体、字号、样式、间距、对齐、描边、辉光与渐变直接保存在 UI 节点上。共享文本或特殊用途的文本仍可选用 `textConfig`。`textConfig` 非空时，编辑器禁用这些内联样式字段，运行时改用 TextConfig。富文本可以用 TextConfig 定义具名标签样式。

## 实时控件 Registry

`Engine.EmitterView` 是无子节点的 Visual 控件，属性为 `particle`（`Data/Particles` 下不带扩展名的键，默认 `""`）、`size`（默认 `[100,100]`）、`anchor`（默认 `[0.5,0.5]`）和 `autoPlay`（默认 `true`）。它沿用父节点的 Slot、排序与裁剪，GPU 粒子使用所属 Canvas 的逻辑坐标域，代码通过 `getEmitter()` 控制播放。隐藏或未挂载时冻结，dispose 时释放播放，切换 Canvas 时重置坐标域。资源 Schema、时序与缩放见 [通用粒子](<../../02.编辑器用户指南/10.通用粒子.md>)。

`Engine.Button` 接受 `texture`、可选的 `textureRect`、`colour`、`hoverColour`、`pressedColour`、`gamepadButton` 与 `gamepadLongPress`。`gamepadButton` 使用 `"X"` 等逻辑名称，默认为 `""`；`gamepadLongPress` 默认为 `false`。运行时绑定与交互见 [Engine：运行时值与功能控件](<../08.全局与 Core 模块/02.Core Modules/01.Engine/09.运行时值与功能控件.md#button>)。

`Engine.TextBox` 是无子节点的 Input 控件，包含 `size`、`windowSkin`、`text`、标准纯文本属性和编辑器专用的 `previewText`。编辑行为与回调见 [Engine：交互与声明式 UI 控件](<../08.全局与 Core 模块/02.Core Modules/01.Engine/13.交互与声明式 UI 控件.md#textbox>)。

编辑器从当前项目编译出的 `EditorCache/UiPreview.registry.json` 读取原生描述，与 `EditorCache/UiPreview.json` 核对后，再与项目 UI 资产合并。只有 `palette.exposed = true` 的资产会作为项目控件出现。游戏使用编译进原生代码的描述，不读取这份开发期 JSON。

`Engine.TabView` 是不含子节点、也没有自身 Slot 的 Input 控件。它与普通文本共用内联文本样式或可选 `textConfig`，另有 `size`、`windowSkin` 和仅构造期生效且非空的 `items: string[]`。资产通常写入 `#TAB 1...`，让原生预览显示每个 Tab。Controller 必须在首个可见帧之前通过 [Engine：交互与声明式 UI 控件](<../08.全局与 Core 模块/02.Core Modules/01.Engine/13.交互与声明式 UI 控件.md#tabview>) 提供本地化标签并绑定选择行为。`selectedIndex` 与按键提示表只属于运行时，不接受 `tabCount`。

`Engine.CharacterView` 是无子节点的 Visual 控件，包含 `size`、`texture`、可选 `textureRect`、`characterScale`、`animatable`、`switchInterval`、`shader`、`hue` 与 `colour`。`shader` 为空，或是一条完整的 `/Game/Assets/Shaders/...` 逻辑路径。裁剪、动画、Actor 缩放适配、Shader 与 Hue 合成以及固定边界都由该控件负责。它不是输入控件。

编辑器与 Preview Host 会拒绝 adapter fingerprint 和完整 Registry 摘要不匹配的情况。文件资源使用规范逻辑路径，UI 资产身份仍相对 `Data/UI/Assets`。
