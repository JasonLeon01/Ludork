# 事件、公共函数与 Blueprint 流程

Blueprint 把类默认值与可视化图保存在 `Data/Blueprints`；公共函数保存可复用的图。两者都按当前项目的 metadata 目录（catalogue）进行校验。

通过 **游戏 → 新建蓝图** 创建 Blueprint：选择有效父类，添加受支持的事件入口，连接执行与数据 pin，然后校验并保存。当多个图需要相同的操作时，按 F7 打开公共函数。Script Mixin Blueprint 遵循独立的 [Script Mixin](<../03.脚本 Mixin/01.编写工作流.md>) 契约，不会执行其图。

![带有事件图和已连接节点的 Blueprint 编辑器](../../../_images/editor/blueprint-editor.png)

*图通过执行 pin 表达执行顺序，通过类型化数据 pin 传递值。*

![显示可操作诊断的 Blueprint 校验窗口](../../../_images/editor/blueprint-validation.png)

*校验会指出普通保存前必须修正的 class、graph、node、link 或 pin。*

## 目标

构建通过校验的有效事件 graph：执行流明确、数据 pin 类型化、公共函数可复用、默认值有意设计。

## 前置条件

- 具有当前 metadata 的图模式 Blueprint。
- 受支持事件入口与工作流需要的节点 API。
- 任何公共函数与被引用项目数据都要有稳定名称。

## 步骤

1. 添加一个受支持事件入口。
2. 添加节点，先连接执行再连接数据，并设置每个必需的未连接输入。
3. 把重复逻辑移入公共函数（用 F7 打开）。
4. 校验、保存，再保持 Console 可见并运行事件。

## 事件

事件是以 `type = "event"` 声明的入口，提供有序数据 pin 和执行输出。没有显式 split 的事件会获得默认执行输出。

General Data 的成员图是同步的 Ability，不会继承 Blueprint event，也不会隐式接收它。`Source.Gameplay.GeneralDataGraphAbility` 以 `GameplayEventData` 为父级（parent）激活所选 graph；start 为 `null` 时返回 `NoGraph`，不允许 latent node，错误向调用方传播。

## 公共函数

打开 **数据库 → 公共函数**（F7）。公共函数拥有一个可复用的 graph，可以新建、重命名、复制、删除、整理与校验。请通过与之匹配的节点调用它，而不必复制图中的片段。

## 执行语义

- `Pure = true` 移除执行输入输出；存在返回值并不代表 pure。
- `ExecSplit` 把命名执行输出映射到结果值。
- `Latent` 节点挂起 graph，并在之后通过声明状态恢复。
- 对同一 graph 实例与事件 key，只要当前执行还有未完成的 latent 节点，蓝图事件就会丢弃重复触发；该次执行的全部 latent 工作结束后才接受新触发。不同 graph 实例与事件 key 之间保持相互独立。
- `LoopNode` 描述循环体与完成行为。
- 数据 link 连接类型兼容 pin；执行 link 连接流程 pin。

运行时事件查询与执行使用原生 `Engine.Graph` userdata。原始 GraphData 用于定义阶段的事件检查；本地执行上下文保存调用状态，本身不是可执行图。

## 默认值与引用

参数默认值按位置与参数名数组对应。显式 `nil` 返回类型仍是数据输出；空 return table 才表示没有输出。

## 类定义与会话生命周期

VM resolver 在整个 session 内持有已解析类、定义表、实例默认值记录与已编译图模板。所有 ClassDict 实例共享这些状态。不提供按路径失效或热重载；重新加载类需要重启运行会话。

`ClassDict:getData(path)`（Sample 中也通过 `Data.GetClassData(path)` 暴露）先沿用 `get` 的加载路径解析类，再返回 resolver 持有的 JSON 定义表。未知路径报错，没有 JSON 定义的模块类返回 nil。同一 VM 内重复读取返回同一张表；需要独立表时使用 `copy` 或 `deepcopy`。

修改该表会反映在后续定义读取中，但不会更新已生成类、实例默认值记录或已编译模板。新实例与可执行事件查询继续使用已生成结果。

## 调试

从事件起点开始跟随执行 link，再检查数据来源和未连接默认值。移动或重命名节点函数后应校验。

## 限制

Graph 校验检查结构与 metadata 契约，不会证明玩法正确，也不会执行 latent 工作。
